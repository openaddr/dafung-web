壹

方向一 · 府库陈设

牌背与陈设(§6 唯一未做项)

主张:珍宝的收藏感从收纳态开始——立于案的暗底牌背(漆木底 + 金云纹 + 朱印「寶」),悬停翻面见正面;翻面暗示用「右下角金线起翘」这件器物语言承担,不落文字标牌(DESIGN §4.6)。

料表:sanguosha-ui-07(三牌背立于案;网图不入库,以 manifest 登记为据)/ 开源素材官方牌背(暗底 + 云纹 + 中央金印)/ 现行牌背语言 jinnang-card.css 末段(漆木底 + 回纹双环)。

一行设计说明:牌背与「锦囊」背同语而异饰——金归边饰(双环+云纹),朱恒归印(章恒朱砂红线不破,官方「中央金印」参考转译为金饰环抱朱印);云纹原样移植现役 PATTERN_PATHS.cloud 线稿,零新增图案资产;右下起翘角即 hover 翻面的可发现性方案,施工时翻面动画入 reduced-motion 兜层口径,交互语义(长按/hover/选中)归消费方。

贰

方向二 · 材质品阶

金银铜平色内环 → 材质分层

主张:铜银金从「一条平色内环」升级为可读的材质阶层——渐变高光定质感、内环双线定精度、角饰密度定阶差;壹品素铜与拾品满饰金,余光一瞥即分高低。

料表:sanguosha-ui-08(铜/银/金材质分层 + 「同形框,异色=品级」的成体系做法;网图不入库)/ noname-live-10(装备常驻栏的品级辨识诉求)/ 现状平色内环 jinnang-card.css .tone-*。

壹 贰 叁 肆 伍 陆 柒 捌 玖 拾

一行设计说明:编码规则=铜(1-3)单环→双环+角饰初显,银(4-6)冷调双环+角饰渐密,金(7-10)暖金双环+四角括线满饰+对角高光扫+品级大字鎏金渐变(纸底可读档 gold-deep 收底);角饰粗细/透明度随 --lv 线性递增,牌面形制与笺头/宝章/笺脚一律不动。框色 token 化提案:--color-gem-tong: #9a6a3c / --color-gem-yin: #8d9298 进 theme.ts 单源(gen:theme 产出),清 jinnang-card.css 文件头的 CSS 豁免账;官方「编号顶章」做法不取——与品级大字双通道说同一件事,违 §4.6。

叁

方向三 · 名家鉴藏

装裱藏品叙事(§6 之外自由探索)

主张:珍宝不是「游戏卡」,是「被装裱的藏品」——绫边装裱 + 题签 + 鉴藏印 + 跋文,一张牌自带收藏叙事;「宝」章化入鉴藏印体系,朱砂语言不变。

料表:DESIGN.md §3 方向 B 吸收自弃案 A 的「装裱意识」(四角包角、金线双勾入正文)/ 中国书画装裱形制通例(题签 / 距条 / 鉴藏印 / 边跋)。

一行设计说明:题签顶替笺头承牌名(竖排 brush,签首「珍」小字引),「宝」章移位右下压距条成鉴藏印(章恒朱砂不破,位置换了、语义入收藏体系);品级通道收进品级大字 + 画心距条色两处(同 --tone 一色两用,沿现行「一处色双处用」口径);远山线稿与绫边斜纹全程序化(inkwash token + 两组 repeating-gradient),零图片;副印「府库珍藏」为氛围件,小尺寸(牌架明细档)可按拍板减配为单印。件面最密,适合「府库/鉴赏」类慢速展示场景,若嫌噪音可只取「题签+鉴藏印」两件。

将

名将节 · 名将笺

可选 —— 拍板人决定是否纳入施工

主张:牌架陈列位的名将从「一行纸签」升为与珍宝同语言的「名将笺」——朱砂界格线 + 「将」章 + 身价大字,与珍宝品级大字同槽位、同形制;此前拍板「名将不复用画像卡」指对局内卡片(名将已有画像卡),牌架明细行是另一场景,本节不动对局内画像卡。

料表:现状 hand-rack.css .pile-slip.pile-hero(名 + 浮签「破产清算时换 200 分」)/ DESIGN §4.2(名将属性色 attr-hero 本就是朱砂)/ 珍宝品级大字槽位语言 .gem-lv / .gem-pin。

落架形态:珍宝牌面(左)与名将笺(右)同排于手牌架明细行,同为 3:4 竖笺、同为「大字+角标」中堂——身份锚点(身价)与价值锚点(品级)共用一个视觉槽位,架上一眼两读。浮签口径(title「破产清算时换 200 分」)由身价大字承接,不再双通道。

一行设计说明:身价大字用大写「贰佰」取清算锚点的庄重感(数据仍 200,渲染层转写;拍板可改「二百」或「200」),「身价」竖排角标对位珍宝「品」角标;笺脚放称号(雅量高致,与现浮签 title 同源,数据零新增);「将」章朱砂=attr-hero 通道色,与宝章朱砂同族不撞车(形制差:将章可按拍板换金章,沿 #229 令笺「技」金章先例,则需给 attr-hero 之外再开金通道,本稿从简用朱)。技能明细不入牌面——明细行是陈列位不是详情位,点击详情归消费方(同珍宝 title 浮签口径)。
