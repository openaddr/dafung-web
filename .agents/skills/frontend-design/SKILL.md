# 界面设计

先读 [DESIGN.md](../../../docs/design/DESIGN.md) 与 [组件收口](../../../docs/design/组件收口.md)。围绕当前任务安排信息层级、触区与动效，沿用游戏既有水墨语言和字体；配色只从 `core/theme.ts` 维护。交互使用项目的 shadcn/Base UI 组件，状态优先通过视觉变化表达。

以安卓横屏 844×390 为设计基准，保留软键盘、系统返回和无障碍。视觉、手势和原生交互由用户验收 APK；仅用户明确要求页面观察或复现时使用浏览器辅助，见 [开发与测试](../../../docs/how-to/开发与测试.md)。
