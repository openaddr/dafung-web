# 锦囊系统规格(设计定稿,待终审)

来源:#122 + 2026-09-09 拷问会(四轮,全部分歧已收敛)。术语已登记 CONTEXT.md「锦囊与暗牌」节;暗牌的联机协议决策另见 ADR-0016(per-seat 快照投影)。

## 1. 定位与设计红线

- **中频暗牌博弈系统**,对局**基本机制,无开关**(单机/联机默认always on,不做配置文件/起兵屏开关/房主选项)。
- 全游戏**唯一的隐藏信息**:持有暗置,使用与结算公开。
- **红线:拿到即用、无需思考的牌不配当锦囊**——那类效果属于机遇。每张锦囊必须在「用不用/对谁用/这回合用哪张」中至少一问上有真实权衡。

## 2. 频率与获取(五条渠道)

| 渠道 | 规则 | 频率定位 |
|------|------|----------|
| 起手发牌 | 选都完成、进 Playing 前各发 1 张(座位序,dice 驱动) | 保底,开局即感知系统 |
| 锦囊格 | 落格必抽 1 张;sanguo 现有 Chance 格复活 + 再转 1 个普通格(共 2/40 格;格位实现时避开开局热区),zhongyuan(8 格测试图)不动 | 主渠道 |
| 机遇奖励 | 好运目录新增「圯上授书」:effect 新 kind `grantCard`(纯抽一张);`EncounterTag` 枚举增「锦囊」 | 佐料 |
| 声望献计 | 声望首次越过 +30 / +60 / +90 各抽 1(只认向上穿越,浮字「民心所向,贤士献计」+战报);钩子在 `addReputation` 一处 | 主渠道之二,焊住声望循环 |
| 军师来投 | 辅路随机事件池(events.ts)新增低权重条目「军师来投:抽一张锦囊」 | 佐料 |

目标手感:人均每局经手 3~5 张。牌库抽空后一切抽牌**落空**(浮字「锦囊已空」),不报错不回流。

## 3. 牌库与手牌

- **牌库 15 张**:目录 8 种,缓兵之计 ×1(全场唯一,公开信息),其余 ×2。开局按 dice 洗序。
- **手牌上限 3**:满手时抽牌作废(浮字「锦囊已满」)。
- 弃牌堆:使用/作废/破产清空均入弃牌堆,**一局内不回流**。
- 剩余牌数全员可数;牌库/弃牌堆/各座手牌全量进快照(可见性由投影层裁,见 §6)。

## 4. 目录终稿

| id | 标签 | 目标域 | 效果 | 作废/不可用条件 |
|----|------|--------|------|-----------------|
| 连环计 | 谋 | 指定两名其他玩家 | 二人各掷 1d6 拼点:赢家 +300 两(国库),输家向你付 400 两(上限=其现金);平局双方无事 | 对手 <2 不可用 |
| 军情密探 | 谋 | 指定一名玩家 | 窥探:从现在到**你的下回合开始**,其手牌对你可见(卷轴即时展示+窗口期手牌面板可见) | 对手 <1 不可用 |
| 缓兵之计 | 谋+攻 | 指定一名玩家 | 其下回合被跳过(skipTurns +1);牌库全场唯一 | 对手 <1 不可用 |
| 横征暴敛 | 攻 | 全体其他玩家 | 每人向你付 200 两(上限=各自现金,不触发清算) | 对手 <1 不可用 |
| 窃玉偷香 | 攻 | 指定一名玩家 | 随机夺其一张珍宝归你 | 目标无珍宝不可用(选项灰,reason) |
| 火烧连营 | 攻 | 指定一名玩家 | 随机一座其城池降 1 级;全是 0 级则随机失去一座(变无主)——与体力耗竭同款语义 | 目标无城不可用 |
| 免战金牌 | 守 | 自身 | 你下一次应付的租金全免,持续到你的下回合开始(过期作废) | 无(但同类名额仍受限) |
| 求贤令 | 援 | 自身 | 招贤一枚武将(机遇 grantHero 同款,fallbackCash 300) | 无(但同类名额仍受限) |

数值口径:玩家间银两转移一律「上限=付款方现金,不触发清算」(机遇 siphon/levy 既有口径);锦囊不计身价;破产清算时手牌直接弃入弃牌堆、不变卖。

## 5. 使用流程(引擎)

- 新决策相位 **`AwaitingJinnang`**:回合开始、掷骰前进入;`PHASE_CHOICES` 注册选项计算器——每张可用牌一选项(载荷带 cardId/标签/目标集)+「今不用」。
- **零可用自动过**:无手牌或全部牌无效(目标缺失)时选项集 ≤1 → 静默跳过不弹卷轴;只要有一张可选,卷轴必弹且「今不用」永远在场。
- **每回合每类标签限一张**:使用即占用该牌全部标签的本回合名额(缓兵之计〔谋+攻〕占两席)。
- 需要选人的牌进入**目标段**:同一相位内重算选项集为候选座位(连环计两步选人:A 段全员→B 段排除 A)+「作罢」(保留牌,收卷)。
- 用后:牌入弃牌堆,窗口收起,进 Roll。出牌是**公开事件**(浮字+战报「魏 使用了连环计」),结算全员可见;只有持有暗置。
- `GameCommand` 新变体 `useJinnang`(cardId + targets),`submitCommand` 校验相位/持有/标签名额/目标合法——UI 永不裁决(ADR-0013 同则)。

## 6. 暗牌协议(ADR-0016)

引擎快照仍是 god-view(单一事实);可见性由传输层 `clientView` 的 **per-seat 投影**裁剪:他人手牌→数量、私有载荷(抽牌结果/窥探)只发本人、含手牌内容的 choices 只留 decisionOwner。**对局日志不落手牌内容**(只记「抽了一张锦囊」——抽牌 dice 驱动可重放推导,日志本身可安全外发)。单机引擎在本机不设防,UI 只渲染自己的手牌(bot 手牌同样隐藏,军情密探在单机因此同样有用)。

## 7. UI / 演出 / 契约

- 侧栏:己方牌面(牌名/单字标签方章/文案);他人座位「锦囊 ×n」牌背计数——复用 note-head 单字印章视觉,标签方章同款。
- 锦囊卷轴:ScrollShell 挂轴复用,牌选项 = note-card 列表 + 标签方章;目标段列国号方章候选。
- 演出:全部走既有 PresentationEvent——出牌 `sealStamped`(牌名首字方章)+ `textFloat`;拼点 `diceRolled` ×2;转移 `cashDelta`。不新增事件类型。
- testids(入 SCROLL_TESTIDS/TESTIDS 单源):`scroll-jinnang`、`scroll-jinnang-option-*`、`scroll-jinnang-target-*`、`scroll-jinnang-pass`(今不用)、`scroll-jinnang-cancel`(作罢)、他人计数 `jinnang-count-<seat>`。既有 testids 零改动。

## 8. bot / 看门狗 / 托管

- `INPUT_PHASES` 增 `AwaitingJinnang` → driveBots/托管/看门狗自动覆盖,room.ts 无需新机制。
- bot 策略(EV 贪心,先过选项集同口径):横征暴敛=可用即用;连环计=选现金最高的两人相咬,次富者现金 ≥400 才值得;窃玉=目标珍宝最多者;火烧=城最多的领先者;缓兵=仅当目标当前身价领先;密探=自己手牌 ≥2 时用(bot 拿信息无用,基本留给玩家);免战=现金低于场上房租均值时用;求贤=可用即用;Simple 难度 50% 弃权。
- **看门狗接管:永不主动用牌**(一律「今不用」,保守推进);托管按上表(玩家自愿交出)。

## 9. 重放与持久化

- 抽牌/拼点全走 `this.dice` → 命令流重放天然复现;`useJinnang` 是普通 cmd 行。
- 快照新增字段:牌库/弃牌堆/各座手牌(cardId 数组)、`rentImmunity`、窥探状态(viewer/target/到期回合)、声望已领里程碑。`restoreFromSnapshot` 全量还原;房间持久化/重启恢复自动携带(随快照走,room.ts 零改动)。

## 10. e2e 方案

- 无配置开关 → 既有用例兼容靠共享助手:`actIfCan` 学会 `scroll-jinnang`(默认点 `scroll-jinnang-pass`)。
- 专项 spec(固定 seed):起手有牌→卷轴弹出→连环计两步选人→拼点演出→银两转移断言;引擎配置 fail-fast 照 `window.__dafung.getEngine()` 惯例;声望献计/军师来投单测覆盖为主,e2e 只做冒烟。

## 11. 实现切面(改动清单)

- **core**:`types.ts`(JinnangTag/JinnangCardDef/hand 字段/新 TurnPhase/GameCommand)、新 `jinnang.ts`(目录+抽牌+标签名额)、`game.ts`(相位机/命令/抽牌/声望钩子/免战旗/结算)、`choices.ts`(注册表)、`snapshot.ts`(字段+restore+契约测试)、`encounters.ts`(grantCard/圯上授书/锦囊内容标签)、`events.ts`(军师来投)、`bot.ts`(策略表)。
- **scripts**:room.ts 仅 `INPUT_PHASES` 加一行;server.ts/replay-log.ts 零改动(无配置、命令流已覆盖)。
- **app**:HandPanel(己方牌面)/OthersPanel(计数)、DecisionScrollLayer 路由、presentation 提取器、testids 单源、`Tile.tsx`/`EditorScreen.tsx`(Chance 格更名「锦囊格」)、`sanguo.json` 加一格。
- **单测**:目录数据校验(因果/标签/目标域)、相位机与零可用自动过、标签名额、拼点三态、转移上限、投影 redact 函数、看门狗不用牌、重放含手牌对局。

## 12. 明确不做(v1)

反应牌(非自己回合) / 购买渠道 / 弃牌回流 / 移动类锦囊 / 任何配置开关 / 跨局收藏。
