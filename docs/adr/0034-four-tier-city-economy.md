# 四档城制:县城/郡城/奇城/名城 + 补给固定值化

日期:2026-10-28;取代:经济 v2 的「七档价位 + 乘法城另表」口径(#299 一系)。

## 背景与问题

经济 v2 的城池曲线与设计初衷错位:

1. **「乘法城」是被支配档**:普通城曲线(`tradeMult [2,4,6,10]` + 逐档加值)在同级下处处严格压过乘法城(`[2,3,4,5]` + 恒零)——对任何正指导价,乘加公式都更高。乘法城购价 3,000 还比 2,700 档贵,纸面上是全图最差交易。
2. **曲线形状单一**:绝大多数城同属一族「乘数递进 + 逐档加值」,买城决策退化成比价格,没有「选收银曲线」的维度。
3. **补给按地域三档 × 等级放大**,与「选都看位置」的直觉脱节,且逐城可覆盖的配置面养了无谓的 schema 复杂度。

## 决策

同一条公式(指导价 × `tradeMult[Lv]` + `tradeAdd[Lv]`)装下**四档城形**,引擎零特判,全部差异在地图数据:

| 城档 | 购价  | tradeMult | tradeAdd           | 定位                          |
| ---- | ----- | --------- | ------------------ | ----------------------------- |
| 县城 | 1,800 | [1,1,1,1] | [100,200,400,800]  | 纯加法入门档                  |
| 郡城 | 3,000 | [1,1,1,1] | [200,400,800,1600] | 纯加法满配档                  |
| 奇城 | 3,000 | [2,3,5,7] | [0,0,0,0]          | 纯乘法:高等级配高价值珍宝翻盘 |
| 名城 | 4,800 | [2,3,4,5] | [200,400,600,1200] | 乘加全能,购价明显高           |

设计原则(拍板记录):①大多数城是加法城,便宜宝靠大额加值也有收益;②奇城倍率(满级 ×7)**必须高于**名城(×5)——专精的极致;③名城加值(满级 +1200)低于郡城(+1600),全能但不称王;④变卖价改按购价 60/90/120/150% 折算——城可增值,但变卖只挂破产自救且「凑足即止」,不构成套利;⑤都城补给退役「逐城 ×(Lv+1)」公式,改地图顶层 `resupply` 固定值(内置图 1,000 两/次),`resupplyPerLevel` 字段与地域三档整体退役。

逐城分配:环游图 38 城 = 名城 4(长安/洛阳/成都/建业,魏蜀吴都城+汉室西京)/ 奇城 5(街亭/子午谷/华容道/合肥/赤壁,有故事的知名城池)/ 郡城 12 / 县城 17;中原图 8 城 = 1/2/2/3。各档数量盘子由守卫测试锁定,防逐城微调悄悄改盘子。

## 后果

- **满级分域自然涌现**:指导价 <600 加法系/名城占优,>600 奇城一骑绝尘;青囊书(600,牌堆存量最大 5 张)恰是奇城/名城满级的精确分水岭(同售 4,200)。斩杀线:奇城满级 × 玉玺 = 21,000(胜利目标 70%),且访客不可拒绝——苛刻前提下的翻盘神器,有意为之。
- **郡城在名城面前无严格占优价位段**(加值低一截、倍率差一截),立身之道是便宜 1,800 两买得起买得多——接受此定位。
- **补给早期大 buff**:固定 1,000 约为旧中庸城 Lv0-1 的 3 倍,起手经济加速;以机器人对局模拟器对账局均时长/破产率,漂移超 ±20% 才回调,否则认账。
- schema 收紧:地图 JSON 顶层 `resupply` 必配,逐城 `resupplyPerLevel` 删除(`loadMap` 当场校验);`PropertyDef.resupply` 由 loader 注入,城侧查找链形状不变;自定义地图需同步改顶层字段。
