# ADR-0064: 城池防御值系统(火焰伤害吸收实体,等级-城防橡皮筋)

日期:2026-11-13
状态:已接受
来源:#1385(提案)/ #1386(spec 拷问定稿)/ #1387(T1 实施)

## 背景

- 城池受损旧制 = 「直接降级」一步到位:`demolishOnVictim` 随机降目标一座 Lv>0 城 1 级,城防全 0 级时兜底失一座非都城。火烧没有攻防过程,城防没有可感知实体——被烧过一半的城和满血的城在盘面上无从分辨,「指定目标烧城」类机制(#1385 周瑜重做)没有可积累的伤害靶。
- 三国杀契合视角:火攻在原型里是「1 点火焰伤害」的结算实体,映射到大富翁需要有「体」接伤害;拷问 Q5 拍板失城语义由新系统接管,不再走「全 0 级兜底失城」。
- 等级与城防此前混称(「城防等级」=等级俗称,无独立字段);方案把「等级」(经济资产维度)与「防御值」(受损维度)拆成两个量。

## 决策

- **防御值 = 等级附带的受损额度**,满值按等级取表:0 级 5 / 1 级 4 / 2 级 3 / 3 级 2。**等级越低城防越厚的橡皮筋设计**:满级城有最多可拆的账面(也是被火攻优先照顾的目标),光脚 0 级城反而难拆——攻方拆强城快、拆弱城慢,强势方的资产天然是火攻靶心。机制域单源 `src/core/defense.ts`(`DEFENSE_BY_LEVEL`),越界等级响亮抛错(零兜底;内置图 maxLevel 全 =3,表完备)。
- **火焰伤害 = 逐点扣防的结算单点** `applyFireDamage`(全局唯一):防御归 0 时——等级>0 降 1 级并回满新等级满值(剩余点数继续扣新防);0 级非都城失城(回无主,无补偿);0 级都城**打空即停**,此后对一切火焰伤害免疫(溅射同样不受理)——「都城不可失」三处既有同口径(#226)不破。结算果三态 `demolished`/`lost`/`absorbed`(打空≠降级≠失城,归 absorbed),城损时机派发归调用侧按果择一(#457 口径延续),单点只结算不派发。
- **等级一变一律重置满值**(购入/建都/赐城/扩军升级/公道买卖成交/降级/易主转移):升级回满算奖励;降级回满=受损不跨等级记账;易主不继承旧伤。平时不回复——回复机制将来预留,当前零实现。
- **无主城不受火焰伤害**(免疫);但可作火烧连营溅射中心(自身免伤、几何中心成立,拷问 Q17 附加问拍板 b)。
- **外敌乘虚显式两分**:体力耗竭(`exhaustIfDepleted`)保持直接降级、0 级封底、永不失城,**不走防御值**——内乱占领与火烧是两种语义,不硬凑一套(统一原则:语义不同才许形制不同)。
- **距离谓词全局唯一单源**(board.ts):默认「距离 N 格以内」=双向最短(自格=0,相邻格=1);单向判定必须显式写「前方距离 N 格以内」(GLOSSARY「距离」词条命名纪律)。此前全仓无距离函数,单环正向步进是唯一路径语义。
- **零兼容**:持有态 `PropertyHolding` 必填 `defense`;旧落盘记录缺键 undefined 直灌让问题暴露(项目不考虑兼容,同 encounterFlags 直灌口径);防御值入快照(联机/恢复一致),入 goldens stateHash。

## 后果

- goldens 三图 stateHash 全量漂移(新字段入 hash),笔数与 logHash 零行为漂移(457=457 逐位一致);旧快照/旧对局日志不兼容,零兼容口径内不迁移。
- 旧 `demolishOnVictim` 进入退役倒计时:火攻技路(T2)与火烧连营锦囊路(T3)都切到 `applyFireDamage` 后删除,连同「城防全 0 级失非都城」兜底分支。
- 盾排 UI(T5)获得数据源;防御值只显当前值、区分不了等级,等级视觉(建筑形制)并存——格面布局按 DESIGN 844×390 档细排。
- 失城通路现状唯一 = 火烧连营磨 0 级城(防御 5,需 5 发);「谁还能瞄准 0 级城」的能力分配将来预留(拷问 Q10)。
- 防御回复机制将来扩展点在满值表与重置单口旁,当前不实现(拷问 Q14:暂时没有)。
- DoD 口径:规则页回填(03 行军与骰/04 地产经济/08 名将与技能/数值总表)随 T2-T5 各自票内完成,本 ADR 为机制总档。
