# ADR-0064 城池防御值系统

2026-11-13 接受。来源 #1385、#1386 和 #1387。后续尺度与伤害结算见 [ADR-0070](./0070-city-levels-and-defense-scale.md)，攻陷与奖励见 [ADR-0067](./0067-city-conquest-economy.md)。

## 背景

早期的城池受损直接降级，玩家无法从盘面分辨部分受损与满防城池，指定目标的火攻也缺少可以积累的伤害。等级表示资产的成长档位，防御值记录该档位剩余的承伤额度。两项数据分别显示。

## 决策

- 持有态 `PropertyHolding` 记录当前防御值。低等级城满防更高，让高等级城在提供更多收益的同时更易受损。等级、满防表和城损规则见[地产经济](../reference/rules/04-地产经济.md#防御值与城池伤害)。防御值属于权威状态，随快照和状态校验序列化。
- 城池伤害统一由 `defense.ts` 的 `applyCityDamage` 结算，直接受火另由 `applyDirectFireDamage` 处理燃烧。降级、攻陷与满防重置见 ADR-0070。外敌乘虚同样走城池伤害结算，触发条件见[体力与休整](../reference/rules/07-体力与休整.md)。
- 无主城可以作为火烧连营的溅射中心，该城自身没有防御值可扣。
- 默认距离取环上前后步数的较小值，自格为 0。现行范围文案见[术语表](../../GLOSSARY.md#地图)的「距离」。距离计算见 [board.ts](../../packages/core/src/engine/board.ts)。
