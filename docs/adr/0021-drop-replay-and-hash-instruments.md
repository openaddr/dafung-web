# ADR-0021: 删除重放校验与快照哈希仪器

日期:2026-10-04
状态:已接受(2026-10-04 架构拷问会,用户拍板「没啥用,去掉吧」)

## 背景

引擎维护着两台确定性仪器:①命令日志重放校验器(ADR-0014——记人类命令、重算 bot 路径、校验终态);②同种子快照哈希验收(#315 引擎重构的验收门禁:新旧代码同种子各跑一遍比对快照)。二者共同要求「全链确定性」:rngState 随快照序列化、时机按座位序×技能序派发、扩展禁用真随机与时钟。

用户判定两台仪器在实际开发流中从未产生对等价值,而确定性税常驻(每个新机制都要守、扩展作者被束缚、旧日志随规则变更腐坏)。两台仪器中哈希验收不依赖日志形式,但确定性纪律是它们的共同前提——用户选择连根删。

## 决策

1. **删**:命令重放校验器脚本、同种子快照哈希验收工具、扩展 seeded-rng 纪律(扩展可自由使用 Math.random 与时间)。
2. **留**:对局日志写入(纯归档,写入零成本,有据可查);rng 状态序列化(对局恢复/房间持久化需要它,不是仪器的零件);bun test 与 e2e(日常回归,不受影响)。
3. **修订**:ADR-0014 相应条款标记由本 ADR 取代;AGENTS.md 开发陷阱速查与关键文件中重放相关条目清理。

## 后果

- 失去「朋友报 bug→丢日志→重放复现」的调试通路,定位靠描述+截图+现场重跑。
- 未来大重构失去「同种子哈希不变」保险,验收=测试全绿(既有 e2e 与引擎不变量套件承担)。
- 确定性不再是引擎纪律;旧对局日志无法跨版本重放(本就随规则变更失效,零兼容原则下无所谓)。
- 扩展作者获得 FreeKill 级自由:随机、时间随意用。

## 备选

- 保留仪器(重放是验证器、事件录像只是放映机):被否——用户判定验证价值未兑现,不愿再付确定性税。
- 只删重放留哈希:哈希同样依赖确定性纪律,留着即税在,不彻底。
