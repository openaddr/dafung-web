# 掉线处理:默认冻结等重连,房主可解散或 bot 接管

玩家掉线时,其 Seat 默认**冻结**——游戏不自动改由 bot 接管,只有轮到该 Seat 行动时才卡住(别人照常出牌)。掉线者凭入座时拿到的 seatToken 重连,直接夺回原 Seat。

不采用"掉线立即 bot 接管"(多数联机游戏的常见做法):休闲桌游更应保护掉线者——朋友手机闪断不应被 AI 替打一手。但纯冻结会永久卡死,故给 **Host** 两个手动出口:解散房间、或强令 bot 接管该掉线 Seat。若 Host 自己掉线,Host 身份自动移交在场最久的真人 Seat,确保始终有人能操作。

Host 强令 bot 接管后,原玩家持 token 重连仍可夺回(token 是 Seat 归属的唯一凭证,与接管动作无关)。
