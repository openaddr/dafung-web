# ADR-0065: 测试成本优先与浏览器回归退役

日期:2026-11-14
状态:已接受(用户明确确认后实施)

## 背景

项目为朋友圈自用的回合制游戏,正式交付为安卓 APK。规则、序列化、控制器和真实 WebSocket 已有无浏览器覆盖。浏览器套件的选择器、瞬态等待、输入驱动、环境取证和重复收口持续占用开发时间;用户选择亲自承担视觉与设备交互验收。

本决策取代 ADR-0056/0058/0059/0062 中要求保留浏览器地板、脊柱、快慢池、构造器守卫以及全量浏览器放行的条款。旧 ADR 作为历史保留,不能用于恢复这些要求。

## 决策

- 常驻浏览器回归整体退役,不新增、不恢复。开发、PR、集成和发版均不运行浏览器测试;用户要求截图也不授权建设长期测试。
- 浏览器辅助仅在用户明确提出页面观察、截图对比或浏览器复现时执行,服务于本次具体问题。实现页面、修改样式、修复 bug 不自动触发浏览器操作。脚本不固化为回归用例、不接入门槛。能力仅是现有单次工装,没有必须使用的场合。
- 规则、存档、联机和恢复以无浏览器测试为主。happy-dom 接线也属于无浏览器测试,只守关键命令、状态投影与私密信息通路;普通展示、文案、样式与重复数值不补测试。
- 删除浏览器用例不要求逐例迁移或等价替代。已有领域覆盖直接沿用;纯视觉和真实设备交互交人工。确认独有的关键逻辑缺口时才补最小直接回归。
- 默认整局只留固定代表样本和恢复锚点。完整语料、故障注入和重型 CLI 例仅在对应能力改动时定向执行,不因批次收口或发版自动跑完整慢池。
- 表现层只保确定性的队列、清理和锁等逻辑;使用真实等待但以 mock 替代实际渲染的整局演出例退役。
- 迭代只跑受影响测试。最终收口执行一次完整 Bun 默认池、构建与静态检查;有新失败或新代码影响才补验,不为重复生成报告重跑同一批检查。

`check:test-boundaries` 随 lint 检查依赖、测试入口、配置、常驻目录及测试内浏览器导入,防止自动恢复。允许截图/探针工具依赖普通 Playwright,测试不导入真实浏览器。

## 保留的职责

核心规则与拒绝路径保持直接期望;独立双客户端守真实 WS、座位隔离、恢复和反应窗。接线只保购地、目标出牌、应答、技能确认、清算/交涉、恢复退出和私密信息等关键通路,以实际测试文件为准。整局、黄金台账和 bot 基准各守确定性、行为漂移和统计性质,不互相冒充规则正确性证明。

视觉、动画、命中区域、手势、系统返回、键盘、后台恢复和原生保存由用户在 APK 中验收。设备安装启动工具保留为按需工装,不成为每个开发任务的自动步骤;网页截图不替代 APK 真机验收。

命令与触发条件唯一事实源为[开发与测试](../how-to/开发与测试.md)。
