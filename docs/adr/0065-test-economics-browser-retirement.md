# ADR-0065: 测试成本优先与浏览器回归退役

日期:2026-11-14
状态:已接受(用户明确确认后实施)

## 背景

项目为朋友圈自用的回合制游戏,正式交付为安卓 APK。规则、序列化、控制器和真实 WebSocket 已有无浏览器覆盖。浏览器套件的选择器、瞬态等待、输入驱动、环境取证和重复收口持续占用开发时间;用户选择亲自承担视觉与设备交互验收。

## 决策

- 常驻浏览器回归整体退役,不新增、不恢复。开发、PR、集成和发版均不运行浏览器测试;用户要求截图也不授权建设长期测试。
- 浏览器辅助仅在用户明确提出页面观察、截图对比或浏览器复现时执行,服务于本次具体问题。实现页面、修改样式、修复 bug 不自动触发浏览器操作。脚本不固化为回归用例、不接入门槛。能力仅是现有单次工装,没有必须使用的场合。
- 规则、存档、联机和恢复以无浏览器测试为主。happy-dom 接线也属于无浏览器测试,只守关键命令、状态投影与私密信息通路;普通展示、文案、样式与重复数值不补测试。
- 删除浏览器用例不要求逐例迁移或等价替代。已有领域覆盖直接沿用;纯视觉和真实设备交互交人工。确认独有的关键逻辑缺口时才补最小直接回归。
- 默认整局只留固定代表样本和恢复锚点。完整语料、故障注入和重型 CLI 例仅在对应能力改动时定向执行,不因批次收口或发版自动跑完整慢池。
- 表现层只保确定性的队列、清理和锁等逻辑;使用真实等待但以 mock 替代实际渲染的整局演出例退役。
- 迭代只跑受影响测试。最终收口执行一次完整 Bun 默认池、构建与静态检查;有新失败或新代码影响才补验,不为重复生成报告重跑同一批检查。

`check:test-boundaries` 随 lint 检查依赖、测试入口、配置、常驻目录及测试内浏览器导入,防止自动恢复。允许截图/探针工具依赖普通 Playwright,测试不导入真实浏览器。

## 保留的职责

核心规则与拒绝路径保持直接期望。整局、黄金台账和 bot 基准各守确定性、行为漂移和统计性质,不互相冒充规则正确性证明。协议故障与持久化恢复的独有覆盖按对应能力定向运行。

### 真实 WS 与双端隔离

双端对跑使用两个独立 Bun 子进程,各自持有生产 OnlineController、模块缓存、gameStore/netStore 与连接,经真实 WebSocket 连引擎服务器。IPC 只传测试意图和读数,对局协议始终走生产 WS。公开状态做两端引擎与各自 store 的四向对账;私密手牌按座位与本端引擎对账,座位和连接状态取各端真实 store。单端 reset 只证明隔离或清理,不能帮助收敛。

固定种子走到决策门后冻结读数,用真实下行历史屏障确认应答已处理,不靠静置猜稳定。Setup 原座恢复走公共 `reconnect()`;Playing 恢复只经 guest 的公开 `socketFactory/timer/random` 边界捕获真实 WS、冻结退避回调,先证明两端独立断线状态,再放行真实重拨与摘要校准。禁全局假时钟、弃试重跑或另造 socket 语义。既有 `outcomeKind` 豁免仅限 Playing 恢复边界,健康、Setup 与反应窗保持全公开字段等式。

反应窗使用固定宽窗,逐次以有效应答及拒绝重复的真实下行作屏障;分别检查私密询问集与每座恰一次持久化记录,不能让超时代答替代手答。

### 关键接线与业务控时

接线只保购地、目标出牌、应答、技能确认、清算/交涉、恢复退出和私密信息等关键通路,以实际测试文件为准。真 React 组件、控制器和 store 保持真实装配;happy-dom 只断 DOM 结构、testid、类名与状态语义,不判几何、像素或真实演出存在性。

业务等待只在时间边界复用 `test/wiring/controlled-clock.ts`,异步更新纳入 act,多段协议按 React 提交分段推进。先卸载组件、清理控制器和 store、移除宿主,再恢复计时器;保留调度所需的原生宏任务让步,不以排空全部计时器替代生命周期清理。全局可变状态须可显式重置、持久化或实例隔离;污染应在源码边界治理。

### 场景构造与演出阀门

无浏览器测试与明确请求的单次辅助共用 `core/planter.ts` 具名种植件构造前态;能走引擎公共方法就直接调用,字段构造归种植件,不复活 force。种植只服务被测行为的前置,被测操作与结果经真实公共接口验证;缺能力按需补种植件,不预建调试桥。

现有瞬空阀门只把演出吸附档钉成测试常开档,产品默认关闭,不改引擎状态或产品节拍。调试能力沿用 dev 或显式桥键门禁,不能据此恢复浏览器回归。

### 人工验收

视觉、动画、命中区域、手势、系统返回、键盘、后台恢复和原生保存由用户在 APK 中验收,标准为移动横屏 844×390。设备安装启动工具保留为按需工装,不成为每个开发任务的自动步骤;网页截图不替代 APK 真机验收。

命令与触发条件唯一事实源为[开发与测试](../how-to/开发与测试.md)。
