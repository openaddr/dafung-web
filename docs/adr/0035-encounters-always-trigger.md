# 机遇必出:概率触发退役与触发豁免归一

日期:2026-10-29;取代:#120 决策 2「天命格不参与机遇 roll」与规则页 07「必停都城不触发」豁免口径(实现随 #776)。

## 背景与问题

机遇自 #123 起是落格概率事件:每次落格先 roll `triggerRate`(产品默认 40%),未中则本回合机遇位空转;天命格、必停都城截断两处在触发链上硬短路豁免(历史问题陈述:「天命格」一词与其豁免面均已退役——今「天命城」且免掷机遇,见 [ADR-0037](0037-special-city-event-field.md))。三条问题:

1. **决策密度被稀释**:40% 触发下平均 2~3 回合才来一条机遇,而 #188 决策化扩容后抉择型占目录一半(霉运抉择一律「两害相权」)——设计投入最重的部分兑现频率最低。
2. **激励链路模糊**:触发与否、抽哪档、抽哪条三层随机叠乘,「声望高→好运肥」的长线激励被「今天根本没触发」淹没。
3. **框架多例外**:「落格必有事件」的统一图景上挂了两个手工例外(天命格自己已是确定性声望泉、驻跸截断另走特化流;两个例外均已随 ADR-0037/#826 退役),每个新落格场景都要额外回答「这里掷不掷」。

## 决策

**机遇必出**:凡走到落格结算的(主路落格、拦停止步、必停都城截断、天命格),必先出一条机遇——「发生与否」不再掷概率,`triggerRate` 字段全链退役。正典次序不变:机遇先于落格结算,解完再走本格(天命 +20 叠在机遇后;驻跸截断按正常落格走机遇→补给→结束回合)。选都落位与白盒测试 land() 不走行军通路,自然不在触发面。

配套拍板:

- **抽取仍随机**:档位(声望调制)与档内条目(权重)保持概率;「必出」只管发生,不管抽中什么。
- **零豁免**:不保留任何「这里不触发」的特殊格或特殊流;天命城身份由「固定声望泉」单义表述,不再兼任「机遇禁区」(#826 起天命城更进一步:免掷随机机遇,固定事件即固定机遇)。
- **配置面**:`triggerRate` 删除(不留「设 100」僵尸语义),换 `enabled` 布尔开关 + 三档基准;引擎缺省 `enabled:false` 保住测试隔离开关,产品默认 `jiyu.json` `enabled:true`;设置屏删「触发概率 %」输入,留开关与三档滑条。
- **不做同条目去重**:新增可序列化状态换「不连续重复」不值得,先看实机。
- **数值划界**:频率约 ×2.5(0.4 条/回合 → 1 条/回合)放大体力损耗与银两随机流,三档基准/体力损耗/目录扩容一律不动,合入后 dogfood 看耗竭频次与破产率另开数值票。

## 后果

- **骰流契约变化**:触发 roll 撤除后,机遇通路每落格固定消耗 2 次 nextFloat(原未中 1 次、命中 3 次)——同 seed 重放整体漂移,`probeNextEncounter`/`seedDrawing` 等骰流探针按新契约改写;历史对局日志按局头 encounter 配置要素区分口径。
- **事件面**:`encounterMiss` 战报线消失;`encounterTriggered` 每回合必发,演出队列增厚——由既有背压/配速机制(#735,ADR-0034)承接,合入后观察水位。
- **经济水位待观**:体力期望损耗与银两摆动约 ×2.5,经济 v3(#737)调平的收支可能被冲开;数值回调与否走 dogfood 结论,不预先拍。
