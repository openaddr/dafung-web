# AGENTS.md 内容分级:红线与指针,配方下沉

日期:2026-10-28(#724);先例:#522/#523 首次瘦身(2026-10-16,7,971→7,627 字节)。

## 背景与问题

AGENTS.md 十二天从 7,627 字节涨回 14,211 字节(+86%):增长主体是实锤换来的活纪律,但其中配方、命令速查与机制口径和各自声明单源(开发与测试.md、rules/、GLOSSARY、对局日志.md)形成复写。沉积速度恒大于清理速度——每次实锤都往 AGENTS 加一段,瘦一次管几个月。

## 决策

AGENTS.md 只住两类内容,**新增内容入文件前先过此闸**:

1. **红线纪律**——违反即出错的行为约束:架构红线、零兜底原则、版本协作铁律、DoD、验证门禁。
2. **导航指针**——指向声明单源的路由:事实源地图、关键文件、各节指针。

配方、命令速查、机制口径、数值一律下沉其声明单源,AGENTS 不留复写。**守门类陷阱视同红线,可常驻**:已退役勿复活(如 `AwaitingCapitalHalt` 相位)、代码单源指针(如机遇档位归一在 `core/encounters.ts`)、rules 零覆盖的建模坑(如起点=各人自己的都城)——共同点是 rules 天然不会写它们,删了就没有第二处可寻。

## 后果

- 体量闸:AGENTS.md 常态预算 ≤10KB(方向性,逐行裁断优先于凑数),超限即触发瘦身票;本次 14,211 → 10,384 字节(−27%,残余超出为 fmt 表格对齐 padding 与拍板语气词,不再切肉)。
- 行为零变化:任何被下沉内容必须在声明单源可寻址,纪律只搬家不消失;下沉时逐条核对覆盖(`testUnscaled`/分层/freshness/陷阱口径等均有实查)。
- 白名单豁免沿用 #522 判词:rules 锚点、10 页范本、README、GLOSSARY 墓碑。

## 修订:全 docs 通用闸(2026-11-09,#1337 拍板,#1338 落地)

「沉积速度恒大于清理速度」在 AGENTS 之外同样复胖实证:e2e-分类表两日 119KB、dogfood 闭环报告堆积、GLOSSARY 墓碑只增不减。本闸由 AGENTS.md 专用扩为**全 docs 通用**,判据五拍(用户拍板):

1. **一次性过程文档闭环即删**:dogfood 报告/调研/普查类,结论落 spec/PR/代码后过程件退役,git 即归档,不留「存档声明」件。
2. **ADR 可整删**:被后续 ADR 明确取代的、纯票级流水的(记录「某票怎么改的」而非「为什么这样设计」);新立 ADR 过三条件——难逆转+没上下文会困惑+真权衡,缺一不立。
3. **账本覆写当前态**:耗时回顾/死代码台账/覆盖率台账类只留「当前态快照+判据指针」,追加条款一律改覆写,历史靠 git 考古;计数指向代码或 issue 不落数。
4. **拍板流水不入正文**:规则句留、案例史(「#NNN 实锤…」)下沉耗时回顾/ADR/票;指针随所指内容迁移同步(压缩/退役后改指新落点或 git 考古)。
5. **目录天然分类优于文字分类表**:可目录化的分类面(如 e2e specs)以目录承载分类、判词随文件头注,文字账本表退役为指针(执行范式 #1345)。

体量闸改**双档机械制**:`check:agents-budget` 硬闸 14KB 超闸禁合并——净增长须**等量置换**(挤掉等量旧文),冻结+置换为反复胖机制;≤10KB 维持方向性提醒(逐行裁断优先于凑数,原口径不变)。2026-11-09 全量去重后诚实底线 13.8KB:10KB 预算对红线本体的合法增长不可达,取冻结达标而非凑数达标。上文白名单豁免(#522 判词)自本修订**废止**,全 docs 同闸。

## 修订:10KB 达阵语义恢复(#1452,2026-11-14)

2026-11-09「诚实底线 13.8KB」判词推翻:该底线测于验证纪律「十条常驻」分级下;#1442 已将验证纪律改写为指针式(取舍见 ADR-0065),#1452 再将「文档风格规约」整节下沉 docs/how-to/文档规约.md、守门陷阱与括号例证电报化,事实源地图按判五由文字表改目录(表格式列对齐 padding 不可入预算),AGENTS.md 落至 10,022B。**10KB 方向性线恢复「达阵」语义**:超线即触发瘦身票,不再按「提醒」放行;14KB 硬闸与「净增长须等量置换」不变。守门类陷阱常驻判词(上文「决策」节)不变——rules 天然不会写它们,下沉无落点。
