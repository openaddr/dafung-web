# AGENTS.md 内容分级:红线与指针,配方下沉

日期:2026-10-28(#724);先例:#522/#523 首次瘦身(2026-10-16,7,971→7,627 字节)。

## 背景与问题

AGENTS.md 十二天从 7,627 字节涨回 14,211 字节(+86%):增长主体是实锤换来的活纪律,但其中配方、命令速查与机制口径和各自声明单源(开发与测试.md、rules/、GLOSSARY、对局日志.md)形成复写。沉积速度恒大于清理速度——每次实锤都往 AGENTS 加一段,瘦一次管几个月。

## 决策

AGENTS.md 只住两类内容,**新增内容入文件前先过此闸**:

1. **红线纪律**——违反即出错的行为约束:架构红线、零兜底原则、版本协作铁律、DoD、验证门禁。
2. **导航指针**——指向声明单源的路由:事实源地图、关键文件、各节指针。

配方、命令速查、机制口径、数值一律下沉其声明单源,AGENTS 不留复写。**守门类陷阱视同红线,可常驻**:已退役勿复活(如 `AwaitingCapitalHalt` 相位)、代码单源指针(如机遇档位归一在 `core/encounters.ts`)、rules 零覆盖的建模坑(如起点=各人自己的都城)——共同点是 rules 天然不会写它们,删了就没有第二处可寻。

## 后果

- 体量闸:AGENTS.md 常态预算 ≤10KB(方向性,逐行裁断优先于凑数),超限即触发瘦身票;本次 14,211 → 10,384 字节(−27%,残余超出为 fmt 表格对齐 padding 与拍板语气词,不再切肉)。
- 行为零变化:任何被下沉内容必须在声明单源可寻址,纪律只搬家不消失;下沉时逐条核对覆盖(`testUnscaled`/分层/freshness/陷阱口径等均有实查)。
- 白名单豁免沿用 #522 判词:rules 锚点、10 页范本、README、GLOSSARY 墓碑。
