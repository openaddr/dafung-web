# ADR-0023: 删除辅路(分岔捷径)机制

日期:2026-10-11
状态:已接受(2026-10-11 设计拷问会,用户拍板「完全移除,一刀切」)

## 背景

棋盘模型 = 不规则主环 + 至多一条分岔辅路。辅路从主路岔出又汇入(现存三图均为许昌→襄阳同款 5 格:探宝×3 + 随机事件×1 + 中伏×1),入辅路=本回合停摆,下回合掷骰逐格推进,溢出汇入主路。设计意图是「高风险高回报的探宝捷径线」。

机制成本横跨全栈:引擎(入口抉择相位 AwaitingBranch、辅路推进/溢出汇入、BranchEntered/BranchExited 时机、onBranch/branchWaypoints 快照字段)、编辑器与渲染(碑亭/虚线/格图标)、抉择卷轴(驿道岔口)、bot 估值、CLI 子命令、单测与 e2e、规则文档;另有 `skipTurns`(中伏产物)被耗竭善后与缓兵之计借道共用。收益端从未兑现:四张地图三条辅路全是同一款 5 格拷贝,地图作者不复用;机遇系统已按「辅路即将整体移除」做了规避(movement-flow 内早有此注释)。

用户判定:复杂度账单与地图设计负担不成比例,整条机制没有存在必要。

## 决策

1. **一刀切全删,不留配置开关**:引擎(相位/命令/推进/溢出/时机/快照字段)、地图 JSON `branch` 字段与三张图的辅路数据、生成脚本的辅路段与断言、SVG 渲染、抉择卷轴、bot 估值、CLI `main|branch` 子命令、相关单测与 e2e。存量存档/对局日志直接作废(零兼容原则)。
2. **`CHANCE_EVENTS` 事件池连「军师来投」全删**:辅路 event 格是该池唯一生产消费方(主环锦囊格=必抽一张,机遇系统走 encounters 目录),职能已被覆盖,不迁移。「随机事件格」术语随格型退役。
3. **「中伏」一词随辅路退役**:`skipTurns` 字段保留(耗竭善后/缓兵之计共用),但 endTurn 跳过日志的 category `"branch"` 与「中伏未消」文案改为中性归类与措辞;术语表收「中伏」入弃用。
4. **`BranchEntered`/`BranchExited` 时机删除**:无任何已落地技能使用,时机框架文档中六个以辅路为前提的灵感技能示例一并清除。
5. **珍宝频率补偿与宝物城改造另立一票**:辅路 3 个探宝格的频率损失不在本票补偿。后续票把宝物城改为可购买(与普通城池同权)、落格结算顺序(机遇/探宝/交易)显式化,各图宝物城数量按最终语义一次调平;中原图(zhongyuan,8 格纯买地无辅路)不参与,维持极简定位。 (已废:正典「珍宝城」, #825)

## 后果

- 棋盘模型简化为纯单环:溢出汇入、branchPrefix 重算、AwaitingBranch 相位、驿道岔口卷轴、辅路探宝/辅路锦囊/中伏格全部消失。
- 探宝渠道收窄为宝物城(每图 4 座,可反复尝试,整局 14 件挖完即止)+ 机遇 grantTreasure 线;频率瓶颈在牌堆与拼点成败,不在格点数(格点补偿见决策 5,另票处理)。
- 锦囊佐料少一条「军师来投」渠道;主环锦囊格与机遇 grantCard(圯上授书)覆盖其职能(锦囊格已随 #826 退役,承载转「锦囊城」)。
- 三张图环内走廊留白(辅路均为环内短廊,SVG 逐元素绘制,删除零残影)。
- 旧 ADR-0012/0013 中的辅路举例句不回写,由本 ADR 接替说明。

## 备选

- 保留机制重平衡(辅路尽头放高价值珍宝做风险捷径):被否——用户判定复杂度与地图设计负担不值,救不回来。
- 留「地图可用可不用」开关:被否——留开关等于复杂度全留原地,只省画图。
- 探宝等量迁移(每图按旧语义先补 3 座宝物城):被否——可购买语义定了之前调数量是白调,并入决策 5 的改造票一次调平。 (已废:正典「珍宝城」, #825)
