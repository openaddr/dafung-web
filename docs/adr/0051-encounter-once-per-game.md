# 0051 · 奇遇:机遇一局一遇制

日期:2026-11-06 · 状态:已接受 · 关联:机遇扩展 wayfinder(#1103)形制票 #1110、跨事件标记原语 #1108、协议面盘点 #1126

## 背景

机遇目录 30 条全常驻:同一条目可反复抽到(中性条目人均每局约 1.6 次),而大典故大奖励(传檄而定)只能靠把条目权重压到 0.2(全局约 0.7%)来装稀有,结果是多数玩家一局根本见不到——「稀有」与「可见」打架。目录扩容至 60 条后重复频率自然下降,但机制性缺失仍在:大事件卡没有「本局唯一」的结构性分量,重复遭遇持续侵蚀大典故的戏剧价值。

## 决定

机遇条目可标**一局一遇**(正名「奇遇」):每名玩家每局至多一遇,遇后移出其**个人**抽取池;与三档**正交**——档位管强度(声望 softmax 抽取照旧)、奇遇管出现法。

- **按玩家计,不按全桌**:四人四条独立机遇流,无先到先得;奇遇是「每人的本局限定」,不是抢夺型资源。
- **链式典故**拆前编/后编两张奇遇,以 P2 跨事件标记(#1108)衔接(后编仅对持前编标记者可抽);不做单卷轴两段式——机制预算守住 P1+P2 两原语,多步卷轴状态机明确不做。
- 存量仅传檄而定标入;扩容新增 12 张奇遇跨三档(好运纯收益大奖、中性选择题、霉运重挫皆可有)。
- **不建用户可见的稀有度标签**:三档分色已是唯一档位视觉通道,再加徽记=文字标牌(撞状态表达原则);奇遇的分量靠结构与演出承载(演出诉求归叙事演出票 #1111)。
- 配比定案(全目录 60):好运 21 / 中性 16 / 霉运 23;29 抉择 / 31 即时;玩家侧 13;奇遇 12。

## 备选

- **纯权重稀有化**(现状):0.7% 的传檄大半对局无人得见,稀有成了「不可见」;弃。
- **全桌一次性**:先到先得让后手玩家结构性失去内容,四人体验不均;弃。
- **显式稀有度档(常规/超稀二分)**:第二套档位系统 + UI 徽记,撞档位结构冻结面与状态表达原则;弃——「文档命名、UI 不加标」已并入本决定。

## 后果

- 引擎:每玩家「已遇奇遇集」状态(序列化友好)+ 抽取过滤;联机协议面经 #1126 盘点为**零改动**(快照自然携带,事件批不新增 kind);需与 #1126 新护栏同族——奇遇声明不得破坏选项集可用性。落地施工归 spec 拆票,本 ADR 只钉形制。
- rules/07 实施时新增「奇遇」小节;GLOSSARY 同步立条(「奇遇」从「机遇泛称弃用词」转正为一局一遇条目专名,旧泛称义并入住释)。
- sim-batch(#1127)增加奇遇命中统计(命中率/人均目击数)供平衡验收;奇遇条目平衡以「每局有人撞见、每人只一次」为验收语感。
- 档位语义正典随本票重申:好运=纯收益(奉迎天子为唯一调味孤品)、中性=选择定吉凶(全档抉择)、霉运=倒霉(含两害相权)。
