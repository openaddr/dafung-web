# ADR-0073 额外回合归入原轮次

2026-11-26 接受，已实现。额外回合接在原回合之后，再继续按座次轮替。这样本轮最后一位诸侯也可以赶在轮末持城收益发放前再行动一次。

## 回合与轮次

- 有额外回合待处理时，先结清当前实际回合的技能、待决选择和到期燃烧，再按当时的局面判胜。对局继续且获得额外回合的诸侯仍在场，才处理这个额外回合。
- 实际进行的额外回合照常摸牌、出牌、掷骰、行军和收尾。若该诸侯还有跳过次数，这个额外回合消费一次跳过次数。两种情况都使全桌回合编号增加 1。
- 所有接续的额外回合都归入原轮次。处理完毕后，继续处理常规座次。到轮末时结算轮末技能，发放一次持城收益并判胜。按回合计的效果随回合编号推进，按轮计的效果随轮次推进。

轮末接续额外回合前的判胜是常规收尾只判胜一次的例外。若对局继续，但额外回合因跳过或诸侯离场而未实际进行，且本轮已无后续常规回合，轮末技能和持城收益结清后仍判胜。常规次序见 [ADR-0067](./0067-city-conquest-economy.md#胜利判定)。

## 首版锦囊「挟天子以令诸侯」

首版牌库放 1 张，标签为「谋」。所有在场诸侯均可在自己的出牌阶段使用，额外回合也可使用。

> 出牌阶段，对自己使用。此牌生效后，立即结束你的出牌阶段。本回合结算完毕后，你获得一个额外回合。

- 牌打出即入弃牌堆，随普通锦囊洗回。重新摸到这张牌时可按牌面规则再次使用。
- 此牌被「识破诡计」拆掉时照常消耗，出牌阶段按其余可用项继续。只有生效时才结束出牌阶段并安排额外回合。结束出牌阶段后，本回合照常进入掷骰、行军与落格结算。
