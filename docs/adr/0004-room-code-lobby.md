# 房间形成:房间码大厅 + FCFS 入座 + 房主开局

多人对局以"房主建房 → 发房间码 → 他人输码入座 → 房主开局"形成,**不采用陌生人自动匹配**。建房者(Seat 0 = Host)选定座位数 2–4(空位可标 bot),他人按加入顺序 FCFS 自动占下一个空 Seat。Host 点开局后,服务器用这套 seat 配置(真人 + bot 填充)构造 GameEngine → `doDraftRoll` → Setup → Playing。国号沿用 CLI 的 `doDraftRoll` 自动从字池分配(不为 v1 加一层选国号 UI)。

不采用"人满自动开局"——休闲局房主要能等朋友到齐再开,而非一满就强制开始;不采用"固定 4 人"——2–4 灵活且代码代价极小。入座即签发 seatToken,作为 Seat 归属凭证(见 ADR-0005)与掉线重连凭据(见 ADR-0002)。
