# ADR-0041: 城池购价回调 ÷1.5 + 起手现金砍半,引擎缺省退位地图必配

状态:已采纳(2026-11-01,用户六问拷问拍板;动机 a+b=前期过阔 + 数字膨胀观感)

## 背景

#827 曾给环游图单独 ×1.5(购价百两速记 27/45/72 档)回补 36 格圈的每圈水槽(圈长 45→36 实锤局长 −39%/−31%,超 ADR-0061 ±20% 判据)。×1.5 实跑一阵后,玩家侧判定两个问题:

- **前期太阔绰**:起手 10,000 两想买啥买啥,买城无抉择压力;
- **数字膨胀观感**:名城 7,200 臃肿,偏爱小数字。

## 决策

1. **购价全表回 ÷1.5**(县城 1,800/郡城·奇城 3,000/名城 4,800;变卖价保持购价 ×[60,90,120,150]%、建城费保持 50% 同步回),**两图统一一张标准表**——两图倍率/加值曲线本就同值,双表并存只剩维护成本;环游图生成器 TIERS 与守卫测试同批改单表。
2. **起手现金 10,000→5,000**(两图同改,治前期过阔)。
3. **奇城 Lv2 倍率 5→4 驯化保留**(#827 独立于 ×1.5 的实测修复:大单 78% 出在奇城,驯化后大单局均 −27%)并**推广到中原图**(虎牢关/宛城同为双奇城相邻);满级 ×7、青囊书 600 分水岭(奇/名满级同售 4,200)与斩杀线 21,000 不变。
4. **引擎缺省退位**:`authority.ts` `DEFAULT_TARGET`(30,000)/`DEFAULT_CASH`(10,000) 删除,`EngineConfig.targetNetWorth/startingCash` 改**必配**;`loadMap` 补两字段校验(镜像 resupply)。装配层显式解析:CLI 旗标 `?? map 字段`(解析值落盘 config,重放要素);联机 `room.startGame` 与 `room-record` 恢复同语义(`hostConfig.target ?? map.targetNetWorth`,起手现金产品面无旋钮恒随地图);`loadEngineAt` 对旧格式 state 缺字段响亮拒载。孪生常量同根红线一并处理,非本议题扩权。

## 承认的取舍

- **水槽回浅**:价格是系统唯一真水槽(#827 实锤,调曲线局长零响应),回调等于放弃 #827 的局长校准——以「前期压力 + 数字观感」换「局长 −13%」,模拟留档认账。
- **旧存档/旧房间记录不兼容**:`loadEngineAt` 拒载缺起手/目标的旧 state(零兜底红线,无兼容负担)。
- **测试场景经济与产品数值脱钩**:单测 cfg 显式 `startingCash: 10000` 自持场景(与 `targetNetWorth: 8000` 等既有自定义同款),产品数值只由地图+守卫测试锁定。
