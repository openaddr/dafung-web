# ADR-0026: 视觉方向修订——玄墨鎏金全面皮化

日期:2026-10-13
状态:已接受(2026-10-13 用户三轮拷问逐项拍板,[#489](https://github.com/openaddr/dafung-web/issues/489);建图[#487](https://github.com/openaddr/dafung-web/issues/487))

## 背景

2026-09 的视觉重做将方向 B「水墨留白·笺纸集」定稿并全屏落地(DESIGN.md §3)。
2026-10-13 的六路 UI 审计确认工程与视觉语言上乘,但用户在同日的「画与戏」
wayfinder 建图拷问中连续拍板:**全面皮化**(对 DESIGN.md 方向 B 的方向修订)+
**全面 juice 化**,并在基准定档三轮中选了每一项的激进档:棋盘宣纸底同步换深、
古画退役、标题字换游戏感黑体、水-墨-印器物族全部重评、全屏同批不分期。
即:这不是在既有体系内做素材注入,而是整体视觉识别的更替。

审计同日确认的前提变化:外部立绘素材(无名杀系,约 2342 张拼音命名原画)
接入难度 S,画心/画像通道早已预留——「画」的短板有低成本解法,使得
「全面立绘化」从高风险提案变为可行路径。

## 决策

1. **视觉基准定名「玄墨鎏金」**:漆黑为纸,鎏金为骨,立绘为魂。对标三国杀
   十周年 UI 语感——深墨底面板、漆金描边、全幅立绘卡、盾形血条与徽章角标。
2. **棋盘同步深底化**:不保留宣纸底;地形/驿道/城池铭牌/事件格对照新基准重绘。
3. **色彩单主题直接换值**:theme.ts 值换血(玄墨深底阶/漆金阶/朱砂印/势力色
   重映射),gen:theme 全局生效,浅色不留档;token 单源机制不动。
4. **字体**:标题字换站酷酷黑体(免费商用,既有离线子集管线入库);正文文楷保留。
5. **古画退役**:千里江山/溪山清远下架,换外部深色古风素材;素材授权纪律
   (manifest/CREDITS/review_required)沿用。
6. **水-墨-印器物族全部重评,裁决放演出票逐件过目**:重评≠必换,印章大概率
   以漆金印形态延续,卷轴可能演进为全屏宣告横幅。
7. **施工口径:全屏同批**,不分期。

## 后果

- 方向 B 全部章节降级为历史档案与机制参照,不再作视觉验收依据;
  §4-§7 的值表与分屏要旨随皮化施工批次逐屏修订。
- 现有四套字体中马善政从标题位退下(存量引用随批次清理);文楷仍为正文
  安全位,字体安全规约(空芯字形禁用清单)延续。
- 两幅 PD 古画素材与相关引用退役;新增外部素材按授权纪律登记。
- e2e 视觉断言面随全屏同批显著扩大——前后对比以 #493 截图基线为锚,
  testid 契约与交互断言不受换肤影响(红线不变)。
- 在途行为层快赢(#494-#497)不受方向修订阻塞:它们改的是反馈行为而非皮肤,
  合入后皮肤随新基准走。

## 备选

- **B 案渐进皮化(纸底+金框画心)**:保留既有体系只加不动——与用户「全面皮化」
  的明确拍板相悖,否。
- **双主题并存(浅色留档可切)**:个人项目不考虑兼容,双倍对比度/断言成本
  无对价,否。
- **棋盘保留宣纸(深 HUD 环抱浅棋盘)**:审计曾推荐;用户明确选「同步换深底」,
  否。
