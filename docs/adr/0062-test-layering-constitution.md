# ADR-0062: 测试分层宪法(五层金字塔 + 可隔离性原则)

日期:2026-11-08
状态:已接受

## 背景

三轮 e2e 清退(#1165/#1181/菜单A)与两轮唯一守环审计(#1279/#1281,132→121 例)之后,浏览器例逐例证明守的是「回路」环:引擎状态真的画上屏幕、玩家真的点得动——再删就是点名放弃某个环。同时无头层已有 1013 单测 + 整局金账 + 300 局基准,**游戏场景的全量回归早已住在无头层**。真正的缺口在中间:app 层的测试跳过 UI 组件直取纯逻辑(30 个测试文件),组件级只有 `renderToStaticMarkup` 静态标记两个先例(tile-badge/tile-form)——于是「点击→命令→UI 更新」这条接线的整体守卫住在了浏览器里。

既有先例证明两头都可无头:单机全栈(local-room:进程内 RoomRegistry + MemorySocket 双工 + 真 LocalController + 真 store,#398 单机统一——单机也走协议通道不直读内存)、联机客户端(online-first-frame-fold:OnlineController 消息注入零网络)、协议双端(ADR-0055 故障注入代理:双无头客户端连真实服务器)。缺的是把它们立成**可复制的层**。

拍板(2026-11-08,grill 十二问全拍):**两刀都做,哪怕做慢一点**——接线层是用例大头(~40-60 例),联机对跑砍慢池;联机先行(先例最厚),接线层紧随。

## 决策

### 五层金字塔

| 层                | 载体                                                   | 守什么                           | 禁什么                                   |
| ----------------- | ------------------------------------------------------ | -------------------------------- | ---------------------------------------- |
| ① 引擎纯逻辑      | bun test(src/core)                                     | 规则/数值/语义                   | —                                        |
| ② 整局无头        | goldens / sim-bench                                    | 整局行为回归(全量口径所在)       | —                                        |
| ③ 协议/控制器无头 | bun test(local-room / first-frame-fold / **双端对跑**) | 数据过网 + 投影进 store 后的语义 | DOM 断言                                 |
| ④ 接线测试        | bun test + happy-dom                                   | 「点击→命令→UI 更新」接线        | 几何 / 像素 / 演出泵                     |
| ⑤ 浏览器回路      | Playwright e2e                                         | 地板名册(见下)                   | 逻辑断言(逻辑透过 UI 已随 ADR-0056 退役) |

### 双端对跑(层③新增)

两个完整客户端栈(OnlineController + gameStore/netStore)经**真 WebSocket** 连进程内引擎服务器(`scripts/server.ts` 起临时端口),零 DOM 零浏览器;断言 = store 投影状态逐字段收敛 + 关键节点事件批折算对账(event-fold 结果),零 DOM。传输恒取真 WS——测试跑的就是生产传输面(重连/心跳/真实分帧),不造第二套 socket 语义(统一原则);ADR-0055 故障注入代理的真服务器语义直接复用。单机半已由 local-room 守,本层只补联机。

### 接线测试(层④新增)

bun test 进程内 happy-dom 渲染**真 React 组件 + 真 store**。断言宪法:**只许 DOM 结构 / testid / 类名 / store 状态;禁几何**(假 DOM 无排版引擎,`getBoundingClientRect` 恒 0)、**禁像素、禁演出泵与真实时钟**;响应式分档允许 stub matchMedia 断类名。第一波只收 store 投影型纯渲染组件;泵驱动组件(行军/横幅/反应窗)留浏览器——演出的存在性归 visual-compare(与 ADR-0059 瞬空判据同构:接线归组件级,存在归真渲染)。

### 迁移判据

断言面=「操作过后 store / 渲染树里的语义」→ 下放;「真实排版几何 / 真实输入语义(长按 / hover / pointer 抑制)/ 真双端过网呈现 / 挂载路由冒烟 / 真浏览器 API 面(剪贴板、文件下载、UA、LoAF 等 happy-dom 无真值的通路)」→ 永留浏览器。判例:#1013(合成层)、#833(价签首帧裁切)、#817(载体装配)——三层全绿漏网、只有真渲染抓得住的真 bug 钉。

### e2e 地板名册

永留浏览器的例在 [e2e-分类表](../reference/e2e-分类表.md) 标「地板」:脊柱六条 + 构造器守卫组 + 几何/真 bug 钉 + 真双端呈现冒烟 + 挂载冒烟。名册固化后迁移不侵蚀地板;名册外即可迁移池,按判据逐例标。

### 测试可隔离性(常设原则)

全局可变状态必须满足其一:**可显式重置 / 落盘持久化 / 实例隔离**。存内存的东西要么落盘,要么保证测试期隔离——发现污染即治理源码,随票走,不开独立治理票。

### 范例代码纪律

每层**试点例按范例标准写**(头注判词 + 装配配方 + 判层理由),先合入 master 再铺开——后续用例(尤其 AI 派单)以范例为参考模板,不以旧例为参考。

## 后果

- **经济学如实账**:ADR-0059 后浏览器例地板 ~2s,迁移收益主要在**覆盖结构**(接线守卫进 bun test 大军、慢池大头下放)而非墙钟;vera20k 的单元层主力形制不照抄——它的 shell 例是分钟级真 exe,我们的是秒级,经济学不同。
- 不引入 vitest/jest(2026-10 拍板:迁 vitest 不值);happy-dom 是纯库,测试入口恒 `bun test`,零新命令。
- 接线层与对跑层会暴露 store 单例/全局状态的纠缠——按可隔离性原则顺手治理,预期这是两刀的主要隐性成本。
- server.ts 可能需要开编程内起小缝(main 守卫或导出装配函数);OnlineController 若硬连浏览器 WS 则需 socket 注入缝——先量再改,最小缝。
