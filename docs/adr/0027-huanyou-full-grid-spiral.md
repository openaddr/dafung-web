# ADR-0027: 环游图满格螺旋重排——9×5 满格与唯对角闭环边

日期:2026-10-17
状态:本体形制已随 [ADR-0048](0048-map-system-slimming.md) 删环游图退役;下列两条判词**现役**,且为其唯一存档出处(BoardView.tsx / StaticLayers.tsx / game/layout.css 活引用)。已退役形制(9×5 满格螺旋环、唯对角闭环边 会稽⇗长安 凑奇环、满格最少转向哈密顿环序与地理带重排、四都锚环距硬断言面、换图重钉与种子级联流水;拍板:满格重排/45 格不变/四都锚环距为唯一环序硬断言/视口动态推导)不再复述,git 史可考。

## 现役判词

1. **总览视口动态推导**:`computeFitView` 按当图城池包围盒 + 渲染占面外扩
   (城台半宽/王旗顶/价格字底/避城弧线档位)计算,`FIT_VIEW` 常量退役——
   地图统一自适应,「改图忘改视口」漂移绝根;自制图/中原图总览视口同步受益
   (此前共用同一个错配 FIT_VIEW)。
2. **游戏屏棋盘区让位席位竖卡列**(CSS `:has` 随列存在性开合,桌面档右让 128px,
   4-6 席左列同款;短横屏席位折横排维持原状)。
