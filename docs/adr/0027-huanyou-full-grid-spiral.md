# ADR-0027: 环游图满格螺旋重排——9×5 满格与唯对角闭环边

日期:2026-10-17
状态:已接受(2026-10-17 用户拷问会拍板:满格重排/45 格不变/四都锚环距为唯一环序硬断言/视口动态推导)

## 背景

环游图自 ADR-0024 起为「7×6 满格 + 东西延伸列三格凸出」:上庸/下邳/弘农三座宝物城塞在
延伸列(与相邻标准列间距 250,标准列距 400),全环步距混杂 250/310/400/650 四档,并有
三条例外长边(上庸→交州 650 横跨、江陵→下邳 560 斜跨、弘农→子午谷 650 横跨)。玩家
可感知的三个问题:

1. **行进乱跳**:凸出再折返的环序几何让棋子走到图缘又原路横穿折返(商市被连续掠过
   两次),移动动画本身平滑(逐格插值),「跳」感纯来自几何。
2. **排布挤处挤、空处空**:延伸列间距 250 塞同尺寸城台视觉拥挤;延伸列把内容包围盒
   撑到 2900×1550(宽高比 1.87)。
3. **两侧留白**:`FIT_VIEW` 是 #58 时代布局的硬编码总览框(3180×1908,比例 1.667),
   内容包围盒早已漂移;宽屏容器下 `preserveAspectRatio meet` 按高度受限,左右各空
   约 12%。

另有硬数学约束:纯上下左右一格邻接的网格图是二部图,环必须偶数格——**45 格(奇数)
不存在纯正交闭环**,至少要一条非正交边。旧图用三条例外长边凑环,是上述乱跳的根源。

## 决策

1. **9×5 满格螺旋环,45 格一格不动**(城池/特殊格内容与经济数值原样):零凸出列、
   零空洞,列距 380 / 行距 320 全统一;内容 3269×1514(比例 2.17)更贴宽屏容器,
   总览下棋子渲染尺寸约 +19%。
2. **唯一非正交边 = 对角闭环边 会稽(3,1)⇗长安(2,0)**:对角连接同色格,恰一条
   对角边即凑出奇环,是数学最小代价;兼收 #249「首尾可见闭环」之利——闭环边是
   左上角一格对角线,一眼可读收环。
3. **环序 = 满格最少转向哈密顿路径**(tmp 求解器海选,16 转向):外环 24 格
   (= 2×(9+5)−4,恰为整圈边界)先环游边境一周,再螺旋收入中原腹地。地理带随之
   重排:边地(幽燕/青徐/岭南/凉陇)环游于外环,蜀道/荆楚居内环,中原逐鹿于腹地;
   四都锚点(长安/长沙/洛阳/临淄)环距 11/11/11/12(max−min=1)。
4. **硬断言面更新**(生成脚本,违反即抛错):满格无洞、全边一格邻接且对角边恰一条
   (必为闭环边)、边不过城(线段距第三方格心 ≥ MIN_TILE_DIST,旧 650 长边跨城之忌)、
   都城锚点环距差 ≤2、全格最小间距。「无三连同型」自断言降级为软目标(用户拍板)。
5. **总览视口动态推导**:`computeFitView` 按当图城池包围盒 + 渲染占面外扩
   (城台半宽/王旗顶/价格字底/避城弧线档位)计算,`FIT_VIEW` 常量退役——环游图、
   中原图、自制图统一自适应,「改图忘改视口」漂移绝根。
6. **游戏屏棋盘区让位席位竖卡列**(CSS `:has` 随列存在性开合,桌面档右让 128px,
   4-6 席左列同款;短横屏席位折横排维持原状)。

## 后果

- e2e/单测按 ADR-0025 换图重钉纪律重钉:`board.test` 阈值语义改合成双城板(新图
  全边 ≥ 行距,短边直线在环游图上不复存在)、reaction-window 走廊改赤壁→武昌→江夏、
  treasure premium 按落点城 def 推导(旧图钉咸阳价)、local-room 换 seed 1
  (候选最远点采样吃坐标,seed 7 先手漂移)。
- `offeredCapitals` 采样吃坐标 ⇒ 种子级联全面洗牌:react-reaction 开局停靠点从
  「招贤卷轴」改「购地抉择卷轴」,周瑜改 `heroDefs` 调试面直授;react-reaction-online
  双人类同窗种子重海选。种子级联离线仿真不可信(Bun/浏览器 rng 消耗偏差,见
  sim-jinnang 头注),重钉以真浏览器探针为准。
- 自制图/中原图总览视口同步受益(此前共用同一个错配 FIT_VIEW)。
- 老存档/老房间引用旧环序作废(零兼容原则,无需迁移)。

## 备选

- **只修间距不动环序**:三处凸出折返仍在,移动观感改善有限,否。
- **46 格(8×6 切两角满格,纯网格零对角)**:需加 1 格特殊格凑偶,城池/特殊格配比
  变化属玩法面改动,文档对账面更大;用户拍板 45 格不变,否。
- **砖砌错排格(半格错位排布,三角格网天然容奇环)**:视觉语言全面偏移、道路画法
  重做,收益仅「零对角边」,否。
- **保持 7×6+3 凸出骨架仅调间距**:即「只修间距」加强版,凸出列与折返长边是结构
  性的,否。
