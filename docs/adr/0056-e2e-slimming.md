# ADR-0056: 浏览器 e2e 瘦身收尾——UI 壳分类判据与验证分层定案

日期:2026-11-07 · 状态:已采纳 · 票:[#1165](https://github.com/openaddr/dafung-web/issues/1165) · 地图:[#1160](https://github.com/openaddr/dafung-web/issues/1160)(无头确定性 e2e 测试体系,wayfinder;前置 [ADR-0052](./0052-headless-deterministic-testing.md)、[ADR-0055](./0055-protocol-fault-e2e.md))

## 背景

无头确定性测试体系四票落地后,浏览器 e2e 的定位问题浮出水面:`e2e/*.spec.ts` 40 个文件混装两类断言——**UI 壳**(布局/拖拽/横屏/可见性/交互形态,浏览器在场的理由成立)与**逻辑透过 UI**(断言的其实是引擎/协议行为,经浏览器绕路取证)。后者坐浏览器层成本畸高:每例要 build + 起双 webServer + 停车坪钉相位 + 与演出/负载赛跑,而引擎与协议行为的确定性回归已由无头层全面接管(两跑门 / 黄金差分 / bot 基准 / 协议故障注入)。本 ADR 记收尾票定案的活口径:分类判据、无头层暂未覆盖而暂留的应迁候选登记、验证分层的最终口径;本票删缩与 #1181 重筛的逐条流水已删,git 史与 [e2e-分类表](../reference/e2e-分类表.md) 可考。

## 分类判据

按**断言面**分类,不按文件名或历史归属:

- **UI 壳用例**(留):断言面 = 布局几何 / 拖拽输入 / 横竖屏形态 / 可见性(锦囊·secrecy·横幅·弹层)/ 交互语义(点选·长按·二段确认·悬停·reduced-motion 退场)。判据问句:**「这条断言换到无头层还成立吗?」**——无头层不持有 DOM 与演出面,几何/可见性/真输入断言在无头层根本无法表达,即为壳。
- **逻辑透过 UI**(已迁/应迁):断言面 = 引擎结算 / 协议行为,浏览器只是取证绕路。识别特征:断言主体是快照字段、引擎留痕行、事件批内容,而 UI 交互仅是触发手段甚至没有交互(调试钩子直呼引擎)。已由无头层覆盖的标「已迁(落点)」,尚未迁移的标「应迁候选」——**候选只登记不迁移,不得据此删例**(范围护栏:本票是审计与收尾,不是迁移施工票)。

「接线断言」的归属判据(两类的接缝处):**「UI 控件 → 引擎命令」的通路证明是壳**——无头层直呼引擎方法,永远证明不了「点这个按钮会发这条命令」;但接线例里沿带的引擎结算细则断言(留痕行全字段对账、结算数值等式)是逻辑,落点在无头层。前者留,后者已在无头层的不再重复加强。

## 验证分层定案(口径翻面)

- **无头层是主力**:`bun test` 默认池(无头整局两跑门 + 快照往返门)、`check:goldens`(黄金差分)、`check:sim-bench`(bot 基准)、`DAFUNG_SLOW=1` 慢池(协议故障注入)承担引擎与协议行为的回归。
- **浏览器层是 UI 壳冒烟**:只断言无头层替代不了的可见性/几何/交互形态;新逻辑断言进 `test/` 不进 `e2e/`。
- **AI 浏览器自动化(dogfood / shot / 浏览器取证)是探索性工具**:找测试没想到的问题,不是回归主力。
- **门槛清单扩一条(2026-11-07 拍板)**:改 `src/core/`(引擎行为面)加跑 `check:goldens`;影响局长/破产面的机制改动加跑 `check:sim-bench`。已落 AGENTS.md「门槛挂 PR 前——本地全绿」清单与 how-to 黄金台账/bot 基准两节。
- 逐条分类与落点速查:[e2e-分类表](../reference/e2e-分类表.md)(本 ADR 的活索引,spec 增删时同步维护)。

## 承认的取舍

- **混合例一律留**:接线例普遍「壳面 + 已迁结算面」同体(如 react-scrolls 交涉/破产例),按用例粒度处置时缩不净;在本票只登记落点不拆断言,避免「删断言留骨架」的半残例——骨架例守不住回归,反而是负资产。
- **分类表的落点注记会漂**:单测用例改名/搬文件后表中锚点会过时;表格定位是审计快照 + 分类判据的活样本,漂移随触到的票顺手修,不设专门哨兵。
- **spec 计数不落数**:分类表记录本票时点的用例数(131 → 128),不追踪总数漂移;how-to 的池规模标定数字保持其标定日期原样。
