# 城池档位视觉通道:建筑形制独占承载 + 区域轴退役

日期:2026-11-01;票:[#916](https://github.com/openaddr/dafung-web/issues/916);补全 [ADR-0034](./0034-four-tier-city-economy.md)(四档城制的经济面,本篇定其视觉面)。

## 背景与问题

ADR-0034 落地后,城池档位(县城/郡城/奇城/名城)是纯经济数据:购价 1,800/3,000/3,000/4,800、三条等级曲线形状天差地别,但 UI 零视觉通道——棋盘上并排两座城分不出档,买卖价值差必须点开弹层读数才知道。

同时,棋盘建筑的形制差异(北官式/南粉墙黛瓦/西凉土堡)承载的是**区域风味**(group a–h),而区域轴已经名存实亡:

1. 机制零消费:`group` 字段在 schema 必配、穿透 `PropertyDef` 与快照,但没有任何规则读它;loader 暴露的 `groupMembers()` 全仓零调用。
2. 视觉半退役:格上分组色带 2026-10-23 退役(#670);背景区域晕染+装饰江河 2026-10-24 退役(实拍 A/B 近零感知),当时留话「区域视觉待机制化时重新设计」。唯一残迹=建筑墙柱配色与详情卷轴地域行文字。

当年「按规模换形制」随经济 v2 退役,理由是「两张内置图全部城池同档,单靠规模分不出形制」——城池档位机制化之后,该理由已失效。

## 决策

拷问两轮收敛(2026-11-01,拍板记录):

1. **建筑形制独占承载城池档位**,四档四形制:县城=单檐悬山灰瓦小院(矮、素);郡城=现行重镇画(夯土城台+两层木构城楼+重檐,零新工);名城=现行画强化(台基加高+琉璃瓦+檐口描金加档);奇城=关隘特形(墩台+雉堞+门洞+戍旗,雉堞元素自西凉土堡迁移)。奇城是「异类」不是「次级」(满级倍率 ×7 高于名城 ×5,专精极致),五座奇城全是战场关隘(街亭/子午谷/华容道/合肥/赤壁),名实相副。
2. **区域轴正式退役**:西凉土堡形制退场,西凉诸城改走标准档位形制;`group` 字段与详情卷轴地域行文字保留现状(机制零消费,不动)。v2「规模三档形制退役」决议正式翻案。
3. **数据面显式化**:地图 JSON 逐城显式 `tier` 必配,loadMap 校验(缺配报错,零兜底);守卫测试改「tier ↔ 标准曲线」对账;编辑器加档位选择。配置即唯一事实源——否决 core 分类函数方案(`cityTierOf(def)` 按形状归类:把守卫知识复制成第二事实源,且作者无法表达「数值微调但这城就是奇城」的意图)。
4. **正交纪律**:形制=城的恒常属性;王旗/候选印/归属染=时变状态;等级珠=等级通道。互不叠写——延续 2026-10-17「等级与归属不上楼」裁决(形制是楼的固有规格,不是状态);否决「都城化建筑再强化」(把状态叠回建筑,总览下会吞掉档位信号)。
5. **辨读判据=总览可辨**:844×390 总览下并排两城可分档(与等级珠拷问同款判据「总览可数、不依赖识字」);放大细读不作要求。否决同画换瓦色微变(县/郡同为加法城,总览难辨)与独立部件通道(总览下部件太小)。
6. **读数场合缀两字档位名**:详情/购地/扩军卷轴与名下城池清单只缀「名城」式两字名,板上不立文字牌(状态表达原则);名词简短干练上升为 DESIGN §4.8 名词纪律。否决形制×区域 4×3 复合(工作量三倍,风味收益 A/B 近零感知)。
7. **术语**:逐城正名「城池档位」;「档位珠」改名「等级珠」——「档位」一词已三义(Fortune Tag/消费档位/城池档位),旧名从历史包袱变现役误导。

## 后果

- 新美术工仅关隘一张,县/名两档自现行画派生,郡城零新工——成本可控。
- GLOSSARY 同批:「四档城制」词条补「城池档位」正名,「档位珠」改名「等级珠」(带墓碑注);DESIGN 新增 §4.8 名词纪律;rules 04 补视觉通道指针,全面回填随施工票。
- 施工面(另票):两图逐城配 `tier` + loadMap 校验 + 守卫重钉 + tile-building 四形制 + 弹层/清单档位名 + 编辑器档位选择 + e2e。
- 自定义地图作者需逐城补 `tier` 字段(loadMap 严格校验当场报缺;本项目不考虑兼容性)。
