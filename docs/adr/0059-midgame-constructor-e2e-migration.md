# ADR-0059: 测试中盘构造器与 e2e 全量迁移(vera20k 二阶采纳)

> 历史决策:浏览器地板、脊柱、快慢池与强制放行条款已由 [ADR-0065](0065-test-economics-browser-retirement.md) 取代;当前只按需执行独有无浏览器覆盖,不得据本页恢复浏览器回归。

日期:2026-11-07 · 状态:已采纳 · 票:[#1247](https://github.com/openaddr/dafung-web/issues/1247)(规格)及实施票

## 背景

直通形制([ADR-0058](0058-e2e-direct-path-doctrine.md))收官后:快池 107 例墙钟 3.6m(W4 零挂),每例物理地板 3.258s,最大单块=首掷链 2.324s(演出真播;负 ROI 清单证实地板下没有刀);浏览器 e2e 到中盘状态只有「真跑多回合」或「深种(doctrine 禁止)」两条路。vera20k 参考仓三形制对照(详见[参考仓索引](../reference/参考仓索引.md) vera20k 节):中盘构造器/长局 digest 台账/认证出套件——后两者我方已有等价物([ADR-0053](0053-goldens-ledger.md) 黄金台账逐回合 digest、[ADR-0054](0054-sim-bench.md) 统计带、快慢池 #1026),唯中盘构造器是真缺口。用户拍板:三裁决落地,「除脊柱全部迁移,目的是减少测试用例耗时」。

## 决策

1. **采纳:中盘构造器(含瞬空钩子与开口吸收)**。浏览器侧一等公民到站通路:冻结编排时钟 → evaluate 内按无头整局驱动器同款语义(回合数变化定界、botAct 同源)经**房间命令面**逐回合调公共命令推进到第 N 回合 → 解冻沉降(演出追帧/吸附自动排空,[ADR-0029](0029-presentation-self-consistency-invariants.md))→ 交还被测环。合法性=**按构造等同**:现场由引擎真逻辑长出、RNG 流位与事件批按真实序产生,不属深种(种植合法性分层不变,force 仍须判词);真人决策点在 evaluate 内 async 轮询逐个应答(命令调度锁只在宏任务事件拍解锁,纯同步连发会吞命令)。**瞬空钩子**=把演出变速箱的吸附档(「落后即校准」重档)变成测试可钉死的常开档——演出层阀门,测试专用,产品行为零变化。**开口吸收**:非脊柱用例的 postRoll 真播首掷链换为构造器+瞬空通路,地板 3.3s→~1s 档(示导波实测定版)。
2. **采纳:视觉对照工具(非门禁)**。发版前场景清单截图(主页/设置/对局冻结静帧/终局屏,844×390)× 上一 tag 构建并排人工过目;真值源=上一发版。像素 diff 自动门禁继续否决(flake 零容忍+无 CI)。
3. **登记:长局断言媒介与重认证分层不重建**。黄金台账(逐回合 digest:rngState 游标+链式战报哈希+stateHash)= vera20k parity digest 台账的逐回合版;sim-bench 300 局统计带=大语料层;重认证不进例行测试的分层已在(快慢池/小改动禁全量)。防重提登记于参考仓索引 vera20k 节。
4. **迁移判据:脊柱由五条扩为六条**。「除脊柱全部迁移」的边界成文:脊柱清单在 [ADR-0058](0058-e2e-direct-path-doctrine.md) 决策 3 五条之上新增 **⑥整局骑局**(加速到胜利——唯一骑生产装配走完全局的 e2e,整局装配验证者),共六条永不迁移。脊柱=生产激活通道(看门狗/controller 装配/UI 布线)的验证垄断,迁它=「全绿但游戏坏」的假绿开门。迁移对象=仍走真实多回合到站的例;只动到站通路,被测环保持真实(一环一真);被测环含演出/真链路的例按其 spec 头注判词逐例判(导览见 [浏览器回归退役决策](0065-test-economics-browser-retirement.md)),保留其真实段。
5. **公共能力借机抽象成层**。drivers(回合驱动)/scenes(quickStart 家族+中盘构造器)/settle(沉降谓词)/patrol(不变量巡检);浏览器侧**唯一新缝=调试桥扩展**(「驱动」+「瞬空」两能力,双门禁纪律不变),其余全复用既有缝(房间命令面/演出阀门/沉降谓词族/截图通道)。桥能力按需生长纪律不变(ADR-0058 决策 5)。
6. **两段式目标线**。示导波(构造器+瞬空+一个迁移示导例)实测新地板与沉降成本后,耗时目标线定版回填本 ADR;不预设数——「快池」是相对史名,绝对口径以实测为准(定版数字见后果节与[耗时回顾](../agents/耗时回顾.md)账)。

## 后果

- 到站成本与回合数脱钩,「每例几十秒」的机制账清零;快池地板~~→~1s 档~~**实测定版 1.6-2.1s(「~1s」预测作废,2026-11-08)**——瞬空只清演出钱,残余=seedSolo 开局链+300ms 沉降窗+构造器态演出排空(#1272 负结果:轮询税不在关键路径;#1277 打点定版:引擎构造仅 8ms,大头=地图取析+首执行编译税,后者已随懒化移出)。
- 演出层获得测试阀门,产品零变化;脊柱六条垄断生产通道验证,「全绿但游戏坏」被六条堵死。
- vera20k 对照账清毕:三形制一采纳两等价,防重提。
- 快池命名顺带评估更名;台账数字为唯一诚实口径。
