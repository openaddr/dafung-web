# ADR-0020: 同步模型切换——事件流为主、客户端折叠、god-view 明传

日期:2026-10-04
状态:已接受(2026-10-04 架构拷问会,grill 流程收口,用户落章);**已落地**(2026-10-05,折叠切换①-⑦ #390..#389);决策 2 保密后置条款**已兑现**(2026-10-05,#381)

## 背景

现行模型是「快照单源」:引擎全量快照(ADR-0016 按座位投影)是唯一同步单元,客户端只读水合,动效靠相邻快照 diff 反推因果,猜不出的开旁路口子(出牌线 `lastJinnangPlay.seq`)。对标调研(FreeKill/无名杀,结论登记于参考仓索引「类游戏对照」节)后,用户拍板彻底切向 FreeKill 的同步切片:动效因果应是协议一等公民,而非 diff 猜测;并知情接受其配套(明传、漂移、无可靠性机制)。

拷问过程中的核心论证:「成熟的是新月杀整体,不是事件通道零件」——其四个选择(事件折叠/全网明传/客户端技能码/Lua 生态)互为配套,本 ADR 有意**整体**对齐切片而非嫁接单件。

## 决策

1. **事件流为主,客户端折叠**:引擎每次状态转移产出类型化事件(行动者/动作/对象/原因),服务端流式下发;客户端折叠事件为本地状态,动效照读因果。事件词汇表以 FreeKill 协议蓝本为参照(如移动牌类带 from/to/reason/skillName)。
2. **god-view 明传,保密后置**:数据全量广播,不做逐事件座位过滤;后补时在发送总口做单点过滤。ADR-0016 的 per-seat 投影实现**冻结保留**(不删)作为后补落点。后补前他人手牌内容、牌库顺序、反应窗询问集三类信息全网可见——知情接受(朋友圈信任模型)。
   **后补已落地(2026-10-05,#381)**:发送总口单点兑现——`scripts/seat-projection.ts` 新增 `redactEvents`(事件批逐座位过滤,穷尽 switch 登记隐私档位)与复活的 `redactSnapshotForSeat`(open 摘要/flush 校准改回 per-seat 投影)同居一文件;server.ts 三处全量下行全部按接收座位下发。事件词汇 38 kind 审计:37 种全桌公开透传,唯 jinnang 反应窗 `queriedSeats` 裁剪——**身份匿名、数量保留**(非自己座位置换 -1 占位):折叠器闭窗算术依赖询问数量,且应答事件 seat 本就公开(每被询问座位恰应答一次),数量可由公开应答流推出,匿名化相对 god-view 恰好只裁「谁」、零额外泄漏;与快照投影的「清零」口径是分通道的两个形状(快照水合无闭窗算术)。`treasureStolen` 牌名定为明置信息(珍宝列表全员可见、战报公开记名)不裁。
3. **关键节点周期校准**:开局、破产清算、洗牌类节点强制全量状态同步,结构性兜住折叠漂移(FreeKill 同款三道减震)。
4. **重连=整房摘要灌状态**:断线重连(ADR-0002)下发整局全量状态一次性重建,不重放事件;无 seq/ack,断线期间事件直接丢弃,可靠性全靠重连全量。
5. **漂移纯信任**:不做哈希对账、不做版本仲裁;客户端失步靠玩家刷新。漂移 bug 类(客户端状态与服务端不一致)从「物理不存在」变为「常态病」——知情接受。
6. **引擎快照不删**:快照生成、水合机制保留但降频(重连/校准/归档用),不再作为逐步同步单元。

## 后果

- 动效因果直读,diff 启发式与 seq 旁路口子逐步退役;新增动效=新增事件类型。
- 客户端新增折叠投影器(事件→状态映射),联机协议换血,联机 e2e 断言面大改(施工主体,跨 B/C 工作线)。
- 安全论证从「线上没有的东西就是没有」降级为「过滤器写对才有」(后补);ADR-0016 作为后补时的实现蓝本继续有效。
- 旧对局日志的 diff 动效语义随协议切换失效;日志本身降级为纯归档(见 ADR-0021)。
- 随带宽不再是同步单元,六人局全量事件的包大小与频次显著下降(非动机,顺带收益)。

## 备选

- **快照+语义注记**(事件作为快照附件,状态仍由快照单源):对动效因果的解决度相同且保留安全论证——被否,用户拍板彻底切换以换取与参考实现的整体同构。
- **纯事件无锚**(连重连摘要都不要):无任何成熟项目在跑,否。
