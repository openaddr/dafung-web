# ADR-0027:识破可被识破——反识破反应链

日期:2026-10-17
状态:已拍板(拷问会 2026-10-17,四问全收敛;随 #571 实施)

## 背景

#281 拍板「识破不可被识破」,唯一原始理由:「防嵌套,引擎现红线『效果内禁同步再派发时机』口径一致」。三重实现保证:反应牌不经 announce 通道(出牌阶段「唯反应」灰置 + `executeJinnang` 豁免)、窗内结算不开新窗(`reaction-window.ts` `settleCounterWindow` 对 reaction 域抛错)、牌面/GLOSSARY/rules 盖章。

2026-10-17 拷问会重审,两条论据动摇原判词:

1. **红线论证不成立**:「效果内禁同步再派发时机」约束的是 effect 帧内的同步派发;反应窗本身是相位(`AwaitingReaction`),结算走 `submitCommand` 异步续。链环从窗结算帧(命令处理帧)开新窗、开完即返回,栈不加深——红线字面不破。当年系一刀切,未走此论证。
2. **链长天然封顶**:识破诡计全场仅 2 张(18 张牌库),每环消耗一张,手牌无识破即触发现有「无人可识破不开窗」自终止——「无限反制链」在物理上不存在,「防嵌套」防的东西不存在。

支持翻案的另一面:删掉「识破不可被识破」特例后规则归一(他人锦囊宣布皆可识破),被识破的挫败感获得解药(原使用者可以救计),「无博弈不锦囊」红线更满足——反不反识破变成真权衡。三国杀无懈可击的反无懈层在本仓 research 从未调研过(当时是简化,非研究后拒绝)。

## 决策

**翻案:识破诡计可以被另一张识破诡计识破(无懈式)。**四条子决议(拷问会全票):

1. **全对称资格**:反识破窗的被询问集=持识破者(除本环打出者)——含原锦囊使用者救自己的计;「公告者除外」一条规则管到底,不设第二排除项。
2. **消耗口径**:识破**宣布即扣账,被反识破也不回手**(与主规则「出牌即扣账:被识破也不回手」完全同口径);同窗同份竞争败者仍退回手牌(#281 现有规则不动)。识破成为有风险的牌:保护被拆即白亏一张,救计要花真牌。
3. **bot 口径**:从「只自保」推广为「公告伤我利→净值贪心」——攻我份的锦囊考虑拆(#281 现状),我的计被拆时持第二张识破也考虑救。同一估损函数(`counterLossEstimate`)泛化,无新增常数。
4. **范围仅识破-vs-识破**:半路杀出/行军拦检线保持终端,拦检结算不开新窗(#281 拦检红线独立保留;识破的触发面=锦囊公告,拦检不是锦囊)。

### 链语义(推导即定,非独立拍板)

- 链根与链环:根锦囊宣布(出牌即扣账)→ 识破窗;有效识破从「直接生效」改为**宣布进下一环**(宣布即扣账)→ 新识破窗;某环无人可反(或全员不用/超时)即站住,判定结算在链终落账。
- 站住判定:链终生效的是最后一张未被打断的识破,其否定生效——被它拆的对象作废,被作废者的否定不再适用(逐环交替,等效于「最后出牌者赢」)。
- AOE 按份:每份独立成链;识破被反=仅该份恢复受击,他份不牵连;兄弟链按座位序串行开窗,豁免份集合随链累积。
- 连环计缺角语义不变:识破站住=全计作废;识破被反=全计恢复,拼点照常。
- 链终止:每环消耗一张识破;被询问集逐环按手牌现算,手牌无识破即「无人可识破不开窗」(#281 现有规则)直接站住。全场 2 张 ⇒ 链长 ≤2,但机制不写死深度(牌堆数据变更自动跟随)。
- 表现:识破宣布走 `JinnangAnnounced` 时机(公开事件+浮字,出牌指示线照画);判定浮字(「作废/落空/免于」)移到链终——零反制时与旧观测完全一致。
- 降噪口「本回合不再询问」覆盖链上每一环;窗级 deadline 按 `seq` 逐窗武装(#284 机制天然兼容,每环是新窗实例)。

## 后果

- 引擎:`reaction-window.ts` 续结算载荷(`ReactionPayload`)增 counter 链环形状(携链根上下文+争夺份+已豁免份+兄弟链队列),识破窗结算按载荷分支;`settleCounterWindow` 的 reaction 域抛错改为链环结算;`respondReaction` 份校验按载荷种类分流(链环的争夺份由载荷携带,应答不带 shareSeat)。
- 快照/联机:新载荷全序列化友好纯数据,随 `pendingReaction` 既有单口走;`seq` 逐环递增,`armReactionWait`(#284)零改动天然兼容;`redactReactionView` 为 spread 透传,公开字段零投影改动。
- bot:`botReactionDecision` 增链环分支(救计/护份同一伤我利判据)。
- UI:`GameScreen` 反应横幅链窗文案分支(「X 识破【根牌】」);选份笺行对链窗天然为空(识破的目标域=反应)。
- 文档:GLOSSARY「识破诡计」词条反转+「反识破」登记;rules 06(触发点/牌表/拆招细则/bot 段);rules 03 拦检红线措辞脱钩;牌面文案尾句「识破不可被识破」→「识破亦可被识破」。
- 红线延续:「效果内禁同步再派发时机」不动——链环从命令处理帧开窗,相位链不构成效果帧嵌套;`case "reaction"` 抛错仅在根窗(根窗永不该挂反应牌)保留。
- 重估触发:若牌堆大扩容(识破 copies 上调)或新增反应牌,链长上界与询问频率需重估;机制本身按数据自终止,无需改引擎。
