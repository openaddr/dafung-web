# ADR-0013:决策相位选项集(choice-set)与唯一选项自动执行

日期:2026-08-23
状态:已接受(2026-08-23 与用户确认四项决议)

## 背景

游戏存在多个决策相位(`AwaitingDecision`/`AwaitingTreasureOwner`/`AwaitingBankruptcySettle`/`AwaitingHeroPick`/`AwaitingBranch`/…),传统做法是相位一到就弹卷轴问玩家。但很多时刻玩家**只有一个真实选择**(如 L51:银两/委任状不足落无主城,只能放弃购买)——弹框是"假选择",浪费一次点击、打断节奏。随着技能体系(ADR 时机框架)扩展,选项的可用性会动态变化,散落各处的判断会失控。

## 决策

1. **choice-set 唯一事实源在引擎层**:新增集中注册表(每相位一个选项计算器),选项带 `available + reason`。引擎在进入决策相位前先计算选项集;**≤1 个可用选项时直接自动执行默认行为**(留战报),不进决策相位。UI/bot/联机只消费结果——单机联机天然一致(bot 的决策启发式也改为先消费同一选项集)。
2. **自动执行给浮字轻提示**:棋盘冒一条浮字(如「银两不足,未能购城」,1.3s 自消)+ 战报留痕;不用 HintBar(频繁会烦),不完全静默(玩家会困惑)。
3. **破产清算是例外**:重大不可逆事件,即使唯一选择(无可卖资产只能认赔)仍弹确认卷轴,让玩家看清损失——重大事件优先于流畅性。
4. **扩展口**:集中注册表 + 可注入——未来技能(免委任状购城/低价买城)经时机框架在选项计算前修改状态或注入额外选项,与 timing 框架同构;禁止在 UI 层私自增删选项。

## 后果

- L51 的内联预检(购地 affordability)迁移为 choice-set 注册表条目,行为不变。
- 「假选择」从产品层面消失:弹卷轴 ⇔ 至少两个真实选项。
- 快照无需新增序列化状态(选项集由相位+玩家状态实时派生)。
- bot 决策与人类决策共用同一选项集口径,消除第三套判断漂移的风险。

## 术语(登记入 CONTEXT.md 语言表)

- **Choice-set(选项集)**:某决策相位下决策者当前全部可用行为(含 available/reason)。
  _Avoid_: options(过泛)、actions(与 GameCommand 混淆)
- **Default action(默认行为)**:选项集 ≤1 时引擎自动执行的那一个(如放弃购买)。
  _Avoid_: fallback choice
- **假选择(False choice)**:弹框但实际只有一个可选项——本 ADR 之后应绝迹的形态。
