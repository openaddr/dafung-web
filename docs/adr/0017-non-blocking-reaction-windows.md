# ADR-0017 按座位询问的反应窗

2026-09-23 决定，随 #281 实施。此约定用于识破诡计、反识破及半路杀出等反应锦囊，具体牌效见[锦囊规则](../reference/rules/06-锦囊.md)。

## 决策

1. 权威引擎在结算点开启 `AwaitingReaction`，只向具备反应条件的座位投影可操作信息。当前结算等这些座位答齐后继续，其他座位无需应答。已答齐的窗立即结算。
2. 窗号由 `PendingReaction.seq` 标识。开窗时引擎将 `REACTION_WINDOW_MS` 中相应窗种的时长写入 `ReactionView.windowMs`。权威编排层据此登记一次共同截止时刻，选牌、改选和其他座位应答均沿用该时刻。下一窗（含反识破）有自己的窗号和截止时刻。
3. bot 在开窗时按策略应答。托管座位由房间驱动按同一 `botReactionDecision` 策略代答。被询问的真人到点未答时，由权威编排经 `respondReaction` 提交普通「不出」命令（见 [ADR-0028](./0028-takeover-is-autopilot.md)）。
4. 被询问者在手牌区查看可用反应牌及操作。选择「本回合不再询问」后，余下询问自动不出，当前行动者换回合时解除。该偏好保存在当前客户端。
5. 投影由 `assembleDownlinkShot` 向被询问座位发送窗号和发送时的剩余时间，重连沿用该窗的截止时刻。同窗后续消息只会缩短客户端显示期限。房间编排的时钟独立于引擎序列化状态（#284、#1511）。
6. 联机房间将活窗的窗号和权威截止时刻与局面一起保存。服务器恢复时沿用原截止时刻。已到期的窗口由房间为未答席按「不出」处理，首个座位重连前也可推进。已应答的结果与提交回执一并恢复，进入下一窗时重新计时（#1684）。
