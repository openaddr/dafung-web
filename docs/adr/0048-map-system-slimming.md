# 地图系统瘦身:删环游图 / 删编辑器+自建图库 / 删棋盘平移缩放

日期:2026-11-01;票:[#945](https://github.com/openaddr/dafung-web/issues/945)(spec;实施 #946/#947/#948,文档回填 #950)。

## 背景与问题

关中图 4×7 缩域盘(#938/#941)以「28 城一屏全览、城距疏朗、城池可读」成为默认与主体验后,地图系统的旧形态——三张内置图并存、编辑器 + localStorage 自建图库、棋盘自由平移缩放——三处同时成为负资产:

1. **环游图与缩域快局方向相悖**:36 格大环对局时长与缩域快局的产品方向相悖,且是全仓测试钉谱的隐性锚——e2e 场景编排(停靠点/种植位/骰走位)与大批离线核算种子都钉在它的环序上,任何机制改动都要背着这张图重验。
2. **编辑器是无人使用的生产通路**:EditorScreen 约 825 行,是自建图(localStorage 图库)的唯一生产者,而朋友圈实际无人自建图;自建图还拖着 LocalStorageMapSource/CompositeMapSource 两层来源抽象与 `custom-` 前缀、「自建」标记一串协议面。
3. **平移缩放在小盘上无用且有毒**:usePanZoom 约 372 行(拖动/滚轮/捏合全形态),在 4×7 一屏全览的缩域盘上没有可平移可缩放的需求,反而是低端机(卓易通一类 WebView)手势卡顿的来源。

## 决策

三刀,单批次交付(#946/#947/#948 三个实施票折入集成书签):

1. **删环游图**(#948):`public/maps/huanyou.json` 及其生成器退役;测试钉谱基准全量重钉关中图;CLI/Server/e2e 默认图随之换关中。内置图余两张:**关中图**(默认)/ **中原争霸**(速战)。
2. **删编辑器+自建图库通路**(#947):EditorScreen、首页「编辑地图」入口、LocalStorageMapSource/CompositeMapSource、`custom-` 前缀与「自建」标记全退役;MapSource 收敛为 FetchMapSource 单实现(接口保留,作测试注入缝)。**地图扩展能力改由「PR 一个 JSON」承担**:内置清单通路(`public/maps/*.json` + `index.json`)即扩展点,配套贡献指南([自制地图](../how-to/自制地图.md))。
3. **删棋盘平移缩放**(#946):usePanZoom 整退役(拖动/滚轮/捏合全形态),棋盘取景恒 `computeFitView`(`BoardView.tsx`)总览定格;氛围层([ADR-0039](0039-board-ambient-layer.md)/[ADR-0040](0040-board-split-static-dynamic.md))机制保留,只删「随 pan/zoom 矩阵逐帧联动」一环——矩阵降为挂载/容器尺寸/换图/字体就绪几个事件拍的定格写入。复位/缩放语义不复存在(符号行已随之收口退役)。

## 备选与取舍

1. **只从选图清单摘除环游图、留文件作测试锚**——否:留玩家不可达的死图,违反零兜底原则;数据、文档、钉谱三处照样背着它。
2. **保留编辑器降低做图门槛**——否:目标用户不写图;JSON + PR 评审是更简单的质保通路(评审看得见 diff、装载校验响亮失败),维护一个 825 行的交互编辑器去服务一个不存在的用户群是纯负资产。
3. **保留捏合缩放、只删拖动**——否:中间形态破坏「能一套就不做两套」的统一原则(手势族要维护两套语义),且小盘无缩放需求,留下的捏合同样走低端机手势卡顿路径。

## 后果

- **测试面**:54 个 bun test 文件 + 20 个 e2e spec 重钉关中图(种子哨兵重钓,配方见[开发与测试](../how-to/开发与测试.md));实施票 #949 承接重钉收口。
- **选图面**:MapStrip 内置 2 张不再溢出;选图即三入口首页(单机/联机/选图)一屏完成。
- **棋盘交互**:取景不可调,手势族 e2e 随之退役;对局屏交互面收敛为「点格看详情、席位格看人」。
- **性能预期**:手势卡顿路径整段消除(低端 WebView 指针事件风暴源消失);静止/活动期帧耗不回退(删前后 844×390 探针对比数据见实施 PR 正文)。
- **历史 ADR 的 supersession 注记**(历史 ADR 正文一律不改,supersede 关系只记本篇):
  - 本篇取代 ADR-0008(多图选择)与 ADR-0025(地图收敛),二者已删,git 史可考;幸存的架构决策(清单发现/`loadMapById`/mapId 协议、「多图收敛」方向)由本篇承接。
  - [ADR-0027-huanyou-full-grid-spiral](0027-huanyou-full-grid-spiral.md):环游图本体(36 格满格螺旋)形制段已随删图退役;该篇仅保留「视口按城池包围盒动态推导」判词留存(活代码唯一出处)。
  - [ADR-0039](0039-board-ambient-layer.md)/[ADR-0040](0040-board-split-static-dynamic.md) 中「pan/zoom 联动/同拍双写」一环由本篇收窄(氛围层静态/动态分层机制不变);[ADR-0024](0024-treasure-city-parity.md)/[ADR-0041](0041-city-price-rollback-starting-cash.md) 中以 huanyou 为调平/数据落点的叙述随之成为历史。
- 扩展新地图的通路与 schema 导览见[自制地图](../how-to/自制地图.md);schema 权威恒为 `src/core/board-loader.ts` 的 MapData/MapTile 定义。
