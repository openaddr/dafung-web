# ADR-0047: 帧诊通道——对局屏自动采样 + 诊断包一键导出,真机卡顿取证

状态:已采纳(2026-11-01,用户问「能不能采集真机对战的帧率日志判断卡顿」即席拍板;第三波渲染治本 ADR-0045 的终审取证基建)

## 背景

前两波性能归因全靠桌面探针(CPU 节流 + 分层 A/B),桌面已到分辨率极限:合成器/栅格侧的卡顿(卓易通主嫌)在桌面测不出体感,真机「卡卡的」只有用户能裁。需要一条**真机取证通道**:把「哪类演出卡、卡在哪一层」从用户设备带出来。

对局日志(ADR-0014)是引擎事件流,类型化 schema,性能数据混入会污染 core 语义;胜利屏「导出日志」只在终局可达——用户测试常常不打完一局。

## 决策

1. **帧诊采样器(`frameDiag.ts`,app 层)**:对局屏挂载即采、卸载即停。三路:rAF 帧距直方图(5s 一窗,p50/p95/max)、longtask + LoAF 慢帧拆分(Chromium 123+ 的 long-animation-frame,每个 ≥50ms 慢帧自带 script 与 style/layout 耗时——浏览器自己写好归因)、演出上下文快照(fxStore 计数:行军会话/浮字/印章/铜钱飞行/指示线/金圈)。卡顿事件 = 帧距 >50ms,当场冻结上下文。
2. **诊断包(`diagExport.ts`)**:设置弹窗「性能诊断」行**局中随时导**(不需打完;行尾实时卡顿计数)。载荷三段:设备画像(发版号/UA/DPR/视口)+ 全部历史对局日志(`loadAllArchive`,IndexedDB 归档全量——归档是局中增量写,30 天保底内的含未打完局)+ 当前帧诊缓冲。文件名带发版号,收包即知对方跑的哪个 release。

   > 2026-11-01 修订(#952):原「版本号 + 构建戳两把尺」口径废止,构建戳全链退役(用户拍板)——诊断包 build 字段删除、文件名改用发版号;归因只留 release 一把尺。

3. **与对局日志分立 schema**:帧诊不混入 ADR-0014 的 `LogEvent` 事件流(core 不知 UI);导出独立 `dafung-diag-*.json`,判读表消费端直读。

## 承认的取舍

- **恒轻纪律是硬约束**:每帧成本 = 1 次数组 push;LoAF/longtask 只对慢帧回调;上下文 5s 一拍读 store(零 DOM 查询);缓冲全有界(窗 60/卡顿 500/慢帧 50/原始帧距 2000)。为测卡顿引入卡顿 = 通道自毁。
- **LoAF 能力位如实**(`loafSupported`):WebView 过老不支持时如实记 false——「无 LoAF 数据」≠「无卡顿」,判读表有对应行,不装假观察器。
- **采样覆盖不挑局**:单机联机都采(采样在客户端,联机真人局数据更真);但联机局的**对局日志**部分不在诊断包(在服务器 `data/logs/`),如实缺。
- **原始帧距不进包**(只进窗摘要):包体可控,判读表只吃分位;要逐帧看走档 3(WebView 远程调试)。

## 判读表(证据签名 → 结论)

| 证据签名                         | 结论                                        |
| -------------------------------- | ------------------------------------------- |
| LoAF 里 script 占大头            | 演出队列/React 侧(演出积压型)               |
| LoAF 里 style/layout 占大头      | 主线程仍有回流(渲染债)                      |
| LoAF/longtask 都小、帧距整体右移 | 合成器/栅格欠债(GPU 型,JS 无责——卓易通主嫌) |
| 卡顿事件按演出上下文聚簇         | 某类演出独,定点修                           |
| `loafSupported=false` 且帧距长尾 | WebView 过老,LoAF 盲区,档 3 深采            |

档 3(重型一次性):Tauri 安卓 debug 包开 WebView 远程调试,USB + `chrome://inspect` 全 Performance 面板;卓易通兼容层是否透传 adb 待实测定。

## 修订(2026-11-01 当日,用户实测反馈)

- **入口迁主页**:原设「设置弹窗『性能诊断』行局中随时导」——用户指出测试常不打完就退出对局,取证入口不该绑对局屏。修订:入口落**主页**(地图行下小字「性能诊断」,工具位不入玩法按钮列);帧诊停采定格收编 `lastDump` 跨屏存活,主页导出包含**最近一局**帧诊 + IndexedDB 全部历史对局日志。
- **胜利屏「导出日志」退役**:单局 jsonl 导出是诊断包的真子集,双入口冗余;按钮与 `gameLogExport.ts`/`scroll testids.logExport` 一并退役,对局日志导出语义由诊断包承接(ADR-0014 落盘通道不变,只是不再有单局文件导出按钮)。

## 验收

- 单测:窗口分位/LoAF 拆分/边界(空窗、起点倒挂夹 0)锚定(`test/infra/frameDiag.test.ts`);
- e2e:`react-diag-export`(局中导出,不打完)——下载 `dafung-diag-v*.json`,断言 kind/appVersion/build/UA/帧诊块/历史日志数组;
- 恒轻:采样器路径零 DOM 查询、零 React 重渲(计数读取在设置弹窗打开拍一次)。
