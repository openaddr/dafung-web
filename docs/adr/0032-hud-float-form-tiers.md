# 对局屏全浮层形态:金铲铲式构图与形态分档

日期:2026-10-27 收口(#703);拍板链:#678 定案图 → #680 形态分档口径 → #697 分票实施(spec ①-⑥,#698-#702 落地)。

## 背景与问题

旧对局屏是「顶部条 + 右缘席位竖卡列 + 底部仪表条」三区结构(#253 骨架):仪表条常驻 172px 深底横带吃掉下缘,席位竖卡 104px 宽整列压右缘,顶部条再占一条——棋盘被三面 chrome 框死;移动横屏(矮横屏 390px 高)下纵向空间所剩无几。#678 出定案图:对齐金铲铲(TFT)移动端构图——棋盘全幅垫底、是唯一主角,一切信息退为悬浮件,零常驻深底横条。

## 决策

五拍(拍板链 #678 → #680 → #697):

1. **定案图不施工**:#678 图只定形态方向;几何/字号/间距逐件以原型走查判决为准
   (tmp/席位侧列原型.html),不照图直抄。
2. **形态分档**:同构模板一套,按视口分两档——**矮横屏档**
   (`orientation: landscape and max-height: 500px`)= 全浮层紧凑档,允许重排;
   **桌面档**(其余一切横屏)= 布局零重排,密度/字号随视口舒展。修订
   [ADR-0018](./0018-mobile-landscape-only.md) 的「断点只调密度不重排」旧口径;
   「竖屏游戏布局永不做」原样维持。
3. **激进从简**:旧顶栏(目标身价/回合方字条/牌库角标/复位缩放静音钮)与底部仪表条
   (自局徽章区/托管钮/手牌漆木条)整体退役(#700)——现金/体力/属性计数归席位格,
   签面归手牌区,托管归席位格 tap 弹层(#701),音效归设置弹层。凡席位格或弹层
   可承载的信息,不再设第二常驻位。
4. **「桌面零变化」废除**:旧口径「断点外桌面零变化」翻面——桌面档给密度舒展
   (手牌卡与三圆钮适度放大),但仍不做桌面专属布局(#680)。
5. **观战不做**:观战(未入座)无手牌区无自机格,看席位条与诸侯总览即可,
   不为观战另设计形态。

## 构图(金铲铲式全浮层)

- 顶左两钮:诸侯总览 ☰ / 设置 ⚙(32×32,避 safe-area);
- 顶中:「N 轮」浮置 chip;
- 右缘:**席位条**——96×38 双行八项格,一人一格(自机入列),满编八席零滚动(#698);
- 底缘:透明手牌区——签面驻左端 + 手牌架,右下「锦囊」圆钮兼显隐开关(#700);
- 右下:藏品三圆钮(锦囊/珍宝 N/名将 N/3,#700);
- 弹层四件族:设置 / 诸侯总览(#702)/ 席位格 tap 单人纵深(#701)/ 藏品(珍宝/名将)
  ——常驻面只留锚点,纵深全走弹层。

## 关键几何

- 席位条满编列高 318px(8 格×38 + 7 道间距×2)≤ 326px(矮横屏主力档列区可用高,
  #697 拍板口径);更矮档(375/320)靠格高自适应 `clamp(30, (可用高−14)/8, 38)`
  继续保零滚动(下限 30);
- 列区可用高 = 视口高 − 顶距 8 − 钮区预算(钮高 + 底距:基准 44+10=54,桌面档
  舒展 52+10=62);
- 棋盘取景右让 104px(席位条 96 格宽 + 8 右距),棋盘在余幅内居中净空;
- 桌面档舒展(#703):手牌卡 em 基 8→9.6px(牌面 120×160→144×192),三圆钮
  44→52px;动作条锚点与列区下界两处几何随拍耦合。

## 后果

- 正面:移动横屏的纵向空间全给棋盘;全员信息密度由席位条一格承载;桌面「一般都能
  用」即可(移动端为主,#680),不为桌面过度设计。
- 代价:自机现金不再有常驻大数位(席位格与弹层两查);牌库余量不再展示(耗尽自动
  洗回);旧顶栏信息(目标身价等)归诸侯总览/设置弹层纵深。
