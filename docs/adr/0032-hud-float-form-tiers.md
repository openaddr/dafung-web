# 对局屏全浮层形态:金铲铲式构图与形态分档

日期:2026-10-27 收口(#703);拍板链:#678 定案图 → #680 形态分档口径 → #697 分票实施(spec ①-⑥,#698-#702 落地);2026-10-28/29/31 三轮修订与 2026-11-01 回合横幅退役的现行定案见文末「修订定案」。

## 背景与问题

旧对局屏是「顶部条 + 右缘席位竖卡列 + 底部仪表条」三区结构(#253 骨架):仪表条常驻 172px 深底横带吃掉下缘,席位竖卡 104px 宽整列压右缘,顶部条再占一条——棋盘被三面 chrome 框死;移动横屏(矮横屏 390px 高)下纵向空间所剩无几。#678 出定案图:对齐金铲铲(TFT)移动端构图——棋盘全幅垫底、是唯一主角,一切信息退为悬浮件,零常驻深底横条。

## 决策

五拍(拍板链 #678 → #680 → #697):

1. **定案图不施工**:#678 图只定形态方向;几何/字号/间距逐件以原型走查判决为准
   (tmp/席位侧列原型.html),不照图直抄。
2. **形态分档**:同构模板一套,按视口分两档——**矮横屏档**
   (`orientation: landscape and max-height: 500px`)= 全浮层紧凑档,允许重排;
   **桌面档**(其余一切横屏)= 布局零重排,密度/字号随视口舒展。修订
   [ADR-0018](./0018-mobile-landscape-only.md) 的「断点只调密度不重排」旧口径;
   「竖屏游戏布局永不做」原样维持。
3. **激进从简**:旧顶栏(目标身价/回合方字条/牌库角标/复位缩放静音钮)与底部仪表条
   (自局徽章区/托管钮/手牌漆木条)整体退役(#700)——现金/体力/属性计数归席位格,
   签面归手牌区,托管归席位格 tap 弹层(#701),音效归设置弹层。凡席位格或弹层
   可承载的信息,不再设第二常驻位。
4. **「桌面零变化」废除**:旧口径「断点外桌面零变化」翻面——桌面档给密度舒展
   (手牌卡与三圆钮适度放大),但仍不做桌面专属布局(#680)。
5. **观战不做**:观战(未入座)无手牌区无自机格,看席位条与诸侯总览(旧称,已废)即可,
   不为观战另设计形态。

## 构图(金铲铲式全浮层)

- 顶左两钮:诸侯总览(旧称,已废)☰ / 设置 ⚙(32×32,避 safe-area);
- 顶中:「N 轮」浮置 chip;
- 右缘:**席位条**——96×38 双行八项格,一人一格(自机入列),满编八席零滚动(#698);
- 底缘:透明手牌区——签面驻左端 + 手牌架,右下「锦囊」圆钮兼显隐开关(#700);
- 右下:藏品三圆钮(锦囊/珍宝 N/名将 N/3,#700);
- 弹层四件族:设置 / 诸侯总览(#702,旧称已废)/ 席位格 tap 单人纵深(#701)/ 藏品(珍宝/名将)
  ——常驻面只留锚点,纵深全走弹层。

## 关键几何

- 席位条满编列高 318px(8 格×38 + 7 道间距×2)≤ 326px(矮横屏主力档列区可用高,
  #697 拍板口径);更矮档(375/320)靠格高自适应 `clamp(30, (可用高−14)/8, 38)`
  继续保零滚动(下限 30);
- 列区可用高 = 视口高 − 顶距 8 − 钮区预算(钮高 + 底距:基准 44+10=54,桌面档
  舒展 52+10=62);
- 棋盘取景右让 104px(席位条 96 格宽 + 8 右距),棋盘在余幅内居中净空;
- 桌面档舒展(#703):手牌卡 em 基 8→9.6px(牌面 120×160→144×192),三圆钮
  44→52px;动作条锚点与列区下界两处几何随拍耦合。

## 后果

- 正面:移动横屏的纵向空间全给棋盘;全员信息密度由席位条一格承载;桌面「一般都能
  用」即可(移动端为主,#680),不为桌面过度设计。
- 代价:自机现金不再有常驻大数位(席位格与弹层两查);牌库余量不再展示(耗尽自动
  洗回);旧顶栏信息(目标身价等)归诸侯总览/设置弹层纵深(旧称,已废)。

## 修订定案(现行口径;中间翻案流水已删,git 史可考)

- **顶左行序与知会横幅槽(#731 拍板)**:顶左 **⚙ 设置 → ☰ 详情** 两钮(总览钮正名「详情」,弹层题名「诸侯详情」,GLOSSARY 登记);顶中让位**知会横幅槽**——统一槽位锚定顶中贴顶,**可排队**(先进先出依次播报,不被互相顶掉)、**同槽互斥**(同一时刻只有一条);瞬态横幅优先于等待条,横幅播完等待条自动回归;等待条(「X 正在抉择…」)与都城停宣告同槽作条带级知会(知会不压盘、不打断看盘)。
- **知会/响应分流铁律**(贯穿性原则,后续新增横幅类演出先归类再落位):知会类(纯播报、无点击)→ 顶中知会横幅槽;响应类(限时应答、带选项)→ 手牌架上缘(反应横幅现役形态不动,拇指操作路径不变);决策类(必须处置、带选项的全屏弹层:机遇三选一/定都确认/破产清算/胜利结算)→ BannerShell 族另论,维持全屏形态。响应件不得入槽,知会件不得落架缘。
- **标准分辨率原则**:**844×390 = 视觉设计与回归的唯一标准分辨率**——原型/mock 画布、截图自证(`shot.mjs` 默认视口)与 e2e 功能冒烟一律按此档;矮横屏专项档(667×375)与竖屏提示 case(390×844)保留;932×430 由弹性伸缩覆盖,不设档;桌面档维持「零重排、密度舒展」但**不设专项布局断言**,桌面只保功能冒烟。
- **回合宣告唯一形制 = 常驻回合胶囊(#958 拍板,翻两段式横幅)**:常驻胶囊(国号印+名号+「第 N 轮」)永答「谁在打」,所有回合(真人/bot 一律)只更新胶囊——key=id 重挂重播入场过渡即回合切换视觉信号;全幅回合横幅/两段式亮相/TurnNoticeFx 全链退役,whoosh 音退役不补(回合切换静音,掷骰签自带起手声),编排停留窗(FX.bannerMs/bannerHoldMs)退役,turnBanner 事件即发即忘。「N 轮」chip 同理退役,轮次唯一落胶囊。**不建跑马灯**:常驻滚动层与「事件离散通知也该离散」两判共同否决,重要事件知会另立票复用知会槽瞬态条带形制(滚入式、排队互斥)。
- **常驻胶囊与等待条同槽融合**:胶囊主体 = 回合方,等待条的「已候 N 秒」附加信息落胶囊右侧(等待对象=回合方时省名号);当前回合方棋子加金呼吸环(棋盘锚,与胶囊双锚点指名,reduced-motion 退化为静态细环)。
- **断线让位**:断线横幅与知会槽同踞顶中,横幅在场时 `--conn-h`(值 = 横幅体高 32px,不在场恒 0px)下发给知会槽 + 选都提示 chip + hint 行三消费方,整列下移后槽位落横幅底缘下 8px,与常态几何同距;断线是异常态,下移的槽件临时压到行 0 格顶可接受(常态零变化)。
