# 对局屏全浮层形态:金铲铲式构图与形态分档

日期:2026-10-27 收口(#703);拍板链:#678 定案图 → #680 形态分档口径 → #697 分票实施(spec ①-⑥,#698-#702 落地);2026-10-28 追记(#731 拍板、#733 落地)、2026-10-29 追记(#762 两段式亮相+常驻回合胶囊,见文末修订记)。

## 背景与问题

旧对局屏是「顶部条 + 右缘席位竖卡列 + 底部仪表条」三区结构(#253 骨架):仪表条常驻 172px 深底横带吃掉下缘,席位竖卡 104px 宽整列压右缘,顶部条再占一条——棋盘被三面 chrome 框死;移动横屏(矮横屏 390px 高)下纵向空间所剩无几。#678 出定案图:对齐金铲铲(TFT)移动端构图——棋盘全幅垫底、是唯一主角,一切信息退为悬浮件,零常驻深底横条。

## 决策

五拍(拍板链 #678 → #680 → #697):

1. **定案图不施工**:#678 图只定形态方向;几何/字号/间距逐件以原型走查判决为准
   (tmp/席位侧列原型.html),不照图直抄。
2. **形态分档**:同构模板一套,按视口分两档——**矮横屏档**
   (`orientation: landscape and max-height: 500px`)= 全浮层紧凑档,允许重排;
   **桌面档**(其余一切横屏)= 布局零重排,密度/字号随视口舒展。修订
   [ADR-0018](./0018-mobile-landscape-only.md) 的「断点只调密度不重排」旧口径;
   「竖屏游戏布局永不做」原样维持。
3. **激进从简**:旧顶栏(目标身价/回合方字条/牌库角标/复位缩放静音钮)与底部仪表条
   (自局徽章区/托管钮/手牌漆木条)整体退役(#700)——现金/体力/属性计数归席位格,
   签面归手牌区,托管归席位格 tap 弹层(#701),音效归设置弹层。凡席位格或弹层
   可承载的信息,不再设第二常驻位。
4. **「桌面零变化」废除**:旧口径「断点外桌面零变化」翻面——桌面档给密度舒展
   (手牌卡与三圆钮适度放大),但仍不做桌面专属布局(#680)。
5. **观战不做**:观战(未入座)无手牌区无自机格,看席位条与诸侯总览(旧称,已废)即可,
   不为观战另设计形态。

## 构图(金铲铲式全浮层)

- 顶左两钮:诸侯总览(旧称,已废)☰ / 设置 ⚙(32×32,避 safe-area);
- 顶中:「N 轮」浮置 chip;
- 右缘:**席位条**——96×38 双行八项格,一人一格(自机入列),满编八席零滚动(#698);
- 底缘:透明手牌区——签面驻左端 + 手牌架,右下「锦囊」圆钮兼显隐开关(#700);
- 右下:藏品三圆钮(锦囊/珍宝 N/名将 N/3,#700);
- 弹层四件族:设置 / 诸侯总览(#702,旧称已废)/ 席位格 tap 单人纵深(#701)/ 藏品(珍宝/名将)
  ——常驻面只留锚点,纵深全走弹层。

## 关键几何

- 席位条满编列高 318px(8 格×38 + 7 道间距×2)≤ 326px(矮横屏主力档列区可用高,
  #697 拍板口径);更矮档(375/320)靠格高自适应 `clamp(30, (可用高−14)/8, 38)`
  继续保零滚动(下限 30);
- 列区可用高 = 视口高 − 顶距 8 − 钮区预算(钮高 + 底距:基准 44+10=54,桌面档
  舒展 52+10=62);
- 棋盘取景右让 104px(席位条 96 格宽 + 8 右距),棋盘在余幅内居中净空;
- 桌面档舒展(#703):手牌卡 em 基 8→9.6px(牌面 120×160→144×192),三圆钮
  44→52px;动作条锚点与列区下界两处几何随拍耦合。

## 后果

- 正面:移动横屏的纵向空间全给棋盘;全员信息密度由席位条一格承载;桌面「一般都能
  用」即可(移动端为主,#680),不为桌面过度设计。
- 代价:自机现金不再有常驻大数位(席位格与弹层两查);牌库余量不再展示(耗尽自动
  洗回);旧顶栏信息(目标身价等)归诸侯总览/设置弹层纵深(旧称,已废)。

## 修订记

- **2026-10-28(#731 拍板、#733 落地):顶左行序与顶中知会横幅槽——移动横屏 844×390 标准原则**。实机(手机横屏)游玩暴露两处旧判词的代价:顶中被「N 轮」小 chip 占位,而知会类演出(换手回合横幅、都城停宣告、等待他人提示)各飞各的落点,顶部信息零散互抢;视觉设计与回归又长期以桌面视口为默认,与实机游玩设备脱节。三拍:

  1. **构图变更**:顶左行序定为 **⚙ 设置 → ☰ 详情 → 「N 轮」**——轮次 chip 视觉原样迁位(保留「轮」字浮置形态),与钮行基线对齐,safe-area 口径照旧;总览钮正名「**详情**」(钮名/aria-label/title 全链同步),弹层题名定「**诸侯详情**」(GLOSSARY 登记,与「城池详情」并存互不混淆)。顶中让给**知会横幅槽**:统一槽位锚定顶中贴顶(safe-area 口径照旧),**可排队**(知会事件先进先出依次播报,不被互相顶掉)、**同槽互斥**(同一时刻槽内只有一条);瞬态横幅优先于等待条——横幅播完等待条自动回归。等待条(「X 正在抉择…」)并入槽作常驻级知会,等待文案派生逻辑原样、只换渲染宿主;回合横幅入槽(落点从顶中偏下迁至槽位,漆金横幅带、飞入入场、时长全保留,时长仍走 Motion.dur.banner 单源,演出三不变量不破,ADR-0029);都城停宣告**降格为一条横幅带**,与其他知会同形同槽(用户明确拍板:知会不压盘、不打断看盘),号角音保留,震屏与编排占用按条带级校准。
  2. **知会/响应分流铁律**(贯穿性原则,后续新增横幅类演出先归类再落位):知会类(纯播报、无点击)→ 顶中知会横幅槽;响应类(限时应答、带选项)→ 手牌架上缘(反应横幅现役形态不动,拇指操作路径不变);决策类(必须处置、带选项的全屏弹层:机遇三选一/定都确认/破产清算/胜利结算)→ BannerShell 族另论,维持全屏形态。响应件不得入槽,知会件不得落架缘。
  3. **标准分辨率原则**:**844×390 = 视觉设计与回归的唯一标准分辨率**——原型/mock 画布、截图自证(`shot.mjs` 默认视口随之翻面)与 e2e 功能冒烟一律按此档;矮横屏专项档(667×375)与竖屏提示 case(390×844)保留;932×430 由弹性伸缩覆盖,不设档;桌面档维持「零重排、密度舒展」,但**不再设专项布局断言**——存量桌面对照 case(1280×800/1024×768)退役,布局回归收窄到标准档,桌面只保功能冒烟。

  本节修订 #700 时代「顶中 = N 轮 chip」的构图判词;上文「构图(金铲铲式全浮层)」节保留 #700 时代原貌作决策存档,现行构图以本节为准。

- **2026-10-29(#762 落地):知会槽内部修订——回合横幅两段式亮相 + 常驻回合胶囊**。#732 落地后移动端 UI 审计(#762 票面)实锤两处槽内代价:回合横幅 1800ms 单段播完即逝,「谁在打」在横幅消散后重归无字答案,bot 连续回合反复串播全幅大字段形同刷屏;且旧横幅渲染高(28px 字+padding≈46px)溢出 32px 槽体、与第二行 hint 净距不足 1px。三拍(知会/响应分流铁律原文不动,本节只修知会族内部形态):

  1. **两段式亮相**:回合横幅拆两段——前段大字亮相(入场动画原样,--dur-banner 之半 900ms;几何微调:字号 28→24、纵向 padding 6→4,渲染高 ≈40px),后段**收编**(--dur-slow 400ms 缩位淡出),终态落为槽内**常驻回合胶囊**——内容 = 国号印 + 名号 + 「第 N 轮」,横幅消散不带走,此后常驻显示当前回合方(「谁在打」永有答案)。都城停条带**不两段化**,照旧单段全长(fx-banner-fly 现为条带独占);JS 编排窗 FX.bannerMs 改两段全长 + 清理余量(--dur-banner/2 + --dur-slow + 100),停留窗 FX.bannerHoldMs 盖亮相段(收编段是背景动画,骰子可与之重叠)。
  2. **知会槽合并规则**:bot→bot 同轮连续回合的「X之回合」族不再串播全幅,只更新胶囊内容(无横幅音效、无编排停留窗);真人回合、每轮首个回合宣告(跨轮/首宣告)仍放全幅。判别条件写死在 fxStore 知会槽泵(isBot/round 随 turnBanner 事件提取拍烤定,播放期零读引擎),不留开放配置;合并语义只对「回合宣告」族生效,都城停条带/其他知会行为不变。
  3. **槽内三态融合与几何修正**:常驻胶囊与等待条药丸同槽位融合——胶囊主体 = 回合方,等待条的「已候 N 秒」附加信息落胶囊右侧(等待对象=回合方时省名号,不重复);三态(等待药丸↔全幅横幅↔胶囊)切换挂 150ms(--dur-fast)过渡。几何:hint 第二行 +48→+56,回合横幅下缘净距 ≥8px,844×390 / 844×360 两档均不溢出、不遮 hint 行;配套当前回合方棋子加金呼吸环(棋盘锚,与胶囊双锚点指名,复用席位活跃呼吸语言,reduced-motion 退化为静态细环)。
