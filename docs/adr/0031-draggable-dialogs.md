# 弹窗可拖动:居中弹窗题名拖动+遮罩联动减淡

游戏内弹窗(两壳全部成员)固定屏幕中心,打开即挡住背后棋盘——而决策弹窗恰恰是最需要**边看边掂量**的时刻:破产变卖想先清点名下城池,机遇抉择想看场上局势,招贤想掂量阵容。玩家此前只能凭记忆或关掉弹窗再看。旧卷轴壳曾有「拖到一旁」拖拽,BannerShell 换壳时以「横幅是宣告件,轮到即弹、选完即走,无常驻需求」为由随壳退役(#515)。该判词把**演出宣告**(选完即走,拖之无用)与**需要掂量的决策**(看着棋盘才能答)混为一谈——决策弹窗的常驻窗口期正是拖动的价值所在。2026-10-24 拷问翻案(#674),本 ADR 记录翻案理由与行为口径。

故决议:

- **诉求定位=纯看**:模态语义零改动——遮罩仍拦指针、焦点陷阱保留、Esc 与点遮罩关闭口径照旧;拖动只挪位置,不松交互。非模态化(弹窗开着操作背后 UI)是另一个量级的改造,不做。
- **范围=全部居中式弹窗,壳级内置**:`ui/dialog` 底件系出厂即带(PileShell 五藏品弹层/窥探/选宝/城池清单/技能全览/确认框/地图选择/锦囊详情桌面形态),`BannerShell` 横幅系全部成员(城池详情/购地/扩军/机遇/耗竭/招贤/破产/珍宝使/定制问询);业务弹窗消费方零改动。拖拽逻辑单源 `src/app/hooks/use-dialog-drag`(自研特许登记见[组件收口](../design/组件收口.md)豁免节)。
- **手势=仅题名行**:抓手光标示意;X/决策钮豁免(起点命中 `button` 不启动拖);10px 位移阈值保点击语义;桌面鼠标与触屏同款 pointer events(`touch-action:none` 只隔离题名行,内容区滚动不受影响)。整窗拖在触屏上是拖/滚/点三义打架,不做。
- **位置零记忆**:每次打开回中心,关闭即随卸载复位;横幅同实例换题名(#90 身份协议)随 resetKey 回中。会话内/持久化记忆都是过度设计,回中心让 e2e 与心智都最简。
- **边界=题名行任一部分不出视口**:窗体允许大面积拖出屏,靠题名行拉回——「会不会拖丢」的焦虑只系于把手,而把手永远可见。
- **遮罩联动减淡**:拖离中心(位移超出 ±24px 吸附带)遮罩墨纱减淡,拖回吸附带内松手自动吸附回正并复原,关闭复位。色值 2026-10-31 随 #870 玄墨底重定标:常态 `rgba(5,4,2,0.55)`、拖离 `0.25`(浅底时代 0.42/0.15 在漆黑底上 ΔRGB≈7 不可感,像素采样实锤);色值单源 hook 文件 `OVERLAY_TINT*`。只拖不减等于隔纱观望——遮罩全屏压暗,拖开弹窗后露出的棋盘仍是暗的,「看清楚」的诉求就只解决了一半。两档色值单源 hook 文件 `OVERLAY_TINT*`。
- **叠层 z 序不动**(横幅 30 / 底件 50),拖动不改层级。
- **不参与**:战报抽屉与贴底抽屉(停靠语义即其价值,浮窗化是另一种改造)、VictoryScreen(全屏覆盖非弹窗)、横屏提示层(形态门卫)。

放弃的替代:**非模态化**(焦点/指针管理重做,且「看」不需要「操作」);**整窗拖**(手势泥潭);**位置记忆**(见上);**抽屉浮窗化**(战报抽屉的价值就在贴边);**点遮罩临时透视/彻底去遮罩**(模态焦点语义还在,减淡即可,不必发明新手势)。
