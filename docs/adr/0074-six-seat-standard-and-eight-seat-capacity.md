# ADR-0074 六人标准局与八人上限

2026-11-26 接受，待实现。六人是开局默认人数，也是规则设计与平衡评估的基准。八人是对局人数上限。

开局由权威引擎用本局骰流随机排一次选都顺序。排在第一位的诸侯也先行动，此后按座次轮替。[开局](../reference/rules/02-开局.md) · [回合与轮次](../reference/rules/03-回合与行军.md#回合结束与轮次)

中原争霸沿用八城地图并开放八人对局。每位诸侯各建一座都城，选都候选随剩余城池缩减，最后一席从余下一城定都。八城均为都城期间，购地和普通持城收益暂时没有结算对象，都城补给、城池攻防和珍宝交涉继续提供行动机会。[中原争霸](../../packages/core/maps/zhongyuan.json) · [选都](../reference/rules/02-开局.md#阶段-3选都三选一) · [地产经济](../reference/rules/04-地产经济.md)

首版规划 24 名名将。每席最多招揽三名，八席满编时恰好覆盖全部名将。招贤展示池中实际可选的候选，仍可求书。[招贤规则](../reference/rules/08-名将与技能.md)

首版使用一副 56 张锦囊，六人局和八人局共用。八人局发过起手牌后，按八席每轮各行动一次、每次只摸一张估算，六轮正好摸完初始牌堆。己城补给和额外回合会增加摸牌次数。六人局用于校准常规牌序和回流节奏，八人局用于验证牌库周转与反应等待。[锦囊摸牌](../reference/rules/06-锦囊.md#摸牌)
