# 掷骰签:常规行军掷骰退出全屏制式,钤于回合胶囊侧旁

日期:2026-11-01;票:[#927](https://github.com/openaddr/dafung-web/issues/927);延续 [ADR-0030](./0030-duel-sign-face-presentation.md)(拼点签面,本篇不改动它)。

## 背景与问题

旧掷骰演出(全屏签面,#483 起)是「大事件制式」错配到最高频事件上:每次行军掷骰都全屏压暗(墨褐径向渐变盖住整张地图)+ 中央偏下骨牌大字签卡(96px 字/132px 卡)+ 摇签换字轮换(600ms 内 10 次换字,每 60ms 重绘一枚 96px 毛笔大字再随机微旋)+ 260px 落点金圈,人类全程约 2 秒、bot 半速约 1.5 秒。

用户实机三不满:**有点大、晃眼、卡顿**。晃眼与卡顿同源——换字轮换是低端 WebView(卓易通档)的持续掉帧通道,压暗幕是全屏渐变的两次合成;而「骰值在引擎里早已确定」的前提下,换字轮换纯属悬念表演。行业惯例(Monopoly GO/大富翁 4/Ludo 类/桌游数字平台)也一致:常规掷骰小体量、跟当回合玩家身份 UI 走或浮在棋盘上,不压暗幕、不占中央;全屏只留给大事件。这与 DESIGN §6 的既定层级(震屏/全屏仅限全场级大事件)同构。

## 决策

拷问两轮收敛(2026-11-01,拍板记录;「骰子可以稍微有一点延迟,但不要再有乱七八糟的动画」):

1. **形制**:常规行军掷骰改「**掷骰签**」——小签卡(64px 字/约 90px 卡,骨牌材质字面量存续)钤于顶中**回合胶囊**侧旁(「谁的回合+第几轮+掷几点」聚簇一处);虚位淡现身(静态 ~250ms,无换字无旋转)→ 真字 outBack 钤落(260ms)+ 骰落声 → 停留 400ms → 渐隐 250ms,单程约 0.9s。裸点数,不标掷骰者(归属由回合胶囊与席位高亮表达,DESIGN §4.6)。定位锚点=知会槽内的**常驻零宽锚点件**(几何恰在胶囊右缘,随槽挂载与槽同寿)——不读胶囊节点本身:bot 配速关 0 的批洪流下,横幅演出可能作为过时批被吸附作废(ADR-0029),胶囊节点合法地不物化,瞬态节点不可为锚(实测实锤:首实现读胶囊节点,react-solo 四例被锚点 throw 连环打断)。
2. **退役清单**:摇签换字轮换、全屏压暗幕、落点金圈、起手沙锤音、bot 半速分档(diceFast 整条,含表现事件的 `fast` 字段与 audio 的 `diceRoll` 合成音)。
3. **单节拍**:人类/bot 同参数。这是「**统一原则**」(能一套就不做两套;仅语义不同才分形制,禁止按玩家身份或运行模式分参数档)的首例执行,原则随本票入 AGENTS.md。
4. **常驻锚点不动**:左下**签面**芯片继续驻留点数,落定拍揭示机制(#849)保留——瞬态确认在上(胶囊侧旁),持久记录在下,两处各司其职。
5. **范围边界**:拼点签面(ADR-0030)零改动;探宝拼点维持现状(本就无骰面演出,浮字+战报表达);回合横幅→掷骰的串联节奏(bannerHoldMs)不动,并行化另票观察。
6. **术语**:一次性演出正典名「掷骰签」(与「拼点签面」同族);「签面」词条改写为只指左下常驻徽章。否决「掷骰浮签」——「浮签」已是 hover 名词释义气泡的用词,撞词。
7. **行业查证支撑落点选择**:Monopoly GO=小体量骰掷在棋盘上方不压幕;大富翁 4=当前玩家头像面板旁;Ludo 类=玩家所属角落;BGA=toast 跟头像。「跟回合读数聚簇」落在惯例上。

## 后果

- 晃眼与卡顿的两个人为源头(60ms 级大字重绘+全屏渐变合成)随改造拆除;每回合编排链缩短 ~0.5–1.1s。
- 回合胶囊成为掷骰签的视觉邻位(锚点件=槽内常驻零宽件,缺席即炸——零兜底);吸附作废横幅批时掷骰签照常钤落,不受演出作废面牵连。
- GLOSSARY 同批:「掷骰签」新增、「签面」改写;rules 03/10、DESIGN §6 骰子段同步回填。
- 后续候选(不在本票):掷骰与回合横幅并行化、diceRolled 的同步件延后窗(deferSync)在无幕时代是否有必要重审。
