# ADR-0029:演出自洽三不变量——提取即定格、单写者、落后即校准

日期:2026-10-19
状态:已拍板(拷问会 2026-10-18,四票决议收口 #597/#598/#570/#599;行为落地随实施票)

## 背景

权威引擎推进与客户端演出播放是两条速率悬殊的流水线:服务端产出可以毫秒级连跑(bot 连锁零延时同步、快档托管每步 40ms 级),客户端演出按实速串行播(单回合数秒)。这条裂缝在三个场景同时漏水(2026-10-17 四路取证,票 #570):

1. **行军乱跳、落点错**——锚定、播放、状态折叠三者无归属锁:`anchorMarches` 在播放队列外无条件覆写棋子锚点,动画在队列内串行播,事件折叠又在队列外推进状态。播放期还活读可变引擎态(按棋子 id 查玩家现值、按播放时刻的占位算槽位偏移),bot 零延时推进后读取即失配——「第五步跳走」「落错槽」皆源于此。另有一个确定性 bug:同批同 id 双预塞时第一段锚点被覆写,「有锚即复用」守卫令第一段从第二段起点开播。
2. **演出积压**——产出速率高于播放速率时播放队列无界堆积:普通对局每轮人类要陪跑整批 bot 演出数秒;快档托管整局秒级跑完、实播却要数分钟(积压数十倍);全 bot 观战瞬时全额生成、实播全场(积压千倍级)。终局封场(#569)修掉的骰子压屏只是这条裂缝的特例。
3. **交互锁永续**——`canAct` 的 `fxPlaying` 门挂「全局表现队列排空」,演出积压即交互持续关门;托管局产批节拍快于单步播放节拍,锁在结构上趋向永续(与 ADR-0028 托管单节拍口径的结构性冲突)。

三仓先例研究(#600,存档见研究分支 `research/catchup-precedents` 的 `docs/research/2026-10-18-catchup-precedents.md`,研究分支永不合并)给出方向裁决:colyseus / boardgame.io / FreeKill 无一家「锁交互等演出排空」——演出落后从不反压交互输入;落后检测应当**分类**(持续发散 vs 瞬时抖动)而非布尔;校准分两档(硬吸附只给无因果意义的跳变,渐变给有因果的误差);丢弃判据挂到达序,不挂墙钟。

本 ADR 把四张决策票的决议立为三项演出自洽不变量与一条交互锁口径,供实施票施工。

## 决策

### 1. 不变量①:提取即定格

**表现事件在提取拍算死播放所需的一切,播放期零读可变引擎态。**

- **行军全烤 keyframes**(#597):提取拍按 `prePositions` 与批终引擎态把整条行走序列算死进 `tokenMoved` 事件——每段「起点中心 → 弧线途经点 → 终点(含落格槽位偏移)」的坐标数组;播放器纯哑渲染,逐帧写 transform,连棋盘对象都不摸。`PresentationEvent` 是客户端内存对象、不跨线,零带宽代价。棋盘布局等静态几何是提取拍与播放期都不变的事实,豁免于本不变量。
- **FxSink 全坐标化,删引擎 getter**(#597):所有 sink 方法收烤好的坐标——行军两法收 keyframes,印章与落点脉冲收 (x, y);起签印在到达同步点换算坐标再进 sink;`createEngineSink` 的引擎 getter 参数删除。**FxSink 类型签名 = 「播放期摸不到引擎」的编译期证明**。
- **类型 + choreography 双守卫**(#597):类型层管 sink 接口(上条);运行时层在 choreography 不变量族(`test/choreography-invariants.test.ts`)新增一条——「提取完成后引擎继续推进,再播放,逐帧坐标与预计算完全一致」(memory sink 断言),防提取器内藏活引用延迟求值。
- **批内近似豁免与绊线**(#597):提取期取批终态的近似保留两处——锦囊指示线端点与得宝印格;行军提取的转移前位置比较改用事件自带字段(零成本修正)。豁免的前提是**相位互斥**:行军/出牌/交涉独占状态转移,同一座位批内 position 至多变一次,真实对局触发不了错位。**绊线**:将来引擎引入「同座位批内多段位移」的新机制时,此处近似必须重审。

### 2. 不变量②:单写者

**每枚棋子的视觉位置同一时刻只有一个写入者;归属单位是 per-id 行军会话。**

- **跨批顶替 = 立即取消**(#598):同 id 新批锚到达,在途旧动画自终止(per-id 会话令牌,段边界生效)。语义与不变量③「过时演出无因果意义」同族——重叠只发生在队列积压时,让在途播完 = 纯陈旧演出。
- **切换点直切,禁 glide**(#598):新动画从新路径起点一帧直切(豁免 CSS 过渡)到位再逐段走;顶替/锚定切换点禁止滑动过渡——棋子的既有 CSS 过渡与动画内联时长正是今天「乱跳」观感的物理通道,在切换点焊死。动画对自己的路径负责(与不变量①哑渲染同构),不为罕见病态场景拼过渡段。
- **同批多段 = 段队列衔接**(#598):同批到达的多条同 id `tokenMoved` 在同一会话内按序排队播(预塞即追加段);**顶替只发生在跨批**,判据 = 批到达序。「有锚即复用」的双预塞错接起点 bug 随会话化一并消灭。
- **预塞保留,语义会话化**(#598):到达拍预塞(锚定)保留——删了就是骰子期「闪现终点再拽回」;但锚定不是动画:新批预塞对在途 id 即顶替、同批预塞即追加段。断线重连边界(`resetEventFace`/`dropStalledBatch`)对全部在途会话统一作废(`abandonMarch`)——「旧演出无因果意义」同一语义,与不变量③的「边界清待播队列」共用动作。

### 3. 不变量③:落后即校准

**演出落后于权威产出时,治理演出,不锁人、不硬等。**

- **判据 = 混合尺,分类非布尔**(#570):主尺 = 未消费批数(`netStore.eventBatchSeq` − `SnapshotEffects` 消费游标,机器时间,负载免疫、e2e 天然不误触发);辅尺 = 最早未播批的等待时长(防单批超长漏报)。单次超线只升追帧档,**连续 N 批超线才升吸附档**——瞬时抖动平滑吸收、持续发散才校准(colyseus drift 三分分类同构,#600)。N 与阈值常量进 `fx/timings` 吃 `sc` 并登记 e2e-time-scale 恒等快照组,数值由实施票观感定标,本 ADR 不落数。
- **响应两档:追帧 → 吸附**(#570;重档决议原文称「丢弃」,本 ADR 定名「吸附」,GLOSSARY 已登记):轻档**追帧** = `sc()` 运行时化(由模块加载时读 localStorage 常量,改为可被队列状态驱动的运行时倍率),积压越深播得越快,倍率上限为 1.5~3x 全演出压缩;重档**吸附** = 封场剩余未播块(在途会话统一作废收队,棋子直切引擎终态)。**追帧倍率上限即两档分界**:追到顶仍追不上才丢。浅积压用渐变手段(加速播 = 演出仍在),深积压才硬吸附。
- **观感全静默**(#570):不设任何玩家提示;开发诊断面留痕(console.debug + `__dafung` 调试桥计数,e2e 可断言、现场排查可取)。战报不加——ADR-0014 纯归档记命令,不记表现事件。
- **反应窗无豁免**(#570):吸附封场全部未播块,不因批内含反应窗前因而保留。依据:ADR-0017 既有语义 = 窗逻辑(倒计时/代答)权威侧自走、零依赖演出(controller 的反应窗分支本就不吃 `fxPlaying`);吸附后棋子直切终态、横幅倒计时照常。吸附后余段基准与转移前位置的对齐口径由实施票处理。
- **落地挂点**(#570):判落后度定档挂 `SnapshotEffects.play()` 的 fxQueue 出队点(present 前);提取照跑(跨批游标 `cursors.lastAnnounce` 不可断);重连边界清待播队列与不变量②共用动作。

**判据基调(零兜底口径)**:丢弃/吸附是「过时演出无因果意义」的**生命周期语义**,与断线即丢(ADR-0020 决策 4)同构,不是静默容错——它治理的是「演出落后于权威」这一确定事实,不掩盖任何引擎 bug,引擎逻辑错误照旧炸出来。与终局封场(#569)**正交**:追帧治不了骰子压屏(封场治),封场治不了观战回放积压(追帧治)。治理顺位:产出端节拍已由 ADR-0028(托管)+ [ADR-0034](./0034-bot-step-pacing-lag-recalibration.md)(bot 配速,#730 修订:原句「已收口、播放侧无需配套」的前提只覆盖托管,bot 0ms 连锁致校准成每局常态)收口为单节拍;判据阈值亦随 ADR-0034 再定标(正常局水位之上)。

### 4. 交互锁解绑:canAct 改绑本座位演出

- **解锁规则 = 只等自己棋子到位**(#599):`canAct` 的 `fxPlaying` 门从「全局表现队列排空」改绑「**本座位相关演出**播完/被追帧放完/被跳过」——本座位 `tokenMoved` 全部落定(即不变量②的会话语义)即放锁。轮到你时别人的棋子照飞、城池宣告照播,决策卷轴照弹、按钮照点;你的等待上限 ≈ 自己那步动画的时长,队伍积压由不变量③清理。否决口径:绑「决策方相位演出」(对还没走到的城做决定,空间感崩)与「被注视座位」(根本限制仍在)。
- **提示统一一把锁**(#599):「能不能操作」单一口径 = `canAct`(新规则 + `pending` 命令回音锁保留防重复提交);「行军中…」提示与按钮同源 `canAct`——亮一起亮、灰一起灰,消灭「提示消失按钮仍灰」的分叉观感。既有反应窗例外分支不动(ADR-0017 语义不受影响)。

## 后果

- **修订既有决议**(已在原文标注):ADR-0020 决策 3 的校准触发源扩为「服务端结算节点 + 客户端按积压自吸附/追帧」两道;决策 4 补「吸附 = 断线即丢的局内同构」;ADR-0010 关联节的 tokenMoved 联机载体句改写(注入通路已随 #385 退役)。
- **实施触点**(供实施票,非本 ADR 交付):提取器烤 keyframes;`sinks.ts` 全坐标化删 getter;起签印坐标换算;`useMarch` 哑渲染消费与 per-id 会话(全局代际号 → Map<id, 令牌>、活跃集 → Map<id, 会话>、`endMarch` 会话主校验、`abandonMarch` per-id 化、C5 订阅器换 selector 订阅);`anchorMarches` 追加段/重置语义;TokenLayer 直切样式通道与落位公式同源校验;`SnapshotEffects` 出队点判档;`controller.ts` 的 `canAct` 判定与 GameScreen/WaitingBar 提示源统一;对应测试面(`presentation.test` 直译断言、choreography 定格不变量、local-room 「interactive==排空」钉子改写、controller-policy 全输入空间表扩维)。
- **词汇**:提取即定格/单写者/行军会话/落后即校准/追帧/吸附 已登记 GLOSSARY「表现」节。
- 玩家可见行为的文档回填(rules/03、联机架构 §5 与「回前台追平」句、DESIGN)随行为落地归终验票 #612,本 ADR 只立法。

## 备选

- **只烤落点、弧线现算**(#597 否):提取拍信息完备,现算即播放期摸引擎,病根不除。
- **保留引擎 getter,只加运行时断言**(#597 否):类型不封口,「播放期摸引擎」永远只是纪律不是事实。
- **批内近似全折叠修正**(#597 否):相位互斥下真实对局触发不了错位,为其加提取器折叠复杂度不值;绊线已立。
- **顶替允许播完 / 从当前视觉位置拼过渡段**(#598 否):播完 = 纯陈旧演出;拼过渡段是为病态场景造机器。
- **判据挂墙钟批龄、布尔一刀切**(#600 推翻):墙钟负载敏感、e2e 易误触发,单布尔不分类。
- **玩家可见积压提示 / 战报记校准**(#570 否):观感全静默;战报纯归档不记表现事件。
- **反应窗前因豁免**(#570 否):窗逻辑权威侧自走,豁免只会造出「演出特权批」特例。
- **锁绑决策方相位 / 锁绑被注视座位 / 维持全局排空**(#599 否):现状即锁永续病,后两者见决策 4 否决口径。
