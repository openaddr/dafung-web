# ADR-0024: 宝物城与普通城池并权,落格结算顺序定序 (已废:正典「珍宝城」, #825)

日期:2026-10-11
状态:已接受(2026-10-11 设计拷问会,用户拍板「宝物城也应允许购买,跟普通城池一样才对」;触发顺序设计权下放实现侧) (已废:正典「珍宝城」, #825)

## 背景

宝物城(TileType `"TreasureCity"`)是全图唯一天然不可购买的城池格:无经济字段、无归属、无图标(客户端渲染成无 group 的建筑怪态),落格唯一行为=拼点探宝(2d6≥珍宝等级,失败回堆底)。用户判定:城池就该可购买——宝物城与普通城池的差别应当只是**多一件落格探宝**,而非经济上的二等公民。 (已废:正典「珍宝城」, #825)

同时,落格结算的真实顺序(机遇 roll → 城池/特殊格分流)此前只散落在 `resolveLanding` 的分支代码里,无任何文档定义;本次借宝物城改道把它定成正典。 (已废:正典「珍宝城」, #825)

## 决策

1. **宝物城与普通城池完全同权**:loader 为 `TreasureCity` 建立与 `Property` 同口径的 catalog(完整经济字段:price/buildCost/valueByLevel/tradeMult/tradeAdd/group/region——region 已随 #828 区域单源化退役),赋 propertyId,**可购买、可扩军、可交涉、可公道买卖、可当选都候选**(`isCapitalEligible=true`)。TileType 保留 `"TreasureCity"` 成员不收编——它承载渲染身份与规则叙事,探宝挂件随 type 走。
2. **落格结算顺序定序为正典**(写入 rules/03 与代码注释):**机遇 roll(既有前置,仅天命格豁免——该豁免面已随特殊城池制退役,见 [ADR-0037](0037-special-city-event-field.md))→ 城池交易链(购地/扩军/按兵不动/珍宝交涉,含买不起等自动拒绝;一次落格至多一段)→ 探宝**。宝物城的探宝固定挂在交易链尾:链上任何终端(买成/升成/按兵不动/交涉三择/自动拒绝/他人城无宝)之后必触发一次探宝;链中途转入清算或破产则探宝不触发;探宝结算自带 endTurn。探宝本体(抽一件→2d6≥等级→得宝/回堆底)逻辑不变。
3. **数量调平**:huanyou/chessboard/sanguo 三图各新增 3 座宝物城(4→7),既有 4 座补全经济字段;zhongyuan(8 格纯买地小图)不参与。新城约束:与既有宝物城环距不相邻、过地图生成断言(huanyou 无三连同型/间距)、价格取邻近城档位、三图同 id 同名同 group/region(region 已随 #828 退役)。(**2026-10 注**:chessboard/sanguo 两图已随 [ADR-0025](0025-map-consolidation.md) 收敛移除,本项调平最终只在 huanyou 落地。)
4. **术语**:GLOSSARY 新增「宝物城」词条;「拼点」词条登记两义(锦囊/拦检=双人对骰;探宝=2d6≥珍宝等级的单人判定),不改名。 (已废:正典「珍宝城」, #825)

## 后果

- 选都候选池扩大(三图各 +7 候选);己方都城化的宝物城落格走驻跸(补给+招贤),不探宝——都城特化流先于城池结算,与普通城一致。 (已废:正典「珍宝城」, #825)
- bot 购地启发式(`cash > price×1.5`)自动适用新城,无 bot 特判;宝物城定价档直接进入 bot 决策。 (已废:正典「珍宝城」, #825)
- 联机侧 `event-fold.ts` 的落格镜像推演必须同步(宝物城有 propertyId 后走城池折叠路径),否则折叠相位漂移。 (已废:正典「珍宝城」, #825)
- 客户端宝物城获得 group 色带/归属/等级渲染,图标独立标识「宝」身份;TileDetailScroll 文案改为可购买。 (已废:正典「珍宝城」, #825)
- 探宝先于交易被否:交易是决策相位,探宝若在其前派发 `TreasureGained` 等时机,会在决策挂起期间触发技能效果,交错难审计;交易链尾探宝保证时机全部在结算点派发。
- 独立「探宝标志」字段方案被否:TileType 已承载身份,再造一个布尔字段是第二事实源。

## 备选

- 宝物城收编为 `Property` + 探宝布尔标志:被否——丢失渲染/规则身份,编辑器与规则叙事都要另立「哪座是宝物城」的口径。 (已废:正典「珍宝城」, #825)
- 探宝先于交易(机遇→探宝→交易):被否——决策相位挂起期间派发时机交错,且「先得宝再问买不买」观感割裂。
- 宝物城不参与交涉(探宝专属):被否——「跟普通城池一样」= 交易面无豁免;城主无宝时探宝自然独占,已满足「探宝入口」定位。 (已废:正典「珍宝城」, #825)
