# 授技分布:均匀掷改几何衰减

日期:2026-11-01;票:[#969](https://github.com/openaddr/dafung-web/issues/969)。

## 背景与问题

#787/ADR-0036 的授技公式 = 基数 1..池大小**均匀**掷 + 池内 Fisher-Yates 取前 k。三技将每档概率同为 1/3、华佗二技池为 1/2——「得将带满池技」是每两三次得将就撞上一回的常事。用户实局中经机遇「以宝换贤」(两珍宝换一将)来投的武将带全部技能,预期却是「大概率一技、小概率两技、极小概率更多」;均匀分布与设计意图错位:多技从稀罕事变成常事,得将的戏剧性被稀释。

## 决策

拷问一轮收敛(2026-11-01 拍板):

1. **基数服从几何衰减**:P(k) ∝ (1/5)^(k-1),衰减基数 5 定死为单一常数(`roster.ts` `SKILL_DECAY_BASE`),三送将路同一公式、不按将配表。三技将 1 技 25/31(80.6%)/2 技 5/31(16.1%)/3 技 1/31(3.2%);二技将 5/6(83.3%)/1/6(16.7%)。
2. **衰减率选 1/5 而非 1/2**:候选 1/2、1/3、1/4、1/5 四档对比后,用户判 1/2 档「衰减太慢」,拍 1/5——81/16/3 的三档形状逐字命中「大概率/小概率/极小概率」的语义;更陡(1/10 级)则满池趋近传说、两技存在感偏薄,不取。
3. **强度下调接受**:三技将期望授技数 2.0→1.23、华佗 1.5→1.17。池大小旋钮语义随之改变:陡衰减下期望几乎不随池大小变,池大小改调**多技尾部**(满池存在感),不再线性调期望。
4. **实现纪律不变**:仍单掷定基数(整数权重 5^(池大小−k) 求和反变换落档)+ Fisher-Yates 洗牌定成员,骰流消耗次数不变(1 + 池大小−1);「至少一技」天然成立、零保底;招贤预掷明牌机制不动(卡面亮什么 = 实际入麾下什么)。

## 后果

- 满池从 1/3~1/2 的常事降为 3.2%/16.7% 的稀罕事,「得满池将」成为对局中的可炫耀事件;名将整体强度下调,既有局里满池将的强势感缩水。
- 数值观察点转移:原「期望=2 是否过强」改为「衰减档位是否合适」;若未来要回调强度,旋钮是衰减基数(常数)与池大小(数据表),公式形状不动。
- 测试重钉:hero-skill 均匀性抽样测试改**衰减形状护栏**(全档可达无空洞 + 频次单调递减 + ±3σ 外宽护栏防 flake);同 seed 确定性重放测试不受影响(骰流次数不变、数值映射变,重放自身仍一致)。
- e2e 无 `skills=` 断言,钉谱不受授技结果变化影响;确定性引擎测试谱随骰流数值分叉,靠全量 bun test 验证(改公式必跑)。
