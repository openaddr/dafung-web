# ADR-0014 对局日志系统

日期:2026-08-26
状态:已接受(2026-08-26 与用户四项决议对齐)

> **2026-10-04 更新**:重放校验职能由 [ADR-0021](./0021-drop-replay-and-hash-instruments.md) 取代——重放校验器(`scripts/replay-log.ts`)与自证测试已删;日志**写入保留为纯归档**(局头行/cmd 行/终局行照写,双轨落盘与清理不变),不再承诺跨版本可复现。

## 背景

需要"从日志几乎完全复现一局游戏"。现状缺口:LogEvent 无时间戳/轮次、无局头(地图/seed/座位)、部分事件未记(三候选/托管/房间进出)、无独立日志文件、无清理机制。

## 决策

1. 联机在服务器逐局追加 JSONL，本机按局归档到 IndexedDB，支持按局导出。
2. 日志包含中文简报和机读详情。局头记录局 ID、地图、种子、座位、起始现金和目标。后续记录玩法、技能、命令、房间状态和终局。
3. 服务器启动时、本机归档新局时分别清理过期记录。

现行字段、写入点及留存见[对局日志与诊断](../reference/对局日志.md)。
