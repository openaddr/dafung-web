# ADR-0038: ink token 改名对齐纸色语义(paper 系)

状态:已采纳(2026-10-31,UI 二轮收官拷问会拍板)

## 背景

#509 玄墨鎏金换血把主题从浅底反转为深底,「墨系」token 值随之整体翻转,但名字没跟着改:`ink` 名叫墨、值是纸色 f4ecd8(正文/标题字);`inkDim` 名叫淡墨、值是淡纸 c6b491;`inkwash` 名叫淡墨、值是暗金棕 9c8a5e。token 是主题模块的词汇表接口——接口名字撒谎,每个调用点都在付理解税。首次咬人:#867 拼点泼墨引 `--color-ink` 当墨色用,渲成米白洗版糊住点数(反馈环实锤,修复见 #867)。

## 决策(路线 A:改名对齐值,值零变化)

| 现 token                                 | 值     | 实际语义              | 新名                                                                                                                               |
| ---------------------------------------- | ------ | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `ink`                                    | f4ecd8 | 纸色·正文/标题        | **`paper`**                                                                                                                        |
| `inkDim`                                 | c6b491 | 淡纸·次级文字         | **`paperDim`**                                                                                                                     |
| `inkwash`                                | 9c8a5e | 暗金装饰(远山/书法线) | **`goldWash`**(色相归金族、低亮度,CSS var `--color-inkwash→--color-gold-wash`,kebab 管线机械产物,与 `inkDim→--color-ink-dim` 同构) |
| `lacquer` / `lacquerGold` / `--hairline` | —      | 漆木/漆金/发丝线      | 不改(名实相符或已中性)                                                                                                             |

改后纸族四阶 `paper/paperDim/paperHi/paperLo` 语义自洽;单源 `core/theme.ts` 改名 → gen:theme 产出 CSS var 随动 → 全消费点机械替换 → 单测钉值镜像同步。**一次性改齐不留旧名 alias**(项目明规不考虑兼容性)。

## 例外细则

- 「墨线/水墨」是**风格语汇**不是 token 名:画心墨线、Sym 墨线、`ink-art/` 目录、`inkBloom/inkBlot` 动画(真墨视觉本体)全部保留;
- lacquer 系的「墨=落子无悔」语义由漆木承担(#509 定案),不受本改名影响。

## 验收

改名 PR 的最硬门槛 = **改前后整屏渲染逐像素全等**(值一个不动,渲染输出必须 byte-identical;typecheck/test/build 全绿之外加此条)——防机械替换手滑改值。

## 后果

- 正面:词与物对齐,词汇表纸族四阶自洽;后续主题工作不再付「名叫墨其实是纸」的理解税;
- 代价:一次性全仓替换(≈98 处 CSS var + TS 消费点),机械但量大;旧名在 git 历史与 ADR-0038 可溯;
- 实现票:随本 ADR 同 PR 落地(机械改名+像素全等自证)。
