# ADR-0039: 棋盘氛围层——常驻装饰动画出 SVG 入 HTML 合成层

状态:已采纳(2026-10-31,卓易通卡顿归因拷问会拍板)

## 背景

2026-10-31 用户实机报告卓易通(鸿蒙 NEXT 安卓兼容层)里对局严重掉帧。归因探针(桌面 Edge + CDP CPU 节流,844×390×DPR3,seed 2026)实证:

- 桌面 CPU 基线即有 **60fps 下主线程 43% 常态占用**,layout+style recalc 恒定 **64 次/秒**——静止期也在烧;
- JS 逻辑只占 ~1%(非逻辑慢);DPR 3 vs 1 帧率完全一致(非像素填充率瓶颈);
- 分层冻结实验:藏 fx 特效层无效、藏棋盘或禁 CSS 动画即归零、冻结引擎时钟 churn 照跑 → 来源是**棋盘 SVG 内的常驻 infinite CSS 动画**;
- 4x 节流(中端手机档)主线程饱和,掉到 12~~23 fps;6x 仅 5~~7 fps ≈ 用户「好卡」体感。

根因机制:棋盘是一整张 `<svg id="board">`(纸面不透明底 + 40 城 + 棋子 + 特效),Blink 对 SVG 子元素的样式/几何变化按整张 SVG 失效——任何子元素每帧变动 = 每帧全板 style recalc + layout + 重绘记录,全在主线程。而 board.css/layout.css 有**五组永不停歇的常驻 infinite 动画**逐帧污染:旗面摇曳(`bv-flag-sway`)、都城光晕脉动(`bv-pulse-glow`)、活跃格虚线环(`bv-ring-march`)、自机光环呼吸(`bv-mine-halo`)、回合方金环呼吸(`bv-token-active-breath`,layout.css,#762)。桌面余量扛得住,手机(4~8 倍慢)直接饱和,卓易通兼容层再打折。

SVG 子元素动画拿不到合成器(Blink 不给 SVG 内部子树独立合成),「SVG 内优化」无解,**出路只剩把这些元素搬出 SVG**。

## 决策

新设**氛围层(AmbientLayer)**:棋盘 SVG 的 HTML 兄弟层(`#board-wrap` 内 absolute 铺满、`pointer-events:none`),五组常驻装饰整体迁入,动画变 HTML 元素上的 transform/opacity CSS 动画——Blink 对可合成属性走合成器线程,**主线程零逐帧参与**。

1. **迁移清单**:都城光晕、活跃格虚线环、棋子旌旗(含国号字)、自机微光圈、回合方金环。旌旗/光环/金环原是 token `<g>` 子节点,随氛围层出 SVG;SVG 侧 Token/Tile 删除对应节点(净减动画元素,静态美术不动)。
2. **行军换装**(Q1a 拍板):行军接管期(`skipTokenIds` 在册)该棋子的旗/光环/金环**暂隐**——行军强调已有金边拖影+落脚指示环(#30),0.5~1s 行军里不缺这两件;落定即回(同一响应式 marching 集,无逐帧同步)。行军金环与候选呼吸(#256)、选都脉冲等**阶段性** infinite 留在 SVG(只在相位窗内存活,非常驻污染)。
3. **活跃环改 rotate**(Q2 拍板):`stroke-dashoffset` 永远吃不到合成器(绘制属性),改虚线环整体 `transform: rotate` 等效——虚线周期 21 单位/1.3s 的爬行速度换算为 r=80 圆周整圈 31.12s 匀速旋转,方向与原 dashoffset 推进同向(顺时)。旧「dashoffset 而非 rotate」注释的依据(AABB 漂移令 playwright 点击稳定性检查超时)随环出 tile `<g>` 自动消解:氛围层 `pointer-events:none`,tile 包围盒不再被环污染。
4. **都城光晕保真**:氛围层盖在 SVG 之上(SVG 纸面不透明,「垫底下」不可行),原「亮心被城台遮挡、只露外圈」的观感用 **SVG mask 挖城台形孔**逐像素复刻(渐变色标不动);不再用近似环形渐变。
5. **pan/zoom 跟随**:usePanZoom `apply()`(viewBox 单写者收口点)扩展可选 onSync——同一节拍把 viewBox→客户端矩阵(`translate(ox-vx·s, oy-vy·s) scale(s)`,meet 等比)写进氛围层容器 transform;挂载/resize 由 ResizeObserver 补同步。装饰子元素一律以世界坐标(逻辑单位=px)定位,容器一层矩阵全包。
6. **槽位单源不破**:旗/光环/金环的落点 = TokenLayer 同一套槽位公式——`computeTokenSlots` 从 TokenLayer 抽出导出,两层各取所需(氛围层滤掉 marching 与 opacity 0),同源强制不复制公式(#608 教训)。
7. **M-9 跟移**:`prefers-reduced-motion` 对新层同样生效(旗静/晕钉中程/环停转),语义不变、选择器更新;应用内「减弱动态」设置项**不做**(Q4 拍板:治本后无必要)。
8. **回归守门**(Q3 拍板):新增 `bun run check:board` 静态断言——board.css/layout.css 的 `infinite` 动画名逐行对白名单(阶段性动画),氛围层白名单不限(HTML 合成层即豁免理由),防止旧病回流。

## 承认的取舍

- **氛围层盖过特效层**:SVG 是单一原子层,HTML 兄弟层只能整体在其上——浮字/铜钱经过旗杆时从「压旗」变「绕后」。低频瞬态,截图对拍可辨度低,接受;真嫌扎眼再议 FxLayer 出 SVG(大工程,不搭车)。
- **行军期旗/光环缺位**:换装方案的代价,换主线程零逐帧参与。视觉上由 #30 行军强调补位。
- **阶段性 infinite 留存**:选都脉冲/候选呼吸/行军金环只在相位窗内存活,且窗口内棋盘本就因行军/交互在高频失效——靜止期零贡献,不入本票面。

## 验收

1. 探针复跑:4x 节流 ≥30fps(改前 22.8),静止期 layout <15 次/秒(改前 64);
2. 视觉三对拍(844×390,seed 2026 选都后定格):都城光晕/活跃环/旗+光环形色位一致;
3. 终闸 = 用户卓易通实机复测。

## 后果

- 正面:常驻逐帧主线程成本归零(合成器接管),低端 WebView 满帧动画两全;SVG 内 infinite 绝根且有机械闸;
- 代价:装饰元素双轨(槽位坐标/缩放系数在氛围层复刻一份视图,公式单源在 tokenSlots/常量);氛围层 z 序与 SVG 层不可插混(见取舍);pan/zoom 增一次容器 transform 写(仅手势期);
- 后续方向:若特效层(浮字/流光)也观测到负担,可沿同一「出 SVG 入合成层」路线迁移,本 ADR 是先例。
