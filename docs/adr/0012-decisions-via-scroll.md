# ADR-0012 对局决策的交互入口

早期将购地等行军决策放在常驻信息旁。实玩时容易错过需要抉择的停顿点，因此由卷轴集中呈现这些决策。

## 决策

- 购地、扩军、招贤、珍宝交涉和破产清算轮到自己时，用卷轴展示当前决策与可选操作。对局弹层由 `DecisionScrollLayer` 挂载。
- 出牌阶段从手牌区选择锦囊、主动技或可研读的技能书，再按各自的目标与确认流程执行。反应锦囊的手牌与操作见 [ADR-0017](./0017-non-blocking-reaction-windows.md)。
- 「你可」技能触发后使用技能选择卡。进入掷骰阶段自动行军。阶段与出牌入口见[回合与行军](../reference/rules/03-回合与行军.md)。

决策完成后的演出见 [ADR-0010](./0010-presentation-event-stream.md)。卷轴按钮符号见 `src/app/screens/shared/Sym.tsx`。
