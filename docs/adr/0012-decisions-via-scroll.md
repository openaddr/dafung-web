# 决策交互统一:玩家权衡一律卷轴,侧栏不承载决策

React 版早期把购地/扩军/驻跸/择路的决策按钮内嵌在侧栏手牌区(沿袭旧 vanilla 版布局)。实际游玩反馈:决策选项混在信息区里,重要性被稀释,玩家容易忽略"此刻需要我抉择"。本 ADR 记录统一后的决策交互约定。

## 决策

### 1. 需要权衡的选择 → 自动弹卷轴
凡"多选项、需玩家判断"的操作(购地/扩军/驻跸或继续/走大路或入辅路/招贤三选一/珍宝交涉/破产清算)一律以卷轴弹窗呈现,轮到即自动弹出,卷轴是唯一决策入口。卷轴不可点遮罩关闭(决策相位必须选择,防误关后卡死)。

**为何**:决策是对局节奏的"停顿点",弹窗天然阻断其他操作、聚焦注意力;侧栏是信息常驻区,决策按钮混在其中会被当作状态信息忽略。卷轴也是本项目已确立的抉择视觉语言(招贤/交涉/破产早已如此),此举只是把残留在侧栏的四类补齐。

### 2. 主行动留守:行军按钮不进卷轴
「行军」(掷骰)是每回合的固定主行动,无权衡、单选项——不是"选择"。留在手牌区做主按钮。每回合弹"确认行军"卷轴仪式感过重,长局会烦。

### 3. 手牌区职责收窄
侧栏手牌区此后只承载:行军主按钮、签面、现金/委任、珍宝/名士卡、托管行——纯信息+主行动,零决策按钮。
