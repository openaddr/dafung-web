# 声望 softmax 三元拉锯:无界成长与渐近奖励

日期:2026-11-06;取代:规则页 [07 · 声望与机遇](../reference/rules/07-声望与机遇.md) 旧「三档基准 + 线性调制夹紧」口径与声望 ±100 封顶(拍板 #1090、实现 #1091,文档回填 #1092)。

## 背景与问题

旧制两条腿(均已退役):

1. **声望本体 ±100 封顶**:`addReputation` 落账即夹紧 ±100。
2. **三档线性调制**:三档基准(默认 30/45/25,可配置、按占比归一)之上,好运 = 基准 + 0.25s、霉运 = 基准 − 0.20s,各夹紧到 [5, 95],中性吃剩余。

三条问题:

- **成长有墙**:声望 100 封顶 + 三档 5/95 夹紧,把激励天花板钉死在「+100 → 好运 55%」;刷到顶的仁主与摆烂的枭雄抽同一副牌面,行善的边际收益归零。
- **旋钮纠缠**:基准配置 × 两个系数 × 夹紧带三层互相耦合,任何调参都要脑内跑一遍完整管线才知后果,数值不可直觉推理。
- **叙事断在半山腰**:玩家对「声望」的直觉是 LoL 护甲式的「无限逼近 100% 免伤」——越堆越强、永不封顶;旧制却在 100 处立一堵墙,「民心所向」的长线许诺兑现不到底。用户借这一叙事提出无界成长 + 无限逼近最好奖励。

## 决策

**声望无界**(开局 0,可负):`reputation.ts` `addReputation` 直接累加,±100 夹紧删除。**三档概率 = softmax 三元拉锯**:三档权重 2^(s/100) : 1 : 2^(−s/100),归一成百分比——

- 好运% = 2^(s/100) / (2^(s/100) + 1 + 2^(−s/100))
- 中性% = 1 / (三者之和)
- 霉运% = 2^(−s/100) / (三者之和)

K = 100 是唯一旋钮,代码常量 `encounters.ts` `TIER_SOFTMAX_K`(与 `REP_MILESTONES` 同待遇,不进配置);计算单点 `tierShares(reputation)` 单参。性质:0 声望三档各 1/3;声望每 +100 好运权重翻一倍;负向完美镜像(−s 的好运/霉运与 s 互换、中性不变);两端各奔好运 100% / 霉运 100%,三档恒为正——数学上永远差一点到不了端点。

配套拍板:

- **中性不留底**:中性不再是「吃剩余」的兜底档,权重恒 1;其份额随 |s| 增大而收缩(0 声望的 33.3% 即峰值)。
- **机遇配置只剩纯开关**:三档基准 baseRates 与归一函数 `normalizeEncounterBaseRates` 全链退役;`public/config/jiyu.json` 只认 `enabled` 布尔,单机配置屏机遇区收缩为纯开关 + 说明文案。
- **献计三碑**:+30/+60/+90 里程碑(`reputation.ts` `REP_MILESTONES`)每碑只赠一次、三碑送完不续送——已随 #1096 **整线移除**(送牌机制不复存在)。
- **bot 折银系数不改**:每点 5~9 两按座位散列的线性性格近似保留,高声望段的折银失真登记接受(见后果)。

## 论据两分:曲线族是科学,常数是文化

- **曲线族 = 科学**:三元 softmax 是 Bradley–Terry 配对比较模型的最大似然经典解,国际象棋 Elo 与电竞评级同族——「连续投入换分配概率、永不封顶」有几十年的实战标定背书,不是拍脑袋曲线。
- **常数 = 文化**:Elo 的 400 分不是自然常数,是对齐「棋协 200 分一班制」与实测 76% 胜率的标定产物。我们的 K = 100 同理按自家生成速率标定:行善一局 +200~~300 → 终局好运 76~~88%;且 +100 锚点 57.1% 衔接旧制 +100 处 55% 的手感,老玩家的直觉不跳档。

## 被否备选

1. **线性抬高帽**(±200 / ±500 一类):仍是墙不是渐近线,只是把断头路推远,下次还得再抬。
2. **softsign 双支四帽**(好运 90 / 霉运 5 / 两端帽 60 一类):四顶不对称——同为端点却厚薄不一,被对称美学否决。
3. **对称跷跷板**(中性恒定、好运霉运此消彼长):数学定理封死——对称 ⇔ 中性恒定 ⇔ 好运封顶 55(恰为旧制 +100 水平),声望无限刷也刷不动牌面。

## 后果

- **声望量程换挡**:数字可至数百上千,席位格 / 详情 / 浮字按新量程验收;获取通路不变(天命城 +20、机遇抉择 `repDelta` ±8~18),高量程是长线累积的自然结果。
- **事件流 delta 语义**:`reputationChanged` 与时机 `ReputationChanged` 的 delta = 无界直加的实际增减,「夹紧后差值」口径随夹紧一并退役。
- **bot 折银失真登记**:`repCoefficient` 线性性格近似未随 softmax 新曲线调边际,高声望段折银价系统性偏高——接受;bot 与玩家仍同规则同抽取。
- **配置面收缩**:baseRates 链退役后机遇只剩一个布尔;「三档概率」从此是声望的函数,不是配置的函数。
