# ADR-0058: 浏览器 e2e 程序化直通形制(真实段/种植段/脊柱例)

日期:2026-11-07 · 状态:已采纳 · 票:[#1211](https://github.com/openaddr/dafung-web/issues/1211)(开局段)及后续分波票

## 背景

e2e 逐例计时取证(#1165 会话)把账算清了:每例地板 ~10s(单跑)的大头是**真 UI 开局链被 ~100 例逐例重复**,而它不是这些例的断言对象;同时种植式(freezeClock+force 后断 DOM)已是这层的半壁江山——23 个 spec、~79 处 force。用户拍板方向:「每个用例尽可能程序化直通到被测面,用例关键的操作真实验证,其他都种出来」。

与 [ADR-0056](0056-e2e-slimming.md) 的关系:0056 管「哪些例留在浏览器层」(分类判据);本 ADR 管「留下的例以什么形制跑」(真实段/种植段判据)。与无头层(ADR-0052)分工不变:引擎/协议行为归无头层,浏览器层守 DOM/呈现/交互接线。

## 决策

1. **一环一真(真实段判据)**:每个用例声明「守的那一环」——种到该环的**前一拍**(状态经调试桥/引擎公共方法构造),**真做该环的完整操作链**(从第一个相关点击到断言面),操作引发的引擎结算与 UI 呈现全真。操作之前全种、操作之后不种;链式多环例(如反应窗三分支走查)允许,每环各按「前一拍→真操作→真断言」,不拆例(拆了丢时序语义)。
2. **种植合法性分层**:能走引擎公共方法(生产漏斗)必走公共方法——种出的局面不变量全保真;`force()` 直改字段仅限「断言面需要引擎到不了的形态」(满级城/破产态等)且**用例头注写一句判词**。存量 ~79 处做只读审计归类红牌,逐波清偿,**完成线=零未判词 force**。
3. **脊柱例五条(永不深种)**:守「每环都对且串得起来」——①开局链(react-setup 起兵流/home-strip 选图开局);②回合自转链(react-solo 行军自动触发);③反应窗全链(react-reaction 三分支走查/识破);④联机全链(react-online 双端流程);⑤教程走查(react-tutorial,兼文档防漂移)。脊柱例禁止新增种植化改造;新机制动到脊柱链路时,脊柱例是真回归的第一现场。
4. **前门/侧门**:「真人从首页能玩进来」由旅程例(react-setup/home-strip/react-tutorial)专守,其余用例一律侧门种局(#1211 的 `quickStart` 快路径是第一刀)。
5. **桥能力按需生长**:种到中盘任意态的桥口子(seedSolo 及后续各族种态钩子)随波建设——迁到哪族、那族要什么种能力才建什么,不预建。

## 分波与完成线

| 波  | 族                  | 例数 | 主要工作                                             |
| --- | ------------------- | ---- | ---------------------------------------------------- |
| 1   | 开局段(全量)        | ~113 | #1211 quickStart 快路径(在途)                        |
| 2   | 锦囊族              | 27   | 标真实段 + 前置链种局化 + force 红牌清偿(存量最大户) |
| 3   | 反应窗族            | 13   | 同上;脊柱例③在其中保持全真                           |
| 4   | 卷轴/系统族         | ~17  | 同上                                                 |
| 5   | 骨架几何族 + 联机族 | ~40  | 大多是种植式现状,主要是标注 + 红牌清账               |

完成线:①全部存留用例头注声明真实段;②force 红牌清零(清偿或判词合法);③[分类表](../reference/e2e-分类表.md)增「真实段」列登记齐。每波收口=全量快池绿一次。

## 后果

- e2e 语义重心从「走流程」转到「验接线与呈现」;流程串联的回归责任移到脊柱例与无头层。
- 快池墙钟随波下降(逐波计量,开局段先行);并发税同减(单例存活时间变短)。
- 深种依赖调试桥(双门禁,生产零暴露)——桥面变大,门禁纪律不变。
- force 判词头注 = 每处「引擎到不了」主张可评审;审计红牌清单挂在分类表,清偿可搭车不可烂尾(完成线锁死)。
