# 手册弹层形态(非全屏屏,对局内复用前置)

首页「手册」(#1069)的玩法内容总览,形态拍板为**大弹层**而非独立全屏屏:设计前置是对局内将来也要能打开手册——玩家不在自己回合时翻阅,全屏会盖住回合胶囊等「轮到谁」信息;故一套组件两处挂载(统一原则),弹层占大部分面积、内容区内滚、顶边恒让出 ≥44px 顶带。备选「screen 枚举+全屏屏」(SoloSetupScreen 骨架)被否:游戏内得再做第二套受限形态,正是统一原则禁绝的两套。层内顶部五类页签是手册语境的合法形制,不外溢藏品弹层(「点谁开谁的层,无互切页签」旧决议维持,#700);弹层内滚保 844×390 可达,不重蹈 #707 选图弹层档位裁切退役的覆辙。
