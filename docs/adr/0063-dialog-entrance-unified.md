# ADR-0063: 弹窗入场形制单源(底件默认入场,pile-modal-in 退役)

日期:2026-11-11
状态:已接受
来源:#1370(spec)/ #1371(实施)

## 背景

用户报安卓真机(卓易通)点开手册系详情卡弹窗,每次先见半透明壳卡 ~0.5s 才见整窗。代码定性无需真机再测,四条:

1. 底件 `ui/dialog` 遮罩**零入场动画**,出现瞬间整帧跳成暗纱(`dialog-stack.ts` 头注自认);
2. 壳体入场**各族散形制**:藏品/详情系 `pile-modal-in` 250ms 淡入上浮(pile-modal.css)、抉择卷轴 `banner-drop` 400ms 落卡(banner.css,自组壳)、手册大壳零入场瞬间出现——「半透明卡一瞬」=250ms 淡入的中间态;
3. 卓易通 GPU 栅格债是放大器:栅格赶不上帧期时未完成光栅块按底色显示(ADR-0040 同机制),把 250ms 拉长到 ~0.5s 体感;
4. 用户设想的「弹窗组件自带默认动画」本该存在——shadcn 正典弹窗入场就是遮罩淡入+壳体淡入+95%缩放同拍 150ms,移植成水墨皮时丢了。

## 决策

- **底件补默认入场**:`ui/dialog` 遮罩淡入 + 壳体淡入+scale 0.95→1,同帧起、同速 `--dur-fast`(150ms)+`--ease-out`;类挂底件默认类(`.dialog-overlay-in`/`.dialog-content-in`),全部基座弹窗(确认框/藏品/详情/手册大壳)自动继承,消费方零改动。fill 不 forwards——一次性过场,播完回自然态。壳体关键帧只动 `transform`,不碰 `translate` 属性(题名拖动 `--drag-x/--drag-y` 消费位是另一条通道,叠加合成不互抹)。
- **`pile-modal-in` 退役**:藏品/详情系 250ms 上浮删净,归一底件默认入场,不造 opt-out 机制。
- **入场与退场同居 app.css,源序即接管序**:入场段声明在退场段(`.dialog-overlay-out`)之前——开后立即关(<150ms)时同元素两类并存、同特异度 `animation` 按源序后者胜,退场类接管动画;退场关键帧 from-less(只有 to,从当前透明度起退),无透明度闪变。退场协议本身不动(`hooks/use-dialog-exit` 210ms 出口,#1182 刚修完)。
- **抉择卷轴落卡保留,天然豁免**:`banner-drop` 400ms 是事件演出,语义不同才许形制不同(统一原则);BannerShell 自组壳非 ui/dialog 基座,**天然不在底件默认入场覆盖面内,不造 opt-out 机制**。
- **形制抄正典不换库**:留在 Base UI+shadcn 形制上回归正典入场,不自造;时长/缓动嫁接自家 token(`--dur-*`/`--ease-*`),入场时长零第二事实源。
- **reduced-motion 零新兜层**:入场两类是普通 CSS animation,`app.css` M-4 全局兜层(`*` 选择器压 `animation-duration`)一并压瞬时,不另写媒体查询。

## 后果

- 全部 ui/dialog 基座弹窗开窗 = 遮罩+壳体同帧起、同速 150ms 一口气出现,「壳先卡半透明」两段感消失;手册大壳从「瞬间出现」归入同一默认。
- 真机渲染债**不在本票**:paper-skin 噪点+大阴影的弱 GPU 首栅成本(卓易通放大器那一档),真机肉眼复验后若仍黏**另立票**,不同票混修——本票只管入场形制归一。
- DoD 口径:演出形制非玩家可见机制清单项,规则页不回填;ADR+组件收口附表+DESIGN 动效节三处回填在本票内完成。
- 断言纪律:不新增「动画类存在」式测试(spec 拍板=镜像实现,宁缺毋滥);回归面=既有钉谱(react-manual / react-popup-clamp / react-tutorial)。
