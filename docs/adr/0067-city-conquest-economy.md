# ADR-0067 城池攻陷与持城收益

状态：已接受（#1566）

城池是规则教学与玩法设计的主线。买城带来交易与持有收益，守城保住收入，攻城可以得银或接城，最终以现金称帝。名将、锦囊与体力围绕这条主线为诸侯提供选择。

## 攻陷

- 火攻、火烧连营和外敌乘虚按实际扣除的防御值记伤害。有存活诸侯对敌城造成伤害时，按伤害发放即时奖励。伤害随当前持有期累计，城池升降级时保留，易主或变为无主时清空。
- 0 级非都城的防御值降至 0 时，累计伤害最高的存活诸侯接城，并列时先达到该数值者优先。新城主接手时城池为 0 级、防御值回满。没有造成过该城伤害的存活敌方诸侯时，城池回到无主。
- 打出最后一点有效敌城伤害的诸侯领攻陷奖励。结算奖励形成独立的银两池，由对该城造成过伤害的存活敌方诸侯按各自累计伤害的比例分配。
- 攻陷时发银以当前行动诸侯为起点，按座位环序发放。
- 己方误伤与无来源伤害照常扣防御值并触发相应时机。若导致攻陷，按已有的敌方累计伤害结算归属和分池。己方误伤和无来源伤害均不计入任何诸侯的累计伤害，无人领取对应的即时奖励与攻陷奖励。
- 都城防御值可被打空，扣除的敌城防御值照发即时奖励。都城不可攻陷。本决策变更了 [ADR-0064](./0064-defense-value-system.md) 中非都城的失城结算。

## 外敌乘虚

体力降至 0 时，名下各城分别受到等于各自当前防御值的城池伤害，然后该诸侯进入休整。这批城池伤害沿用把体力降至 0 的那一击的来源。归零一击无来源时，派生城损也无来源。规则见[体力与休整](../reference/rules/07-体力与休整.md#耗竭外敌乘虚与休整)。防御归零后按城池伤害规则处理降级、攻陷和都城打空，取代 [ADR-0064](./0064-defense-value-system.md) 中耗竭直接降级的规则。

当前行动诸侯耗竭时，城损和休整落定后进入回合收尾。其他诸侯耗竭时，城损、休整及相关时机结清后，继续当前行动诸侯的回合。

## 计价

三项奖励与持城收益均由国库发放。即时奖励按敌城实际扣除的防御值乘固定每点金额，逐城到账。攻陷奖励、结算奖励池和持城收益按地图购入价计，并按每座城分别四舍五入为整两。现行计价见[城池攻陷与奖励](../reference/rules/04-地产经济.md#城池攻陷与奖励)和[持城收益](../reference/rules/04-地产经济.md#持城收益)。

结算池先按比例四舍五入各人的份额，再对齐固定总额。若合计少于奖池，从发放顺序靠前且份额向下取整的人开始调高份额。若合计超过奖池，从发放顺序靠后且份额向上取整的人开始调低份额。所有人的份额确定后再发放。

## 持城收益与查阅

全桌轮末，每座有主的非都城发一次持城收益，收入归轮末城主。跳过自己回合的诸侯在轮末仍然领到名下城池的收益。

购城时显示该城每轮持城收益，城池详情显示公开的伤害排行榜。

## 胜利判定

每个实际回合只在收尾时判胜一次。当前回合产生的时机、技能和选择全部处理完毕后再判胜。若该回合也是全桌轮末，持城收益和相关时机先结算。时机与选择的收尾顺序见 [ADR-0068](./0068-moment-stages.md)。

唯一存活的诸侯直接获胜。其余情形，现金达标者中现金最高的诸侯获胜。最高现金并列者一起拼点，各自沿用现行拼点的骰面规则。最高点并列时，由这些并列者继续掷骰，直到出现唯一胜者。
