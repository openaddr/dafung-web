# ADR-0037 特殊城池用 `event` 声明固定落地事件

2026-10-30 接受。城池种类与落地结算顺序已按 [ADR-0071](./0071-city-combat-cards-and-hero-progression.md) 更新。

## 背景

棋盘采用全城池制。部分城池需要额外的固定效果，同时保留购买、升级、交易与选都资格。

## 决定

- 地图通过城池的可选 `event` 字段声明固定事件。`board.ts` 的 `TILE_EVENTS` 是白名单，装载器校验字段。现有 `treasure`（探宝）、`hero`（招贤）和 `market`（商市行情）。省略字段即普通城。棋盘用印章标明具体事件。
- 普通城直接进入城池交易链。特殊城池先结固定事件，再按最新现金、归属等状态进入交易链。己城摸牌按实际行军经过或到达结算。自己的都城按都城规则处理。
- 招贤城等招将、求书或跳过结清后续接交易链。`pendingCityEvent` 随权威状态保留续接。行情导致清算或破产时中断落格。
- 珍宝城的固定事件是拼点探宝，先于城池交易链。详见 [ADR-0024](./0024-treasure-city-parity.md) 和 [03 · 回合与行军](../reference/rules/03-回合与行军.md#落格结算总表)。

## 影响

给城池配置固定事件只需改地图数据，城池经济字段与其他城一致。都城必停、拦停止步及掷骰落点的处理以实际行军为准。
