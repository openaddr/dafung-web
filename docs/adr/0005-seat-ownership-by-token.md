# Seat 归属凭 seatToken,房间码只授权占空座

房间码的可猜测性(4 位 ~120 万组合)决定了它不能作为 Seat 归属凭证。规则:**房间码只授权"进入大厅 + 占一个空 Seat";夺回已占/掉线 Seat 必须出示该 Seat 入座时签发的 seatToken**(不可猜,仅存客户端本地)。

因此猜到房间码的人顶多坐进空位,**偷不走已占的座**——尤其是掉线者的座:否则 ADR-0002 的"冻结等重连"会被码猜测者劫持。seatToken 是 Seat 归属的唯一凭证:重连夺回、Host 强令 bot 接管后再重连,都以 token 为准。生产全程 TLS(WSS/HTTPS 经 Caddy 终结),token 不在明文链路暴露。
