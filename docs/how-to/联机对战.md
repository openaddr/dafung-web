# 联机对战

每位玩家准备一台手机，安装[安卓客户端](../../README.md#下载)，然后从首页打开「联机模式」。

## 选择服务器

直接使用联机入口即可连接公共服务器。使用[自建服务器](./部署服务器.md)时，每位玩家在「高级」的「服务器地址」填入同一个 HTTPS 地址并保存。清空地址并保存可恢复公共服务器。

## 建房与开局

1. 发起人从「创建房间」设置诸侯数和目标身价，然后点「创建房间」。人数见[开局规则](../reference/rules/02-开局.md#首页)。
2. 房主点大厅中央的房间码复制给朋友。来宾输入房间码并点「加入房间」。若入口列出了该房间码，也可点「重进」。已开局的房间停止接受新玩家。
3. 房主点「选择地图」，确认大厅显示的地图和目标身价，再点「开局」。来宾在大厅查看座次和开局改称。若出现「正在同步棋局…」，等棋盘出现即可。
4. 轮到你定都时，按[教程里的选都步骤](../tutorials/新手第一局.md#选都)确认都城。

## 应对断线

看到「连接中断，自动重连中…」时，保持应用打开。横幅消失表示连接和棋局校准都已完成。

看到「自动重连已耗尽」时，在横幅上点「重新连接」，继续使用这一会话恢复原座位。失败后可以再次尝试。点「返回首页」会结束本机会话，首页的房间码只用于入房。

## 应对有人卡住不动

在线座位无操作或离线超过服务器的等待时限后，电脑会代打。玩家回来后，可按[对局中的托管操作](../reference/rules/03-回合与行军.md#托管与代打)收回手动控制。

## 离开或更换房主

在大厅点「离开房间」。在对局中点左上角齿轮，选择「回到主页」并确认。房主离开或掉线时，房主身份移交给在线真人中席号最靠前的一位。没有在线真人时保留当前房主。

服务器如何保留座位和代打见[联机架构](../explanation/联机架构.md)。
