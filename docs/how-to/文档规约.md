# 文档规约

AGENTS.md「文档风格规约」节整节下沉至此(#1452;分级判据见 [ADR-0033](../adr/0033-agents-content-tiering.md))。

## 风格

全中文,入口文件英文命名(深层文档中文文件名,ADR 英文);受众玩家优先;数值表只做索引 + 代码锚点,**不复制数值造第二事实源**(计数同理——用例数/时机数/文件数等一律指向不落数),活文档禁写行号;README 主 CTA 置顶,开发内容下沉 how-to/。

## 发版

发版走 git tag + GitHub Releases,不建 CHANGELOG;打 tag 前先 bump package.json 的 version(唯一版本源,CalVer 制式 YYYY.M.P、月份不补零,如 2026.10.0;tauri.conf.json 经路径引用它,APK/桌面包版本随之)。**发版时机:玩家可见变更(DoD 清单口径)合入 master 后,合并会话自动发版,不再等确认;纯文档/测试/脚本基建合并不触发,拿不准就发**——细则与防挤兑三闸见[开发与测试](./开发与测试.md)「发版时机」节。
