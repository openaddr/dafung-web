# 自制地图:画一张图并接入游戏

给进阶玩家:用内置编辑器改图出图,存进本地图库单机即玩,或收进仓库成为内置图;加城、删城、
配辅路需手改 JSON。全文口径以 [`src/core/board-loader.ts`](../../src/core/board-loader.ts) 的实际读取为准——
缺必需字段直接抛错、零兜底,照下文标注配齐即可。货币单位一律**分**(1 两 = 100 分,1 锭 = 100 两)。

## 用编辑器画一张图

编辑器起点是**当前选中的内置图**(首页「编辑地图」;自建图不在起编范围——先「导出」存文件,再「导入」载回编辑)。

1. **摆城**:拖拽城池改位置,松手自动按数组顺序连线;空白处拖动平移、缩放。位移 6px 内松手 = 单击选城,不搬动、不记撤销。
2. **改属性**:右侧面板编辑「类型」「城名」「id」「分组(a-h)」「区域」「价格」「筑城费」与「城池价值表(Lv0~Lv3)」;一次表单编辑(焦点离开面板)记一步撤销,「撤销/重做」深 50 步。
3. **盯校验**:全程实时严格校验——图非法时侧栏红字给出原因,「保存」「试玩这局」随之禁用;两城过近时红圈高亮,提示「第 X、Y 城距离过近(红圈标出),保存前请拉开」。
4. **试玩**:点「试玩这局」以 1 真人 + 3 bot 直接开局(不经图库),先跑一圈看节奏再定稿。
5. **出图**:「导出」把当前图下载为 `my-map.json`;「重置」经卷轴确认(「重置回内置地图?当前编辑会丢失。」)后回到起编图并清空撤销栈。

## 把图接入游戏

- **本地图库(单机即玩)**:「保存」以首格名字入库(提示「已存入自建图库」),「另存新图」弹卷轴输名(默认「自建地图 N+1」,空名禁确定)。首页「选择地图」面板会出现带「自建」标的条目,选中开局。图库存于浏览器 localStorage,不跨设备。
- **收进仓库(内置图)**,两步:
  1. 导出的 JSON 放 `public/maps/<id>.json`(如 `wuzhang.json`);
  2. 在 `public/maps/index.json` 追加登记——六字段缺一不可(清单解析逐项校验,`tileCount`/`targetNetWorth` 须为正数):

    ```json
    { "id": "wuzhang", "name": "五丈原", "file": "wuzhang.json",
      "desc": "一句话简介(选图面板展示)", "tileCount": 24, "targetNetWorth": 30000 }
    ```

  清单**首项即默认地图**;`tileCount` 填 tiles 实数,`targetNetWorth` 与图内该字段一致。

## 手改 JSON 补齐编辑器盲区

- `tiles` 数组顺序 = 主环行进顺序(首尾闭合)。加城 = 插入一项并配齐城池字段;删城记得同步 `index.json` 的 `tileCount`。
- 辅路 `branch` 只能 JSON 手配:`start`/`end` 引用主路格 `id`(须存在且不同),`cells` 逐格给 `kind`(`treasure` 探宝 / `event` 锦囊 / `penalty` 中伏)与手配 `pos`;编辑器中辅路只读展示,格式错在加载时抛可读错误。入口抉择与逐格行进见 [03-回合与行军](../reference/rules/03-回合与行军.md#辅路分岔捷径)。

## 查地图字段速查表

标**必填**的缺失/非法即抛错;标可选的有缺省行为(括号内),均出自 [`board-loader.ts`](../../src/core/board-loader.ts),类型定义见 [`types.ts`](../../src/core/types.ts)。

顶层:

| 字段 | 必填 | 说明(数值单位:分) |
|---|---|---|
| `version` | 必填 | 恒 `1`,其余值抛「不支持的地图版本」 |
| `tiles` | 必填 | 非空数组,顺序即主环 |
| `targetNetWorth` | 必填 | 胜利目标身价;选图面板展示;内置图统一 30000(300 两) |
| `startingCash` | 必填 | 起手现金;内置图统一 10000(100 两) |
| `maxLevel` | 可选 | 城池最高等级(缺省 3);各城 `valueByLevel` 长度必须 = maxLevel+1 |
| `resupplyPerLevel` | 可选 | 逐城补给缺省档(缺省 0 = 无补给);分/级 |
| `branch` | 可选 | 分岔辅路,见上节 |

格子(`tiles[]`;城池专有字段仅默认类型 `Property` 生效):

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 必填 | 全图唯一,特殊格也要有 |
| `name` | 必填 | 棋盘与战报显示名 |
| `pos` | 必填 | `[x, y]`;两格间距 ≥ 80,过近抛「距离过近」 |
| `type` | 可选 | 缺省 `Property`;另有锦囊格/天命/赋税/市易/卧龙/宝物城六种,落格效果引擎内置、不接参数 |
| `valueByLevel` | 城池必填 | 长度 = maxLevel+1,下标 = 等级;变卖价(破产自救按此变现) |
| `price` | 可选 | 购地价(缺省 0),不可为负 |
| `buildCost` | 可选 | 选都建城费(缺省 0),不可为负 |
| `group` / `region` | 可选 | 编组与区域名(缺省 `"z"`/空),纯标注,引擎暂无同组联动结算 |
| `resupplyPerLevel` | 可选 | 该城为都城时驻跸补给 = 本值 ×(等级+1);缺省回退顶层 |
| `tradeMult` / `tradeAdd` | 可选 | 坐地起价:成交价 = 指导价 × `tradeMult[城等级]` + `tradeAdd[城等级]`(先乘再加,下标 = 等级,照 maxLevel+1 配满);公式见 [05-珍宝·坐地起价公式](../reference/rules/05-珍宝.md#坐地起价公式) |

## 按内置口径调平衡

内置三图数值被 [`test/map-economy-guard.test.ts`](../../test/map-economy-guard.test.ts) 锁定;自制图不跑守卫,沿用口径最稳(机制细则:[04-地产经济](../reference/rules/04-地产经济.md)、[05-珍宝](../reference/rules/05-珍宝.md)):

- **城价三件套**:`buildCost` = 购价 × 50%(两取整);`valueByLevel` = 购价 × `[0.4, 0.6, 0.85, 1.2]`(两取整);`tradeAdd` 参照同价位档,如 40 两城取 sanguo 长安的 `[300, 1200, 3000, 7000]`。
- **补给区域档**:`resupplyPerLevel` 沃野(中原/江东)400、中庸(荆楚/巴蜀/青徐/淮南/并州)300、边陲(其余区域)200、乘法城 300——sanguo 现值即此分布,补给公式见 [04-地产经济·都城补给](../reference/rules/04-地产经济.md#都城补给两大收入来源之一)。
- **乘法城 vs 加法城**:战略要地(如成都/华容道)配乘法城 `tradeMult = [2, 3, 4, 5]`、`tradeAdd` 全 0,交涉价曲线平缓;普通城 `tradeMult = [2, 4, 6, 10]` 叠加 `tradeAdd`,高等级交涉价陡增。
- **建价分档**:选都三选一按 `buildCost` 分低/中/高三档各抽一城,自制图保留三档跨度,开局路线才有多样性。

## 校验自制地图

编辑器实时校验与「导入」「试玩」同走一套严格检查,报错照改即可;收进仓库后跑 `bun test` 确认新图加载不抛(守卫只锁内置图),再起一局走到选都、首圈补给、第一次珍宝交涉,核对现金流与身价符合预期。
