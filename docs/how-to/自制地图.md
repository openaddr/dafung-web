# 自制地图:PR 一个 JSON 扩展地图

地图扩展能力 = **内置清单通路**:`public/maps/*.json` + `index.json` 即扩展点,PR 一个地图 JSON、登记进清单,合入即全平台可玩(单机/联机同源)。没有编辑器、没有上传通路——编辑器与 localStorage 自建图库已随 [ADR-0048](../adr/0048-map-system-slimming.md) 退役,「PR 评审 + 装载校验响亮失败」就是做图的质保通路。

**Schema 权威 = 代码 [`src/core/board-loader.ts`](https://github.com/openaddr/dafung-web/blob/master/src/core/board-loader.ts) 的 `MapData`/`MapTile` 定义与 `loadMap` 校验**——本页只做导览,字段语义与约束以代码为准;活例读 [`public/maps/guanzhong.json`](https://github.com/openaddr/dafung-web/blob/master/public/maps/guanzhong.json)(关中图,逐字段照着抄最稳)。

## 三步交付

1. 写 `public/maps/<id>.json`(schema 见下节;拿 guanzhong.json 当模板改)。
2. 在 `public/maps/index.json` 登记一条(六字段,见下节)。
3. 本地对账 `bun run check:map-docs` 过 → 开 workspace 提 PR(版本协作纪律见 [开发与测试](./开发与测试.md))。

## 地图 JSON schema 导览

一张图 = 顶层元数据 + `tiles` 数组。**`tiles` 数组顺序即主路环序**(行军按此序闭合循环),下标 0 为出生位(全员选都期的临时落位)。

顶层字段(`MapData`):

| 字段             | 语义                                                         | 校验                     |
| ---------------- | ------------------------------------------------------------ | ------------------------ |
| `version`        | schema 版本,当前恒 `1`                                       | `loadMap` 只认支持的版本 |
| `targetNetWorth` | 胜利线(两):身价达标即称帝                                    | 数值必配                 |
| `startingCash`   | 起手现金(两)                                                 | 数值必配                 |
| `maxLevel`       | 城池等级上限(逐图必配,≥1 整数;经济数组长度随之 = maxLevel+1) | `loadMap` 校验           |
| `resupply`       | 都城补给(两/次,地图级固定值,不随城池等级)                    | 数值必配                 |
| `tiles`          | 城池格数组,非空                                              | 每格校验见下             |

单格字段(`MapTile`;**全城池制**:每格都是一座城池,无不可购买格):

| 字段           | 语义                                                                                                                                                                                     | 必配性              |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| `id`           | 城池唯一 id(全仓句柄:地产/存档/交易链都用它),全图不可重复                                                                                                                                | 必配                |
| `name`         | 城名(盘面铭牌与卷轴显示)                                                                                                                                                                 | 必配                |
| `pos`          | `[x, y]` 世界坐标(px,逻辑单位);格间距离有下限(`constants.ts` `MIN_TILE_DIST`,防 UI 压盖,装载校验)                                                                                        | 必配                |
| `type`         | 格型;唯一合法值 `"Property"`(缺省同值),其他值装载即拒                                                                                                                                    | 可省                |
| `group`        | 区域分组字母 a–h(`theme.ts` `groupNames` 八区名单;区域单源见 [ADR-0048](../adr/0048-map-system-slimming.md) 后的 #828 收口)                                                              | 城池格必配,装载校验 |
| `tier`         | 城池档位:县/郡/奇/名 单字(`economy.ts` `CITY_TIERS`,四档城制见 [ADR-0034](../adr/0034-four-tier-city-economy.md))                                                                        | 必配,白名单校验     |
| `price`        | 购价(两);免费城显式写 `0`                                                                                                                                                                | 必配                |
| `buildCost`    | 建城费(两,选都落地按购价折算的另一半口径见 rules)                                                                                                                                        | 必配                |
| `valueByLevel` | 各等级变卖价数组,长度 = maxLevel+1,下标 = 等级(#671 正名)                                                                                                                                | 必配                |
| `tradeMult`    | 坐地起价乘数(per-level 数组,长度 = maxLevel+1)                                                                                                                                           | 必配                |
| `tradeAdd`     | 坐地起价加值(per-level 数组,长度 = maxLevel+1)                                                                                                                                           | 必配                |
| `event`        | 特殊城池固定事件(`board.ts` `TILE_EVENTS` 白名单:`treasure`/`hero`/`jinnang`/`fate`/`market`,五城语义见 [ADR-0037](../adr/0037-special-city-event-field.md));缺省 = 普通城(机遇必出照旧) | 可选                |

数值不进本页、也不进任何文档第二事实源——经济曲线形状由档位与数组现值承载,逐字段实例看 guanzhong.json。

## 清单登记(index.json)

`public/maps/index.json` 每张图一条,六字段:

| 字段             | 语义                                                  |
| ---------------- | ----------------------------------------------------- |
| `id`             | 地图 id(CLI `--map` 参数、联机 mapId 协议都用它)      |
| `name`           | 显示名(选图条带)                                      |
| `file`           | JSON 文件名(相对 `public/maps/`)                      |
| `desc`           | 一句话简介(选图条带副题)                              |
| `tileCount`      | 城池数 = 实际 `tiles` 长度(#826 全城池制后恒等于格数) |
| `targetNetWorth` | 胜利线(与图内同值,选图面展示用)                       |

清单首项 = 默认地图(`map-sources.ts` `getDefaultMapId`,零兜底:清单空直接抛错)。

## 对账与验证

- `bun run check:map-docs`——机器对账:清单 `tileCount` 与图内实际城池数逐张核对;docs 里出现的「N 格 / N 城」数值必须与某张现存地图一致(改图没改文档,这里红)。
- 装载校验即最硬的门:`loadMap` 对缺字段/坏值/坐标过近/环上重复 id 全部**响亮抛错**,不存在静默回退——PR 评审前本地先让图真正开局一局(`bun scripts/cli.ts new --map <id>`,用法见 [开发与测试](./开发与测试.md))。
- 合入后该图即进 e2e 钉谱视野:改既有图的环序/布局会让场景编排系统性失效,重钉规矩见 [开发与测试](./开发与测试.md)「换图重钉」节;全新追加图不改既有图,不影响既有钉谱。

## 红线

- 不手写生成器脚本入仓:地图 JSON 即交付物,可读可评审可 diff;历史生成器已随 ADR-0048 退役,不做第二通路。
- 不为「装载失败」加兜底:校验红了改数据,不在加载层吞错(零兜底原则)。
