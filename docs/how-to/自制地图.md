# 自制地图

## 新增地图

1. 按[版本协作](./开发与测试.md#版本协作jj一律先开工作区)建立工作区。
2. 在[地图目录](../../packages/core/maps/)新增 JSON，可从[关中图](../../packages/core/maps/guanzhong.json)开始改。在[地图清单](../../packages/core/maps/index.json)登记地图。把地图排在清单首项可设为默认。
3. 从新地图开一局并完成选都，再按[本地验证](./开发与测试.md#按生产变更选择本地验证)交付。可用 CLI 从指定地图直接开局。

```bash
bun scripts/cli.ts new --map <地图-id> --state tmp/map-check.json
bun scripts/cli.ts auto-setup --state tmp/map-check.json
```

## 查配置字段

- 地图的结构、必填字段和校验见[地图加载器](../../packages/core/src/engine/board-loader.ts)中的 `MapData`、`MapTile` 与 `loadMap`。调整 `tiles` 的排列会改变[行军环序](../reference/rules/03-回合与行军.md#棋盘)。
- 清单字段见[地图清单解析](../../packages/core/src/engine/map-source.ts)的 `CatalogFileEntry` 与 `parseCatalog`。清单里的格数和目标身价由本地检查与各图配置对账。
- 城池的经济字段按[地产经济](../reference/rules/04-地产经济.md)和[珍宝交易](../reference/rules/05-珍宝.md)解读。城形或曲线的变动可与[地图经济守卫](../../test/maps/map-economy-guard.test.ts)对照。

地图由单机客户端和联机服务端共用。清单与装载机制的设计原因见 [ADR-0048](../adr/0048-map-system-slimming.md)。
