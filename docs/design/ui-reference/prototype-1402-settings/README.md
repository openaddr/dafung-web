# 对局设置开关触区原型（#1402）

打开 [可点原型](./index.html) 切换 A、B。也可单看 [对照图](./compare.png)。每张样张都保留 844×390 横屏的完整棋盘和八席。底图是 #1402 此前保留的八席对局截图，弹层和虚线是本轮构图。虚线可以在原型里关闭。

## 待决定

- **A 整行可点**。音效、托管各占 40px 高。点文字、中间空白或右侧开关，都切换同一只开关。
- **B 只点右侧**。两行高度同 A，各自只在右侧 56×40px 生效。标签和开关之间的空白无动作。
- 两案保留现有 32×18.4px 开关外观，划出独立触区。首行下移到关闭按钮和题头拖动区以下。演出加速与版本仍为只读，战报、对局诊断和回到主页继续走各自入口。

## 已核对

- 之前的 844×390 触屏模拟中，两个开关均为约 55×33.5px 命中区，标签侧点击没有触发。当前合入基线 `c06119c8` 仍使用同一右侧开关和伪元素扩区。普通触区下限是 40px。
- 使用当前 `LocalController` 和 `SettingsDialog` 做无浏览器接线核对。点托管后控制器已为开启，已打开的弹层仍显示关闭，重开后显示开启。单机房间字段从本地控制器下行，现有 hook 只订阅了联机 store。实施时应让已开的设置随权威状态刷新，并用同一口径核对席位标记与收回操作。
- [准备页弹层字盘 #1507](https://github.com/openaddr/dafung-web/issues/1507) 和 [反应选份 #1403](https://github.com/openaddr/dafung-web/issues/1403) 已交付。本轮对照聚焦设置弹层。
