# 城池建筑对照（#1414）

打开 [对照页](index.html) 可切换两案，以及对局总览、火烧连营选城和城池缩略图。直接查看 [844×390 总览对照](compare.png)。样张可离线阅读。

| 方案 | 无主城 | 建筑 |
| --- | --- | --- |
| A 淡框精绘 | 保留整格淡框，沿驿道仍易读格位 | 四档沿用单檐、重檐、琉璃与关隘雉堞，加重瓦垄和砖层 |
| B 石台落子 | 低矮石台取代无主整格框，棋盘更像实体沙盘 | 四档保留现行建筑，石台和城池档位相互独立 |

总览中魏方当前在邺城。对照时可先找有金匾、王旗的临淄，再找无旗、无盾的晋阳与赤壁。选城帧以洛阳为火烧连营火源，洛阳出现双金环。洛阳为蜀方名城，2 级，防御已从 3 降到 1。魏方许昌是 0 级满防，显示 5 枚蓝盾。缩略图使用矮横屏现行的 48px 高度。

两案共用关中图的 28 城、驿道与现役 Tile 组件。总览用现役取景函数，给右席位区留出 104px。都城由引擎确定，领地和受损状态通过 Planter 种植，建筑和棋盘画面经 React 静态渲染和 librsvg 栅格化。对局按钮及席位区为同布局的示意样张，动效和触达待 APK 验收。

起基于 e3ddcf9423eebefe54660f555ae010979330a533。原型只供 [#1414 拍板](https://github.com/openaddr/dafung-web/issues/1414)。
