# #1413 房内座次对照

同一房间状态，两套 844×390 构图。[打开原型](index.html?variant=A&scene=mapped)

| 方案 | 看什么 | 满房 |
| --- | --- | --- |
| A 邀请与地图集中 | 左侧先找到房码和当前地图，右侧两列顺读座次，底部拍板。 | [来宾](a-full.png) |
| B 同桌入席 | 房码在桌心，八席围桌，地图在右上，底部操作与 A 同区。 | [来宾](b-full.png) |

waiting 为八席两人、房主待选图。mapped 为八席两人、房主已选关中图。full 为八席满员、来宾可见三号离线和自己的重名预告。duel 为中原争霸双人房。方案、视角和地图状态可以在原型切换。

场景由现行 RoomRegistry 建房、入座、选图及 lobbyView 生成，重复国号由 resolveGuohaoClash 演算，房码固定为符合正式规则的四字母示例。原型用静态场景图验证构图，复制与选图是示意入口。房主可开局，未选图时开局失效，空位由电脑补齐。来宾看到房间与地图并等待开局。实际 Android 触达由实施后的 APK 验收。
