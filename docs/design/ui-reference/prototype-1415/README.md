| 方案 | 观感与取舍 |
| --- | --- |
| A 骨纹印泥 | 将骨纹集中于边缘，保留大字的干净底色。中缝印用不匀双线表现印泥。点差大胜仍用现役金圈、二次波、洗幕和败方角部墨渍。 |
| B 大胜收锋 | 和 A 共用骨签与印泥。两签落定、首层金圈和沉暗已分出胜负之后，在现役二次波窗里压低亮环，用胜方签后一笔分担高潮。笔锋向签外掠过，到窗尾退尽。 |

普通胜负和金「平」两案相同。参与者判词拍使用现役己签加权，旁观两签等权；场景里印章和骨纹的位置均一致。减少动态效果使用静态金圈、沉暗、角墨与「平」印，七点大胜可直接显示既定放大终态；不播摇签字影、震屏、洗幕、二次波或收锋。

棋盘复用前波 #1414 以现役 Tile、取景与关中图渲染的底图，席位与按钮为该阶段的 HUD 示意。样本用具名种植件钉点并为魏授周瑜英姿，经引擎真实 `resolveDuel → duelResolved` 和现役 `extractBatchEvents` 生成签面投影，字形取自 `SIGN_FACES`。对照页以现役 `DUEL` 时间表示意 1× 节拍，高潮冻结在判词后第 425ms。位移、色阶和质感是原型对照值。后续真机验收再核对点数先读、笔势退场、1× 节奏与减动设置。
