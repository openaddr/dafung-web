## 构图取舍

- A「胜者画卷」左侧先读称帝、都城和本局名将，战果落于画卷底边。右侧按名次纵读，八席全部入屏。画卷在无将时以都城铺开，八席时以较紧的行距换取更大的名将画幅。
- B「终榜优先」用浅横幅交代胜者、战果及缩略画件；下面两列展示第 1–4 名、第 5–8 名，两席时改用单列。金额各列右对齐，破产在原名次同行显示。八席全部入屏，行距比 A 宽，名将和都城的视觉分量较轻。
- 两案的「再战一局」位于同一底部操作区，原型触区为 164×44。构图建议为 A，八席已完整入屏，且都城与名将有足够画幅表达这一局的身份。玩家若更想对照各席差距，优先考虑 B。最终以用户拍板为准。

## 数据与验证

- 八席用关中图，双席用中原争霸。用公共选都命令确定都城，`planter.ts` 种植现金与胜者名将，通过引擎 `endTurn`、`payOrLiquidate`、`declareBankruptcy`、`abortGame` 得到三种终局快照。国号「东魏」由联机共用的 `resolveGuohaoClash` 生成。都城从 `capitalIndex` 回查地图并用现役 `TileThumb` 与 `BoardDefs` 画出，名将和画像从胜者的实际 `heroes` 槽位回查。终榜沿用身价降序，现行身价就是现金，金额经 `formatMoney`。胜者身份按快照 `winner` 标示，排序次序按 `netWorth` 独立计算，多人同时达标也适用。
- `TargetNetWorth` 是现金达标的「富甲天下」。`LastStanding` 是其余玩家全破产的「群雄尽灭」。`aborted` 是对局作废，胜者、终榜和庆祝皆省略，沿现有出口。样张显示快照的 `round`，故写「第 N 轮」。现役 `DecisionScrollLayer` 把 `snapshot.round` 传为 `turnNumber` 后显示「回合」，后续接线需明确选哪个字段。规则见[总览与胜利](../../../reference/rules/01-总览与胜利.md)。
- 现役已有烟花、分段入场和鼓／锣／号角。`UI.victoryButtonMs` 基准为 1800ms，胜局与作废共用，理由是防入场误触。原型只取按钮已挂载后的稳态，等待是否有必要及多久留给实际触达观察。当前 CSS 已针对减少动态效果停用标题呼吸和印章入场，本原型三场均为静帧。后续需分别看常态和系统减少动态效果下的粒子、分段及再战时机。
- 已用引擎核对两种胜因、破产状态、在场名将、作废无胜者，并用无浏览器栅格化查看五幅样张。后续接线可用快照断言胜者、都城、名将与终榜排序。Android APK 人工验收标准为 844×390，检查双字国号、八席与双席阅读、44px 再战触达及演出节奏。静态切换页来自同一组样张。
