# 机遇画心 · #1411 原型

离线打开 [可点原型](index.html) 或 [六屏 PNG 对照](compare.png)。手册从首页打开。在手册点任意机遇笺看大图、全文与即时效果或选项。八张样本压排同屏，便于一起比对画心，实际手册目录密度沿当前布局。切到「局内抉择」，在同一条目切 A、B，点卷轴选项可看本次选择。用「重看抉择」复位。样本可从地址栏分享或书签保存，离线打开时用 `#variant=b&surface=scroll&scenario=huarong`。

| 方案 | 手册目录与详情 | 局内抉择 |
| --- | --- | --- |
| A · 抉择都见画心 | 每条画心按故事绘制，小笺和详情共用一张图 | 普通卷与奇遇宽卷均为左图右文，完整故事和选项在右 |
| B · 画心留给奇遇宽卷 | 与 A 共用 | 普通卷的正文和选项占整行，奇遇宽卷才展开左图 |

「携民渡江」在两案都是普通中性卷。「疫病入营」与「华容道」同属霉运，后者是引擎登记的奇遇。A、B 都保留普通卷约 72% 画布宽、奇遇约 80% 画布宽及题行两端金穗。画心表达故事，两处档位各沿其现有通道。手册用青绿、黛青、朱砂档位章，卷轴用亮金、黛青、朱砂题印与题条。霉运的两项均用同等笺钮。即时条目在手册可查，局内抉择样本只从具备实际抉择的条目取。

建议 B。普通卷里，尤其是疫病这种需要比较损失的抉择，可以更快扫完正文和代价，宽卷展开画面也更醒目。A 的优势是玩家第一次在对局遇到普通条目时就能建立故事印象，之后更容易在手册里用图找回。选案由用户确认。

| 疫病入营 | 雨帐、病卒与火上的药罐 | `art/outbreak.webp` | 图集第三行右 |

建议以玩家能指出的主体和动作判断是否复用。草船和渡船可以共用水江画法，各自保留箭束与流民这一眼可认的主体。神医行诊与疫病入营可以共享药材物件，家中问诊与军营疫情各用自己的构图。只有看小笺仍能认出同一个核心行动时，才复用同一画心。

实施时可按引擎目录逐条登记 ID、故事动作、画心键、来源、作者或生成记录、授权与裁切决策，再与 `ENCOUNTERS` 逐条核对是否缺画。先用本组核定画材与复用判断，再铺其余目录。每条核小笺的主读点、详情裁切及该选案涉及的卷轴场景。用生产接线核对 ID、档位、奇遇身份、正文和选项集。用 APK 核对横屏图文几何、实绘、触达以及原生返回。

## 资料与验证范围

- 条目、效果、题印颜色和金穗来自工作区起基 `662bb00d2f45cc116dfe2284f7d6692b39dd354c` 的 `src/core/encounters.ts`、`src/core/theme.ts`、`DecisionScrolls.tsx` 和 `EncounterSpray.tsx`。样本假设当前两个实际选项均可用，实机选择、灰显与原因继续由权威选项集决定。
- 七张新增样画共用一份原创图集，内置 ImageGen 单次生成，记录 `01a1f7e7-93f7-7492-99f2-474fd5de2268/exec-98278ac6-fc0f-4ee0-b2b4-58770a7264ae.png`。原图 1024×1536，两列四行等分，每格四边内裁 2px 后缩到 480×359。统一低饱和设色和墨线，大主体按小笺中心取景。图集第四行右未用。新增图与上一轮渡江裁片均为样张，当前用途限本次比选。[前置决议 #1408](https://github.com/openaddr/dafung-web/issues/1408#issuecomment-7032993454)
- `art/board.webp` 沿用 #1408 的关中对局底图，作为两案相同的地图背景。手册下的 `art/home.webp` 取自上一轮 844×390 首页 B 对照样张，保持首页打开手册的入口语境。网页原型在完整仓库内沿用已有离线字体，在独立目录用系统中文字体。PNG 从同一原型的渲染函数导出，六格各 844×390，使用静态排版和文泉驿。静态排版与无浏览器点按验证现有原型，Android 字体、动效、实际选项禁用和触屏表现待实现后真机验收。[#1408 原型素材来源](https://github.com/openaddr/dafung-web/blob/28c50ecb58c46d012fa2f5afe7603e2678371100/docs/design/ui-reference/prototype-1408-1412/README.md#样张来源)
