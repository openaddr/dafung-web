# 锦囊选目标的实盘原型

同一张关中图、相同八席在 844×390 下实点。原型将动作条放在顶部，经过选牌、目标选择和确认时都在同一位置。

- **连环计**先从下方手牌区点牌，再点顶部「选目标」。两位诸侯都在右侧席位区选。点「下一步」后可以点「上一步」回到第一步，原第一位仍为选中。改选第一位后，第二步候选随之更新。选完两位后在顶部「出牌」。[手牌区](duel-1.png) · [上一步入口](duel-5.png) · [返回保留首选](duel-6.png) · [改选后出牌](duel-9.png)
- **火烧连营**从手牌区点牌并选择目标后，牌架自动收起，在地图上点一座城作火源，再到顶部「出牌」。[地图选城](fire-3.png)
- **识破诡计**反应窗一开就显示来者、牌名、倒计时和本次三座受击城的名字，「本回合不再询问」单独分区。点手牌中的反应锦囊后，牌架自动收起，地图亮出可保护的城。点其中一城，顶部回显保护对象并启用「出牌」，按钮位置保持不变。[选牌前的影响范围](counter-1.png) · [地图选保护对象](counter-2.png) · [顶部出牌](counter-3.png)

## 横征暴敛

- **出牌**在下方手牌区点牌。顶部显示其余在场诸侯的人数及每位征收上限，点「出牌」即对这些人结算。八席局的这一幕有七位诸侯各付 200 两。[顶部确认](levy-2.png) · [缴付结果](levy-3.png)
- **识破**选牌前顶部显示其余七位诸侯受影响。在下方点反应锦囊后，右侧七个受影响席位可点，选一人后顶部显示保护对象并启用「出牌」。实点保护「滇」后，滇保留原现金，其余六位各付 200 两。[选牌前的影响范围](levy-counter-1.png) · [席位选份](levy-counter-2.png) · [顶部出牌](levy-counter-3.png) · [免征结果](levy-counter-4.png)

出牌场景参数为 `?target-demo=levy`，识破为 `?target-demo=levy-counter`。

Chromium 触屏模拟实点了以上五条线路，使用同一个对局屏、真实可选对象与引擎提交结果。反应窗实测从 15 秒开始。选火源时逐格验证了全部 28 座城的中心触点。顶部横幅和第一排城格同框，后续真机复验这处边缘触达。

在原型分支运行 `bun run --bun vite build --mode target-prototype`，再运行 `bun run --bun vite preview --host 127.0.0.1 --port 5433`。页面参数 `?target-demo=duel`、`?target-demo=fire`、`?target-demo=counter` 分别打开三种样张。
