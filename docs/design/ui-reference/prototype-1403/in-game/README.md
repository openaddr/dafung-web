# 锦囊选目标的实盘原型

同一张关中图、相同八席在 844×390 下实点。原型将动作条放在顶部，经过选牌、目标选择和确认时都在同一位置。

- **连环计**先从下方手牌区点牌，再点顶部「继续」。两位诸侯都在右侧席位区选，顶部「下一步」锁定第一位，第二步展示第一位国号。选完两位后在顶部「出牌」。[手牌区](duel-1.png) · [右侧选第二位](duel-5.png) · [顶部出牌](duel-6.png)
- **火烧连营**从手牌区点牌并继续后，牌架自动收起，在地图上点一座城作火源，再到顶部「出牌」。[地图选城](fire-3.png)
- **识破诡计**先点手牌中的反应锦囊，牌架自动收起，地图亮出本次的三座受击城。点其中一城，顶部回显保护对象并启用「落印」。[地图选保护对象](counter-2.png) · [顶部落印](counter-3.png)

单次 Chromium 触屏模拟实点了以上三条线路，使用同一个对局屏、真实可选对象与引擎提交结果。反应窗实测从 15 秒开始。选火源时逐格验证了全部 28 座城的中心触点。顶部横幅和第一排城格同框，后续真机复验这处边缘触达。

在原型分支运行 `bun run --bun vite build --mode target-prototype`，再运行 `bun run --bun vite preview --host 127.0.0.1 --port 5433`。页面参数 `?target-demo=duel`、`?target-demo=fire`、`?target-demo=counter` 分别打开三种样张。
