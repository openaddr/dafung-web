# 操作文案排查

原型中，反应锦囊用「出牌／不出」。选完牌后如果还要指定对象，入口叫「选目标」；想回到手牌重选时点「取消选牌」。反应窗的降噪说明也用「不出」。

## 正式界面中查到的同类问题

| 场景         | 现有文案                                                     | 建议                                                                           |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| 锦囊选目标   | 「已出牌 · 待择目标」                                        | 「正在选目标」。这时牌仍在手里。                                               |
| 锦囊目标段   | 「出／作罢」                                                 | 「出牌／取消选牌」。取消后可以重新选牌。                                       |
| 触发技       | 「暂不发」；行殇的目标已定仍提示「可指定目标」               | 「不发动」；行殇直接问是否对该诸侯发动。                                       |
| 购地、扩军   | 「不取」「按兵不动」                                         | 「不买」「不扩军」。                                                           |
| 选都确认     | 「再想想」                                                   | 「重选都城」。                                                                 |
| 城主出售珍宝 | 「公道买卖／坐地起价」的具体区别在按钮悬停提示和下一步选宝页 | 在第一步直接显示「指导价出售，成交后城池升一级」和「加价出售，城池等级保持」。 |

对局按钮先说玩家即将做的事。涉及两种价格或结果时，在作选择的那一步显示差别。
