# 空手时的锦囊入口（#1404）

玩家希望确认自己有没有牌，并继续查看被手牌区覆盖的棋盘。打开 [空手原型](./empty-hand.html)，在同一个八席关中图的 844×390 画面中切换 A／B／C，点右下「锦囊」试开收。下方控件用来换回合、模拟结算最后一张和再次得牌，也可核对空手时有主动技能的状态。

现状核对基线为 `6297e9fe`。当前 `GameScreen` 已按手牌和可用主动技判断架上是否有内容。空手且无技能卡时，双方回合都默认收起，只有手动打开才显示牌背。手动选择在回合或决策窗边界重置。当前 844×390 样式下，牌背本体为 96×128 CSS px，旋转后外接框约 115×142 px，牌背不接收触摸。空手的占地问题是可见遮挡。

| 对照 | 点「锦囊」后 | 可看到什么 |
| --- | --- | --- |
| A 现行牌背 | 底部中央出现斜放牌背 | 长沙城楼、旗和防御盾被遮，赤壁格亦有部分覆盖 |
| B 底缘小提示 | 底缘出现「暂无锦囊」，圆钮亮起 | 长沙城楼、旗和盾可见，空手信息好找 |
| C 圆钮内显示 | 圆钮亮起，在「锦囊」下显示「0 张」 | 与收架时一样露出棋盘，提示集中于刚点的位置 |

[三版底缘对照](./empty-hand-compare.png)。建议 C，保留原位置的 44×44 锦囊触区，点击后在同一位置提供明确结果。若圆钮里的两行在真机上难读，B 的一行提示也能露出棋盘主要信息。两案都沿用回合与待决状态联动，不加演出，计数与可用技能分别以各自含义呈现。

- 另一方回合自动收架。手动开收持续到原有边界。这一边界之后，空手默认只保留锦囊钮。
- 最后一张结算后默认让出棋盘，手动打开可确认空手。再次得牌时沿用既有显隐与数目提示。锦囊变成 0 张但仍有可用技能时，技能卡仍可呈现。
- 对照适用范围为本座手牌区，不改暗牌、他人席位读数、出牌机制、反应时间或 #1402 的触区测量。拍板后再写实施规格。
