## 1. 命题

**「一纸墨戏,方寸庙堂」**

棋盘是一幅摊开的水墨长卷——山水为底,城池为子,旌旗为魂;
HUD 是案头笺纸——手札、签筒、印匣,一切数字皆墨书;
决策是展开的卷轴——读诏的仪式,展开、落定、卷起;
一切确认,以落印为终。

## 2. 审计(2026-09-06,基线截图见 §7)

14 张基线截图(home/setup/lobby/棋盘全景/拉近/详情/五类卷轴/胜利/编辑器/骰子)
走查后的问题清单,按四维归档:

### 2.1 视觉

- V1 菜单三屏的纸纹是一张 960px 平铺的实拍照片,soft-light 0.45 下读作「失焦展厅」,
  不是宣纸;纸没有纤维感,反而带来脏灰的 photo 泥点。(app.css A1 层)
- V2 金色按钮(bg-gold/80 大面积金底)发「土」;金在纸底上既不贵重也不醒目,
  主操作与危险操作(朱砂)之间缺少一个真正的「行动色」。
- V3 全局圆角 rounded-lg + 纯黑投影是现代 Web 语义;与水墨器物语境脱节,
  投影应带墨褐色(43,35,23)而非 #000。
- V4 符号 tofu:「← ↶ ↷」挂在 font-brush/font-deco(离线子集无这些字形)下,
  大厅「返回■首页」、编辑器「■撤销 ■重做」实拍可见豆腐块。(ui-symbols 的
  符号是字符方案,字体缺字形是系统性风险)
- V5 名将头像缺文件时直接露 alt 文本+破图(华佗画像),破图是体验硬伤。
- V6 图标体系除了骰子/静音 SVG 外基本为空,按钮视觉锚全靠文字。

### 2.2 信息层级

- H1 首页 2×2 白板 + 大真空,标题外的空间全部浪费,没有「开局前」的氛围叙事。
- H2 侧栏四段(回合/手牌/珍宝/诸侯)权重均等;珍宝空态独占 1/3 高度只有一行 12px 灰字;
  诸侯行三种字号挤在一行;品牌横幅 65px 信息量为零。
- H3 棋盘左上控制条(◎/+−/回合 chip)是白底浮块,与棋盘语言断裂。
- H4 卷轴弹层标题/正文/按钮字阶接近,主次按钮权重不足;纸面无器物感
  (它自称卷轴,看起来是圆角卡片)。

### 2.3 动效

- M1 落格结算无仪式:棋子到了、数字跳了,但落点没有「定音」一拍
  (印章已有 ADR-0015 管线,但购地/事件/机遇落点缺统一的视觉锚)。
- M2 屏幕切换转场已有(screen-in);卷轴两层摊开已有;主要缺的是
  卷轴「杆」的器物呼应与确认按钮的落定反馈。
- M3 动效 token 体系(--dur-_/--ease-_)已建成且接 gen:theme,本次沿用不改节奏
  (改时长牵连 fx/timings 编排与 e2e,风险大于收益)。

### 2.4 一致性

- C1 控件四种物种并存:首页笔触按钮 / setup 原生表单 / lobby 卡片 / HUD chips,
  没有统一的「控件种」。
- C2 色彩引用分裂:SVG 内 rgba 字面量(棋盘体系,量大有注释豁免)与 token 体系并存;
  本次新 UI 一律 token,棋盘字面量仅在换色时同步。
- C3 玩家 8 色只在旌旗/小圆点出场,UI 主色与玩家色没有转译关系(可接受,保持)。

## 3. 立意:三个方向

### 方向 A「绢帛工笔」

- 情绪板:马王堆帛画、故宫绢本、工笔界画、泥金描边。
- 色板:茶色深绢底 #3a2f24 / 浅绢面 #b49b74 / 泥金 #caa24a / 朱砂 #a83a2c / 石青 #4a6a8a。
- 字体:楷体正文 + 仿宋标签 + 衬线 display 数字。
- 布局:每个面板是一幅装裱绢本——四角包角、金线双勾。
- 动效哲学:金线描边生长(draw-on)。
- 全局签名:泥金界画线框。
- **弃用理由**:深绢底要求棋盘整体换底,现有宣纸棋盘(用户已认可)、水墨资产
  (千里江山/溪山清远/宣纸纹理)全部报废;全屏深底长时间阅读疲劳;工程风险最大,
  换来的是与存量资产为敌。

### 方向 B「水墨留白·笺纸集」(选定)

- 情绪板:生宣、松烟墨五阶、朱砂印、界格笺纸、手札、卷轴、案头灯下的一桌一卷。
- 色板(§4 全表):宣纸暖白系 + 墨五阶 + 朱砂/黛青/赭石/石青/青绿/鎏金点缀。
- 字体:马善政(大字/城名/横幅)、霞鹜文楷(正文)、站酷小薇(标签)、龙藏(手书输入)。
- 布局:面板=笺纸(有衬里、有边、有界格);卷轴=真卷轴(上下杆);控件=印/签两族。
- 动效哲学:器物的物理——纸展开、墨落定、印钤下;少而精,全部走既有 token 与
  表现事件管线。
- 全局签名:**朱砂印章系统**(身份印/功能印/确认落印)+ **界格笺头**
  (每块面板的笺头:单字朱印 + 小薇体标签 + 细墨线)。
- **不落入 AI 默认审美的自查**:默认是奶油底+高反差衬线+赤陶点缀;本方向是
  「纸-墨-印」完整器物系统,色彩全部来自中国画颜料(朱砂/黛青/赭石/石青),
  结构语言(笺头/卷轴杆/印章)取自真实文房器物,装饰皆有信息职能。

### 方向 C「青铜漆器·虎符兵书」

- 情绪板:战国漆器黑朱二色、云雷纹、错金银、竹简、虎符。
- 色板:漆黑 #1a1512 / 朱砂 #b23a2e / 错金 #c9a227 / 青铜 #7a8a6a。
- 布局:竹简竖条面板、虎符对拼按钮、云雷纹边框系统。
- 动效哲学:金属机括——卷帘、错位、咬合。
- 全局签名:云雷纹边框。
- **弃用理由**:黑漆底与宣纸棋盘彻底冲突(同屏两个世界);HUD 高密度信息在黑底
  长时间阅读疲劳;与既有字体资产(楷体系)气质相斥。

### 选定 B 的理由

1. 棋盘已是宣纸水墨且用户明言「现在这个样子的程序画的就还可以」——重做棋盘是纯风险;
   把预算花在把「纸、墨、印」做成系统,全屏受益且气质统一。
2. 存量资产(离线字体四套/千里江山/溪山清远/宣纸纹理/朱砂印动效/ADR-0015 宣告管线)
   全部复用,工程预算花在刀刃上。
3. 吸收 A 的「装裱意识」(面板有边有衬里)与 C 的「器物感」(印=权威,
   与委任状/都/起/胜既有语言同源),但底色与棋盘语言不换。
