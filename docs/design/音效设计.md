# 《群雄逐鹿》音效设计

> 设计定稿，供音效制作、接线和验收。素材的音色、响度和收尾在安卓 APK 上试听定标。现行演出见[视觉设计](./DESIGN.md)。

## 对局密度

让玩家听出自己何时需要应答，以及刚发生了哪一种重要结果。普通回合可以只有骰签落定和一次有意义的反馈。同一次结算影响多处时，突出最重的结果，其余变化由棋盘、席位和战报呈现。

需要确认选中的点按给轻声。公开结果的声音跟可见的结算落点对齐。声音关闭时，画面仍提供操作所需的信息。

## 界面、开局和行军

| 场景                     | 音效与落点                                                                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 选图、选国号、选牌或选项 | 需要确认选中时用轻纸扣。查看、翻页、取消和重新展开已有卷轴用界面反馈。                                                         |
| 进入联机大厅             | 建房或加入成功给一声软木扣。等待和自动重试由状态提示表达。重连失败且需要玩家处理时响一次轻提示。                               |
| 选都、起兵               | 定都成功，石印贴「筑」章落定。全员选都完成后，起兵主题随对局开始响起。                                                         |
| 骰签、行军               | 骰签定面用干脆的硬木碰案，棋子起步用更轻的木滑扣。普通途经、落格、回合和轮次切换留白。                                         |
| 驻跸、都城补给           | 路过己都城必停时，门闩合木声贴驻跸条带。补给的入账和回体共用一组声音。正好落在都城时，从补给直接接招贤。                       |
| 拼点                     | 并行起摇时硬木合击。各签错拍落下，复用骰签落定声。中缝印落定时鸣磬，旁观和平局单音，己胜双音上行，己败双音下行，三支配平响度。 |
| 新抉择卷轴               | 一小段展纸声贴首次出现。已打开的卷轴恢复浏览时，沿用当前画面。                                                                 |

## 反应窗

只有本座新出现可应答的反应窗时，设备才响开窗声。公开的出牌和结算结果照常面向全桌。同桌外放时，其他玩家可能从声源判断哪台设备收到提醒。见[锦囊规则](../reference/rules/06-锦囊.md)。

每个反应窗只在剩 3 秒且本座仍可应答时响一次末段提醒。反识破开启的新窗各自计时。已经应答、启用降噪口或失效的窗退出提醒。回到对局时按当前窗的实际剩余时间计时。

应答提示有时间约束。和结算声撞在一起时，开窗或末段提醒准时响，正在响的尾音平滑压低，提醒结束后平滑恢复响度。应答后若提示仍在响，短渐出收尾。

## 沙盘城池攻防

题材以沙盘上的城池攻防为中心。拟音从桌边的近距离触感出发，纸、木和铜表现日常动作，砖石和旗帛表现城池的变化。通过声音的轻重与长短，让普通行动和改变棋局的结算听起来有差别。见[城池规则](../reference/rules/04-地产经济.md)和[视觉设计](./DESIGN.md)。

| 城池结算                   | 音效                                 |
| -------------------------- | ------------------------------------ |
| 普通受击，实际扣除防御值   | 一记短石击                           |
| 破防后降级，或都城防御打空 | 较重的碎石声                         |
| 非都城攻陷                 | 城栓断裂接旗帛声，随城池归属变化落定 |

石击、碎石、断木和旗帛用录音拟音。普通受击保持短促，破防和攻陷保留碎石滚落或旗帛展开的余声。同一张火烧连营打出多档结果时，只响最重的一档。燃烧的常规扣防由画面表现，发生降级、都城防御打空或攻陷时，响相应的重拍。

## 城池交易、银两与交割

归账铜钱飞抵席位、银两数字回弹时响入账声。同一拨轮末持城收益只响一次，以第一枚铜钱抵达为落点。这让攻陷的旗帛声先贴城池变化，再由短铜钱声把注意力引到席位。

| 场景             | 音效与落点                                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------------- |
| 购地             | 成交时把「据」章和铜钱入囊做成一个短声句。                                                                     |
| 扩军             | 等级实际抬升时，木榫扣合两记。公道买卖引发升级时用同一声。                                                     |
| 独立失银         | 商市下跌等结算实际失银时，用低沉的钱囊收紧声贴负向金额。                                                       |
| 玩家间转账       | 同一笔交易全桌听一声铜钱交接，以收款方的归账铜钱抵达为落点。两边的金额变化由画面表达。                         |
| 珍宝交割         | 入托管时由画面说明。付清、交货时用同一声铜钱交接承接成交。                                                     |
| 探宝、窃宝和求书 | 得宝贴「得」印或入册，用短拨弦双音。窃得珍宝时用同一把弦闷拨。求书成功用书册入案声。探宝落空由画面和战报表达。 |

## 锦囊、名将与体力

本座实际入手锦囊时响一次轻纸声，所有锦囊共用这个声音。同一段行军连续摸牌合为一声，起手发牌随起兵的主题短句收口。

| 场景             | 音效与落点                                                                                                             |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 出牌或发动主动技 | 公开宣布的拂纸声跟指示线或施展浮字走。紧接实际结算时，把声音集中在效果。需要拼点、扣防、失银或招贤的动作走各自结算声。 |
| 识破诡计和反识破 | 识破生效时短铜扣止住余响。反识破恢复效果时以短回音带回实际结算。                                                       |
| 军情密探         | 有权查阅的本座打开窥探弹层时，响一次轻翻页。                                                                           |
| 名将和技能书     | 招将成功用甲扣和短弦，习得技能用翻页与收弦，遣散和折书结果用一次书册入案。被动技按得银、行军等实际效果发声。           |
| 体力和休整       | 袭扰实际扣体用钝击，实际恢复用柔和上行短音。耗竭在城损之后以一记下行闷鼓收口。跳过回合和常驻状态标记由画面表达。       |

## 破产、终局与环境声

出售并清偿成功时，用一次账册合拢声。同次清偿完成珍宝交割时，由铜钱交接声承担结算。确认破产出局时，锣声贴倒旗，雨声低铺，洒落的铜钱在同拍发声。若仪式交棒时还有尾音，在交棒前渐出。

同一主题动机在起兵和正常终局各出现一次。起兵是一句短引子，正常终局以单鼓起势、落印和短角乐句收束。判胜拼点先完成自己的判词，胜利卷轴随后接棒。再战随终榜可用。作废面板用画面表达结果。

棋盘常态留白。拟音、主题短句和环境声共用对局的音效开关。

## 播放与验收

单机、联机、真人和电脑共用同一套音效配方。公开结果跟共用表现事件的画面落点，本座提醒跟当前可应答的反应窗。演出吸附或正常终局交棒时，过时未响的声音立即作废，已经响的尾音短渐出。静音、断线、换局和离开前台时立即停声。见[演出自洽规则](../adr/0029-presentation-self-consistency-invariants.md)。

沿用安卓 WebView 的媒体播放链路和打包内的 Ogg 成品。首页「音效试听」列出全部播放项和触发时机，点一行以素材原速试听，换行、关闭或切到后台时停声。先在试听菜单比较单音，再用 APK 对局外放连播。普通回合用骰签落定作响度参照，轻纸和起步更轻，攻陷和终局才拉开强度和空间。素材记录沿用[音效素材账本](../../apps/client/public/assets/audio/README.md)。

| 连播片段                                 | 听感验收                                                                                   |
| ---------------------------------------- | ------------------------------------------------------------------------------------------ |
| 普通回合接一段己城连续摸牌               | 走格留白，轻纸声清楚可辨，连续入手合为一声。                                               |
| 火烧连营造成扣防、降级、攻陷与发银       | 攻陷声领拍，单次入账接在归账抵达时，能听出两件事的先后。                                   |
| 上一笔归账尾音叠到新反应窗，再连续反识破 | 只有可答的本座及时听到新窗，末段只提醒一次。提示压低旧尾音，旧窗随着应答、降噪或失效结束。 |
| 珍宝交割，对照独立失银                   | 转账两端共享一声交接，独立失银听起来有清楚的下行感。                                       |
| 轮末持城收益、判胜拼点与正常终局         | 入账、判词、胜利主题依次交棒。切出再回来时从当前演出继续。                                 |
