## 1. 命题:为什么是现在

锦囊牌(#122)是本作核心玩法载体,也是全游戏唯一隐藏信息;手牌无上限(#250)、目录 8 种 15 张。**#188 档 1「反应锦囊」在即**:手持「即时」牌可在任意玩家的结算窗打出——手牌将从「自己回合看一眼的静态清单」变成「全场任何时候都可能出手的活物」。UI 若维持现状,反应牌没有任何可立足的界面锚点。

与此同时,我们调研了卡牌游戏的手牌区标杆(无名杀、FreeKill、炉石系克隆、OpenDuelyst,代码结论见 [ui-reference/research-sanguosha.md](./ui-reference/research-sanguosha.md) 与 [research-cardgame.md](./ui-reference/research-cardgame.md)),结论一致:**牌感来自「牌面」这个视觉单元本身**——牌名、标签、框、态(浮起/下沉/禁用原因)都长在牌上,而不是长在一行行按钮上。

棋盘与卷轴壳的水墨语言已经成立(DESIGN.md Wave-2 验收通过),问题集中在**锦囊牌没有「牌」的形态**:

## 3. 参考体系一句话结论

- **手牌区形态**:无名杀与 FreeKill 均为横条重叠式 + `spacing = min(卡宽, 可用宽/(n-1))` 一维压缩;我们的手牌无上限(#250)但寻常三五张,抽到几张全展示几张,重叠压缩算法若日后需要再评估。
- **选牌交互**:点选上浮(n acclaim 20px 两家一致)、悬停展开重叠牌(noname `getSpreadOffset`)、拖牌指目标+拖离即确认(FreeKill Super Drag)、非法原因竖排印牌面(FreeKill `prohibitReason`)。
- **合法性单源**:noname `game.check()` 中枢模式 = UI 只改选中集,合法性由引擎统一重算——与我们 ADR-0013 选项集(`available/reason`)同构,直接对接。
- **出牌方向感**:FreeKill `IndicatorLine.qml` 生长-停留-淡出三段指示线;TablePile 随机微旋转给「人手摆上去」的质感。
- **大富翁侧**:大富翁系 UI 与我们高度同构(棋盘+现金 HUD),可借鉴点已被 §4 覆盖;批量采集的截图抽样废图率约九成,经确认已整批删除,结论以代码调研(research-cardgame.md §2 OpenDuelyst)为准。

图库:可信核心 = 三国杀官方 UI 22 张 + noname 实机 10 张(**manifest 32 条,2026-09-24 质量审计后口径**);批量现搜批次废图率约九成已删除,教训与走查结论见 [ui-reference/README.md](./ui-reference/README.md) 与 [research-cardgame.md §3](./ui-reference/research-cardgame.md)。

## 4. 方案(全部长在「纸墨印」语言内,不引入新视觉体系)

### P0-A 锦囊牌面组件 `JinnangCardFace`(器物件豁免类,自绘 SVG/HTML)

竖式笺牍牌面,约 3:4。自上而下:

- **笺头**:牌名(font-brush 大字,如「火烧连营」),左侧细界格线;
- **标签章**:右上角「谋/攻/守/援」朱砂小方章(与既有印章系统同源,DESIGN.md §4.2 朱=权险;多标签竖排);
- **纹样窗**:中部程序化 SVG 纹样,一标签一族(谋=云纹·黛青 / 攻=火纹·朱砂 / 守=盾纹·赭石 / 援=枝纹·青绿),无图片资产依赖;
- **笺脚**:短文案(font-wenkai 小字,两行截断——完整 `text` 与效果进详情浮层)。**渲染时剥离 `text` 的计法别称前缀**(冒号前的四字计名,如连环计的「二虎竞食:」)——牌面只留效果正文,别称随全文进详情浮层(2026-09-24 原型评审定:牌名+别称双层命名在 120×160 上既挤又惑;剥离后多数牌笺脚可免截断);
- **牌背**(暗置语义):漆木底(lacquer)+ 中央「锦囊」朱印 + 回纹边,给未来「窥探/暗置」玩法留视觉语言。

两档尺寸:卷轴/手牌架共用 ~120×160(3 张并排富余;Android 短横屏降档 ~96×128)/ 详情浮层 ~240×320。手牌架与军师幕同用大牌面,不再设迷你档(反应窗亦复用架上牌面,零新尺寸)。

**交互态**(2026-09-24 修订对齐 §7.5「gold=选中态」——初稿「可选用=上浮+金线」与之冲突,按后决议收口:可用=常态,金线只属选中):**选中=上浮 20px + 金线描边**(放大态即详情态,笺脚放开至 4 行全文可读);不可用=下沉置灰 + **非法原因小字印于牌面下缘**(reason 已由 choices 选项集提供,直接渲染);**放大态即详情态**(2026-09-24 业界惯例对齐,用户拍板;卡牌游戏无「角标看详情」先例):军师幕点牌=选中即放大至详情档(~1.6×,全文可读;LoR/StS 两段式的简化——落印钮已承担确认,选中可逆);手牌架点牌=详情抽屉(移动端)/浮层(桌面),长按同效(炉石/昆特肌肉记忆);hover 放大仅桌面增强,**任何信息不得仅 hover 可达**(Tauri Android 为交付形态)。
**「看不全」的三层保证**(2026-09-24 补):①现状最长文案 46 字,抽屉约 2 行,余量 3 倍;②详情抽屉/浮层实装须 `max-h-[86dvh]` + 超出可滚动(项目 dvh 惯例);③**文案长度纪律**(炉石惯例:卡牌文字设计时 ≤4 行,不靠滚动兜底)——牌面只写做决定需要的部分,细则归规则页;未来新牌写不进「两行牌面+一屏详情」先拆效果。

**品级通道**(2026-09-24 走查增量):官方料表证实「同形框,异色=品级」的成体系做法(sanguosha-ui-08:金/红/黑/银框+编号顶章+铜/银/金材质)——二期珍宝变体(§6)走**框色通道**实现,牌面形制不动,`JinnangCardFace` 预留 frameTone 入参即可。牌背与陈设先例:sanguosha-ui-07(三牌背立于案)、opensource-assets 三张官方牌背(暗底+云纹+中央金印)。

### P0-B 军师幕牌面化

`JinnangScroll`(`DecisionScrolls.tsx`)选项从行按钮改横排牌面:锦囊牌 + 冷却就绪技(技=「令笺」变体:无纹样窗、右上加「技」金章,沿用 #229 的技/牌区分)+「今不用」笺钮殿后。testid 族 `scroll-jinnang*` 原样挂在新组件上,e2e 零漂移。悬停展开重叠、点选上浮、非法原因印牌,全部落在 P0-A 的交互态上。补一条手感对齐(2026-09-24 走查增量,借 OpenDuelyst §2.4):**右键/长按 = 取消选中**——点选与拖拽共用同一动作函数,误选一键回退。

### P1-C 底部「手牌架」

锦囊手牌从侧栏纸签列表(D1 断点)改**屏幕下缘常驻手牌架**(2026-09-23 拍板):横排大牌面,有几张全展示(手牌无上限,#250;压缩算法若日后需要再评估),他人回合同样可见。**常驻不收拢**——档 1 后他人回合恰是反应锦囊最需要被看见的时刻,收拢与反应窗抢戏。空手牌时斜放一张漆木牌背(「锦囊」朱印)占位,示意暗牌语义,不写空文案(器物空态)。hover 详情浮层用 shadcn 现成底件;侧栏原锦囊区位置由其余信息件收编。
布局与状态参数(2026-09-24 走查增量,借 OpenDuelyst,详见 [research-cardgame.md §2/§3](./ui-reference/research-cardgame.md)):手条锚在**棋盘底边之下 ~0.4 卡高**、水平居中后**右重左轻**(右让位给行动钮);均分公式 `(end-start)/(n-0.25)` 末尾留 1/4 卡位;三态正交——不可用=灰度(+原因),选中=上浮,hover=底框高亮;区域名可做**竖排章挂架首**(sanguosha-ui-02 制式)。

### P1-D 反应窗(为 #188 档 1 预留,随档 1 实施)

**牌架即反应窗**(2026-09-23 拍板):结算点上,一条窄事件横幅从手牌架**上缘**长出——左段事件文案 + 朱砂倒计时弧;手牌架中此刻可打的反应锦囊直接**呼吸金边**(不另造迷你牌面带,牌只有一份、就在架上亮);点牌 → 目标选择(候选诸侯笺行高亮/棋盘 token 光圈呼吸)→ 墨钮落印确认;超时自动「不用」。**非阻塞语义已定案**(ADR-0017):联机不暂停全场,per-seat 独立倒计时、超时由权威侧代发「不用」命令(同行军自动化 #225 口径);「本回合不再询问」降噪口对齐 noname「暂定无懈」。
实测锚点:noname 响应窗形态四件套(问句/规则全文/需求计数/取消单键)、超时分型兜底(取消/交 AI/强制执行)、联机 per-玩家计时器,均已实机验证——见 [ui-reference/research-sanguosha.md §6](./ui-reference/research-sanguosha.md)。

### P2-E 出牌指示线 + 牌桌微质感

- 出牌确认后,使用者 token → 目标 token 画墨线:生长 200ms → 停 200ms → 淡出 300ms(FreeKill IndicatorLine 同参数)。**需新增表现事件类型(ADR-0010 双提取器)**,故列 P2。
- 军师幕/反应窗内牌面随机 ±1.5° 微旋(TablePile 质感,幅度收敛)。

### 明确不做

- **扇形手牌**:那是 8+ 张手牌游戏的语言,我们手牌寻常三五张,重叠横排绰绰有余;
- **双排手牌**(noname 遗留布局,反面教材);
- **机遇卷轴牌面化**:机遇是叙事事件不是牌,保持卷轴文字叙事(后续如需再单独评估);
- **全局视觉重做**:DESIGN.md 已定稿,本方案是增量。

## 5. 工程落点与红线

- 新组件 `src/app/components/card/JinnangCardFace.tsx`(纯展示,器物豁免类,同棋盘 Tile 口径;牌面本体自绘、不套 shadcn;**有现成 shadcn 底件的交互一律用现成的**(2026-09-23 拍板):详情浮层=HoverCard/Popover 底件套水墨皮、浮层类=Dialog 底件、焦点/Esc 走 shared/DialogFocusScope 惯用法)。
- 消费方:`HandPanel.tsx` 锦囊区(现纸签列表,迁出侧栏改底部手牌架 `HandRack`)、`DecisionScrolls.tsx JinnangScroll`;侧栏原位置由其余信息件收编。
- **testid 契约不变**:`jinnang-hand / jinnang-card-* / scroll-jinnang / scroll-jinnang-option-* / scroll-jinnang-pass` 原样挂新组件。
- **choices 单源**:UI 只渲染 `available/reason`,不自算合法性(noname `game.check()` 同构)。
- 时长/缓动走 `--dur-*`/`--ease-*`;一次性演出(出牌动效)只走 ADR-0010 表现事件管线;新增 infinite 动画登记 reduced-motion 兜底列表。
- 牌面数据单源 `core/jinnang.ts`(`JinnangCardDef`:id/tags/targetDomain/text),组件不复制文案。

## 7. 已决事项(2026-09-23 拷问会,原「开放问题」销题)

1. **牌面形制**:竖笺约 3:4;纹样窗**要**(谋=云纹·黛青/攻=火纹·朱砂/守=盾纹·赭石/援=枝纹·青绿,程序化 SVG);牌背=漆木底+「锦囊」朱印+回纹边;
2. **手牌区形态**:**底部常驻手牌架**(用户拍板:卡牌游戏通用语言,手牌在下方),不做收拢;空态=斜放漆木牌背;侧栏原锦囊区由其余信息件收编;
3. **反应窗节奏**:方向拍板、数值留档 1 校——联机**非阻塞** per-seat 独立倒计时(默认 3s、配置表驱动),超时=「不用」;单机同步等满。已立 **ADR-0017**,#188 Q2「是否暂停全场」销题;
4. **牌面复用**:珍宝二期复用同组件(独立变体:宝章+等级表达);机遇、名将不复用(机遇是叙事,名将已有画像卡);**有 shadcn 现成底件的交互一律用现成的**(用户拍板);
5. **移动端优先交互**(2026-09-24 拍板,经业界调研修订):牌面**不放角标徽章**(业界无先例);详情=「放大态即详情态」——军师幕**选中即放大**(点牌=选中+放大至详情档,再点它牌切换,落印确认),手牌架**点牌=抽屉**(移动端底部抽屉/桌面浮层,长按同效);hover 仅桌面增强;出牌唯一确认动作=落印钮,与"点按=选择"彻底分离。

剩余实现层微调(不占用户决策,随票内定):短屏尺寸降档断点(Android 短横屏牌架高度)、珍宝变体等级章细节、手牌压缩算法启用阈值(#250 后无固定上限,待 #254 定)。
