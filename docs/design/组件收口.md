# 组件收口:交互类 UI 一律走 shadcn/Base UI 底件

> 原则条文在 [AGENTS.md 架构红线 6](../../AGENTS.md);本文件是其执行细则:附表(逐组件处置)、自研原语特许范围、弹层挂载口径。2026-09-12 定稿(来源 #155 全景盘点),新组件对号入座,不逐案重议。

## 规则

每次新增/重构**交互类** UI 组件(弹层、下拉、确认框、表单控件、popover 等),必须 `bunx shadcn add <component>` 取 shadcn 版为底——复用焦点管理和 ARIA 等无头行为层,再套本项目水墨皮,不手搓交互语义。

- 原语库定 **Base UI**(2026-09-12):shadcn 新项目默认,Radix 转维护。基建:`components.json` + `@app/utils/cn` + [弹窗底件](../../apps/client/src/app/components/ui/dialog.tsx)(已改皮;后续 CLI 更新时 diff 保留皮差异)。
- shadcn 的 CSS 变量在[应用样式](../../apps/client/src/app/styles/app.css)桥接主题 token。调整颜色见[设计参数配方](../how-to/开发与测试.md#更新设计参数)。
- **手写交互语义**(自写焦点陷阱、自绘遮罩开关、裸 role)在附表之外的交互组件上一律打回。

## 豁免

1. **纯视觉/器物件**(棋盘 SVG、卷轴装饰、画像卡)不在此列。
2. **器物级自定义皮肤**可直接用无头原语自行组皮,但焦点管理和触屏点外关闭口径必须与 ui/ 底件一致。
3. Base UI 无独立 FocusScope(#158),焦点陷阱由 `shared/DialogFocusScope` 自研原语承担;Base UI 亦无拖拽语义,#674 起弹窗题名拖动由 `hooks/use-dialog-drag` 自研原语承担——以上两处为**特许的自写交互语义集中点**(再新增自写交互语义一律先在此登记判词,不加第四处不经评审)。

## 弹层挂载口径:不夺焦

卷轴/弹层挂载不夺焦——FocusScope `onMountAutoFocus` 恒 `preventDefault`,避免弹层刚打开就抢走用户当前焦点。新弹层沿用此口径。

**弹层拖动口径(#674,ADR-0031)**:全部居中式弹窗(两壳)题名行可拖,拖离中心遮罩减淡、拖回吸附带回正;模态语义(焦点陷阱/点外关闭)不随拖动变化。原语单源 `hooks/use-dialog-drag`,壳只接把手,业务弹窗零改动。

**弹层进出口径**。Dialog、Sheet 与 BannerShell 的壳体和遮罩直接显示、恢复和移除。最小化与关闭共用题头按钮视觉，具体触区见 [DESIGN](./DESIGN.md)。进退场的历史取舍见 [ADR-0063](../adr/0063-dialog-entrance-unified.md)。
