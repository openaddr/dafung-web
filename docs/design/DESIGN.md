# 群雄逐鹿 · 视觉与交互

现行方向为「玄墨鎏金」。深墨底用于承托棋盘、牌面和卷轴，鎏金描边用于行动焦点，朱砂用于印章与警示。方向从留白调整到深墨的背景见 [ADR-0026](../adr/0026-visual-direction-revision-xuanmo-liujin.md)。素材来源见[登记与授权](../../apps/client/public/assets/CREDITS.md)。

## 4. 设计参数

### 4.1 色板(token 语义)

底色用玄墨深阶，正文用反转的纸色字阶。功能色在深底上降低饱和度并提亮。具体值和修改步骤见[设计参数配方](../how-to/开发与测试.md#更新设计参数)。

### 4.2 语义重排(控件种)

- **墨钮(lacquer 实底 + lacquerGold 字)**:一切「推进对局」的主行动
  (行军/买/扩/结算/开局)。墨=落子无悔。
- **朱印(danger)**:印章、破产、危险、不可逆确认。朱=权与险。
- **金(gold/goldBright)**:轮次光环、选中态、金印(宝/胜)。金=势,不再当按钮底。
- **笺钮(panel 底 + 纸色发丝边 --hairline)**:次级动作/工具。
- 圆角收敛:面板 8px、主控件 5px、小控件/输入 3px、印/章 2px——器物更挺括。
- 投影统一纯黑深影(#509 深底化加重):`--ink-shadow-sm 0 2px 8px rgba(0,0,0,.45)`(面板)/
  `--ink-shadow-lg 0 10px 30px rgba(0,0,0,.6)`(弹层)。

### 4.3 字体与素材策略

- 字体四套沿用离线子集(public/fonts/),消费口径:
  - `font-title`(站酷酷黑,#508 方向 D 入库):标题位——屏标题、横幅题、印文。
    城名已退役迁出(酷黑镜像子集缺字且无 700 字重;城名竖匾归 font-deco,见下)。
  - `font-brush`(马善政):非标题笔书位(按钮字、骰签、国号字;国号手书原用
    龙藏 font-hand,2026-11-01 #955 整族退役改挂 font-brush,手书感同路)。
    **「按钮字=马善政」是全屏铁律(#955 拍板)**——任何屏的按钮不得另立字族;
    同类操作标签(分段选项、国号快选、折叠标题与开关操作短名)同用笔书字。
    **按操作语义定字族,不按整个控件或屏幕继承**:房码(含可点复制的房码)、数值、
    普通输入内容、字段名与说明保留阅读字族;国号输入沿身份字使用笔书字。
    复合控件分别标注操作与阅读内容:步进器仅加减钮用笔书字,中央数字仍为阅读字;
    分段选项的档名用笔书字、金额仍为阅读字;重进按钮里的房间资料仍为阅读字。
  - `font-wenkai`(霞鹜文楷):正文默认(body 已挂)、**新 UI 文案的安全位**、
    笺头标签、数字挂 `tabular-nums`。
  - `font-deco`(站酷小薇):**存量**小注/表头维持;**城名竖匾**(Tile `NamePlaque`,
    2026-11-01 起:魏碑匾额感、92 子集覆盖全部内置城名,竖排字距 +5、恒 400 字重
    不做伪加粗;自定义图城名含回/圃/圄/圊四码位时该字回退楷体,随下条空芯规约);
    新文案不可裸排(见下)。
  - 变量单源:四族 `--font-*` 全在 tokens.css(gen:theme 产出,#931 收编);fonts.css
    只管 @font-face 分片与 `.font-title` 消费类。
- ⚠ **伪加粗规约**:四族离线镜像全是 400 单字重,任何 500/600/700 字重声明 =
  浏览器合成加粗——小字号笔画糊死内白。全仓清零已收官、零特例;
  强调语义一律由字距/色/底承担,新增字重声明即违例。
- ⚠ **字体安全规约**:站酷小薇离线镜像存在「空芯字形」——回/圃/圄/圊 四个囗部字
  在 woff2 里是实心方块(马善政/文楷无缺)。四码位已从 fonts.css 对应
  分片的 unicode-range 剔除令其回退楷体(fonts.css 头注有记,重生成镜像前勿整表覆盖)。
  **在镜像修复前,新增 UI 文案一律 font-wenkai 或 font-brush。**
- **符号字形**:箭头类符号(← ↶ ↷ ◎ ♪ × ▶)一律不在 brush/deco 字族内
  裸排——[`Sym` 组件](../../apps/client/src/app/screens/shared/Sym.tsx)用内联 SVG 渲染,
  任何字体栈下不出 tofu。
- **名将头像兜底**:空路径/加载失败 → 「姓氏单字朱印 + 画像未至」占位
  (空 src 不触发 onError,必须显式判空——三处画像位同口径)。
- 素材:xuan-paper.jpg(实为展厅照片)退役删除;千里江山(首页横带+胜利屏)、
  溪山清远(棋盘远景带)两件 PD 古画已随方向 D 深底化退役摘除
  (S8/S10,#512/#514/#516),「画」的职能转外部古风素材与卡面立绘通道
  (§3 方向 D、§4.5 卡面 B 案)。

### 4.5 锦囊牌面

印章/卷轴之外的第三件器物族:**竖笺牌面**(.jinnang-card,3:4,em 制两档 8px→120×160 / 16px→240×320,矮横屏消费方可降至 6.4px 基)。自上而下笺头(界格线与完整牌名，四字起降档，超出预留宽度时折行)/ 标签章(右上竖排,朱砂,多标签双挂)/ 金框画心(同牌在手牌、窥探、手册与详情共用)/ 笺脚(两行截断,别称前缀已剥离)。窥探翻牌的牌背由漆木底、「锦囊」朱印和回纹双环组成。

- **锦囊故事画心（#1410）**。连环计、缓兵之计、窃玉偷香、火烧连营、识破诡计、半路杀出和挟天子以令诸侯各有完整小场景，缩到手牌大小仍应能认出关键动作。新牌以献帝临朝和曹操所持的封缄诏书为主体。军情密探、横征暴敛、求贤令沿用专属墨线。标签章恒朱砂，谋、攻、守、援、即时的族色继续由 `JINNANG_FAMILY` 及其 CSS 镜像表达。
- **品级框色 frameTone(已启用,#281 珍宝牌面变体;#359 装裱化)**:珍宝走 `TreasureCardFace` 装裱形制(「名家鉴藏」六件套:绫边斜纹/四角包角/画心/题签/鉴藏印/跋文,视觉基准 proto/treasure/r5.html 节二)——品级大字退役,品级=画心距条+右上品级角标(菱形小底+数字,底色随品级)双通道,距条与角标共落 `--tone`。
- **珍宝画心与技能书（#1409）**。合适的器物实拍保留主体，统一暖暗衬底、柔和光感和留边。手册图文行册与局内各珍宝画心消费位共用素材。运行时技能书以一张装订册母版承载实际技名，名称、指导价及研读条件沿用现行规则。
- **藏品弹层与圆钮入口(#361 弹层定形;#700 入口迁右下三圆钮)**:「珍宝 N」「名将 N/3」圆钮点谁开谁的层(珍宝=装裱卡大格网格、名将=人物卷);人物卷由窄画像签、大幅人物与右侧实授技能文稿组成，自己与他人共用形制，只有权限不同。长文在正文区内滚，遣散固定在正文外，切将或名册变化解除旧确认；研读从出牌阶段的手牌区进入选人层。技能书不能研读、名将不能遣散时，各自显示独有的不可用原因。旧牌架右端入口/expandPile 明细排/仪表条徽章展开态均已退役。术语与交互口径见 GLOSSARY「藏品圆钮」「人物卷」。
- **交易选宝弹层(#362)**:交涉使用珍宝拾取器(PileShell 壳+装裱卡网格预选、一次成交),交涉三选仍是卷轴选项集(ADR-0013),拾取器非选项集。模式按钮只显示操作名。选宝时展示实际报价、入账预览和本次成交带来的城池升级。术语见 GLOSSARY「选宝弹层」;组件见[交易选宝](../../apps/client/src/app/screens/game/TreasurePickModal.tsx)。
- **破产自救(#1401)**:珍宝与非都城城池进入分页网格，单件点选，重复珍宝用数量器，跨页保留预选。金额、翻页与拍板区常驻。高度不足时，资产区内滚，翻页后从该页顶部开始。已选足额后禁加选，仍可减量与取消。选中靠金边与色彩，不立文字牌。数值用阅读字体，加减与操作短名用笔书字体。底部只读已选变卖额及还差／超出，足额后一次「出售并清偿」。次要「认破产」须再次确认。名将不列入可卖清单。规则单源见[破产清算](../reference/rules/09-破产清算.md)，标准档构图见[已认可样张](https://github.com/openaddr/dafung-web/issues/1401#issuecomment-6893549118)。
- **交互态**。选中锦囊上浮描金，全文用文楷排在手牌架上方，超高时纵向滚动。顶部动作条和手牌始终可操作。长按手牌打开原有详情。名将技能卡保留放大选中态。不可用卡用灰度下沉与原因印条，长按手势共用 `use-long-press.ts`。出牌阶段/反应窗窗态牌面 ±1.5° 确定性微旋(TablePile 质感;`prefers-reduced-motion` 退场,#281 P2-E)。
- **手牌架**透明浮置于底缘。详情用水墨弹层，宽裕屏幕为底部面板，窄屏为贴底抽屉。可见状态随回合、牌面和决策窗变化。反应或技能询问到来时，即使牌架收起，锦囊钮也会出现金光。操作入口见[手牌架规则](../reference/rules/06-锦囊.md#牌面与手牌架)。
- **手牌架空态（#1519）**。没有锦囊、可展示技能卡或可研读技能书时，手动打开「锦囊」才在棋盘底缘出现「暂无锦囊」，签面随牌行隐藏。一行文楷置于低调的墨底上，采用主题色，静态呈现，城格触摸可穿过提示。按既定规则收架时撤下提示，底缘随即让出空间。有实际牌面可呈现时恢复牌行。锦囊、珍宝、名将三个圆钮沿用同一尺寸和字排，锦囊只在数量非零时显示角标。
- **全展检视(#1423)**:计数章打开原手牌架的横向浏览视口，锦囊、技能卡与可研读技能书按完整牌序排列，超宽内容留在架内；全展持续，选中、取消、换选不收回，同名牌以渲染项独立选择，确认仍走原命令通路。主动关闭、点外、详情／技能全览、完成出牌、目标段、收架或屏前身份切换结束本次检视。放大选中形制沿既有牌面态，视口给实际牌面留完整空间；横滑不选牌、不出牌，架外透明区仍穿透。回合／决策联动及暗牌投影不变。
- **反应窗（#1511/#1514）**。复用顶部动作条并采用 B 分区，按内容收紧空白，长信息可换行。倒计时和事件信息在左，降噪口「本回合不再询问」有独立分隔，「不出／出牌」在右。选牌前给出行动者、锦囊或行军事件及影响范围，选牌和选份时仍可核对。火烧连营列受击城名，横征暴敛报受影响诸侯人数。牌架上可打锦囊金边呼吸，选份复用席位区和棋盘，地图选择自动收架。手牌开收、命令在途和重连均沿用当前权威窗的剩余时间。倒计时常态墨金，末 5 秒弧和秒数转朱砂并呼吸脉动。操作见[反应窗规则](../reference/rules/06-锦囊.md#反应窗)，窗口语义见 [ADR-0017](../adr/0017-non-blocking-reaction-windows.md)。
- 本座出现新的可答反应窗时响一声，仍可答且剩余时间跨到 3 秒时再响一次（`ReactionBanner.tsx` 的 `REACTION_REMINDER_LEAD_MS`）。提醒播放期间压低结算尾音，结束后尾音恢复响度。切回前台或重连时按当前窗剩余时间继续计时。见[音效设计](./音效设计.md#反应窗)。
- **出牌指示线（#281/#284/#385/#849）**。墨线用正文焦墨，笔触宽 10 个逻辑单位，总览约 4px。起点用小圆锚，终点箭羽沿用棋盘驿道的人字羽，整组带金晕。线生长 200ms、停留 200ms、淡出 300ms。线端按事件发生时的棋子槽位和城格定位。宣布时从使用者棋子指向目标棋子，无指向的牌由浮字报牌名。识破结算线从生效识破者的棋子出发。保住一份时指向受保护的城格中心或诸侯棋子，整计被拆时指向原用计者的棋子，反识破时指向被拆那张识破的使用者棋子。护住自己的棋子时，由判词和铜扣表达结果。拂纸声随指示线或浮字，紧接有结算音时由效果声承接。同一批随后开反应窗时，指示线在浮字后约 250ms 落下，给横幅铺开留出时间。批内仍有掷骰签或拼点签面在场时，指示线、铜钱飞行和浮字延后到签面收场。线和浮字随当场或重连后新收到的事件生成，出牌宣布读 `jinnangAnnounced`，识破结算读 `jinnangVoided`，拦检出牌读 `reactionAnswered` 和本次拼点。单机与联机共用表现管线。见[拆招细则](../reference/rules/06-锦囊.md#拆招细则)与[联机同步模型](../explanation/联机架构.md#5-同步模型事件流口径折叠切换⑥-388-落地)。
- **出技指示线(#1388 T2 已实施)**:城目标域主动技(火攻)确认后,使用者 token → **目标城格**水墨墨线(出牌指示线同语系:同一 sink 线件与三段节拍,终点锚城格非棋子);因果同走事件批直读(`heroSkillActivated` 判别联合 fireBlast 支必带目标城,`fx/event-extract.ts` 直译 `skillPointed` 表现事件)。席位域技(赈济/擂鼓)无指向不出线。

### 4.6 状态表达原则(2026-09-25 定,用户拍板)

**能用 UI 状态变化标识的,不增加文字标牌。** 选中/可选/候选/激活等状态一律优先用边框、色彩、位移、光圈等**状态变化本身**承载(如候选席位=金边框+光圈,不再贴「择」字章);文字只保留给状态变化表达不了的信息。理由:文字标牌占面积、小尺寸下不易识别,且与既有状态语言重复——双通道说同一件事,读者反而要学两套。

- 判据:撤掉这段文字,状态是否仍然可辨?可辨 → 不加文字。
- 例外:语义必须由文字承载的(禁用**原因**、数值、牌名),文字本身即信息,不受本条约束。
- AI/贡献者做 UI 设计前**先读本文**(尤其 §4.2 语义、§4.6 本条);设计评审按此原则打回冗余文字标牌。

设备与输入范围见 [AGENTS.md](../../AGENTS.md)。

**UI 只显示当前状态,历史归日志/战报(2026-09-30 定,#361/r5 决议④)**:状态 UI 只呈现**当下**的持有与数值——珍宝/名将弹层陈列现持有全件,不设「曾持有」区、不给已失去的物件留灰化展位;何得何失、来龙去脉一律归战报抽屉与对局日志(ADR-0014,历史在那里本就是唯一事实源)。理由:状态 UI 混入历史,「现在有多少」就要靠辨读,毁掉一眼可读;同一事实两处陈列(状态区+历史区)必然漂移。

**弹窗可拖动(2026-10-24 定,#674)**:全部**居中式弹窗**(ui/dialog 底件系与 BannerShell 横幅系全部成员)题名行可拖,拖离中心遮罩墨纱减淡(2026-10-31 #870 玄墨底重定标:常态 0.55/拖离 0.25)、拖回吸附带回正复原——决策弹窗「边看边掂量」正需要它(破产变卖、招贤选择都是看着棋盘做的决定);模态语义(遮罩拦指针/焦点陷阱/点外关闭)不随拖动变化。位置零记忆(每次打开回中心),抽屉族(战报/贴底)与全屏覆盖不参与。行为口径与翻案理由见 [ADR-0031](../adr/0031-draggable-dialogs.md);原语见[弹窗拖动](../../apps/client/src/app/hooks/use-dialog-drag.tsx)。

**弹窗最小化（#1557）**。对局弹窗和战报抽屉用题头减号或遮罩空白处最小化。棋盘露出时手牌架让位，左上保留返回入口。查阅城池或诸侯后可回到原弹窗，延续该次操作的预选和滚动。联机时限、托管和游戏流程继续按原规则推进，抉择失效时撤下返回入口。最小化与明确关闭各走自己的入口，查阅期间逐层关闭分项和名录后回到棋盘。

**席位卡和诸侯详情**。席位卡保留银两、体力读数与体力条、城池数和锦囊张数。诸侯详情按席列出体力和城池，提供银两、锦囊、名将与珍宝的全员对照。满编名录在标准横屏分成两栏，逐席直接对照数值。城池清单按行军顺序列出城名、等级、防御与价目。

**父子弹层**。诸侯的城池、名将和珍宝分项叠在名录上。战报和对局诊断叠在设置上。关闭分项回到父层原来的位置，关闭父层时一并收起子层。安卓系统返回每次关闭栈顶的弹层，最小化后可恢复原浏览位置。

**研读技能书**。出牌阶段在手牌区展示当前有麾下名将可学的书。点书打开选将弹层，底部固定「确认研读」，退出或取消保留书册。珍宝册仍可查看技能书与交易信息。

**弹窗拍板钮钉底(2026-10-28 定,#729)**:凡**固定抉择钮组**——「内容在上、拍板在下」的形状,如购地/不取、扩军/按兵不动、选都二选一——一律入壳层钉底操作区,不进滚动内容流:`BannerShell` 以 `footer` 槽实现三段式(题行钉顶 + 正文井内滚 + 抉择钮钉底,发丝分隔线与题行对称),破产变卖的结算行与进度随拍板钮同槽。红线:**正文内滚合法(浏览内容是正常形态),拍板钮恒在场、永不滚出视口**(矮横屏 844×390 实测购地表格曾把两钮压出视口)。不适用:珍宝使选项卷轴(选项即内容,滚着浏览是自然形态;问询弹层已随问询线退役,#1065)、点卡制(招贤);PileShell 系 footer 钉底同款纪律见 #708。几何与触达由用户在 APK 中验收。

**首屏信息**。选都固定城池身份、建城费、余额和补给。购地固定购入价、余额和每轮收益。扩军固定等级、防御与交易变化。交易及破产的结算和确认始终可见。等级表、长清单、技能全文和历史战报使用正文空间内滚。

**列表与抽屉空态（#768）**。列表为空时用斜放朱印和短注，清单加载中用墨滴呼吸三点，均见 `screens/shared/ArtifactEmpty`。战报抽屉为空时展现空白笺和虚线格，样式见 `layout.css` 的战报段。长按进度通过牌面微光呈现（300ms 起，达成保持，松手即撤）。战报未读时设置钮出现呼吸金点，打开抽屉即清账。

**对局为横屏构图。** 设备强制竖屏时显示「请横屏游玩」引导。安卓方向和安全区实现见[移动端适配](../explanation/移动端.md)。对局屏同构模板一套、按可用高度分两档(#680):矮横屏档(`orientation: landscape and max-height: 500px`)= 全浮层紧凑档,允许重排;宽裕横屏档(其余横屏)= 布局零重排、密度舒展,兼顾安卓平板。对局屏全浮层构图与几何定案见 [ADR-0032](../adr/0032-hud-float-form-tiers.md);裁决细节与后果见 [ADR-0018](../adr/0018-mobile-landscape-only.md)。

### 4.8 名词纪律(2026-11-01 定,用户拍板,#916)

**读数场合的标签用最短名词。** 弹层/清单/卷轴里的字段名与标注一律最短名词:不加前缀(「城池档位:」)、不加定位语(「名城·乘加全能」)、不加解释性短语——信息由结构承载(建筑形制、数值表),不由文案复述。例:城池档位的呈现=两字档位名「名城」,而非「城池档位:名城·乘加全能」。

  大胜档 6px(与震屏同判一处);判词磬按己方视角拆双音高
  (己胜上行高音/己败下行低音,旁观局与平局中性单音);摇签段空签身旋转墨旋
  (落定即撤,reduced-motion 静态淡印);签排 gap 随视口收紧(clamp),折行时
  中缝「拼」印随首行定位避让;拼点点数只在签面一处,棋盘侧旧印演出已随
  单通道化退役,版式与节拍细则见 [ADR-0030](../adr/0030-duel-sign-face-presentation.md)。
- **拼点骨签（#1415）**。骨纹收在签身边侧，中缝朱砂印保留印泥纹理。大胜先露出双方点数，随后在原二次波内从胜签背后掠出一笔。减少动态效果时只保留静态判词，略去扫锋、二次波、洗幕和震屏。
- **棋盘氛围(§5.2)** 与控制条皮肤(审计 H3):◎/± 改笺钮方章样式。

### 5.2 棋盘(对局内优先级最高的一部分)

- **山水带**:地形图稿上下缘的远景带(高 18%、group opacity 0.10、
  下带镜像)——清·龚贤《山水图卷》(PD,manifest `texture:gongxian-shanshui`)
  中段裁带;前史两件浅色古画(溪山清远/千里江山)已随方向 D 退役摘除
  (#512/S10,manifest 留档标 retired)。同票落 feTurbulence 纸纤维 pattern 与
  路肩细线(roadMain 40% 平行线)。
- **江河**:装饰性蓝灰江线已退役(2026-10-24 拷问:用户判「没啥用」);同批退役的
  还有区域底色晕染(实拍 A/B 近零感知)。区域视觉待机制化时重新设计。
- **城池卡**。
  一格一语言、重复表达裁单一——
  归属=铭牌深玩家色底染+描边(城旗带国号,8 人局近色/色弱的精确通道);
  等级用铭牌左下的一枚固定宽度方徽表示，金底深字，只写 1、2、3 或 4。无主城省略等级徽记。
  都城=光晕+王旗。城楼加层/等级印/屋顶染/无主价签/「都」印/区域色带均退役
  (拷问判词:双通道说同一件事读者要学两套,楼回归纯规格×地域风味;
  色带退役判词:区域暂无机制作用,八组彩色横条只添视觉噪音,机制化时再重新设计)。
- **无主城石台（#1414）**。无主城的四档建筑落在同款低矮石台上，取消常态整格框。现有城格仍可点，按压与选城沿用既有反馈。有主城保留归属框、等级徽记与防御盾，都城继续用金匾、王旗和光晕。棋盘与城池缩略图共用同一城格。
- **防御盾（#1578）**。有主城在棋盘和城池缩略图的格底各显示一枚沿用原轮廓的蓝盾。
  盾内数字是当前防御值，蓝色自下向上按当前值占本级满防的比例填充，满防实心，打空的都城显示空心盾与 0。
  无主城省略蓝盾。满防取 `defense.ts` 的 `fullDefenseOf`，盾色用 `core/theme.ts` 的 `defenseShield`。
  城池详情仍显示「防御 当前/满值」。
- **道路**:主驿道加深(roadMain 新值)+ 更清晰的箭羽;**驿道恒直线**(#928/ADR-0044,
  2026-11-01 拍板):城池间路线一律城心直连,不设避城弧线——路线畅通由地图设计负责
  (网格间距保证直线行廊),不为「理论上可能有密集图」供养避让算法;行军每格一段
  匀速滑动一气呵成(旧弧线每格三段两次减速顿挫退役)。

### 5.3 首页(签名屏)

- **左画右操作（#1412）**。左侧装裱沙盘插画，保留城楼、棋子、路线和谋士。游戏标题在画内，魏蜀吴国号作装饰。沿用玄墨底和金色描边。
- 右侧单机模式独占一行，联机模式与手册同排，下方是选图、音效试听与对局诊断。标准横屏和矮横屏按可用空间排布，左右与上下避让安全区，按钮与地图触区沿用 §4.7。
- 点「音效试听」打开分组清单，每条显示名称和游戏里的触发时机。整行可点，当前声音以金边和停止符号标示，题名和关闭钮固定在滚动区上方。
- 矮横屏沿用原生横滑的地图条带，点地图即选中，金边回显。图少时分配可用宽度，溢出时可滑到末项。长图名换行，城数与目标身价保留阅读字族。宽裕横屏可通过「选择地图」打开现有弹层。沙盘与选图状态互相独立。
- 手册(#1069):次级行笺钮「手册」点开**四类内容总览大弹层**(ManualModal)——大弹层而非全屏屏([ADR-0049](../adr/0049-manual-as-overlay-modal.md)):弹层顶边恒让出 ≥44px 顶带(对局内将来复用同一组件时回合胶囊带不被盖,首页虽无胶囊也照此几何),内容区 ui/scroll-area 内滚。珍宝签采用图文行册：左画心、中名称与完整说明、右品级与指导价，行高随全文增长，整行用 Base UI Button 打开详情，关闭后保持列表位置。其余签保持既有陈列与详情叠层(复用 game 侧 PileShell/SkillGlossaryDialog)。

### 5.4 单机配置

- 手札左列集中地图、诸侯数与目标身价，右列相邻呈现国号和座次。标准横屏的座次双列顺排，八席完整可见，「起兵」固定于下方操作区。
- 国号保留单字输入，旁边的「字盘」打开居中弹层。标准横屏为两排方印，选中用漆金印面表示。每个印格有独立的至少 40px 触区，点字即回填并收起。

### 5.5 联机大厅

- 入口宽度足够时采用同屏双栏，窄屏纵向排列。左栏创建房间并选择目标身价模式，右栏凭房间码加入，上次房间以整行提供「重进」。地图默认值随房内选图显示，高级服务器地址默认折叠。操作标签用手书，房间码、金额和说明保留阅读字族。
- **房内同桌入席（#1413）**。桌心摆可复制的房间码，诸侯依席号分列两侧，地图和可见目标身价放在右上，选图、开局与离开集中在底部。标准横屏八席同时可见。本人、房主、空位、离线与重名预告就近标在各自座位。
- 房主开局时，选图、开局、复制和离开保持原文案并暂时停用。操作区旁只显示一条主状态，依次为「正在开局…」「正在同步棋局…」。收到棋局后切屏。明确失败时在操作区显示原因并恢复操作，连接中断时由现有恢复横幅接手。来宾等待房主开局。

### 5.6 终局

- **胜利页（#1416）**。左侧画卷显示本局胜者、实际都城和实际持有的名将，无将时放大都城。终局现金、胜因和轮数放在画卷下方。右侧终榜按终局身价降序，胜者与破产身份就近标在各自一行。标准横屏八席同时可读。
- 「再战一局」固定在下方，随终榜出现并可用。减少动态效果时终榜与按钮同拍静态出现。对局作废继续显示独立说明与出口。

## 6. 动效规范(不变量)

- 一切时长/缓动走 `--dur-*`/`--ease-*`(唯一源 Motion,经 gen:theme);
  与 JS 编排窗口的硬同步点(timings.ts 注释)一律不碰。
- **进对局**。单机准备页和联机大厅提前加载所选地图数据。棋盘绘制期间保留上一屏，显示「正在绘制棋盘…」。底图和城池触区提交后，直接显示棋盘、棋子与候选标记。其余屏间墨晕与浮现见[屏间过渡样式](../../apps/client/src/app/styles/screen-transition.css)。
- 一次性演出只走表现事件管线(ADR-0010/0015);CSS 只承担
  (a) 常驻呼吸 (b) 状态样式。新增动效前先问「事件从哪来」。
- **弹窗进出**。弹窗和抽屉打开、恢复、关闭时直接响应，对局抉择卷轴同样立即呈现。掷骰、拼点、揭牌与终局由各自的演出编排负责。沿革见 [ADR-0063](../adr/0063-dialog-entrance-unified.md)。
- 震屏仅限全场级大事件(破产仪式/拼点大胜负/都城停);常规回合动作(掷骰落定)
  不上震屏——#490/#492 定档曾把骰签归入大事件,2026-10-17 回摆。
- 金钱反馈三件套(#764):进账铜钱沿贝塞尔弧飞向席位格(present 合帧,同席位
  同帧只飞一枚总差额;出账方向后置)、抵达拍席位现金数字 bump(--dur-fast)、
  席位现金 count-up 滚动补间(rAF,小额 500ms/大额 900ms 两档)——与浮标 delta
  共存不互代。出牌窗聚光=窗态选中时的全屏 radial 压暗(z 序压盘面、让位手牌、正文
  与动作条;现役唯一的全屏 radial 压暗——旧骰子全屏压暗幕已随 #927 退役)。
- reduced-motion:全局兜层已有,新增 infinite 动画必须登记进对应兜底列表
  (屏间转场无 infinite,其延迟归零口径见 screen-transition.css 尾部媒体查询)。
- **资产预热(2026-11-01)**:视觉组件首现的加载税(字体子集按需拉+swap 闪换、
  图片首现解码,弱 WebView 肉眼一顿)由启动预热消除——主页 idle 期全量拉取
  字体与图片，见[资源预热](../../apps/client/src/app/warmup.ts)。
  新增首现型资产(字体族/立绘/纹理)无需登记——预热全量无白名单。
