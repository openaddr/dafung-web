## 评估结论(勿重启)

- **colyseus 不引入**:Schema 要求持有状态,与「快照单源出自引擎」(架构红线 5)死结;不用 Schema 则退化成裸消息壳,卖点全废。
- **Nakama 不引入**:形状对(match handler 内状态对框架不透明)但尺寸错——TS 运行时是 goja 解释器(引擎确定性需在第三个 JS 引擎下全链重验)+ 强依赖 PostgreSQL。**毕业条件**(中两条再评估):公网陌生人局 / 账号好友需求 / 排行榜战绩库 / 多服并发;引擎纯 TS 零 DOM,届时打包进其 TS runtime 模块即可,迁移门常开。
- **boardgame.io 不引入**:引擎形状错——要求引擎写成 moves/phases 纯函数模型;反应窗(ADR-0017,回合中断)、时机总线、掉线接管(ADR-0002)在其模型中无对应物,硬套=概念碎成散落守卫。无存量引擎的新常规回合项目才是它的正解。
- 「早期定过用 colyseus」查无此事:全仓与 git 历史(`-S colyseus`)零提及,ADR-0001 恰是放弃现成框架路线、拍板自研小骨架。

## 已对过的账(结论可查,不必重对)

- **同步协议**:首连 `sync` 全量 + 后续 `update` 增量、`updatedAt` 打点 ↔ boardgame.io `src/master/master.ts`。我们的等价物=命令直达权威服 + 全量快照广播。
- **视野过滤**:boardgame.io `src/master/filter-player-view.ts` ↔ 我们 ADR-0016 引擎内 per-seat 投影。快照架构的安全性论证是「线上没有的东西就是没有」,优于「过滤/解码器写对才有」。
- **种子化随机**:boardgame.io random 插件 ↔ 我们 `rngState` 随快照序列化,同一解法。
- **并发版本化**:boardgame.io `_stateID` 逐 move 递增 + `ignoreStaleStateID` 补丁字段(迟到的 move 撞过期状态)——客户端双跑 reducer 模型的固有代价;我们命令直达权威服,此类竞态物理不存在。
- **纯度边界**:boardgame.io `MoveFn => void | G`,move 体内普遍原地改——纯在 reducer 边界,不在逐函数。我们的纯度边界=引擎公共方法红线,同构。

## 类游戏对照:新月杀/无名杀的服务端·客户端关系(2026-10-04)

用户问「他们像我们引擎单源吗」的调研结论(新月杀=FreeKill 本地克隆实查;无名杀 web 调研,未克隆):

- **新月杀 = FreeKill**(Qsgs-Fans/FreeKill):一套 C++ 经 `FK_SERVER_ONLY` 开关编出客户端(Qt/QML)与单机服务器,正式联机服务端是独立仓 freekill-asio(逻辑仍 Lua,经 `lua/server/rpc` 的 CBOR RPC)。游戏逻辑全 Lua 且**两端各跑同一份**:服务端每房间线程一个 Lua VM 跑 GameLogic(事件栈/触发技/伤害流程)做**裁决线**;客户端跑同一份做**表现线**(ClientCallback 分发、本地 `cardVisible` 决定明暗渲染)。协议=CBOR「命令+数据」事件流(MoveCards/PropertyUpdate/GameLog),仅重连发整房序列化摘要;mod 包由客户端 libgit2 自行 clone,两端 require 同一份包代码;AI 在服务端(`lua/server/ai.lua`)。保密=**信任客户端**:`syncDrawPile` 把洗好的牌堆顺序全量广播、移牌不过滤,防透视靠客户端自律——朋友圈可用,公网陌生人局不行。
- **无名杀**(libccy/noname):全客户端 JS,引擎/UI/AI 一体在浏览器;`packages/server` 仅房间大厅+定向转发,不做游戏运算;**权威=房主客户端**(create 验 onlineKey、config 仅房主、send 允许房主向从属端发任意数据、selfclose=房主退出即房间关),完全信任房主无反作弊。形态≈「把单机模式当联机用」。最小服务器参考:Toukaiteio/noname-minimal-server。
- **与本仓对照**:三家逻辑代码都单源,差异在**权威在哪 + 客户端怎么跑引擎**——无名杀=房主客户端引擎当权威;FreeKill=双活引擎(两端各自推进、事件流对齐,客户端状态可与服务端漂移);我们=权威单端推进(单机=本地引擎,联机=服务器),联机客户端只做 `restoreFromSnapshot` 只读 hydrate,快照 diff 提取动效,无漂移、可审计(replay 校验/快照哈希建立在此)。FreeKill 亦是「逻辑不上原生语言」的佐证:C++ 项目刻意把游戏逻辑放可嵌入的 Lua,换同一份代码两端跑+mod 生态。
