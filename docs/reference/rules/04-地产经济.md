# 地产经济

> 买城可在轮末收银，扩军可提高变卖价与交易加成，进攻则带来银两和接城机会。

正文数字均为机制语义值,逐处带代码符号锚点;纯数值索引(四档城制/建城费/变卖价)统一见 [10-关键数值总表](./10-关键数值总表.md)。

## 经济总纲:无过路费、无升级费

与常规大富翁的两条刻意差异(`economy.ts` 头注):

- **无过路费**:他人落到你的城不付租金,只可能触发珍宝交涉(见 [05-珍宝](./05-珍宝.md))。
- **无升级费**:自己到达己城可选**免费**扩军;他人到达永不升级——升级只挂在公道买卖成交上。

## 四档城制(ADR-0034)

每座城在经济数据上归属**四档之一**,档位决定购价与三条曲线的形状(逐城分配与标准值由守卫测试 `test/maps/map-economy-guard.test.ts` 锁定):

| 城档     | 定位       | 曲线形状                                                        |
| -------- | ---------- | --------------------------------------------------------------- |
| **县城** | 低阶加法城 | 倍率恒 1,小加值——便宜宝靠加值也有收益                           |
| **郡城** | 高阶加法城 | 倍率恒 1,大加值——加法城的满配形态                               |
| **奇城** | 纯乘城     | 加值恒 0,倍率逐级陡升且**高于名城**——高等级配高价值珍宝一举破局 |
| **名城** | 乘加顶级城 | 倍率+加值两者皆有、购价明显高——低中高价值珍宝通吃               |

- 档位只影响**坐地起价**的售价(`premiumPriceOf`,公式见 [05-珍宝](./05-珍宝.md));公道买卖恒按指导价成交,与城档无关。
- 档位的棋盘视觉通道=**建筑形制**(ADR-0042):县=单檐小院 / 郡=重镇形制 / 名=琉璃描金重楼 / 奇=关隘,总览可辨;板上不立文字牌,弹层读数场合只缀两字档位名(DESIGN §4.8 名词纪律)。
- 棋盘上，无主城落在低矮石台上，有主城显示归属边框和国号旗。金底数字徽记显示等级，蓝盾显示当前防御。都城以王旗、金匾和光晕辨认。城池缩略图沿用同一形制。
- 满级分域:便宜宝(指导价 <600)加法城/名城占优,贵宝(>600)奇城一骑绝尘;**青囊书(600)恰是奇城/名城满级的精确分水岭**。
- 「倍率恒 1」即 `tradeMult` 四级全 1(纯加法),「加值恒 0」即 `tradeAdd` 四级全 0(纯乘法)——同一公式 `指导价 × 当级乘数 + 当级加值` 的两种退化形,引擎零特判。

## 城池等级、变卖价与交易加成

- 有主城从 1 级到地图指定的 `maxLevel`，内置地图均为 4 级上限。地图须在 `INITIAL_CITY_LEVEL` 到 `MAX_CITY_LEVEL` 之间配置整数上限（`board-loader.ts` 的 `loadMap`）。无主城没有持有等级和防御值。
- 购入、建都和攻陷接手均为 1 级满防。每次实际升级回到新等级的满防。债主接城保留原等级并回满防御（`defense.ts` 的 `resetToFull`、`resetTransferredHolding`）。
- 满级判定 `canUpgrade`(`economy.ts`:level < maxLevel);满级再升被拒(`AlreadyMaxLevel`,见 `economy.ts` `upgrade`)。
- 各等级**变卖价** = 地图 `valueByLevel` 的当级值（第一项为 1 级，共 `maxLevel` 项）,引擎查价函数 `sellValueOf`(`economy.ts`);按购价系数 50%/70%/90%/110% 逐档生成(#1077,守卫锁定)——满级城变卖**仍高于购价**,城池是可增值资产,但变卖只发生在破产自救且「凑足即止」(见 [09-破产清算](./09-破产清算.md)),不构成囤城套利。
- 各等级**交易加成**由 `cityTradeTermsOf` 取 `tradeMult` / `tradeAdd` 当级值(坐地要价公式的城侧可变部分,形状由城档决定,见上节;公式见 [05-珍宝](./05-珍宝.md))。
- 卷轴陈列(#671):城池详情 / 购地 / 扩军三卷轴的等级表主列 = 交易加成,第二列按城型——普通城 = 变卖价;**都城与选都候选 = 都城补给**(固定值,四行同值;变卖价对都城是死信息:都城永不可变卖,见 [09-破产清算](./09-破产清算.md))。
- 费用按动作区分:选都显示目录 `PropertyDef.buildCost` 与确认后的余额;购地显示 `PropertyDef.purchasePrice` 与购入后的余／差。只读查看自己或他人持有城时,展示持有者、等级、收益与标明含义的购入价资料,不计算不存在的购买余差;单机与联机同一口径。

## 防御值与城池伤害

- **防御值**读 `PropertyHolding.defense`。1、2、3、4 级的满防依次为 40、30、20、10（`defense.ts` 的 `fullDefenseOf`）。详情显示当前防御与满防，棋盘蓝盾按两者的比例填充。
- 火攻、火烧连营、燃烧和外敌乘虚共用 `defense.ts` 的城池伤害结算。单击最多扣除受击时的防御值。2–4 级城防御打空后降一级并回满新等级的防御。例如 4 级满防城受到 20 点请求伤害，实际扣 10 点，降为 3 级并回满至 20。
- 1 级非都城防御打空时攻陷。1 级都城防御打空后仍归原城主，显示空心蓝盾和 0，实际扣掉的敌方防御照发即时奖励。
- 火攻实际扣防响短石击，降级或打空都城响碎石声。攻陷的城栓与旗帛声随归属变化落定。同一张火烧连营在应答前后结算多城，仍只响已发生的最重结果。

## 燃烧

- 火攻和火烧连营实际扣防且同一级仍有剩余防御时，施加 3 个火焰标记（`defense.ts` 的 `applyDirectFireDamage`、`FIRE_MARKS_PER_IGNITION`）。火烧连营波及己城时同样会施加燃烧。
- 续火时补足 3 个标记，整组换成最近施火者，保留该周期已推进的回合数。识破保护的城免当次扣防和续火，保留此前的标记、来源与进度。
- 从首次施加后的下一实际回合开始计时。每完成三个实际回合（`constants.ts` 的 `CITY_BURN_TURNS`），消耗一个标记并扣 1 点防御（`defense.ts` 的 `CITY_BURN_DAMAGE`）。剩余标记从下一个周期继续。续火可以在原定回合到期，到期扣防本身不会续火。
- 跳过的座位和没有实际回合的整轮不推进计时。已经开始的回合即使由行动诸侯主动认破产收尾，也照常推进。
- 「回合结束前」「回合结束时」「回合结束后」及其选择全部结清后，燃烧按地图格顺序处理。每城的扣防、奖励、城池受损或失城时机和选择均结清后，才读取下一座城此时的归属与状态。已经被清除的标记不会结算，新施加的燃烧从下一个实际回合开始计时。
- 城池破防、实际升级、易主或回无主时清除燃烧。债主接城时也清除燃烧。火焰伤害若直接破防，回满的新等级从无燃烧状态开始。
- 燃烧的标记数和伤害来源公开。城池详情可同时查阅这两项和伤害排行榜。施火者破产后，其他诸侯城内的标记仍保留原来源。
- 燃烧常规扣防只呈现满焰与防御变化。燃烧造成破防或攻陷时，响相应的城损声。

## 城池攻陷与奖励

- 敌城实际损失的防御值会记给出手诸侯。可到城池详情查看伤害排行榜。城池升降级时保留该任城主期间的累计伤害，易主或回无主时清空。
- 1 级非都城被攻陷时，由累计伤害最高的存活敌方诸侯接城。同点时先达到该伤害值者优先。新城主以 1 级满防接城，无合格诸侯时城池回到无主。
- 存活诸侯每实际扣除敌城 1 点防御，国库发 5 两**即时奖励**。奖励逐城到账，对局直接显示到账金额。计价见[关键数值总表](./10-关键数值总表.md)的 `CITY_IMMEDIATE_REWARD_PER_POINT`。
- **攻陷奖励**和**结算奖励池**按地图购入价计算。最后一击的合格诸侯领取攻陷奖励，存活敌方诸侯按在该城的累计伤害比例分池。
- 分池按整两四舍五入。最终总额与奖池对齐，余差优先留给靠前的诸侯。发银从当前行动诸侯起，依座位环序。
- 己方误伤、无来源或已破产来源的伤害照常扣防，攻陷时按已有的敌方累计伤害判归属和分池。这些伤害无人领取对应的即时奖励与攻陷奖励。实际扣防为 0 时无即时奖励。
- 奖励铜钱在城损声之后抵达席位并响入账声。技能待决时，已经到账的银两即时可见。每次施放火烧连营的多笔奖励共用一次入账声，技能应答跨断线时按这次施放继续归账。

## 持城收益

全桌轮末，等本回合的燃烧和轮末时机结清后，每座有主的非都城按地图购入价给当时城主发一次银两。持城收益及其派生效果结清后判胜一次。跳过自己回合的城主也能领取。购地卷轴展示该城的每轮收益，计价锚点见[关键数值总表](./10-关键数值总表.md)。

首枚持城收益铜钱抵达席位、数字回弹时响一声。同轮其余持城收益用画面显示。

## 名下城池清单(入口)

从左上「☰」或无需选择席位目标时的任一席位格打开**诸侯详情**。名录同时显示所有诸侯的银两、体力、手牌数、城池、名将和珍宝。点对应行的城池列打开名下城池清单，关闭清单回到全员名录。名下城池清单(只读,组件单源 `src/app/screens/game/CityLedgerModal.tsx`):一城一行按行军顺序(棋盘 index 序),五列 = 城名 / 等级与防御 / 购入价(`purchasePrice`)/ 变卖价(当前档 `valueByLevel`,即上节 `sellValueOf`)/ 交易加成(当前档 `tradeMult`/`tradeAdd`,要价公式见 [05-珍宝](./05-珍宝.md));名下无城呈「名下暂无城池」空态。数值一仍上表与地图,不另设第二事实源。

## 购买城池(进驻)

城池决策按固定事件结算后的状态判定（`movement-flow.ts` 的 `resolveLanding` 与 `resolveProperty`）。例如招贤城选项结清后继续该城交易链。单机与联机都按权威最终落格结果交给对应决策者,不在到达时提前判定。

落到无主普通城可花钱进驻(`movement-flow.ts` `resolveProperty` 无主分支 → `buyProperty`;成交走 `economy.ts` `buy`):

- **价 = 现金**:支付 `purchasePrice`,购入即为 1 级满防。买城门槛只有现金——委任状(旧「进驻额度」机制)已随 2026-11-01 整建退役。
- **拒绝理由**:现金不足 → `InsufficientFunds`(`economy.ts` `TransactionResult` 取值);选项集标「银两不足」并置不可用(`choices.ts` `decisionChoices`)。
- **选项集 ≤1 自动执行**(ADR-0013)。银两不足时只剩默认行为「不取」，`movement-flow.ts` 的 `enterDecisionPhase` 自动执行并结束回合，结果仅记入对局日志。购地卷轴在至少有两个可用选项时弹出，购入价、结算后余额和每轮收益固定在等级表上方。
- **成交声**同时包含「据」章落定和铜钱入囊。

## 免费扩军

**自己到达己城**才可扩军(`movement-flow.ts` `upgradeProperty`;成交走 `economy.ts` `upgrade`):

- **免费**:+1 级不花一分钱。等级、防御与交易加成变化固定在扩军卷轴首屏。
- **满级自动按兵不动**:城已满级时选项集只剩假选择「按兵不动」(`choices.ts` `decisionChoices`),引擎自动执行并结束回合(浮字 + 日志「城已满级,按兵不动」),不弹扩军卷轴。
- 到达本身不升级:落他人城只有公道买卖成交才 +1 级,细则见 [05-珍宝](./05-珍宝.md)。
- 等级实际抬升时，两记木榫声贴等级徽记。扩军与公道买卖升级共用。

## 银两变动的演出

银两到账时，席位数字随归账铜钱抵达回弹并响一声。商市下跌等独立失银响低沉的钱囊声，并在棋盘显示负向金额。玩家间转账在收款方的铜钱抵达时全桌共享一声交接，双方金额由画面显示。见[音效设计](../../design/音效设计.md#城池交易银两与交割)。

## 都城补给

补给只在**自己都城**结算,两个入口同走一处:落点恰是都城(落地补给)与路过必停(驻跸补给),都调 `movement-flow.ts` 的 `applyResupply`。

**补给量 = 地图顶层 `resupply`,固定值**(两/次,不随城池等级、不随城档;查询链 `movement-flow.ts` `capitalSupplyOf`)。

- `resupply` 由地图顶层必配(`board-loader.ts` `loadMap` 校验,缺省抛错);内置图均为 1000 两/次。
- 补给是**正收入**、直接进现金,不走破产裁决路径(`economy.ts` `settleDebt` 头注);都城地产永不可变卖(见 [09-破产清算](./09-破产清算.md))。
- 都城还会恢复已损体力的 50%，半点向上取整（`constants.ts` 的 `CAPITAL_STAMINA_RECOVERY_RATE`）。例如体力 40／100 时补给后变为 70，满体力时省略回血浮字。见[体力与休整](./07-体力与休整.md)。
