# 地产经济

> 一句话:**本作刻意砍掉了传统大富翁的过路费与升级费**——城池价值体现在「扩军抬高变卖价」与「都城补给」的现金流上,收入全靠都城补给与卖珍宝(`src/core/economy.ts` 头注)。

正文数字均为机制语义值,逐处带代码符号锚点;纯数值索引(建城费/变卖价/价位档)统一见 [10-关键数值总表](./10-关键数值总表.md)。

## 经济总纲:无过路费、无升级费

与常规大富翁的两条刻意差异(`economy.ts` 头注):

- **无过路费**:他人落到你的城不付租金,只可能触发珍宝交涉(见 [05-珍宝](./05-珍宝.md))。
- **无升级费**:自己到达己城可选**免费**扩军;他人到达永不升级——升级只挂在公道买卖成交上。

## 城池等级与价值

- 等级 Lv.0–3,由地图逐城 `maxLevel` 配置(默认 3;持有等级 0..maxLevel 共 4 级,购入/建都即 Lv.0;见 `types.ts` `PropertyDef`)。
- 满级判定 `canUpgrade`(`types.ts`:level < maxLevel);满级再升被拒(`AlreadyMaxLevel`,见 `economy.ts` `upgrade`)。
- 各等级**变卖价** = 地图 `valueByLevel[level]`(长度 = maxLevel+1,下标 = 等级),引擎查价函数 `sellValueOf`(`economy.ts`)。

## 购买城池(进驻)

落到无主普通城可花钱进驻(`game.ts` `resolveProperty` 无主分支 → `buyProperty`;成交走 `economy.ts` `buy`):

- **价 = 现金 + 1 张委任状**:支付 `purchasePrice`,同时消耗 `BUY_WARRANT_COST`(`constants.ts`,= 1)张委任状;购入即为 Lv.0。
- **拒绝理由**:委任状不足 → `NoWarrant`;现金不足 → `InsufficientFunds`(两者均为 `types.ts` `TransactionResult` 取值);选项集相应标「无委任状/银两不足」并置不可用(`choices.ts` `decisionChoices`)。
- **选项集 ≤1 自动执行**(ADR-0013):银两或委任状不足时选项集只剩默认行为「不取」,引擎经 `enterDecisionPhase`(`game.ts`)直接自动执行——浮字「银两不足,未能购城/无委任状,不可购」+ 写入对局日志,**不弹购地卷轴**;弹卷轴 ⇔ 至少两个真实选项。

## 免费扩军

**自己到达己城**才可扩军(`game.ts` `upgradeProperty`;成交走 `economy.ts` `upgrade`):

- **免费**:+1 级不花一分钱,也**不消耗委任状**(`constants.ts` `BUY_WARRANT_COST` 注释)。
- **满级自动按兵不动**:城已满级时选项集只剩假选择「按兵不动」(`choices.ts` `decisionChoices`),引擎自动执行并结束回合(浮字 + 日志「城已满级,按兵不动」),不弹扩军卷轴。
- 到达本身不升级:落他人城只有公道买卖成交才 +1 级,细则见 [05-珍宝](./05-珍宝.md)。

## 落他人城:交涉入口

| 城主状态 | 处理 |
|---|---|
| 城主**有**珍宝 | 进入珍宝交涉(`AwaitingTreasureOwner`):公道买卖 / 坐地起价 / 不交易,细则见 [05-珍宝](./05-珍宝.md) |
| 城主**无**珍宝 | 无事发生,直接结束回合(`game.ts` `resolveProperty`) |

## 委任状:买城的额度

委任状只约束**买城**——防止运气好的玩家一圈把城占光(`constants.ts` 头注);扩军、交涉均不消耗。

| 事件 | 变化 | 代码 |
|---|---|---|
| 开局 | 每人 3 张 | `constants.ts` `STARTING_WARRANTS` |
| 经过自己都城(巡幸,必停) | +2 | `constants.ts` `WARRANTS_PER_PASS`;`game.ts` `rollAndMove` |
| 进驻一座新城 | −1 | `constants.ts` `BUY_WARRANT_COST`;`game.ts` `buyProperty` |
| 扩军(升级) | 0(免费) | 同上 `BUY_WARRANT_COST` 注释 |

巡幸的必停与驻跸补给细则见 [03-回合与行军](./03-回合与行军.md)。

## 都城补给:两大收入来源之一

补给只在**自己都城**结算,两个入口同走一处:落点恰是都城(落地补给)与路过必停(驻跸补给),都调 `applyResupply`(`game.ts`)。

**补给量 = `resupplyPerLevel` × (城池等级 Lv + 1)**(`economy.ts` `supplyFor`;字段或等级缺失时为 0)。

- `resupplyPerLevel` 由地图逐城显式配置(tile 字段);内置地图呈三档——边陲 200 / 中庸 300 / 沃野 400,乘法城 300,数值索引见 [10-关键数值总表](./10-关键数值总表.md)。
- 补给是**正收入**、直接进现金,不走破产裁决路径(`economy.ts` `settleDebt` 头注);都城地产永不可变卖(见 [09-破产清算](./09-破产清算.md))。
- 等级越高补给越多——免费扩军由此多一层隐性回报。
