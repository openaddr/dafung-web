# 地产经济

> 一句话:**本作刻意砍掉了传统大富翁的过路费与升级费**——城池的等级收益体现在「扩军抬高变卖价与交易加成」的现金流上,收入全靠都城补给与卖珍宝(`src/core/economy.ts` 头注)。

正文数字均为机制语义值,逐处带代码符号锚点;纯数值索引(四档城制/建城费/变卖价)统一见 [10-关键数值总表](./10-关键数值总表.md)。

## 经济总纲:无过路费、无升级费

与常规大富翁的两条刻意差异(`economy.ts` 头注):

- **无过路费**:他人落到你的城不付租金,只可能触发珍宝交涉(见 [05-珍宝](./05-珍宝.md))。
- **无升级费**:自己到达己城可选**免费**扩军;他人到达永不升级——升级只挂在公道买卖成交上。

## 四档城制(ADR-0034)

每座城在经济数据上归属**四档之一**,档位决定购价与三条曲线的形状(逐城分配与标准值由守卫测试 `test/map-economy-guard.test.ts` 锁定):

| 城档     | 定位       | 曲线形状                                                        |
| -------- | ---------- | --------------------------------------------------------------- |
| **县城** | 低阶加法城 | 倍率恒 1,小加值——便宜宝靠加值也有收益                           |
| **郡城** | 高阶加法城 | 倍率恒 1,大加值——加法城的满配形态                               |
| **奇城** | 纯乘城     | 加值恒 0,倍率逐级陡升且**高于名城**——高等级配高价值珍宝一举破局 |
| **名城** | 乘加顶级城 | 倍率+加值两者皆有、购价明显高——低中高价值珍宝通吃               |

- 档位只影响**坐地起价**的售价(`premiumPriceOf`,公式见 [05-珍宝](./05-珍宝.md));公道买卖恒按指导价成交,与城档无关。
- 满级分域:便宜宝(指导价 <600)加法城/名城占优,贵宝(>600)奇城一骑绝尘;**青囊书(600)恰是奇城/名城满级的精确分水岭**。
- 「倍率恒 1」即 `tradeMult` 四级全 1(纯加法),「加值恒 0」即 `tradeAdd` 四级全 0(纯乘法)——同一公式 `指导价 × tradeMult[Lv] + tradeAdd[Lv]` 的两种退化形,引擎零特判。

## 城池等级、变卖价与交易加成

- 等级 Lv.0–maxLevel,上限由地图 `maxLevel` **逐图必配**(`loadMap` 校验 ≥1 整数,缺省不兜底;内置图均为 3,即持有等级 0..3 共 4 级,购入/建都即 Lv.0;见 `economy.ts` `PropertyDef`)。
- 满级判定 `canUpgrade`(`economy.ts`:level < maxLevel);满级再升被拒(`AlreadyMaxLevel`,见 `economy.ts` `upgrade`)。
- 各等级**变卖价** = 地图 `valueByLevel[level]`(长度 = maxLevel+1,下标 = 等级),引擎查价函数 `sellValueOf`(`economy.ts`);按购价系数 60%/90%/120%/150% 逐档生成(守卫锁定)——满级城变卖**高于购价**,城池是可增值资产,但变卖只发生在破产自救且「凑足即止」(见 [09-破产清算](./09-破产清算.md)),不构成囤城套利。
- 各等级**交易加成** = `tradeMult[level]` / `tradeAdd[level]`(坐地要价公式的城侧可变部分,形状由城档决定,见上节;公式见 [05-珍宝](./05-珍宝.md))。
- 卷轴陈列(#671):城池详情 / 购地 / 扩军三卷轴的等级表主列 = 交易加成,第二列按城型——普通城 = 变卖价;**都城与选都候选 = 都城补给**(固定值,四行同值;变卖价对都城是死信息:都城永不可变卖,见 [09-破产清算](./09-破产清算.md))。

## 名下城池清单(入口)

对局中点席位格的**城池图标**(#700 起城池图标只在席位格;旧仪表条徽章随仪表条退役),可弹任一玩家(含自己)的名下城池清单(只读,组件单源 `src/app/screens/game/CityLedgerModal.tsx`):一城一行按行军顺序(棋盘 index 序),五列 = 城名 / 等级 / 购入价(`purchasePrice`)/ 变卖价(当前档 `valueByLevel`,即上节 `sellValueOf`)/ 交易加成(当前档 `tradeMult`/`tradeAdd`,要价公式见 [05-珍宝](./05-珍宝.md));名下无城呈「名下暂无城池」空态。数值一仍上表与地图,不另设第二事实源。

## 购买城池(进驻)

落到无主普通城可花钱进驻(`movement-flow.ts` `resolveProperty` 无主分支 → `buyProperty`;成交走 `economy.ts` `buy`):

- **价 = 现金 + 1 张委任状**:支付 `purchasePrice`,同时消耗 `BUY_WARRANT_COST`(`constants.ts`,= 1)张委任状;购入即为 Lv.0。
- **拒绝理由**:委任状不足 → `NoWarrant`;现金不足 → `InsufficientFunds`(两者均为 `economy.ts` `TransactionResult` 取值);选项集相应标「无委任状/银两不足」并置不可用(`choices.ts` `decisionChoices`)。
- **选项集 ≤1 自动执行**(ADR-0013):银两或委任状不足时选项集只剩默认行为「不取」,引擎经 `enterDecisionPhase`(`authority.ts`)直接自动执行——浮字「银两不足,未能购城/无委任状/不可购」+ 写入对局日志,**不弹购地卷轴**;弹卷轴 ⇔ 至少两个真实选项。

## 免费扩军

**自己到达己城**才可扩军(`movement-flow.ts` `upgradeProperty`;成交走 `economy.ts` `upgrade`):

- **免费**:+1 级不花一分钱,也**不消耗委任状**(`constants.ts` `BUY_WARRANT_COST` 注释)。
- **满级自动按兵不动**:城已满级时选项集只剩假选择「按兵不动」(`choices.ts` `decisionChoices`),引擎自动执行并结束回合(浮字 + 日志「城已满级,按兵不动」),不弹扩军卷轴。
- 到达本身不升级:落他人城只有公道买卖成交才 +1 级,细则见 [05-珍宝](./05-珍宝.md)。

## 委任状:买城的额度

委任状只约束**买城**——防止运气好的玩家一圈把城占光(`constants.ts` 头注);扩军、交涉均不消耗。

| 事件                    | 变化      | 代码                                                                |
| ----------------------- | --------- | ------------------------------------------------------------------- |
| 开局                    | 每人 3 张 | `constants.ts` `STARTING_WARRANTS`                                  |
| 经过自己都城(巡幸,必停) | +2        | `constants.ts` `WARRANTS_PER_PASS`;`movement-flow.ts` `rollAndMove` |
| 进驻一座新城            | −1        | `constants.ts` `BUY_WARRANT_COST`;`movement-flow.ts` `buyProperty`  |
| 扩军(升级)              | 0(免费)   | 同上 `BUY_WARRANT_COST` 注释                                        |

巡幸的必停与驻跸补给细则见 [03-回合与行军](./03-回合与行军.md)。

## 都城补给:两大收入来源之一

补给只在**自己都城**结算,两个入口同走一处:落点恰是都城(落地补给)与路过必停(驻跸补给),都调 `applyResupply`(`authority.ts`)。

**补给量 = 地图顶层 `resupply`,固定值**(两/次,不随城池等级、不随城档;查询链 `movement-flow.ts` `capitalSupplyOf`)。

- `resupply` 由地图顶层必配(`board-loader.ts` `loadMap` 校验,缺省抛错);内置图均为 1000 两/次。
- 补给是**正收入**、直接进现金,不走破产裁决路径(`economy.ts` `settleDebt` 头注);都城地产永不可变卖(见 [09-破产清算](./09-破产清算.md))。
- 补给与城档、等级全脱钩,选都的补给考量只剩**建城费**(建城费 = 购价 50%,便宜城当选)与棋盘位置。
