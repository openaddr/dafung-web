# 关键数值总表

> 规则手册第 10 页(附录):由原 RULES.md §11 逐行转成的「条目 → 代码锚点」索引,并回填锦囊条目组。**本页不复制任何数值**——数值以代码为准,锚点跟符号走。
## 使用说明

- 想知道值:点锚点读代码;想知道机制语义:去组名标注的详见页。
- 锚点一律「文件 + 符号名」,不写行号(行号必漂移,规约见 [`AGENTS.md`](../../../AGENTS.md))。
- 标「地图」的条目随地图配置变化,事实源在 `public/maps/*.json`;默认地图 = `index.json` 首项(现「棋盘天下」chessboard.json)。

### 对局与胜利(详见 [01-总览与胜利](./01-总览与胜利.md))

| 条目 | 口径一句话 | 代码锚点 |
|---|---|---|
| 目标身价 | 引擎默认值,地图可覆盖 | `game.ts` `DEFAULT_TARGET`;地图 `targetNetWorth` |
| 起手现金 | 引擎默认值,地图可覆盖 | `game.ts` `DEFAULT_CASH`;地图 `startingCash` |
| 座位数 | 引擎构造时校验的合法区间 | `game.ts` `GameEngine` 构造(座位数校验) |

| 移动骰 | 单骰,签面汉字展示 | `dice.ts` `createDice`;`constants.ts` `SIGN_FACES` |
