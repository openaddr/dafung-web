# 08 · 名士与技能

名士(英雄)是挂在玩家名下的技能载体:**被动技**(时机框架自动触发)+ **主动技**(军师幕内手动发动,#188 档 3)并存。核心设计是**技能即数据**:加名将只改数据文件、不动引擎;一武可多技。

## 名士获取

- 起手 0 位,上限 3 位(`constants.ts` `HERO_CAPACITY`)。
- **招贤纳士**:落**自己都城**(驻跸补给之后)或**卧龙岗**时触发(落格分流在 `game.ts` `resolveLanding`,招贤本体 `tryRecruitHero`):从剩余名士池随机抽 3 位(`AwaitingHeroPick` 卷轴),三选一(`resolveHeroPick`);麾下已满或池已空则无事发生,直接结束回合。
- **唯一性**:已被招揽的名士不再进候选池(`recruitedHeroIds`),全场同名士唯一。
- 其他来投渠道与招贤同池同上限:机遇「义士来投」「以宝换贤」(见 [`./07-声望与机遇.md`](./07-声望与机遇.md))、锦囊「求贤令」(见 [`./06-锦囊.md`](./06-锦囊.md))。
- **破产释放**:玩家破产时麾下名士全部释放回招贤池(`finalizeBankruptcy`),他人可再招;见 [`./09-破产清算.md`](./09-破产清算.md)。

## 技能系统:时机框架

技能是纯数据声明,挂 `heroes.ts` `HEROES` 各条 `HeroDef.skills`,由派发器 `game.ts` `dispatchMoment` 消费。三要素:

| 要素 | 载体 | 语义 |
|---|---|---|
| when | `timing.ts` `GameMoment`(26 时机七类,集中注册于 `MOMENTS`) | 什么时机触发 |
| effect | `effects.ts` `EFFECTS` 注册表(EffectId → 效果函数) | 做什么;查不到直接抛错(零兜底) |
| params | 纯数据参数(可序列化) | 效果参数;缺必填项抛错 |

深度设计说明与扩展指南(加效果一步 / 加技能两步 / 加时机三步)见 [`../../explanation/时机框架.md`](../../explanation/时机框架.md)。

### 主动技与军师幕

- **军师幕**(窗口改名,testid 族 `scroll-jinnang*` 不变):回合开始掷骰前的统一决策窗 = 可用锦囊 + 冷却就绪的主动技 + 「今不用」(选项集单源 `choices.ts` `jinnangChoices`);零可用则静默跳过不弹卷轴(ADR-0013 ≤1 自动执行口径,`hasUsableJinnang`)。卷轴里主动技以金底「技」方章与锦囊的朱底标签章区分。
- **独立冷却**:主动技发动记 `heroLastFired`(键 = `active.id`,与被动技同机制;`choices.ts` `skillCooldownLeft` 算剩余轮数),与锦囊的「每回合每标签一张」名额互不相干。发动过技后重算选项集,同回合仍有可用锦囊/其他就绪技则窗口停留(`settleJinnangExit`)。
- **出技是公开事件**:浮字 + `category:"skill"` 战报(detail 锚 `heroSkill owner/skill/kind/target`),与出牌同口径。命令 `useHeroSkill`(`types.ts`):指向域的技选定后进**目标段**(载荷 `types.ts` `PendingHeroSkill`,与锦囊目标段互斥;可「作罢」,不记冷却)。合法性(相位/持有/冷却/费用/目标)由引擎校验(`game.ts` `resolveHeroSkill`),UI 永不裁决。
- **结算纪律**:复用既有结算路径(火攻 = `demolishOnVictim`,不新造 effect kind);技能结算内**不派发时机**(与 `grantSkillCash` 的防连锁同口径——出技不触发他人的 CashLost/CashGained 被动技);免战金牌只挡锦囊(牌面原文),不庇护主动技。
- **快照/重放**:冷却(`heroLastFired` 本就在快照)、目标段载荷 `pendingSkill`、擂鼓加成 `heroDiceBonus` 全量进快照(序列化单点清单 `snapshot.ts`);技能命令是普通 cmd 行,重放天然复现。技能选项不含他人私隐(名士/冷却/城防/现金均公开),ADR-0016 投影无新增泄漏面。
- **bot/看门狗/托管**:bot 出技按净值贪心(`bot.ts` `heroSkillIntent`:火攻挑城最多者、赈济体力 <70 自疗、征辟可用即用补偿给最穷者、擂鼓恒用),Simple 难度同样 50% 弃权;**看门狗/接管/托管(人类座位代驾)永不主动出技**(长线战略资源不替主人花,`BotActOptions.skills:"hold"`),比锦囊代驾口径(接管不用、自助托管按策略)更保守。

### scope 与触发留痕

- **scope**(技能属主与时机主体的关系,缺省 `self`;判定 `game.ts` `scopePasses`):`self` = 属主是主体;`others` = 主体非属主;`any` = 主体不限;`actor` = 主体恰为当前行动玩家(现所有挂点主体即行动者,与 `any` 等价,为未来「回合外」时机预留)。
- **触发留痕**:击发记 `category:"skill"` 战报,detail 含 `skillFire owner/hero/skill/moment/subject`——每次触发可审计、可重放(日志格式见 [`../对局日志.md`](../对局日志.md))。

### 冷却与派发

- **冷却**:技能可带 `cooldown`(单位 = 轮;键 = `skill.id`,记于玩家 `heroLastFired`;`skillReady` 判「距上次触发 ≥ N 轮」)。被动技现役仅华佗带 3 轮冷却;主动技四人全带(3~5 轮,见上表),同用此机制。
- **确定性派发**:`dispatchMoment` 按「座位序 × 名将序 × 技能序」遍历,同种子下联机各端派发次序完全一致。
- **三条纪律**:破产玩家的技能不参与派发;效果函数返回 false = 条件不满足,静默跳过(不记战报/冷却);效果内禁止同步再派发时机(派发深度 >2 直接抛错防递归),效果层收益(如技能给银 `grantSkillCash`)不再触发 `CashGained`——技能链不会自我放大。
