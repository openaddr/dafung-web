# 08 · 名士与技能

名士(英雄)是挂在玩家名下的被动技能载体。核心设计是**技能即数据**:加名将只改数据文件、不动引擎;一武可多技。

## 名士获取

- 起手 0 位,上限 3 位(`constants.ts` `HERO_CAPACITY`)。
- **招贤纳士**:落**自己都城**(驻跸补给之后)或**卧龙岗**时触发(落格分流在 `game.ts` `resolveLanding`,招贤本体 `tryRecruitHero`):从剩余名士池随机抽 3 位(`AwaitingHeroPick` 卷轴),三选一(`resolveHeroPick`);麾下已满或池已空则无事发生,直接结束回合。
- **唯一性**:已被招揽的名士不再进候选池(`recruitedHeroIds`),全场同名士唯一。
- 其他来投渠道与招贤同池同上限:机遇「义士来投」「以宝换贤」(见 [`./07-声望与机遇.md`](./07-声望与机遇.md))、锦囊「求贤令」(见 [`./06-锦囊.md`](./06-锦囊.md))。
- **破产释放**:玩家破产时麾下名士全部释放回招贤池(`finalizeBankruptcy`),他人可再招;见 [`./09-破产清算.md`](./09-破产清算.md)。

## 技能系统:时机框架

技能是纯数据声明,挂 `heroes.ts` `HEROES` 各条 `HeroDef.skills`,由派发器 `game.ts` `dispatchMoment` 消费。三要素:

| 要素 | 载体 | 语义 |
|---|---|---|
| when | `timing.ts` `GameMoment`(26 时机七类,集中注册于 `MOMENTS`) | 什么时机触发 |
| effect | `effects.ts` `EFFECTS` 注册表(EffectId → 效果函数) | 做什么;查不到直接抛错(零兜底) |
| params | 纯数据参数(可序列化) | 效果参数;缺必填项抛错 |

深度设计说明与扩展指南(加效果一步 / 加技能两步 / 加时机三步)见 [`../../explanation/时机框架.md`](../../explanation/时机框架.md)。

### 现役名士表

数据源 `heroes.ts`(下表效果数字随行为描述走,效果函数锚 `effects.ts` `EFFECTS` 对应条目):

| 名士 | when | effect(params) | scope | 行为 |
|---|---|---|---|---|
| 周瑜 | `BeforeMarch` | `moveBonus {steps:1}` | self | 行军步数 +1(掷骰前累计,`takeMarchBonus` 供 `rollAndMove` 消费;见 [`./03-回合与行军.md`](./03-回合与行军.md)) |
| 曹丕 | `CashLost` | `gainCash {amount:50}` | others | 其他玩家被动失财时,自己 +50 分银 |
| 张星彩 | `DieRolled` | `gainIfFace {face:6, amount:20}` | any | 场上任意人掷出 6,自己 +20 分银(非 6 静默跳过,不记战报) |
| 华佗 | `RoundStart` | `regenStamina {amount:15}`,cooldown 3 | any | 每 3 轮恢复 15 体力(回体类,与体力节互链 [`./07-声望与机遇.md`](./07-声望与机遇.md)) |

### scope 与触发留痕

- **scope**(技能属主与时机主体的关系,缺省 `self`;判定 `game.ts` `scopePasses`):`self` = 属主是主体;`others` = 主体非属主;`any` = 主体不限;`actor` = 主体恰为当前行动玩家(现所有挂点主体即行动者,与 `any` 等价,为未来「回合外」时机预留)。
- **触发留痕**:击发记 `category:"skill"` 战报,detail 含 `skillFire owner/hero/skill/moment/subject`——每次触发可审计、可重放(日志格式见 [`../对局日志.md`](../对局日志.md))。

### 冷却与派发

- **冷却**:技能可带 `cooldown`(单位 = 轮;键 = `skill.id`,记于玩家 `heroLastFired`;`skillReady` 判「距上次触发 ≥ N 轮」)。现役仅华佗带 3 轮冷却。
- **确定性派发**:`dispatchMoment` 按「座位序 × 名将序 × 技能序」遍历,同种子下联机各端派发次序完全一致。
- **三条纪律**:破产玩家的技能不参与派发;效果函数返回 false = 条件不满足,静默跳过(不记战报/冷却);效果内禁止同步再派发时机(派发深度 >2 直接抛错防递归),效果层收益(如技能给银 `grantSkillCash`)不再触发 `CashGained`——技能链不会自我放大。
