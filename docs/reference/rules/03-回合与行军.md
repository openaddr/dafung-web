# 回合与行军

> 规则手册第 3 页:棋盘、回合状态机、掷骰行军、必停都城、辅路捷径、落格结算与轮次。

## 棋盘一图看懂

地图数据驱动(`board-loader.ts` `loadMap`;`public/maps/index.json` 首项为默认地图,现「棋盘天下」chessboard.json,7×6 主环 42 格 S 形;「群雄逐鹿」sanguo.json,主环 40 格 30 城另带 5 条要隘辅路)。棋盘由 `board.ts` `createBoard` 装配:

- **主路**:单环;**都城**是玩家开局所选的城,取代传统「起点」,经过必停(见下)。
- **辅路**:独立捷径,起终点都接主路,入口带主题命名(函谷关/赤壁/华容道等),机制同一。
- **特殊格**:卧龙岗(招贤)、宝物城(探宝)、锦囊格(抽牌)、天命格(声望)、税关(缴税)、商市(行情)。

## 回合状态机

每回合按 `types.ts` `TurnPhase` 推进,所有玩家操作统一经 `game.ts` `submitCommand` 提交。主线:`AwaitingJinnang?`(用锦囊/今不用)→ `Roll`(掷骰行军)→ `AwaitingBranch?`(辅路入口)→ `Land`(落格结算)→ `AwaitingDecision?`(购地/扩军)→ `EndTurn` → 下一位。其余抉择相位按落格情况插入,全表见[抉择相位一览](#抉择相位一览)。

## 掷骰行军

- **单骰 1–6**,签面以汉字「一~六」展示(`constants.ts` `SIGN_FACES`;骰子实现 `dice.ts` `createDice`),掷几步走几步(`game.ts` `rollAndMove`)。
- **移动加成**:名士技能可在 `BeforeMarch` 时机追加步数(如周瑜 +1)——见[名士与技能](./08-名士与技能.md)与[时机框架](../../explanation/时机框架.md)。

## 必停都城(巡幸)

| 情形 | 行为 |
|---|---|
| **经过**自己都城、落点非都城 | **必停**:行军截断于都城——巡幸 +2 委任状(`constants.ts` `WARRANTS_PER_PASS`)+ 驻跸补给,**结束回合**,无「驻跸/继续」抉择 |
| **落点恰是**自己都城 | 走正常落格结算:补给 + 招贤纳士,回合照常走流程 |

补给按都城当前等级结算(公式 `economy.ts` `supplyFor`,数值见[关键数值总表](./10-关键数值总表.md));委任状是买城额度,详见[地产经济](./04-地产经济.md)。

## 辅路(分岔捷径)

只有**刚好落到辅路起点**才触发入口抉择(`game.ts` `currentTileIsBranchStart`):走大路(`game.ts` `selectBranch` 传 `Main`)= 起点格按普通落格处理;入辅路(传 `Branch`)= **本回合结束**,棋子留入口格待入辅路。此后每回合掷骰沿辅路走,掷几点走几格,每落一格触发效果(`game.ts` `resolveBranchCell`);掷满溢出则从辅路终点汇入主路继续走剩余步数(路径计算 `board.ts` `computePath`)。

| 辅路格 | 效果 | 详见 |
|---|---|---|
| treasure | 拼点探宝 | [珍宝](./05-珍宝.md) |
| event | 抽锦囊随机事件 | [锦囊](./06-锦囊.md)/[声望与机遇](./07-声望与机遇.md) |
| penalty | 中伏:`skipTurns +1`,下回合跳过 | 本页[回合结束与轮次](#回合结束与轮次) |

## 落格结算总表

机遇先于本表:每次落格、城池结算前先按声望比例掷机遇(`game.ts` `maybeApplyEncounter`,见[声望与机遇](./07-声望与机遇.md))。落点结算入口 `game.ts` `resolveLanding`(特殊格分流 `resolveSpecial`,城池分流 `resolveProperty`):

| 落点 | 处理 | 详见 |
|---|---|---|
| 自己都城 | 补给 + 招贤纳士 | [地产经济](./04-地产经济.md)/[名士与技能](./08-名士与技能.md) |
| 卧龙岗 | 招贤纳士(不可进驻) | [名士与技能](./08-名士与技能.md) |
| 宝物城 | 拼点探宝 | [珍宝](./05-珍宝.md) |
| 锦囊格 | 落格必抽一张锦囊 | [锦囊](./06-锦囊.md) |
| 天命格 | 声望 +20(声望泉) | [声望与机遇](./07-声望与机遇.md) |
| 税关 | 缴税 ¥200,付不出走清算 | [破产清算](./09-破产清算.md) |
| 商市 | 行情随机波动 ±¥100~200 | [关键数值总表](./10-关键数值总表.md) |
| 无主普通城 | 可购买(`AwaitingDecision`) | [地产经济](./04-地产经济.md) |
| 自己的普通城 | 可免费扩军(`AwaitingDecision`) | [地产经济](./04-地产经济.md) |
| 他人普通城 | 城主有宝触发珍宝交涉,否则无事 | [珍宝](./05-珍宝.md) |

## 抉择相位一览

选项集集中注册于 `choices.ts` `PHASE_CHOICES`;除默认行为外可用选项 ≤1 时引擎自动执行、不弹卷轴(见 [ADR-0013](../../adr/0013-choice-set-and-auto-execute.md)),唯一例外是破产清算(`choices.ts` `EXCLUDED_FROM_AUTO`)。

| 相位(`TurnPhase`) | 谁决策 | 一句话 |
|---|---|---|
| `AwaitingJinnang` | 当前回合玩家 | 回合开始掷骰前:用锦囊或「今不用」 |
| `AwaitingBranch` | 当前回合玩家 | 辅路入口:走大路还是入辅路 |
| `AwaitingDecision` | 落格玩家 | 购地进驻或免费扩军,或按兵不动 |
| `AwaitingTreasureOwner` | 城主 | 珍宝交涉:公道买卖/坐地起价/不交易 |
| `AwaitingHeroPick` | 获贤玩家 | 招贤纳士三选一 |
| `AwaitingEncounter` | 当事玩家 | 抉择机遇:是否承担代价换收益 |
| `AwaitingExhaustion` | 耗竭玩家 | 体力归 0 的惩罚自选 |
| `AwaitingBankruptcySettle` | 欠款玩家 | 变卖资产自救或宣告破产 |

## 回合结束与轮次

收尾走 `game.ts` `endTurn`:`TurnEnd` 时机 → 结算胜负(`game.ts` `checkVictory`)→ 推进下一位存活玩家(`game.ts` `advanceToNextActive`)。新活跃玩家 `skipTurns > 0` 则**中伏跳过**:扣 1 继续推进,直到可行动者。**轮次计数**:所有人各行动一次 = 1 轮;回到固定轮次锚点(`game.ts` `roundAnchor`,锚点破产则改指定序首个存活者)时先派发 `RoundEnd` → 轮数 +1 → 再派发 `RoundStart`,随后 `TurnStart` 开启新回合;轮次供名士技能冷却使用(见[名士与技能](./08-名士与技能.md))。
