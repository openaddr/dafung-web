# 回合与行军

> 规则手册第 3 页:棋盘、回合状态机、掷骰行军、必停都城、落格结算与轮次。

## 棋盘一图看懂

地图数据驱动(`board-loader.ts` `loadMap`;`public/maps/index.json` 首项为默认地图,现「环游图」huanyou.json——9×4 满格螺旋环共 36 格(#827):先沿外环环游边境一周再盘旋入中原腹地,36 为偶数、全环纯正交一格邻接,蛇尾洛阳与蛇头长安相邻、闭环边可见闭合)。区域单源(#828):区域 = 分组字母 `group` + `theme.ts` `groupNames` 八区名单,城池格 `group` 必配、装载校验;唯一 UI 出口是城池详情卷轴的地域行(`DecisionScrollLayer.tsx` 按 group 查 `groupNames`)。棋盘由 `board.ts` `createBoard` 装配:

- **主路**:单环;**都城**是玩家开局所选的城,取代传统「起点」,经过必停(见下)。
- **全城池制**(#826):盘面上一切格子都是城池(`board.ts` `TileType` 收口到唯一值,旧功能格五型——招贤/锦囊/天命/缴税/行情——与珍宝城独立格型一并退役,装载器对其他格型值响亮报错)。城池可以是**普通城**(落格掷机遇)或**特殊城池**。
- **特殊城池**([ADR-0037](../../adr/0037-special-city-event-field.md),#823):带固定落地事件的城池——普通城池全权(购买/升级/收租/入区/交易链)+ 落地固定事件,地图数据上是城池格的可选 `event` 字段(`board.ts` `TILE_EVENTS`,装载校验 `board-loader.ts` `loadMap`)。五派生名:珍宝城(`event:"treasure"`)/招贤城(`event:"hero"`)/锦囊城(`event:"jinnang"`)/天命城(`event:"fate"`)/商市城(`event:"market"`);环游图现役 9 座(珍宝×4=辽东/下邳/交州/函谷关、锦囊城×2、卧龙城/天命城/商市城各 1,#827)。盘面识别(#828):特殊城右上角恒有一枚两字方印徽标(`Tile.tsx` `EventSeal`,印文词表 `TILE_EVENT_BADGES`——珍宝/名将/锦囊/声望/商市),印面 32×20、屏上单字约 24px(`TILE_SCALE` 2.2,844×390 档实测可读),一眼区分奖励域。

## 回合状态机

每回合按 `authority.ts` `TurnPhase` 推进,所有玩家操作统一经 `authority.ts` `submitCommand` 提交。主线:`AwaitingJinnang?`(出牌阶段:用锦囊/出主动技/不出)→ `Roll`(掷骰行军)→ `Land`(落格结算)→ `AwaitingDecision?`(购地/扩军)→ `EndTurn` → 下一位。其余抉择相位按落格情况插入,全表见[抉择相位一览](#抉择相位一览)。

**反应窗插入点(#281)**:`Roll` 相位的行军途中,若他人行军**途经你的城池**(城主持「半路杀出」)或任何人**宣布锦囊**(他人持「识破诡计」),回合在结算点挂起进 `AwaitingReaction`——非阻塞询问(语义见 [ADR-0017](../../adr/0017-non-blocking-reaction-windows.md)),应答齐(或超时代发「不用」)后续结算;被询问者才看得见询问,其余座位无感。反应锦囊细则见[锦囊](./06-锦囊.md)。

**掷骰自动触发(#188 行军自动化)**:`Roll` 相位没有可抉择的内容,轮到谁都不用点——先钤一方「签」印起签(~0.8s),随后自动起摇掷骰行军(单机约 1s 静默拍后起摇,节奏见 `src/app/fx/timings.ts` `AUTO_MARCH`;联机由服务器定时经同一条命令路径代发,延迟见 `scripts/room.ts` `AUTO_ROLL_DELAY_MS`)。各相位的**抉择**照旧等人作答,不自动化。

**托管代打节拍(#580)**:托管座位的决策由服务器 bot 逐步代打,**单节拍 2s/步**(`src/core/timings.ts` `AUTOPILOT_STEP_MS`,单机/联机同表同值)——托管是替人玩,节奏要像人;代打行为与 bot 座位同一套策略(行为单源,见 [锦囊](./06-锦囊.md)「bot 与看门狗」)。托管是唯一代打状态域(#591/[ADR-0028](../../adr/0028-takeover-is-autopilot.md)):自助开启与看门狗代开(停摆/掉线保留窗到期)拨的是同一个开关,节拍与打法无分叉。步进经注入时钟异步自续(步间让出宏任务):收回/重开托管命令得以在步间落地,链在下一步的座位归属复查处即停——收回托管**切回即停**(对局停在你的真人决策门),重开再续跑。(#529 快/慢双档叙事随 #580 归一退役。)

**bot 步进配速(#730/[ADR-0034](../../adr/0034-bot-step-pacing-lag-recalibration.md))**:bot 座位的连锁同样逐拍下行——**3s/步**(`src/core/timings.ts` `BOT_STEP_MS`,单机/联机同值),每步动作(掷骰/行军/结算)按实速演出播完再落下一步,轮到你时棋盘已追平、看得清每一步发生了什么。产出配速与播放侧的追帧/吸附治理([ADR-0029](../../adr/0029-presentation-self-consistency-invariants.md))分工:配速让普通对局**够不着**校准线,校准只留给掉线追平、全 bot 观战级的持续发散。e2e 经显式注入关配速(0)保测试墙钟,产品局不受影响。

## 掷骰行军

- **单骰 1–6**,签面以汉字「一~六」展示(`constants.ts` `SIGN_FACES`;骰子实现 `dice.ts` `createDice`),掷几步走几步(`movement-flow.ts` `rollAndMove`)。
- **移动加成**:名将技能可在 `BeforeMarch` 时机追加步数(如周瑜 +1)——见[名将与技能](./08-名将与技能.md)与[时机框架](../../explanation/时机框架.md)。
- **行军表现口径([ADR-0029](../../adr/0029-presentation-self-consistency-invariants.md) 演出自洽三不变量)**:行军动画路径在事件提取拍一次算死(提取即定格,播放期零读对局状态),棋子怎么走、落在哪早已定死;每枚棋子的视觉位置同一时刻只有一个写入者(per-id 行军会话:新批顶替在途旧动画、切换点一帧直切,不滑移)。演出落后于对局进度时治理演出、不锁人——浅积压整场加速播放(追帧),持续落后才作废过时演出、棋子直切终态(吸附),全程无提示;轮到你操作只等**自己的棋子落定**,他人棋子照飞、不挡决策。

## 途经他人城池:拦检(半路杀出,#281)

行军逐格途经时,每个**他人城主城池**(城主存活)都是一个拦检询问点(`timing.ts` `MarchPassedCity` 时机;此前途经城无任何结算,现仅此项):

- 城主持有「半路杀出」则开拦检窗,行军挂起(`movement-flow.ts` `marchTraverse`);无人拦则途经无感,照常走。
- 城主打出**拦检**:城主 vs 行人**拼点**(公共结算 `reaction-window.ts` `resolveDuel`,与连环计共用)。**城主胜=行人止步拦检城**、照常落格结算(可能被交涉);平局或落败=牌白耗,行人自拦检城后续走余下途经格——途中遇到的**下一座城**仍会开新询问点。拼点演出=全屏**拼点签面**(`duelResolved` 事件直译:每方一枚签面并排,并行起摇、依座位序错拍落定;点数只在签面一处,平/负宣告浮字不带点数括注,[ADR-0030](../../adr/0030-duel-sign-face-presentation.md))。
- 拦检结算内不再开新反应窗(拦检是终端结算,反识破链只挂锦囊宣布窗,ADR-0027);拦停成功时的行军动画止于拦检城(表现经 ADR-0010 事件管线)。

## 必停都城(巡幸)

| 情形                         | 行为                                                                                                                                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **经过**自己都城、落点非都城 | **必停**:行军截断于都城——巡幸 +2 委任状(`constants.ts` `WARRANTS_PER_PASS`)+ 机遇必出(ADR-0035:截断格先出一条机遇,见[声望与机遇](./07-声望与机遇.md))+ 驻跸补给,**结束回合**,无「驻跸/继续」抉择 |
| **落点恰是**自己都城         | 走正常落格结算:补给 + 招贤纳士,回合照常走流程                                                                                                                                                    |

补给是固定值(每次结算 = 地图顶层 `resupply`,两/次,不随城池等级;查询链 `movement-flow.ts` `capitalSupplyOf`);委任状是买城额度,详见[地产经济](./04-地产经济.md)。

## 落格结算总表

机遇先于本表:每次落格必出一条机遇(ADR-0035 机遇必出,开关与档位规则见[声望与机遇](./07-声望与机遇.md);`encounter-flow.ts` `maybeApplyEncounter`)。**唯一免掷:特殊城池**——落点是事件城(`board.ts` `isEventCity`,城池格带 `event` 字段)不掷随机机遇,固定事件就是这块地的「固定机遇」([ADR-0037](../../adr/0037-special-city-event-field.md));必停都城截断不落格、机遇必出零豁免照旧。落点结算入口 `movement-flow.ts` `resolveLanding`(特殊城池分流 `resolveCityEvent`,城池分流 `resolveProperty`)。

**落格结算顺序正典(ADR-0024 链序随 #825 迁移;机遇侧随 ADR-0035 改必出、事件城侧随 [ADR-0037](../../adr/0037-special-city-event-field.md) 免掷):机遇必出(事件城免掷)→ [事件城:固定事件] → 城池交易链(购地/扩军/按兵不动/珍宝交涉,含买不起等自动拒绝;一次落格至多一段)→ 结束回合**。固定事件先于交易链、链尾零挂件:旧「链尾探宝」挂件已随 #825 迁为珍宝城固定事件(`event:"treasure"`,见 [珍宝](./05-珍宝.md))——探宝先于交易链,链中清算/破产**不再抑制**探宝,交易链收口**零探宝**。事件城的固定事件与交易链同镜普通城的「机遇 → 交易链」:招贤型经三选一相位解完续跑(`pendingCityEvent` 续跑标记,随快照走),行情型致清算/破产则中断落格。

| 落点         | 处理                                                      | 详见                                                                                   |
| ------------ | --------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 自己都城     | 补给 + 招贤纳士                                           | [地产经济](./04-地产经济.md)/[名将与技能](./08-名将与技能.md)                          |
| 特殊城池     | 固定事件 → 交易链(机遇不掷;固定事件全员无差别,付费仅访客) | [声望与机遇](./07-声望与机遇.md)/[锦囊](./06-锦囊.md)/[名将与技能](./08-名将与技能.md) |
| 无主普通城   | 可购买(`AwaitingDecision`)                                | [地产经济](./04-地产经济.md)                                                           |
| 自己的普通城 | 可免费扩军(`AwaitingDecision`)                            | [地产经济](./04-地产经济.md)                                                           |
| 他人普通城   | 城主有宝触发珍宝交涉,否则无事                             | [珍宝](./05-珍宝.md)                                                                   |

特殊城池五类固定事件(`movement-flow.ts` `resolveCityEvent` 单源):**招贤城**=招贤纳士三选一(池空或麾下满员事件沉默、城照常买卖);**锦囊城**=落格必抽一张;**天命城**=+20 声望(±100 夹紧沿用);**商市城**=±100–200 随机行情;**珍宝城**=落格固定事件位拼点探宝(探宝本体见 [珍宝](./05-珍宝.md))。

## 抉择相位一览

选项集集中注册于 `choices.ts` `PHASE_CHOICES`;除默认行为外可用选项 ≤1 时引擎自动执行、不弹卷轴(见 [ADR-0013](../../adr/0013-choice-set-and-auto-execute.md)),唯一例外是破产清算(`choices.ts` `EXCLUDED_FROM_AUTO`)。

| 相位(`TurnPhase`)          | 谁决策             | 一句话                                                      |
| -------------------------- | ------------------ | ----------------------------------------------------------- |
| `AwaitingJinnang`          | 当前回合玩家       | 回合开始掷骰前:出牌阶段(用锦囊 / 出主动技 / 「不出」)       |
| `AwaitingReaction`         | 被询问座位(多属主) | 反应窗(#281):识破诡计/半路杀出的非阻塞应答点                |
| `AwaitingDecision`         | 落格玩家           | 购地进驻或免费扩军,或按兵不动                               |
| `AwaitingTreasureOwner`    | 城主               | 珍宝交涉:公道买卖/坐地起价/不交易                           |
| `AwaitingHeroPick`         | 获贤玩家           | 招贤纳士三选一                                              |
| `AwaitingEncounter`        | 当事玩家           | 抉择机遇:是否承担代价换收益                                 |
| `AwaitingExhaustion`       | 耗竭玩家           | 体力归 0 的惩罚自选                                         |
| `AwaitingBankruptcySettle` | 欠款玩家           | 变卖资产自救或宣告破产                                      |
| `AwaitingInquiry`          | 被询问玩家         | [定制问询](../../how-to/扩将指南.md):扩展包发起的问询等应答 |

**定制问询相位(#424,[ADR-0022](../../adr/0022-ts-extension-packages-dual-run.md))**:扩展包经引擎公共方法 `askInquiry`(`inquiry-flow.ts`)发起问询,选项集由扩展 handler 产出、仍走选项集单通道(盖 `inquiryId` 章)。分流与 [ADR-0013](../../adr/0013-choice-set-and-auto-execute.md) 同口径:可用选项 ≥2 才进相位弹问询弹层;=1 自动执行(战报;轻提示浮字由 fx 面消费 `inquiryAutoExecuted` 事件派生——单机/联机同见,#719 迁事件面);=0 作废留痕。挂起问询**挡回合收口**(`endTurn` 延期),应答命令 `resolveInquiry` 回灌扩展结算后补完收口——问询期间的回合停摆与反应窗同构。示例:示例名将包太史慈的「信义盲选」(招贤触发,从手牌暗牌盲选一张弃旧换新)。

## 回合结束与轮次

收尾走 `authority.ts` `endTurn`:`TurnEnd` 时机 → 结算胜负(`authority.ts` `checkVictory`)→ 推进下一位存活玩家(`authority.ts` `advanceToNextActive`)。新活跃玩家 `skipTurns > 0` 则**跳过回合**(耗竭善后/缓兵之计的 `skipTurns` 消费点):扣 1 继续推进,直到可行动者。**轮次计数**:所有人各行动一次 = 1 轮;回到固定轮次锚点(`authority.ts` `roundAnchor`,锚点破产则改指定序首个存活者)时先派发 `RoundEnd` → 轮数 +1 → 再派发 `RoundStart`,随后 `TurnStart` 开启新回合;轮次供名将技能冷却使用(见[名将与技能](./08-名将与技能.md))。
