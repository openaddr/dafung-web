# 回合与行军

> 规则手册第 3 页:棋盘、回合状态机、掷骰行军、必停都城、辅路捷径、落格结算与轮次。

## 棋盘一图看懂

地图数据驱动(`board-loader.ts` `loadMap`;`public/maps/index.json` 首项为默认地图,现「环游图」huanyou.json——7×6 蛇形主环 42 格,环序重排后会稽与长安同排相邻、闭环边一格可见;「棋盘天下」chessboard.json 同为 7×6 42 格但环序沿旧图、闭环边绕西缘;「群雄逐鹿」sanguo.json,主环 40 格 30 城另带 5 条要隘辅路)。棋盘由 `board.ts` `createBoard` 装配:

- **主路**:单环;**都城**是玩家开局所选的城,取代传统「起点」,经过必停(见下)。
- **辅路**:独立捷径,起终点都接主路,入口带主题命名(函谷关/赤壁/华容道等),机制同一。
- **特殊格**:卧龙岗(招贤)、宝物城(探宝)、锦囊格(抽牌)、天命格(声望)、税关(缴税)、商市(行情)。

## 回合状态机

每回合按 `types.ts` `TurnPhase` 推进,所有玩家操作统一经 `game.ts` `submitCommand` 提交。主线:`AwaitingJinnang?`(军师窗态:用锦囊/出主动技/不出)→ `Roll`(掷骰行军)→ `AwaitingBranch?`(辅路入口)→ `Land`(落格结算)→ `AwaitingDecision?`(购地/扩军)→ `EndTurn` → 下一位。其余抉择相位按落格情况插入,全表见[抉择相位一览](#抉择相位一览)。

**反应窗插入点(#281)**:`Roll` 相位的行军途中,若他人行军**途经你的城池**(城主持「半路杀出」)或任何人**宣布锦囊**(他人持「识破诡计」),回合在结算点挂起进 `AwaitingReaction`——非阻塞询问(语义见 [ADR-0017](../../adr/0017-non-blocking-reaction-windows.md)),应答齐(或超时代发「不用」)后续结算;被询问者才看得见询问,其余座位无感。反应锦囊细则见[锦囊](./06-锦囊.md)。

**掷骰自动触发(#188 行军自动化)**:`Roll` 相位没有可抉择的内容,轮到谁都不用点——先钤一方「签」印起签(~0.8s),随后自动起摇掷骰行军(单机约 1s 静默拍后起摇,节奏见 `src/app/fx/timings.ts` `AUTO_MARCH`;联机由服务器定时经同一条命令路径代发,延迟见 `scripts/room.ts` `AUTO_ROLL_DELAY_MS`)。各相位的**抉择**照旧等人作答,不自动化。

## 掷骰行军

- **单骰 1–6**,签面以汉字「一~六」展示(`constants.ts` `SIGN_FACES`;骰子实现 `dice.ts` `createDice`),掷几步走几步(`game.ts` `rollAndMove`)。
- **移动加成**:名将技能可在 `BeforeMarch` 时机追加步数(如周瑜 +1)——见[名将与技能](./08-名将与技能.md)与[时机框架](../../explanation/时机框架.md)。

## 途经他人城池:拦检(半路杀出,#281)

行军逐格途经时,每个**他人城主城池**(城主存活)都是一个拦检询问点(`timing.ts` `MarchPassedCity` 时机;此前途经城无任何结算,现仅此项):

- 城主持有「半路杀出」则开拦检窗,行军挂起(`game.ts` `marchTraverse`);无人拦则途经无感,照常走。
- 城主打出**拦检**:城主 vs 行人**拼点**(公共结算 `game.ts` `resolveDuel`,与连环计共用)。**城主胜=行人止步拦检城**、照常落格结算(可能被交涉);平局或落败=牌白耗,行人自拦检城后续走余下途经格——途中遇到的**下一座城**仍会开新询问点。
- 拦检结算内不再开新反应窗(识破不可被识破的同款红线);拦停成功时的行军动画止于拦检城(表现经 ADR-0010 事件管线)。

## 必停都城(巡幸)

| 情形                         | 行为                                                                                                                   |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **经过**自己都城、落点非都城 | **必停**:行军截断于都城——巡幸 +2 委任状(`constants.ts` `WARRANTS_PER_PASS`)+ 驻跸补给,**结束回合**,无「驻跸/继续」抉择 |
| **落点恰是**自己都城         | 走正常落格结算:补给 + 招贤纳士,回合照常走流程                                                                          |

补给按都城当前等级结算(公式 `economy.ts` `supplyFor`,数值见[关键数值总表](./10-关键数值总表.md));委任状是买城额度,详见[地产经济](./04-地产经济.md)。

## 辅路(分岔捷径)

只有**刚好落到辅路起点**才触发入口抉择(`game.ts` `currentTileIsBranchStart`):走大路(`game.ts` `selectBranch` 传 `Main`)= 起点格按普通落格处理;入辅路(传 `Branch`)= **本回合结束**,棋子留入口格待入辅路。此后每回合掷骰沿辅路走,掷几点走几格,每落一格触发效果(`game.ts` `resolveBranchCell`);掷满溢出则从辅路终点汇入主路继续走剩余步数(路径计算 `board.ts` `computePath`)。

| 辅路格   | 效果                           | 详见                                                  |
| -------- | ------------------------------ | ----------------------------------------------------- |
| treasure | 拼点探宝                       | [珍宝](./05-珍宝.md)                                  |
| event    | 抽锦囊随机事件                 | [锦囊](./06-锦囊.md)/[声望与机遇](./07-声望与机遇.md) |
| penalty  | 中伏:`skipTurns +1`,下回合跳过 | 本页[回合结束与轮次](#回合结束与轮次)                 |

| 卧龙岗       | 招贤纳士(不可进驻)             | [名将与技能](./08-名将与技能.md)                              |
| 宝物城       | 拼点探宝                       | [珍宝](./05-珍宝.md)                                          |

## 抉择相位一览

选项集集中注册于 `choices.ts` `PHASE_CHOICES`;除默认行为外可用选项 ≤1 时引擎自动执行、不弹卷轴(见 [ADR-0013](../../adr/0013-choice-set-and-auto-execute.md)),唯一例外是破产清算(`choices.ts` `EXCLUDED_FROM_AUTO`)。

| 相位(`TurnPhase`)          | 谁决策             | 一句话                                                |
| -------------------------- | ------------------ | ----------------------------------------------------- |
| `AwaitingJinnang`          | 当前回合玩家       | 回合开始掷骰前:军师窗态(用锦囊 / 出主动技 / 「不出」) |
| `AwaitingReaction`         | 被询问座位(多属主) | 反应窗(#281):识破诡计/半路杀出的非阻塞应答点          |
| `AwaitingBranch`           | 当前回合玩家       | 辅路入口:走大路还是入辅路                             |
| `AwaitingDecision`         | 落格玩家           | 购地进驻或免费扩军,或按兵不动                         |
| `AwaitingTreasureOwner`    | 城主               | 珍宝交涉:公道买卖/坐地起价/不交易                     |
| `AwaitingHeroPick`         | 获贤玩家           | 招贤纳士三选一                                        |
| `AwaitingEncounter`        | 当事玩家           | 抉择机遇:是否承担代价换收益                           |
| `AwaitingExhaustion`       | 耗竭玩家           | 体力归 0 的惩罚自选                                   |
| `AwaitingBankruptcySettle` | 欠款玩家           | 变卖资产自救或宣告破产                                |

## 回合结束与轮次

收尾走 `game.ts` `endTurn`:`TurnEnd` 时机 → 结算胜负(`game.ts` `checkVictory`)→ 推进下一位存活玩家(`game.ts` `advanceToNextActive`)。新活跃玩家 `skipTurns > 0` 则**中伏跳过**:扣 1 继续推进,直到可行动者。**轮次计数**:所有人各行动一次 = 1 轮;回到固定轮次锚点(`game.ts` `roundAnchor`,锚点破产则改指定序首个存活者)时先派发 `RoundEnd` → 轮数 +1 → 再派发 `RoundStart`,随后 `TurnStart` 开启新回合;轮次供名将技能冷却使用(见[名将与技能](./08-名将与技能.md))。
