# 07 · 声望与机遇

声望是全桌可见的「民心」数值,决定机遇抽好抽坏;机遇按「机遇必出」规则随行军落格而出(ADR-0035);体力是机遇附带的代价货币,归 0 即受罚。术语口径见 [`GLOSSARY.md`](../../../GLOSSARY.md)「声望与机遇」一节。

## 声望

- 每位玩家**无界**(开局恒 0,可负;旧 ±100 封顶已退役,见 [ADR-0050](../../adr/0050-reputation-softmax-tier-shares.md)),**全员可见**(全游戏唯一暗牌只有锦囊手牌,声望不在其列)。
- 写入口唯一:`authority.ts` `addReputation`(无界直加,不夹紧)。调用处仅四处——落**天命城**(`event:"fate"`,特殊城池 [ADR-0037](../../adr/0037-special-city-event-field.md))固定 +20(`movement-flow.ts` `applyFateReputation`)、机遇抉择选项的 `repDelta`(`settleEncounterChoice`)、机遇即时效果的效果级 `repDelta`(`applyEncounterEffect`,#1153)与技能声望族 `grantReputation`(`effects.ts`,屯田/声势/瓮中捉鳖等走此口,#1145);声望不随回合自然波动。

## 机遇(Encounter)

### 机遇必出(触发规则,ADR-0035)

- **先于落格结算**:行军落主路格后、`resolveLanding` 前先出机遇(`encounter-flow.ts` `maybeApplyEncounter`);机遇解完才继续本落格的城池结算。回合全局次序见 [`./03-回合与行军.md`](./03-回合与行军.md)。
- **必出、零豁免(特殊城池免掷除外)**:凡走到落格结算的必出一条,「发生与否」不掷概率——主路落格、半路杀出拦停止步、必停都城截断(先机遇、后驻跸补给、再结束回合)全部同链。**唯一免掷是特殊城池**(#823/[ADR-0037](../../adr/0037-special-city-event-field.md)):落点是事件城(`board.ts` `isEventCity`)不掷随机机遇——固定事件就是这块地的「固定机遇」,链序=固定事件 → 交易链;固定事件对一切落地者无差别触发(含城主)且**与机遇总开关脱钩**。
- **总开关**:引擎缺省 `enabled=false`(测试隔离开关),产品默认来自 `public/config/jiyu.json`(与 `encounters.ts` `ENCOUNTER_PRODUCT_DEFAULTS` 同值,`enabled:true`),单机「起兵」屏可单局覆盖;关闭则整局无机遇、不耗骰流。开关只管普通城的机遇必出:**特殊城池的固定事件是地的属性,不归开关管辖**——引擎缺省下事件城照常触发(普通城不掷)。

### 三档与声望调制

三档概率 = 声望 s 的 **softmax 三元拉锯**(`encounters.ts` `tierShares` 单参;唯一旋钮 `TIER_SOFTMAX_K` = 100,代码常量不进配置):三档权重 **2^(s/100) : 1 : 2^(−s/100)**,归一成百分比——好运% = 2^(s/100) / (2^(s/100) + 1 + 2^(−s/100)),中性% = 1 / (三者之和),霉运% = 2^(−s/100) / (三者之和)。声望无界(曲线定案见 [ADR-0050](../../adr/0050-reputation-softmax-tier-shares.md)):0 声望三档各 1/3,声望每 +100 好运权重翻一倍;负向完美镜像(−s 的好运/霉运与 s 互换、中性不变);两端各奔好运 100% / 霉运 100%,三档恒为正,数学上永远差一点到不了端点。示意:

| 声望  | 好运  | 中性  | 霉运  |
| ----- | ----- | ----- | ----- |
| 0     | 33.3% | 33.3% | 33.3% |
| +100  | 57.1% | 28.6% | 14.3% |
| +300  | 87.7% | 11.0% | 1.4%  |
| +1000 | 99.9% | 0.1%  | ≈0    |
| →+∞   | →100% | →0    | →0    |

(镜像行:−100 → 14.3% / 28.6% / 57.1%;→−∞ 霉运 →100%、其余 →0。)

行善作恶都会在牌面上兑现:声望越高好运越肥,声望越低霉运缠身。「机遇必出」只管发生;落在哪一档仍按上表调制概率。

### 抉择机遇

- 即时机遇直接落账;抉择机遇进 `AwaitingEncounter` 相位,选项带声望增减(`repDelta`)与可选效果,经卷轴选择(`encounter-flow.ts` `resolveEncounterChoice`)。抉择红线:每条抉择必须真两难——两个选项各有实质代价(短期得利 vs 声望长线 / 银两 vs 体力 / 对己 vs 对他),霉运抉择则是「两害相权」,没有明显正确答案。
- 卷轴按档分色(#847):机遇卷轴的题印与题名侧饰条随档位换色——好运亮金、中性黛青、霉运朱砂;霉运档首选项不作主按钮(两害相权的损失不上金),色变即状态、不加文字标牌。档位随选项出快照(`choices.ts` `encounterTier` 单通道透出 `def.tier`,卷轴 `DecisionScrolls.tsx` 消费)。
- 可用选项 ≤1 时引擎自动执行(选项集机制,ADR-0013):「结盟互市」单选项即「使团代应」;「以宝换贤」珍宝不足时自动「婉言相拒」。见 [`../../adr/0013-choice-set-and-auto-execute.md`](../../adr/0013-choice-set-and-auto-execute.md)。
- 选项结算顺序:声望落账 → 效果 → 选项级体力落账(选项现金代价 `cashCost` 在珍宝代价后、声望前实付,#1154);解完**继续本落格的城池结算**。
- 效果里的征银类(`levy`,如假道征粮/盟镇勒币/津口勒索)与 `cash` 负值同款封顶以其现有银两为限,实付额照付对手、资敌语义不变,一律不送清算/破产(#1153 红线,见下节);体力归 0 则耗竭接管本落格——人倒下了不买地,耗竭不再续跑购地/交涉。

### 机遇章与原语(#1153)

- **机遇章(跨事件标记)**:`encounters.ts` `ENCOUNTER_FLAGS` 封闭枚举(现收「元直荐书」「怀玺」两枚,链式典故的前编凭证,见 [GLOSSARY](../../../GLOSSARY.md)「机遇章」)。条目以 `setsFlags`(写点)/`requiresFlags`(闸门)声明:抉择路结算写 `option.setsFlags`、即时路结算写 `def.setsFlags`(`encounter-flow.ts`,经去重落章单口 `grantEncounterFlags`);章按人记账(`Player.encounterFlags`,快照玩家行成对携带),**破产不清章**——章是经历记录,不是资产。带章闸的条目须保有一个无章闸选项(`encounters.ts` 模块初始化守卫 `assertChoicesNotFlagLocked`),整条选项集不得被章锁死;带 def 级章闸的后编条目只出现在持章者的抽取池里(`drawableEncounters` 过滤,每档在无章玩家视角仍须有序可抽——守卫 `assertFlagGatePoolsDrawable`)。
- **指定招揽**:`grantHero` 效果可带 `heroId` 点名将(设计意图:三顾茅庐点名诸葛亮);点名可得则该将必入麾下(非随机盲盒),指定将已被招揽/麾下满/名将已尽 → 按 `fallbackCash` 折现,与既有换贤三连检同口径(`choices.ts` 闸门 reason:「指定名将已被招揽」)。
- **效果级声望**:即时条目的效果可带 `repDelta`(与选项级 `repDelta` 并列的即时通道),经 `addReputation` 唯一写口落账并产 `reputationChanged` 事件(实际增减差值)。
- **选项现金代价 `cashCost`**(#1154):付费与得物分离的选项代价(首例=太平要术「以百金请书」——费银 100 两+得锦囊一张,单 effect 容不下两事),语义与负 `cash` 效果同款:闸门现金不足灰显「银两不足」、结算封顶以其现有银两为限(`choices.ts` `optionCashCost` / `encounter-flow.ts` 结算)。

### 奇遇(一局一遇,ADR-0051)

- 机遇条目可标**奇遇**:每名玩家每局至多一遇,遇后移出其**个人**抽取池;与三档**正交**(档位管强度、奇遇管出现法),按玩家计不按全桌——四人四条独立机遇流,无先到先得。奇遇 id 清单单源 `encounters.ts` `ONCE_PER_GAME_ENCOUNTER_IDS`(现 13 条:12 净增+传檄而定 retro)。「每玩家已遇集+抽取过滤」已落地(#1169):触发即记(`encounter-flow.ts` `markOnceEncounter`,中断路照记)、已遇玩家从抽取池过滤(`encounters.ts` `drawableEncounters`),判定单源 `isOncePerGameEncounter`。
- **链式典故**拆前编/后编两张奇遇,以机遇章衔接(走马荐诸葛→三顾茅庐、匿玺→挟玺号令):前编选项 `setsFlags` 写章,后编 def 级 `requiresFlags` 认章——仅持章者可抽,weight 2.5 高权重只对持章者生效(持章者当局兑现概率约七成半)。
- 不建用户可见的稀有度标签:三档分色已是唯一档位视觉通道,奇遇的分量靠结构与演出承载(#1111 演出决议)。

### 新红线「机遇不送清算」(#1153)

机遇的银两损失**以其现有银两为限**,不把人逼进变卖清算:

1. **抉择现金代价自动闸**:现金低于现金代价(负 `cash` 效果、`levy` 输币额或选项级 `cashCost`,#1154)的选项自动灰显,reason「银两不足」(`choices.ts` 按 effect kind 推导,全目录追溯,引擎规则非逐条数据)。
2. **保底放行**:门槛过滤后若所有选项全灰、而存在仅被现金闸拦下的选项,则放行**现金代价最低**者——卷轴永不全灰;放行项 ≤1 可用即按 ADR-0013 自动执行,实付由封顶兜底。
3. **负现金封顶**:`cash` 负值效果的实际损失 = min(|delta|, 现有现金)(`encounter-flow.ts` `applyCashEffect`);`levy` 输币同款封顶、实付额照付对手(`applyLevyEffect`,资敌语义不变)——即时与抉择两路同款,与玩家间转移「上限=付款方现有现金」的 take=min 语义同款。现金归 0 为限,机遇银两损失一律不产清算/破产。

体力不在本红线内:耗竭 ≠ 破产,体力代价照常结算(见下节)。

### bot 同规则同抽取

bot 与玩家同规则:开关开则同必出、同档位抽取;抉择按**立即净值贪心**:选项银两影响(`bot.ts` `encounterCashImpact`,含选项级 `cashCost` 按面值扣分)+ `repDelta` × 声望折银系数(`repCoefficient`,5~9 按座位散列——重声望的仁主与见利即取的枭雄性格不同)+ 体力增量 × **体力折银率**(`constants.ts` `STAMINA_CASH_RATE`,5 两/点——卖体力不合算就不接,#789)。折银估价按线性性格近似,未随 softmax 新曲线调边际——高声望段折银价系统性偏高,登记接受(见 [ADR-0050](../../adr/0050-reputation-softmax-tier-shares.md))。

## 体力

### 增减来源

体力上限与开局值均为 100(`constants.ts` `STAMINA_MAX` / `STARTING_STAMINA`),常规对局不变,增减只来自机遇(各档数值锚链 [`./10-关键数值总表.md`](./10-关键数值总表.md)):霉运即时条附带体力税(粮道被劫/漕船倾覆/驿马倒毙/火烛惊营/假道征粮 −7~−10,#789 定价;建安大疫 −12、山洪冲道 −6、溃卒为盗 −7、辎重陷淖 −8、流言中伤 −4,#1154);好运回血——「神医行诊」+25、「刮骨」+20、「木牛流马」+8;抉择可拿银换体力或拿体力换利——「温泉疗养」付银 +30、「单刀赴会」博名 −15、「夜行军」耗体力 −20 换银、「疫病入营」硬撑 −25(延医费银 130 消灾,#1109 有意过折银锚让 bot 按性格分化)、「祸水东引/河堤告急」的出兵/听天选项 −20/−15、「华容道」死战 −18、「山越羁縻/千里走单骑/津口勒索/粮仓霉变/敌垒相逼」两害各携体力侧代价(的卢妨主 A 反例:+8 快马)。体力条目守**比价红线**:隐含卖体力价 ≤ 体力折银率 5 两/点为常态锚(高于温泉买价即开「体力套利」,见 [GLOSSARY](../../../GLOSSARY.md)「体力折银」;#1109 疫病 130 为有意过锚的孤例,换取 bot 性格分化)。增减经 `authority.ts` `addStamina` 落账(夹紧 0~100);名将技能亦可回体(华佗,见 [`./08-名将与技能.md`](./08-名将与技能.md))。

演出与战报只记**实际增减**(夹紧后差值,#568):体力浮字由 fx 面消费 `staminaChanged` 事件派生(单机/联机同见),**零实际差不浮字**——无变化无演出(满体力回蓝/顶格赈济/触底机遇不发「体力 +0」);战报增量同记实际差,与棋盘浮字恒一致。耗竭浮字是状态宣告(「体力耗竭…」),不在此限。

### 耗竭惩罚:外敌乘虚而入 + 休整

体力归 0 立即**全自动**结算(耗竭入口 `encounter-flow.ts` `exhaustIfDepleted`,挂在机遇体力落账尾部;无抉择相位,人与 bot 同一套),三步:

1. **外敌乘虚而入**:名下**所有**等级 >0 的城池(含都城)各降 1 级——0 级封底,**永不失去城池**(逐城派 `PropertyDemolished`;降级清单与休整回合数随 `exhaustionResolved` 事件显式下行)。
2. **卧床休整**:`skipTurns += EXHAUSTION_REST_TURNS`(`constants.ts`,休整两回合;与缓兵之计共用 `skipTurns` 计数、可叠加),体力保持 0(卧床状态可见),回合结束。
3. **休整期满回满**:跳回合环把 `skipTurns` 消费完的那一刻(`authority.ts` `endTurn` 推进环,`resting` 标记消费点)体力经 `addStamina` 回满 100(`staminaChanged` `reason=rest`;零实际差不产事件)。休整期间被华佗赈济加体不提前结束休整——固定歇满两回合。

耗竭不再失城,与破产的边界更清晰:耗竭是卧床+城池受损、人不出局;破产是资产易主、玩家退场,边界见 [`./09-破产清算.md`](./09-破产清算.md)。
