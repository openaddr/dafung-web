# 07 · 声望与机遇

声望是全桌可见的「民心」数值,决定机遇抽好抽坏;机遇按「机遇必出」规则随行军落格而出(ADR-0035);体力是机遇附带的代价货币,归 0 即受罚。术语口径见 [`GLOSSARY.md`](../../../GLOSSARY.md)「声望与机遇」一节。

## 声望

- 每位玩家 −100 ~ +100,开局恒 0,**全员可见**(全游戏唯一暗牌只有锦囊手牌,声望不在其列)。
- 写入口唯一:`authority.ts` `addReputation`(落账即夹紧 ±100)。调用处仅两处——落**天命格**固定 +20(`resolveSpecial` 的 Fate 分支)与机遇抉择选项的 `repDelta`(`settleEncounterChoice`);声望不随回合自然波动。

### 声望献计

声望**首次向上**越过 +30 / +60 / +90 三个里程碑时,各获赠锦囊一张(宣告浮字「民心所向(声望 N),名将献计」,由 fx 面消费 `repMilestoneCrossed` 事件派生——单机/联机同见,#719 迁事件面;进手照旧由 `jinnangDrawn` 事件派生「获锦囊一封」)——只看数值是否越过、不看来源,把机遇抉择玩好就有实物兑现。挂点在 `addReputation` 内部,抽牌走 `drawJinnang`;锦囊使用规则见 [`./06-锦囊.md`](./06-锦囊.md)。

## 机遇(Encounter)

### 机遇必出(触发规则,ADR-0035)

- **先于落格结算**:行军落主路格后、`resolveLanding` 前先出机遇(`encounter-flow.ts` `maybeApplyEncounter`);机遇解完才继续本落格的城池/特殊格结算。回合全局次序见 [`./03-回合与行军.md`](./03-回合与行军.md)。
- **必出、零豁免**:凡走到落格结算的必出一条,「发生与否」不掷概率——主路落格、半路杀出拦停止步、必停都城截断(先机遇、后驻跸补给、再结束回合)、天命格(先机遇、后落天命 +20)全部同链。
- **总开关**:引擎缺省 `enabled=false`(测试隔离开关),产品默认来自 `public/config/jiyu.json`(与 `encounters.ts` `ENCOUNTER_PRODUCT_DEFAULTS` 同值,`enabled:true`),单机「起兵」屏可单局覆盖;关闭则整局无机遇、不耗骰流。

### 三档与声望调制

三档基准(默认 30/45/25,配置值之和不必为 100)先按占比归一成百分比(`encounters.ts` `normalizeEncounterBaseRates`),再按声望 s 调制(`tierShares`):好运 = 基准 + 0.25s,霉运 = 基准 − 0.20s,各夹紧到 [5, 95],中性吃剩余。默认基准下的示意:

| 声望    | 好运    | 中性 | 霉运    |
| ------- | ------- | ---- | ------- |
| −100    | 5(夹紧) | 50   | 45      |
| 0(基准) | 30      | 45   | 25      |
| +100    | 55      | 40   | 5(夹紧) |

行善作恶都会在牌面上兑现:声望越高好运越肥,声望越低霉运缠身。「机遇必出」只管发生;落在哪一档仍按上表调制概率。

抉择型共 15 条、恰占一半(#188 档 2 决策化扩容):好运得利附声望代价(奉迎天子),中性权衡取舍,霉运六条一律「两害相权」——每个选项都有实质代价,没有无害的兜底选项。

玩家侧 7 条(带「玩家」标签)是玩家间银两转移,方向不同结算也不同:「敌营哗变/纳款输诚/义释俘虏(押质勒赎)/祸水东引」自随机对手吸银,**上限 = 对方现有现金,不触发对方清算**;「假道征粮/盟镇勒币(隐忍输币)」你被迫输银,付款走支付/清算(现金不足同样可自救/破产,见 [`./09-破产清算.md`](./09-破产清算.md));「结盟互市」国库出银、两家各得。「传檄而定」赐城走**城池易主宣告**上屏(fx 面消费 `propertyGranted` 事件派生,与购地/破产易主同通路,#719 迁事件面——此前赐城是折叠面已知无事件缺口,本事件同时闭合)。

### 抉择机遇

- 即时机遇直接落账;抉择机遇进 `AwaitingEncounter` 相位,选项带声望增减(`repDelta`)与可选效果,经卷轴选择(`encounter-flow.ts` `resolveEncounterChoice`)。抉择红线:每条抉择必须真两难——两个选项各有实质代价(短期得利 vs 声望长线 / 银两 vs 体力 / 对己 vs 对他),霉运抉择则是「两害相权」,没有明显正确答案。
- 卷轴按档分色(#847):机遇卷轴的题印与题名侧饰条随档位换色——好运亮金、中性黛青、霉运朱砂;霉运档首选项不作主按钮(两害相权的损失不上金),色变即状态、不加文字标牌。档位随选项出快照(`choices.ts` `encounterTier` 单通道透出 `def.tier`,卷轴 `DecisionScrolls.tsx` 消费)。
- 可用选项 ≤1 时引擎自动执行(选项集机制,ADR-0013):「结盟互市」单选项即「使团代应」;「以宝换贤」珍宝不足时自动「婉言相拒」。见 [`../../adr/0013-choice-set-and-auto-execute.md`](../../adr/0013-choice-set-and-auto-execute.md)。
- 选项结算顺序:声望落账 → 效果(银两支出走支付/清算,与购地同规则)→ 选项级体力落账;解完**继续本落格的城池结算**。
- 效果致贫可触发清算/破产、体力归 0 则耗竭接管本落格——人倒下了不买地,两者都不再续跑购地/交涉。

### bot 同规则同抽取

bot 与玩家同规则:开关开则同必出、同档位抽取;抉择按**立即净值贪心**:选项银两影响(`bot.ts` `encounterCashImpact`)+ `repDelta` × 声望折银系数(`repCoefficient`,5~9 按座位散列——重声望的仁主与见利即取的枭雄性格不同)+ 体力增量 × **体力折银率**(`constants.ts` `STAMINA_CASH_RATE`,5 两/点——卖体力不合算就不接,#789)。

## 体力

### 增减来源

体力上限与开局值均为 100(`constants.ts` `STAMINA_MAX` / `STARTING_STAMINA`),常规对局不变,增减只来自机遇(各档数值锚链 [`./10-关键数值总表.md`](./10-关键数值总表.md)):霉运即时五条附带 −7~−10(粮道被劫/漕船倾覆/驿马倒毙/火烛惊营/假道征粮,#789 定价);好运「神医行诊」+25;抉择可拿银换体力或拿体力换利——「温泉疗养」付银 +30、「单刀赴会」博名 −15、「夜行军」耗体力 −20 换银、「疫病入营」硬撑 −25(延医费银 120 消灾)、「祸水东引/河堤告急」的出兵/听天选项 −20/−15。体力条目一律守**比价红线**:隐含卖体力价 ≤ 体力折银率 5 两/点(高于温泉买价即开「体力套利」,见 [GLOSSARY](../../../GLOSSARY.md)「体力折银」)。增减经 `authority.ts` `addStamina` 落账(夹紧 0~100);名将技能亦可回体(华佗,见 [`./08-名将与技能.md`](./08-名将与技能.md))。

演出与战报只记**实际增减**(夹紧后差值,#568):体力浮字由 fx 面消费 `staminaChanged` 事件派生(单机/联机同见),**零实际差不浮字**——无变化无演出(满体力回蓝/顶格赈济/触底机遇不发「体力 +0」);战报增量同记实际差,与棋盘浮字恒一致。耗竭浮字是状态宣告(「体力耗竭…」),不在此限。

### 耗竭惩罚

体力归 0 立即结算(耗竭入口 `encounter-flow.ts` `exhaustIfDepleted`,挂在机遇体力落账尾部),四步:

1. **自选降级**:持有等级 >0 的房产时,进 `AwaitingExhaustion` 相位自选一座降 1 级(`resolveExhaustionChoice`;选项集由 `choices.ts` 注册表算出,bot 随机弃一座、可用选项 ≤1 自动执行)。
2. **改失去城池**:全部 0 级时改为失去一座**非都城**(城回无主;都城可降级至 0、不可失去)。
3. **跳过下一回合**:`skipTurns + 1`(耗竭善后与缓兵之计共用同一机制)。
4. **体力重置 100**,回合结束(`applyExhaustionAftermath`)。

无任何房产则 1、2 并为「无可处置」纯跳回合。注意失城 ≠ 破产:耗竭是城回无主、人不出局;破产是资产易主、玩家退场,边界见 [`./09-破产清算.md`](./09-破产清算.md)。
