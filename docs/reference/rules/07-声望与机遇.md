# 07 · 声望与机遇

声望是全桌可见的「民心」数值,决定机遇抽好抽坏;机遇是行军落格时的随机事件;体力是机遇附带的代价货币,归 0 即受罚。术语口径见 [`CONTEXT.md`](../../../CONTEXT.md)「声望与机遇」一节。

## 声望

- 每位玩家 −100 ~ +100,开局恒 0,**全员可见**(全游戏唯一暗牌只有锦囊手牌,声望不在其列)。
- 写入口唯一:`game.ts` `addReputation`(落账即夹紧 ±100)。调用处仅两处——落**天命格**固定 +20(`resolveSpecial` 的 Fate 分支)与机遇抉择选项的 `repDelta`(`settleEncounterChoice`);声望不随回合自然波动。

### 声望献计

声望**首次向上**越过 +30 / +60 / +90 三个里程碑时,各获赠锦囊一张(浮字「民心所向,贤士献计」)——只看数值是否越过、不看来源,把机遇抉择玩好就有实物兑现。挂点在 `addReputation` 内部,抽牌走 `drawJinnang`;锦囊使用规则见 [`./06-锦囊.md`](./06-锦囊.md)。

## 机遇(Encounter)

### 触发时机与概率

- **先于落格结算**:行军落主路格后、`resolveLanding` 前先 roll 机遇(`game.ts` `maybeApplyEncounter`);机遇解完才继续本落格的城池/特殊格结算。回合全局次序见 [`./03-回合与行军.md`](./03-回合与行军.md)。
- **触发率**默认 40%:引擎内建缺省为 0(纯开关),产品默认来自 `public/config/jiyu.json`(与 `encounters.ts` `ENCOUNTER_PRODUCT_DEFAULTS` 同值),单机「起兵」屏可单局覆盖。roll 未中也留机读战报(`encounterMiss`)。
- **例外**:天命格是固定声望泉,不参与 roll;必停都城(驻跸特化流)与辅路格不触发。

### 三档与声望调制

三档基准(默认 30/45/25,配置值之和不必为 100)先按占比归一成百分比(`encounters.ts` `normalizeEncounterBaseRates`),再按声望 s 调制(`tierShares`):好运 = 基准 + 0.25s,霉运 = 基准 − 0.20s,各夹紧到 [5, 95],中性吃剩余。默认基准下的示意:

| 声望 | 好运 | 中性 | 霉运 |
|---|---|---|---|
| −100 | 5(夹紧) | 50 | 45 |
| 0(基准) | 30 | 45 | 25 |
| +100 | 55 | 40 | 5(夹紧) |

行善作恶都会在牌面上兑现:声望越高好运越肥,声望越低霉运缠身。

### 机遇目录索引

目录 19 条(好运 10 / 中性 6 / 霉运 3),中文 id 自带因果(名字与效果互证),各带内容标签与抽取权重(`encounters.ts` `ENCOUNTERS`;权重与效果数值锚链 [`./10-关键数值总表.md`](./10-关键数值总表.md)):

| 档位 | 条目(id × 标签) |
|---|---|
| 好运 | 屯粮居奇/草船借箭/风调雨顺(银两)、神医行诊(体力)、义士来投(武将)、圯上授书(锦囊)、窖藏现世(珍宝)、传檄而定(城池)、敌营哗变/纳款输诚(银两·玩家) |
| 中性 | 携民渡江/散财消灾(银两·声望)、以宝换贤(珍宝·武将)、结盟互市(银两·玩家)、温泉疗养/夜行军(银两·体力)——六条全带抉择 |
| 霉运 | 粮道被劫/漕船倾覆(银两·体力)、假道征粮(银两·玩家·体力) |

玩家侧 4 条(带「玩家」标签)是玩家间银两转移,方向不同结算也不同:「敌营哗变/纳款输诚」自随机对手吸银,**上限 = 对方现有现金,不触发对方清算**;「假道征粮」你被迫输银,付款走支付/清算(现金不足同样可自救/破产,见 [`./09-破产清算.md`](./09-破产清算.md));「结盟互市」国库出银、两家各得。

### 抉择机遇

- 即时机遇直接落账;抉择机遇进 `AwaitingEncounter` 相位,选项带声望增减(`repDelta`)与可选效果,经卷轴选择(`game.ts` `resolveEncounterChoice`)。
- 可用选项 ≤1 时引擎自动执行(选项集机制,ADR-0013):「结盟互市」单选项即「使团代应」;「以宝换贤」珍宝不足时自动「婉言相拒」。见 [`../../adr/0013-choice-set-and-auto-execute.md`](../../adr/0013-choice-set-and-auto-execute.md)。
- 选项结算顺序:声望落账 → 效果(银两支出走支付/清算,与购地同规则)→ 选项级体力落账;解完**继续本落格的城池结算**。
- 效果致贫可触发清算/破产、体力归 0 则耗竭接管本落格——人倒下了不买地,两者都不再续跑购地/交涉。

### bot 同规则同概率

bot 与玩家同触发率同档位抽取;抉择按**立即净值贪心**:选项银两影响(`bot.ts` `encounterCashImpact`)+ `repDelta` × 声望折银系数(`repCoefficient`,5~9 按座位散列——重声望的仁主与见利即取的枭雄性格不同)。Simple/Normal 同策略。

## 体力

### 增减来源

体力上限与开局值均为 100(`constants.ts` `STAMINA_MAX` / `STARTING_STAMINA`),常规对局不变,增减只来自机遇(各档数值锚链 [`./10-关键数值总表.md`](./10-关键数值总表.md)):霉运三条附带 −15~−25;好运「神医行诊」+25;抉择可拿银换体力——「温泉疗养」付银 +30、「夜行军」耗体力 −20 换银。增减经 `game.ts` `addStamina` 落账(夹紧 0~100);名士技能亦可回体(华佗,见 [`./08-名士与技能.md`](./08-名士与技能.md))。

### 耗竭惩罚

体力归 0 立即结算(耗竭入口 `game.ts` `exhaustIfDepleted`,挂在机遇体力落账尾部),四步:

1. **自选降级**:持有等级 >0 的房产时,进 `AwaitingExhaustion` 相位自选一座降 1 级(`resolveExhaustionChoice`;选项集由 `choices.ts` 注册表算出,bot 随机弃一座、可用选项 ≤1 自动执行)。
2. **改失去城池**:全部 0 级时改为失去一座**非都城**(城回无主;都城可降级至 0、不可失去)。
3. **跳过下一回合**:`skipTurns + 1`(与辅路中伏同一机制)。
4. **体力重置 100**,回合结束(`applyExhaustionAftermath`)。

无任何房产则 1、2 并为「无可处置」纯跳回合。注意失城 ≠ 破产:耗竭是城回无主、人不出局;破产是资产易主、玩家退场,边界见 [`./09-破产清算.md`](./09-破产清算.md)。
