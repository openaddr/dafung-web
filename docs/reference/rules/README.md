# 大富翁规则手册

三国大富翁的玩家规则全集,共十页:01–09 按一局的时间线铺开(开局 → 行军 → 经济 → 博弈 → 出局),第 10 页是数值索引附录。可按序通读,也可从导览表直接跳转。

## 权威声明

> **本目录是 `src/core/` 代码的人话镜像,不是第二个真相;代码与文档冲突时以代码为准,改文档。**

全部关键数值统一收录在第 10 页[关键数值总表](./10-关键数值总表.md),逐条标注代码出处(文件 + 符号名,不写行号),便于核对与修改。改动玩家可见机制时,同一 PR 内回填对应规则页(见 [`AGENTS.md` 完成定义](../../../AGENTS.md))。
