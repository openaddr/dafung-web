# 总览与胜利

> 规则手册第 1 页:一局怎么玩、两种胜利方式、身价口径,以及你的对手——AI 诸侯。
> 权威声明:代码是唯一事实源,本文数值一律标注代码出处,冲突以代码为准。

## 一局怎么玩

每位玩家执一枚棋子在环路上行军,轮流行动:开局定国号、点将定序、三选一选都(见[开局](./02-开局.md)),之后进入回合制行军——掷骰前进、落格结算、回合结束(状态机见[回合与行军](./03-回合与行军.md))。

落格遇到什么就结算什么:无主城可购买进驻、己城可免费扩军、他人城触发珍宝交涉、宝物城拼点探宝、锦囊格抽牌、天命格涨声望、税关缴税、商市行情波动——逐页目录即本手册十页。

**收入没有过路费**。两大现金来源:都城补给(每级补给 × (等级 + 1),`economy.ts` `supplyFor`)与卖珍宝。无过路费、无升级费是与经典大富翁最大的刻意差异,详见[地产经济](./04-地产经济.md)。

## 胜利条件

每回合结束(`authority.ts` `endTurn`)先判胜负(`authority.ts` `checkVictory`),两种方式先达成者称帝:

| 方式         | 条件                                                                                                |
| ------------ | --------------------------------------------------------------------------------------------------- |
| **身价达标** | 任一玩家身价 ≥ 目标身价(默认 30000 两;`authority.ts` `DEFAULT_TARGET`,地图 `targetNetWorth` 可覆盖) |
| **群雄尽灭** | 存活玩家仅剩一人(其余全部破产)                                                                      |

- 胜因枚举 `TargetNetWorth` / `LastStanding` 见 `authority.ts` `VictoryReason`(另有异常作废 `aborted`,见下文[异常终局](#异常终局对局作废))。
- **多人同时达标**:先查当前活跃玩家,再查其余玩家,取身价最高者(`authority.ts` `checkVictory`)。
- 目标身价、起手现金等全部数值条目索引见[关键数值总表](./10-关键数值总表.md)。

## 异常终局(对局作废)

对局可能因内部错误当场终止(驱动链死亡、时钟挂死等引擎/驱动侧故障):引擎立即作废本局(`authority.ts` `abortGame`),**无胜者**——没有谁称帝,胜负未分,本局成绩不作数。这不是任何玩家的胜负结果,也不是「认输/投降」。

- **玩家看到**:终局屏不演称帝(无排名、无终榜、无烟花),改为「对局作废」面板——一句说明(内部错误导致对局终止)+ 出口按钮(再战一局/导出日志,与胜利屏同款)。
- **留痕可查**:作废原因机读入对局日志终局行(category `final` 的 `abortReason` 字段,附全体玩家终态),排查直接读 jsonl(见[对局日志](../对局日志.md))。
- **判别口径**:胜因枚举 `aborted`(`authority.ts` `VictoryReason`);终局事件 `gameOver` 以 `reason="aborted"` 判别(`game-events.ts`),客户端演出面照此跳过胜利音效。

## 身价 = 仅现金

身价(`networth.ts` `netWorth`)**只数现金**:珍宝、城池账面均不计入。

战略含义:买城、交涉付款都直接压低身价;只有现金流入(都城补给、卖珍宝、商市行情)才能推高身价。**现金流管理是第一战略**——城占得多未必离称帝更近,囤地断现金流反而替对手做嫁衣。

## AI 诸侯(你的对手)

单机/代管 bot 由 `bot.ts` `botAct` 驱动,单一 EV 策略(#613 难度档退役);所有抉择先经选项集注册表(`choices.ts` `PHASE_CHOICES`)过滤可用项再选——与人类玩家、引擎自动执行同一口径,没有第二套判断(见 [ADR-0013](../../adr/0013-choice-set-and-auto-execute.md))。

| 抉择点         | bot 怎么做                                        |
| -------------- | ------------------------------------------------- |
| 买城           | 现金 > 1.5×价格且有委任状即买                     |
| 扩军(免费)     | 未满级即升(满级已被引擎自动按兵不动,不触达)       |
| 招贤           | 随机选一位                                        |
| 抉择机遇       | 立即净值贪心 + 声望折银                           |
| 珍宝交涉(城主) | 珍宝等级 ≥6 坐地起价,否则公道买卖;20% 概率跳过    |
| 锦囊           | 按牌表策略使用                                    |
| 破产清算       | 优先名将 → 低等级珍宝 → 城池(排除都城),卖够再确认 |

**AI 选都评分**(`setup-flow.ts` `aiChooseCapital`):在三候选(`offeredCapitals`)中取最高分——都城补给性价比 `resupplyPerLevel × 8 / buildCost`,叠加小幅随机扰动(0~~0.3,防同分死板);补给公式的含义见 `economy.ts` `supplyFor`。

各系统页在对应抉择点设「bot 怎么做」回链本节;bot 不看的机制细节走各机制页。
