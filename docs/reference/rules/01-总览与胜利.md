# 总览与胜利

## 一局怎么玩

从[开局](./02-开局.md)定都，按[回合与行军](./03-回合与行军.md)处理沿途发生的事。第一次玩可跟[新手第一局](../../tutorials/新手第一局.md)进入对局。

## 胜利条件

判胜发生在[回合收尾](./03-回合与行军.md#回合结束与轮次)指定的结算点，由[胜利判定](../../../packages/core/src/engine/victory.ts)的 `checkVictory` 检查以下条件。

| 方式         | 条件                                                            |
| ------------ | --------------------------------------------------------------- |
| **身价达标** | 任一诸侯的身价达到本局目标。地图默认值取图内 `targetNetWorth`。 |
| **群雄尽灭** | 存活玩家仅剩一人(其余全部破产)                                  |

- 胜因枚举 `TargetNetWorth` / `LastStanding` 见 `authority.ts` `VictoryReason`(另有异常作废 `aborted`,见下文[异常终局](#异常终局对局作废))。
- **多人达标**。取现金最高的存活诸侯。最高现金并列时，各自按拼点骰面掷骰，点数最高者胜。最高点仍并列，则由这些并列诸侯重掷至唯一胜者（`victory.ts` 的 `checkVictory`）。

胜利页的画卷展示胜者这一局的国号、都城和名将。终榜按现金身价降序排列，同时标示权威胜者和破产诸侯。「再战一局」随终榜可用。

终局演出的节奏见[音效设计](../../design/音效设计.md#破产终局与环境声)。

## 异常终局(对局作废)

对局可能因内部错误当场终止(驱动链死亡、时钟挂死等引擎/驱动侧故障):引擎立即作废本局(`authority.ts` `abortGame`),**无胜者**——没有谁称帝,胜负未分,本局成绩不作数。这不是任何玩家的胜负结果,也不是「认输/投降」。

- **玩家看到**:终局屏不演称帝(无排名、无终榜、无烟花),改为「对局作废」面板和「再战一局」出口。回主页后可用「对局诊断」保存这局的记录。
- **留痕可查**:作废原因机读入对局日志终局行(category `final` 的 `abortReason` 字段,附全体玩家终态),排查直接读 jsonl(见[对局日志](../对局日志.md))。
- **判别口径**:胜因枚举 `aborted`(`authority.ts` `VictoryReason`);终局事件 `gameOver` 以 `reason="aborted"` 判别(`game-events.ts`),客户端演出面照此跳过胜利音效。

## 身价 = 仅现金

对局身价取诸侯当前的现金余额，见[身价函数](../../../packages/core/src/engine/networth.ts)的 `netWorth`。

## AI 诸侯(你的对手)

单机/代管 bot 由 `bot.ts` `botAct` 驱动,单一 EV 策略(#613 难度档退役);所有抉择先经选项集注册表(`choices.ts` `PHASE_CHOICES`)过滤可用项再选——与人类玩家、引擎自动执行同一口径,没有第二套判断(见 [ADR-0013](../../adr/0013-choice-set-and-auto-execute.md))。

| 抉择点         | bot 怎么做                                     |
| -------------- | ---------------------------------------------- |
| 买城           | 现金 > 1.5×价格即买                            |
| 扩军(免费)     | 未满级即升(满级已被引擎自动按兵不动,不触达)    |
| 招贤           | 随机选一位                                     |
| 珍宝交涉(城主) | 珍宝等级 ≥6 坐地起价,否则公道买卖;20% 概率跳过 |
| 锦囊           | 见[出牌策略](./06-锦囊.md#电脑诸侯如何出牌)    |
| 破产清算       | 见[自动清偿规则](./09-破产清算.md)             |

电脑在当前候选城中选最高分。评分以补给性价比 `resupply × 8 / buildCost` 为基准，叠加小于 0.3 的随机值。全图补给相同，建城费低的城池基准分更高（`setup-flow.ts` 的 `aiChooseCapital`）。

各系统页在对应抉择点设「bot 怎么做」回链本节;bot 不看的机制细节走各机制页。

## 席位与诸侯详情

右侧席位格显示该诸侯的银两、体力、城池数和锦囊张数。未进入选人操作时，可点席位格或左上「诸侯详情」查看全员名录。城池、名将和珍宝分项从名录进入，关闭分项回到原位置。
