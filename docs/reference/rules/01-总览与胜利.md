# 总览与胜利

> 规则手册第 1 页:一局怎么玩、两种胜利方式、身价口径,以及你的对手——AI 诸侯。
> 权威声明:代码是唯一事实源,本文数值一律标注代码出处,冲突以代码为准。

## 一局怎么玩

对局支持 2–8 位诸侯，单机和联机默认六人（`constants.ts` 的 `MIN_SEAT_COUNT`、`MAX_SEAT_COUNT` 与 `STANDARD_SEAT_COUNT`）。配置国号后由引擎抽签排定选都顺序，每位诸侯定都于一座城池。首位选都者先行动，此后按座次轮流掷骰行军、落格结算与结束回合。[开局](./02-开局.md) · [回合与行军](./03-回合与行军.md)

棋盘每格都是城池。无主城可购买，己城可免费扩军，落到持珍宝的对手城池可以交涉。珍宝城、招贤城和商市城先处理固定事件，再按落格规则续接。

买城后，每轮可领持城收益。守城保住这笔收入，攻击敌城可得银并争夺归属。都城补给和售卖珍宝也能增加现金。详见[地产经济](./04-地产经济.md)。

从棋盘左上角打开设置，点「音效」或「托管」任一整行即可切换。开启托管后由电脑代打本座，再点一次收回操作。开关显示房间确认的托管状态（`setAutoPilot`）。

局中遇到异常，可从设置打开「对局诊断」保存这一局。离场后可从主页的同名入口选择最近一局或历史局。详见 [对局日志](../对局日志.md#单局诊断文件)。

开局各得一张起手锦囊。每个实际回合先摸牌，再决定是否出锦囊、发动主动技或研读技能书。经过或到达己城还有摸牌补给。体力归零会引发外敌乘虚与休整，都城补给可恢复体力。见[回合与行军](./03-回合与行军.md)和[体力与休整](./07-体力与休整.md)。

全员选都完成时响一次起兵主题，对应实际开局事件 `gameStarted`。

## 联机断线恢复

网络中断后,棋盘保留断线时的可读局面,操作暂时锁定,顶部横幅显示自动重连进度。自动尝试耗尽时,点「重新连接」即可恢复当前房间的原座位,无需重新加入房间。

恢复期间按钮保持忙碌,连接建立后仍需等待权威局面校准;横幅消失才表示本次恢复完成。大厅尚未开局时也可沿此通路恢复。再次耗尽或收到明确错误时,横幅保留失败信息,可再次点「重新连接」发起新尝试。也可点「返回首页」结束本机会话并清除房间状态;此操作不会解散服务器房间,首页不提供原座续局保证。

恢复不会补播断线期间的旧演出。断线前已开启的托管在恢复后继续保留,只有本人沿现有「收回」操作才能恢复手动控制。

通路锚点:`OnlineController.reconnect` / `sessionReady` / `setAutoPilot`、`ConnectionBanner`、`returnHome`。房间凭证与托管口径见[联机架构](../../explanation/联机架构.md)。

## 胜利条件

每个实际回合先结完回合结束技能、待决选择和到期燃烧。有[额外回合](./03-回合与行军.md#额外回合)待接续时，先按此时局面判胜，胜负已定即结束对局。全桌轮末等本轮接续处理完，再结算轮末技能、发放持城收益并判胜。其余回合在收尾结清后判胜（`turn-end.ts` 的 `resumeTurnEnd` 和 `victory.ts` 的 `checkVictory`）。

| 方式         | 条件                                                                                                                                   |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| **身价达标** | 任一玩家身价 ≥ 目标身价(地图顶层 `targetNetWorth` 必配,内置图 30000 两;`board-loader.ts` `loadMap` 校验,`authority.ts` `endTurn` 消费) |
| **群雄尽灭** | 存活玩家仅剩一人(其余全部破产)                                                                                                         |

- 胜因枚举 `TargetNetWorth` / `LastStanding` 见 `authority.ts` `VictoryReason`(另有异常作废 `aborted`,见下文[异常终局](#异常终局对局作废))。
- **多人达标**。取现金最高的存活诸侯。最高现金并列时，各自按拼点骰面掷骰，点数最高者胜。最高点仍并列，则由这些并列诸侯重掷至唯一胜者（`victory.ts` 的 `checkVictory`）。
- 目标身价、起手现金等全部数值条目索引见[关键数值总表](./10-关键数值总表.md)。

胜利页的画卷展示胜者这一局的国号、都城和名将。终榜按现金身价降序排列，同时标示权威胜者和破产诸侯。「再战一局」随终榜可用。

最后一个实际回合的破产、燃烧和发银演出接在终局之前，收尾中跳过的座位仍属于这段结算。已进入演出的当轮持城收益等首枚铜钱抵达席位，再接判胜拼点。拼点的判词收束后，胜利画卷以单鼓登场，落印时接起兵的同主题短角句。从重连或前台恢复看到终局时，已经过去的主题随旧演出一起略过。见[音效设计](../../design/音效设计.md#破产终局与环境声)。

## 异常终局(对局作废)

对局可能因内部错误当场终止(驱动链死亡、时钟挂死等引擎/驱动侧故障):引擎立即作废本局(`authority.ts` `abortGame`),**无胜者**——没有谁称帝,胜负未分,本局成绩不作数。这不是任何玩家的胜负结果,也不是「认输/投降」。

- **玩家看到**:终局屏不演称帝(无排名、无终榜、无烟花),改为「对局作废」面板和「再战一局」出口。回主页后可用「对局诊断」保存这局的记录。
- **留痕可查**:作废原因机读入对局日志终局行(category `final` 的 `abortReason` 字段,附全体玩家终态),排查直接读 jsonl(见[对局日志](../对局日志.md))。
- **判别口径**:胜因枚举 `aborted`(`authority.ts` `VictoryReason`);终局事件 `gameOver` 以 `reason="aborted"` 判别(`game-events.ts`),客户端演出面照此跳过胜利音效。

## 身价 = 仅现金

身价(`networth.ts` `netWorth`)**只数现金**:珍宝、城池账面均不计入。

买城和交涉付款会占用现金。持城收益、攻击奖励、都城补给、卖珍宝等进账直接增加身价。早买城可以多领几轮收入，临近称帝时则要权衡购城支出。

## AI 诸侯(你的对手)

单机/代管 bot 由 `bot.ts` `botAct` 驱动,单一 EV 策略(#613 难度档退役);所有抉择先经选项集注册表(`choices.ts` `PHASE_CHOICES`)过滤可用项再选——与人类玩家、引擎自动执行同一口径,没有第二套判断(见 [ADR-0013](../../adr/0013-choice-set-and-auto-execute.md))。

| 抉择点         | bot 怎么做                                                        |
| -------------- | ----------------------------------------------------------------- |
| 买城           | 现金 > 1.5×价格即买                                               |
| 扩军(免费)     | 未满级即升(满级已被引擎自动按兵不动,不触达)                       |
| 招贤           | 随机选一位                                                        |
| 珍宝交涉(城主) | 珍宝等级 ≥6 坐地起价,否则公道买卖;20% 概率跳过                    |
| 锦囊           | 按牌表策略使用                                                    |
| 破产清算       | 低等级珍宝 → 非都城城池,先拟足额计划再一次出售并清偿;不足则认破产 |

电脑在当前候选城中选最高分。评分以补给性价比 `resupply × 8 / buildCost` 为基准，叠加小于 0.3 的随机值。全图补给相同，建城费低的城池基准分更高（`setup-flow.ts` 的 `aiChooseCapital`）。

各系统页在对应抉择点设「bot 怎么做」回链本节;bot 不看的机制细节走各机制页。

## 席位与诸侯详情

席位卡显示银两、体力、城池数和锦囊张数。点任一席位卡或左上「详情」查看全员名录。城池、名将和珍宝分项在名录上打开，关闭分项回到名录原位置。名下城池清单可查看等级、当前防御与本级满防。锦囊内容仍按[暗牌规则](./06-锦囊.md)展示。
