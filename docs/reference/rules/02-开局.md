# 开局

> 规则手册第 2 页:从选国号到各自落子,三段式 Setup。

## 三段式 Setup

开局三段走完(`game.ts` `SetupPhase`:`Guohao` → `PickCapital` → `Done`;流程由 `game.ts` `setGuohao` / `doDraftRoll` / `pickCapital` 推进):

```
① 国号(各选单汉字)→ ② 点将定序(全员掷骰排座)→ ③ 选都(按序三选一,选都即建城)
```

全员选都完成后 `game.ts` `finishSetup` 收尾进对局,回合状态机启动(见[回合与行军](./03-回合与行军.md)),定序第一人先行。

## 阶段 1:国号

- 每位玩家选**一个单汉字**国号(如「魏」「蜀」「吴」),不可与他人重复(`game.ts` `setGuohao`)。
- 校验:必须是单个 CJK 汉字(`constants.ts` `isSingleCjk`)。

## 阶段 2:点将定序

- 全员各掷一骰,按点数从高到低定出**选都顺序**(`game.ts` `doDraftRoll`)。
- **平局处理**:≤6 人时重摇至全员点数互异(有重摇上限),保证无平局;>6 人不可能全异,接受并列、按座位序破平(`game.ts` `doDraftRoll`)。
- **空座位自动取号**:国号留空的座位(bot,或漏填的人类)在点将时从字池随机分配——去重后洗池取字(`theme.ts` `GUOHAO_POOL`)。

## 阶段 3:选都(三选一)

按定序轮到某玩家时,引擎先为其滚出 **3 座候选城**(`game.ts` `rollOfferedCapitals`,候选快照随 rngState 序列化——联机各端与恢复对局天然一致),玩家只能从中选(`game.ts` `pickCapital`;点非候选城会被拒)。

- **候选生成**:剩余可选城(未选都、未进过任何人的候选集)按建价排序分**低/中/高三档、每档各取一**——廉价/中档/高价拉开经济路线;档内**最远点采样**:首城随机,后两城取「与已选候选最小欧氏距离」最大者前三名再随机,地理分散、避免确定性感。
- **退化规则**:候选不足 3 时跨档补齐;排除历史候选后不足 3 时放行复用未中选的历史候选(小地图也能完成全员选都);候选为空则轮空推进(`game.ts` `rollOfferedCapitals`)。
- **选都即建城**:支付建城费(地图 `buildCost`,口径见[地产经济](./04-地产经济.md)),获得该城地产(**Lv.0**),棋子落于此格——这里成为你的都城与行军起点。

## 开局时刻的锦囊

进对局前按座位序各发 1 张起手锦囊(`jinnang.ts` `JINNANG_STARTING_HAND`;发牌在 `game.ts` `finishSetup`)。牌怎么用、怎么限,详见[锦囊](./06-锦囊.md)。

只列条目,数值与出处统一查[关键数值总表](./10-关键数值总表.md):
