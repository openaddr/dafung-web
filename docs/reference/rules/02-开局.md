# 开局

> 规则手册第 2 页:从选国号到各自落子,三段式 Setup。

## 三段式 Setup

开局三段走完(`authority.ts` `SetupPhase`:`Guohao` → `PickCapital` → `Done`;流程由 `setup-flow.ts` `setGuohao` / `doDraftRoll` / `pickCapital` 推进):

```
① 国号(各选单汉字)→ ② 点将定序(全员掷骰排座)→ ③ 选都(按序三选一,选都即建城)
```

全员选都完成后 `setup-flow.ts` `finishSetup` 收尾进对局,回合状态机启动(见[回合与行军](./03-回合与行军.md)),定序第一人先行。

## 阶段 1:国号

- 每位玩家选**一个单汉字**国号(如「魏」「蜀」「吴」),不可与他人重复(`setup-flow.ts` `setGuohao`)。
- 校验:必须是单个 CJK 汉字(`constants.ts` `isSingleCjk`)。

## 阶段 2:点将定序

- 全员各掷一骰,按点数从高到低定出**选都顺序**(`setup-flow.ts` `doDraftRoll`)。
- **平局处理**:≤6 人时重摇至全员点数互异(有重摇上限),保证无平局;>6 人不可能全异,接受并列、按座位序破平(`setup-flow.ts` `doDraftRoll`)。
- **空座位自动取号**:国号留空的座位(bot,或漏填的人类)在点将时从字池随机分配——去重后洗池取字(`theme.ts` `GUOHAO_POOL`)。

## 阶段 3:选都(三选一)

按定序轮到某玩家时,引擎先为其滚出 **3 座候选城**(`setup-flow.ts` `rollOfferedCapitals`,候选快照随 rngState 序列化——联机各端与恢复对局天然一致),玩家只能从中选(`setup-flow.ts` `pickCapital`;点非候选城会被拒)。

- **候选生成**:剩余可选城(未选都、未进过任何人的候选集)按建价排序分**低/中/高三档、每档各取一**——廉价/中档/高价拉开经济路线;档内**最远点采样**:首城随机,后两城取「与已选候选最小欧氏距离」最大者前三名再随机,地理分散、避免确定性感。
- **退化规则**:候选不足 3 时跨档补齐;排除历史候选后不足 3 时放行复用未中选的历史候选(小地图也能完成全员选都);候选为空则轮空推进(`setup-flow.ts` `rollOfferedCapitals`)。
- **选都即建城**:支付建城费(地图 `buildCost`,口径见[地产经济](./04-地产经济.md)),获得该城地产(**Lv.0**),棋子落于此格——这里成为你的都城与行军起点。
- **确认前看费用**:点候选城后,先看城池身份、建城费、确认后的余额与都城补给;建城费取目录 `PropertyDef.buildCost`,补给取 `PropertyDef.resupply`(`economy.ts`),实际扣款由 `setup-flow.ts` `pickCapital` 完成。等级表可在卷轴内滚动,「定都于此／再想想」固定在底部。

## 开局时刻的锦囊

进对局前按座位序各发 1 张起手锦囊(`jinnang.ts` `JINNANG_STARTING_HAND`;发牌在 `setup-flow.ts` `finishSetup`)。牌怎么用、怎么限,详见[锦囊](./06-锦囊.md)。

## 起手珍宝(#1100)

全员选都落定后的开局收尾(`setup-flow.ts` `finishSetup`)里,锦囊发牌之后、对局开始时机之前,按座位序每人从**统一珍宝牌堆**随机抽 `startingTreasures` 件 **1 级**珍宝、不放回:

- **数量**:地图顶层必配 `startingTreasures`(件/人;缺失或非负整数校验不过,`board-loader.ts` `loadMap` 当场报错——与起手现金必配同款先例);0 = 不发(整段跳过),内置图配 2。发放时 1 级实例不足「座位数 × 件数」响亮抛错(`setup-flow.ts` `finishSetup`)。
- **人内不同款、跨人可同款**:同手几件必不同名(不放回;同名排除仅限人内),跨人拿同款不受限。
- **单池语义**:不设独立起手池——起手抽走即探宝池变薄;所得与一切珍宝完全同权(可交涉、可变卖、可被窃玉偷香),详见[珍宝](./05-珍宝.md)。
