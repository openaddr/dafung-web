# 09 · 破产清算

需付款而现金不足时,引擎给三条路:直接扣、变卖自救、直接破产;真破产则资产易主、名士回池、玩家出局。

## 何时进入清算

一切**被动付款**走同一入口 `game.ts` `payOrLiquidate`:税关缴税、商市行情下跌、机遇银两损失、珍宝交涉价款。主动消费(如买城)现金不足只会被拒绝,不进清算。

## 三条路

```
需付款 amount ──► 现金 ≥ amount? ──是──► 直接扣款,继续            ("ok")
                     │否
                     ▼
              有可变卖资产? ──是──► 进清算相位 AwaitingBankruptcySettle("liquidating")
              (hasMarketableAssets)      逐项变卖凑债
                     │否
                     ▼
                  直接破产(settleDebtTraced → finalizeBankruptcy)("bankrupt")
```

「可变卖资产」= 手中有珍宝、有名士、或有**非都城**房产(都城不算可变卖,`hasMarketableAssets`)。

## 变卖自救(AwaitingBankruptcySettle)

- 三类资产与变现价(具体数值锚链 [`./10-关键数值总表.md`](./10-关键数值总表.md)):
  - **卖珍宝**:按指导价变现(`treasures.ts` `guidePriceOf`,查 `TREASURE_PRICE` 表);
  - **卖城池**:按当前等级价值 `valueByLevel[level]` 变现(`economy.ts` `sellValueOf`;**都城不可卖**,变卖即回无主);
  - **遣散名士**:换银 ¥200(2 两,`game.ts` `cashHeroBankruptcy`)。
- **凑足即止**:现金达到自救线(≥ 债务)后,引擎**硬拒绝**后续一切变卖命令(`assertStillOwing`,战报警告「已凑足债务,不可再卖」)——不靠 UI 禁用自觉;单笔变卖允许超额凑足。选项集同步把变卖项置为不可用(`choices.ts` `bankruptcyChoices` 的 `stillOwing` 门)。
- 凑够后**确认清偿**(`confirmBankruptcySettle`):扣款、转危为安;变卖殆尽仍不足 → 真破产。
- 本相位**永不自动执行**:选项集自动执行机制(ADR-0013)显式排除的唯一相位——重大不可逆,`choices.ts` `EXCLUDED_FROM_AUTO`。
- bot 变卖顺序:名将 → 低等级珍宝 → 城(排除都城),卖到够再确认(`bot.ts` `AwaitingBankruptcySettle` 分支);AI 抉择总表见 [`./01-总览与胜利.md`](./01-总览与胜利.md)。

## 破产后果

(`economy.ts` `settleDebt` + `game.ts` `finalizeBankruptcy`;每处地产易主留 `ownerChanged` 痕,ADR-0015)

| 事项 | 处置 |
|---|---|
| 现金 | 先全部掏给债主(现金归 0) |
| 城池(含都城)与珍宝 | 转移给债主;**无债主则销毁**(城回无主,珍宝灭失);等级不因转移改变 |
| 名士 | 释放回招贤池(`recruitedHeroIds` 删除),他人可再招,见 [`./08-名士与技能.md`](./08-名士与技能.md) |
| 本人 | 标记 `isBankrupt` 退出后续回合、都城归属清空;派发 `PlayerBankrupt` 时机 |

## 谁是债主

`payOrLiquidate` 的债主参数只有**珍宝交涉价款**会带(收款方 = 城主,见 [`./05-珍宝.md`](./05-珍宝.md));税关/商市/机遇等付款均无债主——破产时资产回无主或销毁,不归任何对手。机遇「假道征粮」式的对手收款也不构成债主:若你因它破产,对方分文不得。

## 与托管交割的联动

珍宝交涉**先付款后交货**:成交即入交割托管(escrow),买家经清算自救凑足价款后才完成交割;托管中的珍宝不在买家手里,**不可变卖抵债**(封堵「得宝即卖」套利);买家最终破产则托管珍宝退回卖家(卖家亦已破产则回牌堆)。交割细节见 [`./05-珍宝.md`](./05-珍宝.md)。

破产与耗竭失城的边界:耗竭是体力归 0 的惩罚(城回无主、人不出局,见 [`./07-声望与机遇.md`](./07-声望与机遇.md));破产是偿不了债的出局(资产易主、玩家退场)。
