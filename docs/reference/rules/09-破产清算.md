# 09 · 破产清算

需要付款时,现金足够就直接清偿;不足则先进入清算,预选资产一次出售并清偿,或确认认破产。真破产则资产易主、名将回池、玩家出局。

## 何时进入清算

需要清偿的**被动付款**走同一入口 `bankruptcy.ts` `payOrLiquidate`:商市城行情下跌、珍宝交涉价款。横征暴敛与连环计赔款按付款方现金封顶。主动消费(如买城)现金不足只会被拒绝,不进清算。

## 付款与清算

```
需付款 amount ──► 现金 ≥ amount? ──是──► 直接扣款,继续            ("ok")
                     │否
                     ▼
              进清算相位 AwaitingBankruptcySettle("liquidating")
                     │
                     ├─ 预选足额 ──► 一次出售并清偿,继续对局
                     └─ 确认认破产 ──► 资产处置、名将回池、出局
```

没有可卖资产、只有名将或全部可卖资产仍不足时,同样先展示欠款和不足原因,由玩家确认破产(`bankruptcy.ts` `declareBankruptcy`),不直接跳过清算说明。无需先卖掉一部分资产再确认出局。即使资产足够自救,玩家仍可主动认破产,须再次确认。

## 变卖自救(AwaitingBankruptcySettle)

- **可变卖资产**仅包括持有的珍宝与非都城城池(价格索引见 [10-关键数值总表](./10-关键数值总表.md)):
  - **卖珍宝**:按指导价变现(`treasures.ts` `guidePriceOf`,查 `TREASURE_PRICE` 表);
  - **卖城池**按当前等级的变卖价收银，变卖即回无主。都城不可变卖，价格由 `economy.ts` 的 `sellValueOf` 查 `valueByLevel`。
- **名将不可变卖**,清算期间也禁止普通主动遣散,不能先折成技能书或借得宝技能收入绕过该限制;正常对局的遣散规则见 [08-名将与技能](./08-名将与技能.md)。
- **先预选**:单件珍宝和城池点选切换;同种多件珍宝合并用加减器选数量,减到零取消。预选、取消和翻页均不移走资产、不增加现钱,跨页保留本次选择。
- **凑足即止**:已选变卖额覆盖现钱缺口后,不能继续增加选择,仍可取消、减量和换选。最后一件允许超额,多余银两保留。引擎对最终批次执行同一约束,不能靠数量或批量提交多卖。
- **一次出售并清偿**:选择足额后才可提交(`bankruptcy.ts` `confirmBankruptcySettle`);引擎在变更前完整校验资产和数量,一次完成出售、付款及托管交割。非法或不足额批次不产生部分成交。旧逐件出售、再另点结算的操作退役。
- **金额阅读**:欠款与现钱各表达一次,底部持续显示已选变卖额及还差／超出。超出只是本次变卖相对现金缺口的差额;交割可能继续触发得宝技能收入,不等于最终余额承诺。
- **分页选择**。金额、翻页与操作区常驻。高度不足时，可在资产区内滚动查阅当前页。翻页后从该页顶部开始。标准横屏布局见[设计规范](../../design/DESIGN.md)。
- 本相位**永不自动执行**:选项集自动执行机制(ADR-0013)显式排除的唯一相位——重大不可逆,`choices.ts` `EXCLUDED_FROM_AUTO`。
- bot 仅选择合法资产,沿既有珍宝、城池优先级凑足后提交同一批量清偿命令;不足则提交破产,不因零资产卡住。人类/bot、单机/联机规则一致(`bot.ts` `AwaitingBankruptcySettle` 分支);AI 抉择总表见 [01-总览与胜利](./01-总览与胜利.md)。

## 破产后果

(`economy.ts` `seizeBankruptAssets` + `bankruptcy.ts` `finalizeBankruptcy`;每处地产易主留 `ownerChanged` 痕,ADR-0015)

| 事项               | 处置                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------- |
| 现金               | 先全部掏给债主(现金归 0)                                                                  |
| 城池(含都城)与珍宝 | 转移给债主;**无债主则销毁**(城回无主,珍宝灭失);等级不因转移改变                           |
| 名将               | 释放回招贤池,不换银、不折书、不转给债主;他人可再招,见 [08-名将与技能](./08-名将与技能.md) |
| 本人               | 标记 `isBankrupt` 退出后续回合、都城归属清空;派发 `PlayerBankrupt` 时机                   |

## 谁是债主

`payOrLiquidate` 的债主参数只有**珍宝交涉价款**会带(收款方 = 城主,见 [`./05-珍宝.md`](./05-珍宝.md));商市城付款无债主——破产时资产回无主或销毁,不归任何对手。

## 与托管交割的联动

珍宝交涉**先付款后交货**:成交即入交割托管(escrow),买家经清算自救凑足价款后才完成交割;托管中的珍宝不在买家手里,**不可变卖抵债**(封堵「得宝即卖」套利);买家最终破产则托管珍宝退回卖家(卖家亦已破产则回牌堆)。交割细节见 [`./05-珍宝.md`](./05-珍宝.md)。

耗竭触发[外敌乘虚与休整](./07-体力与休整.md)，受击城池可能降级或被攻陷。破产时诸侯出局，有债主时由债主按原等级、满防御接城（`economy.ts` 的 `seizeBankruptAssets`）。
