# 锦囊

> 一句话:**全游戏唯一的隐藏信息**——持有暗置(手牌内容只有自己知道),使用与结算全员公开(浮字+战报,暗的只是「手里有什么」)。
> 设计红线「无博弈不锦囊」:拿到即用、无需权衡的牌不配当锦囊。术语见 [`CONTEXT.md`](../../../CONTEXT.md)「锦囊与暗牌」;设计叙事见 [`锦囊设计.md`](../../explanation/锦囊设计.md);联机暗牌协议见 [ADR-0016](../../adr/0016-per-seat-snapshot-redaction.md)。

## 获取:五条渠道

| 渠道             | 规则                                                                                                            | 定位       |
| ---------------- | --------------------------------------------------------------------------------------------------------------- | ---------- |
| 起手发牌         | 选都完成进对局前,按座位序各发 1 张(`game.ts` `finishSetup`;张数 `jinnang.ts` `JINNANG_STARTING_HAND`)           | 保底       |
| 锦囊格           | 地图 `type:"Chance"` 格,落格必抽 1 张(`game.ts` `resolveLanding`;与机遇格的区别=必得 vs 概率触发)               | 主渠道     |
| 机遇「圯上授书」 | 好运机遇(`encounters.ts`「圯上授书」条目,effect `grantCard`)纯抽一张                                            | 佐料       |
| 声望献计         | 声望首次**向上穿越** +30 / +60 / +90 各献 1 张(`game.ts` `addReputation`,已领进度记 `repMilestones`)            | 主渠道之二 |
| 辅路「军师来投」 | 辅路 event 格抽中随机事件(`events.ts` `CHANCE_EVENTS` 的 `strategist`)额外献 1 张(`game.ts` `applyRandomEvent`) | 佐料       |

目标手感:人均每局经手 3~5 张。一切抽牌统一走 `game.ts` `drawJinnang`:牌库空 → 浮字「锦囊已空」落空;手牌**无上限**(#250),抽牌恒入手、永不作废——理论上限=整副牌库 18 张。

## 牌库与手牌

- **牌库 18 张**:9 种目录(`jinnang.ts` `JINNANG_CARDS`)按 `copies` 展平(`JINNANG_DECK_LIST`),开局骰序洗牌(`buildJinnangDeck`),抽空即止。
- **缓兵之计全场唯一**(×1):谁打出过、牌库还剩没有,人人可推——唯一的公开计数信息;**半路杀出 ×3**,其余 7 种各 ×2。
- **手牌无上限**(#250):抽牌恒入手,不作废(理论上限=整副牌库 15 张,`game.ts` `drawJinnang`);弃牌堆**一局内不回流**;牌库/手牌剩余数全员可数(快照字段 `jinnangDeckCount` / `jinnangHandCount`)。
- 手牌内容暗置(`jinnangHand`);对局日志只记「抽了一张锦囊」不记牌名(暗牌内容不过日志)。

## 使用:回合开始、掷骰前(军师幕)

- 窗口正名与呈现(#188 档 3 / #256):回合开始掷骰前的决策窗现为**军师幕**——锦囊 + 名将主动技的统一决策窗(主动技细则见 [`./08-名将与技能.md`](./08-名将与技能.md));本页只讲锦囊半边。呈现不弹窗:手牌架就地进**军师窗态**(术语见 [`CONTEXT.md`](../../../CONTEXT.md)),可出的牌金边上浮、不可用灰置印原因,选中与确认走居中动作条。
- 新回合开账(`game.ts` `endTurn`):清空上回合的标签名额与到期的窥探窗口,然后若有可用牌(或就绪主动技)进 **`AwaitingJinnang`** 相位(`enterJinnangPhase`)——用牌/出技决定先于掷骰。
- **零可用自动过**:无手牌且无就绪技(或全部不可用)时,不进窗态直接掷骰(选项集 ≤1 静默跳过,`choices.ts` `hasUsableJinnang`);只要有一张可用牌或就绪技,必进军师窗态,且「不出」永远在场(`jinnangChoices`,动作条呈现)。
- **每回合每类标签限一张**(谋/攻/守/援):用牌即占用该牌全部标签的本回合名额——缓兵之计〔谋+攻〕一张占两席(已用标签记 `jinnangUsedTags`);主动技不走标签名额,走独立冷却。「即时」标记是反应牌族标(非名额):反应牌多在他人回合打出,不入活跃玩家的名额账本(`game.ts` `consumeReactionCard`)。
- 命令 `useJinnang`(`types.ts`):指向他人的牌确认后进**目标段**——动作条切换「选择目标/作罢」,候选席位卡金圈呼吸、点席位即出(免二次确认;候选含灰置原因,棋盘 token 同步呼吸);连环计**两步选人**(第二步排除第一步,载荷 `types.ts` `PendingJinnang`);目标段可「作罢」(牌不消耗收回)。
- 用后:牌入弃牌堆(`consumeJinnangCard`),随即重算选项集——同回合仍有**异类标签**可用牌或就绪主动技则窗口再开(`settleJinnangExit`),否则进掷骰。合法性(相位/持有/名额/目标)由引擎校验(`resolveJinnang`),UI 永不裁决。
- **反应牌不入军师幕**:带「即时」标记的反应锦囊(`jinnang.ts` `isReactionCard`)在军师幕里灰置印「唯反应」,只在反应窗打出(见下节)。

## 反应窗:他人的结算点,你的出手时机(#281)

任何人宣布锦囊(结算前)、或他人行军途经你的城池时,持反应锦囊者会被询问——**牌架即反应窗**(呈现见下节「牌面与界面」;窗口语义见 [ADR-0017](../../adr/0017-non-blocking-reaction-windows.md)):

- **两个触发点**(`timing.ts` 时机注册 + `game.ts` 挂点):`JinnangAnnounced`——任何锦囊宣布、结算前,持「识破诡计」者(使用者除外)可拆;`MarchPassedCity`——他人行军途经城主城池,城主持「半路杀出」可拦检(详见[回合与行军](./03-回合与行军.md)途经拦检)。
- **非阻塞 per-seat**:被询问座位各端独立倒计时(默认 3s,配置表驱动 `constants.ts` `REACTION_WINDOW_MS`),归零=「不用」;无牌座位全程无感。超时兜底在权威侧(单机=LocalController,联机=房间循环)代发普通「不用」命令,重放天然复现。单机应答即走、无应答等满;bot 持牌即时代答。
- **降噪口**:「本回合不再询问」——点下即对当前窗应答不用,本回合(当前行动者回合)后续询问不再弹窗、自动代发不用;行动者回合结束自动解除。
- **识破不可被识破**:反应牌永不经宣布通道(引擎红线「效果内禁同步再派发时机」同口径),窗内结算不再开新窗。
- **命令**: `respondReaction`(`types.ts`);询问/应答挂起态随快照走(`game.ts` `pendingReaction`),断线恢复不丢窗。

## 牌面与界面

- **牌面**:竖笺形制(`src/app/components/card/JinnangCardFace.tsx`):笺头牌名、右上朱砂标签章(多标签竖排)、中部程序化纹样窗(谋=云纹·黛青 / 攻=火纹·朱砂 / 守=盾纹·赭石 / 援=枝纹·青绿 / 即时=电纹·靛青)、笺脚两行短文案——渲染时剥离 `text` 首段四字计名别称(如「二虎竞食:」),别称随全文进详情。牌背为漆木底+「锦囊」朱印,兼作手牌架空态占位。
- **手牌架**:己方锦囊以牌面常驻底部仪表条右段(`HandRack.tsx`),手牌无上限:>3 张**叠加压缩**露牌名条、悬停挥出全显(#254),他人回合同样可见;**点牌或长按**弹出详情(牌名/标签/目标域/全文),Esc 或点旁关闭。
- **军师窗态交互**:点牌=**选中即放大**(全文可读,再点它牌换选,右键/长按取消);**动作条「出牌」才是确认**(数字键 1..n 选中、Enter 确认)——选择与出牌分离;不可用的牌下沉置灰,原因印在牌面下缘(原因单源 `choices.ts` 选项集,UI 只渲染不判定)。窗态牌面带 ±1.5° 随机微旋(TablePile 质感,`prefers-reduced-motion` 退场)。
- **反应窗呈现(#281)**:结算点事件横幅从手牌架上缘长出——左段事件文案 + 朱砂倒计时弧;架上此刻可打的反应锦囊**呼吸金边**,点牌选中 → 墨钮落印确认(超时自动「不用」),降噪口入口在横幅上。出牌确认后棋盘画**出牌指示线**(使用者 token → 目标 token 墨线,生长 200ms → 停 200ms → 淡出 300ms,`src/app/fx/` ADR-0010 表现事件管线;无指向的牌不出线)。
- **牌面用语规范**:目标句「指定一名/两名其他诸侯」「其余所有诸侯」,回指用「其」,时窗一律「至你的下回合开始」,数额用阿拉伯数字——与 `jinnang.ts` 牌面文案同口径,新牌文案照此执行。

## 拆招细则(识破诡计)

- **全口径**:任何人的锦囊指定任何人,持牌者皆可识破——替他人拆招是人玩家的政局玩法(bot 只自保,见下节)。
- **AOE 按份拆**:横征暴敛等全体计,每份(每个被指定者)只免其中一份——识破者指定保护哪份;多持牌者各拆各份,每份计只问一轮。
- **连环计一方被识破=该计作废**(缺角,与平局作废同逻辑);双人同时应答按座位序第一张生效,其余识破原样退回手牌不消耗。
- **只免当前这一下**:牌即耗,无任何持续效果;主动技不可被识破(#229 口径)。

## 窥探:时窗一律「至你的下回合开始」

- **军情密探**:窗口为「至使用者下回合开始」(`types.ts` `JinnangPeek`,到期在 `endTurn` 清);窥探事件本身公开,暗的只是你看到的对方牌面。

## 数值口径

- 玩家间银两转移一律**上限=付款方现金,不触发清算**——横征暴敛与连环计赔款同口径(结算在 `game.ts` `executeJinnang`)。
- **锦囊不计身价**:身价=仅现金(`networth.ts` `netWorth`),手牌/珍宝/城池账面均不入。
- **破产**:锦囊手牌清入弃牌堆(不变卖、不转移、不回流;`game.ts` `finalizeBankruptcy`,守恒由单测锁定,#198)。

## bot 与看门狗

- bot 策略(EV 贪心,`bot.ts`):横征暴敛/求贤令可用即用;连环计挑现金最高的两人相咬;窃玉挑珍宝最多者;火烧挑城最多的领先者;缓兵只拖当前身价领先者;Simple 难度 50% 弃权(主动技的 bot 策略见 [`./08-名将与技能.md`](./08-名将与技能.md))。
- **反应牌 bot 口径(#281)**:识破诡计**只自保**(拆指定自己的,净值贪心;替他人拆招是人玩家专属);半路杀出拦检=确定性启发——行人是当前现金第一才拦,否则不拦。
- **看门狗接管永不主动用牌**(一律「不出」保守推进);玩家自愿托管则按上表策略走。主动技更保守一步:接管与托管(人类座位代驾)都**永不主动出技**——托管/看门狗也**永不主动出反应牌**(超时一律不用,#148/#229 口径)。
