# 锦囊

> 一句话:**全游戏唯一的隐藏信息**——持有暗置(手牌内容只有自己知道),使用与结算全员公开(浮字+战报,暗的只是「手里有什么」)。
> 设计红线「无博弈不锦囊」:拿到即用、无需权衡的牌不配当锦囊。术语见 [`CONTEXT.md`](../../../CONTEXT.md)「锦囊与暗牌」;设计叙事见 [`锦囊设计.md`](../../explanation/锦囊设计.md);联机暗牌协议见 [ADR-0016](../../adr/0016-per-seat-snapshot-redaction.md)。

## 获取:五条渠道

| 渠道 | 规则 | 定位 |
|---|---|---|
| 起手发牌 | 选都完成进对局前,按座位序各发 1 张(`game.ts` `finishSetup`;张数 `jinnang.ts` `JINNANG_STARTING_HAND`) | 保底 |
| 锦囊格 | 地图 `type:"Chance"` 格,落格必抽 1 张(`game.ts` `resolveLanding`;与机遇格的区别=必得 vs 概率触发) | 主渠道 |
| 机遇「圯上授书」 | 好运机遇(`encounters.ts`「圯上授书」条目,effect `grantCard`)纯抽一张 | 佐料 |
| 声望献计 | 声望首次**向上穿越** +30 / +60 / +90 各献 1 张(`game.ts` `addReputation`,已领进度记 `repMilestones`) | 主渠道之二 |
| 辅路「军师来投」 | 辅路 event 格抽中随机事件(`events.ts` `CHANCE_EVENTS` 的 `strategist`)额外献 1 张(`game.ts` `applyRandomEvent`) | 佐料 |

目标手感:人均每局经手 3~5 张。一切抽牌统一走 `game.ts` `drawJinnang`:牌库空 → 浮字「锦囊已空」落空;满手 → 该张作废直接入弃牌堆,浮字「锦囊已满」。

## 牌库与手牌

- **牌库 15 张**:8 种目录(`jinnang.ts` `JINNANG_CARDS`)按 `copies` 展平(`JINNANG_DECK_LIST`),开局骰序洗牌(`buildJinnangDeck`),抽空即止。
- **缓兵之计全场唯一**(×1):谁打出过、牌库还剩没有,人人可推——唯一的公开计数信息;其余 7 种各 ×2。
- **手牌上限 3**(`jinnang.ts` `JINNANG_HAND_LIMIT`);弃牌堆**一局内不回流**;牌库/手牌剩余数全员可数(快照字段 `jinnangDeckCount` / `jinnangHandCount`)。
- 手牌内容暗置(`jinnangHand`);对局日志只记「抽了一张锦囊」不记牌名(暗牌内容不过日志)。

## 使用:回合开始、掷骰前

- 新回合开账(`game.ts` `endTurn`):清空上回合的标签名额、到期的免战盾与窥探窗口,然后若有可用牌进 **`AwaitingJinnang`** 相位(`enterJinnangPhase`)——用牌决定先于掷骰。
- **零可用自动过**:无手牌或全部牌不可用时,不弹卷轴直接掷骰(选项集 ≤1 静默跳过,`choices.ts` `hasUsableJinnang`);只要有一张可用,卷轴必弹,且「今不用」永远在场(`jinnangChoices`)。
- **每回合每类标签限一张**(谋/攻/守/援):用牌即占用该牌全部标签的本回合名额——缓兵之计〔谋+攻〕一张占两席(已用标签记 `jinnangUsedTags`)。
- 命令 `useJinnang`(`types.ts`):指向他人的牌选定后进**目标段**——同一卷轴改列候选座位(国号方章,候选含灰置原因);连环计**两步选人**(第二步排除第一步,载荷 `types.ts` `PendingJinnang`);目标段可「作罢」(牌不消耗收回)。
- 用后:牌入弃牌堆(`consumeJinnangCard`),随即重算选项集——同回合仍有**异类标签**可用牌则卷轴再开(`settleJinnangExit`),否则进掷骰。合法性(相位/持有/名额/目标)由引擎校验(`resolveJinnang`),UI 永不裁决。

## 八牌目录

数值与文案以 `jinnang.ts` `JINNANG_CARDS` 为唯一事实源(下表逐牌核对);目标有效性判定见 `choices.ts` `jinnangTargetOk`。

| 牌 | 标签 | 目标域 | 效果 | 不可用条件 |
|---|---|---|---|---|
| 连环计 ×2 | 谋 | 指定两名他人 | 二人各掷 1d6 拼点:胜者从国库得 300 两,败者向你赔 400 两(上限=其现金);平局双方无事、此计作废 | 有效对手 <2(「对手不足」) |
| 军情密探 ×2 | 谋 | 指定一名他人 | 窥探其锦囊手牌,至你的下回合开始(见下节) | 无有效对手时全部灰置,只能作罢 |
| 缓兵之计 ×1 | 谋+攻 | 指定一名他人 | 其下回合被跳过;牌库全场唯一 | 无有效对手时全部灰置,只能作罢 |
| 横征暴敛 ×2 | 攻 | 全体其他玩家 | 每人向你缴 200 两(上限=各自现金,不触发清算);免战/破产者跳过,可能无人缴纳 | 无(无目标段) |
| 窃玉偷香 ×2 | 攻 | 指定一名他人 | 随机夺其一件珍宝归你 | 目标无珍宝 |
| 火烧连营 ×2 | 攻 | 指定一名他人 | 随机一座其城池降 1 级;城防全为 0 级则随机失去一座(回无主) | 目标无城池 |
| 免战金牌 ×2 | 守 | 自身 | 至你的下回合开始,他人的锦囊无法指定你为目标 | 无 |
| 求贤令 ×2 | 援 | 自身 | 招一名武将来投;帐下已满或名将已尽则折现 300 两(同机遇招贤口径) | 无 |

## 免战与窥探:时窗一律「至你的下回合开始」

- **免战金牌**:使用即挂盾(`jinnangShield`),轮到你的下回合开始时到期(`endTurn` 清账)。窗口内横征暴敛跳过你、指名类牌在目标段把你灰置(reason「免战庇护」);只挡锦囊,机遇/天命/缴税照常。
- **军情密探**:窗口同为「至使用者下回合开始」(`types.ts` `JinnangPeek`,到期同在 `endTurn` 清);窥探事件本身公开,暗的只是你看到的对方牌面。

## 数值口径

- 玩家间银两转移一律**上限=付款方现金,不触发清算**——横征暴敛与连环计赔款同口径(结算在 `game.ts` `executeJinnang`)。
- **锦囊不计身价**:身价=仅现金(`networth.ts` `netWorth`),手牌/珍宝/城池账面均不入。
- **破产**:锦囊手牌不变卖、不转移、也不入弃牌堆——随人退场成死牌(`economy.ts` `settleDebt` 与 `game.ts` `finalizeBankruptcy` 均不清手牌;`drawJinnang` 对破产者拒抽)。注:设计稿「破产清空入弃牌堆」未实现,以代码为准。

## bot 与看门狗

- bot 策略(EV 贪心,`bot.ts`):横征暴敛/求贤令可用即用;连环计挑现金最高的两人相咬;窃玉挑珍宝最多者;火烧挑城最多的领先者;缓兵只拖当前身价领先者;Simple 难度 50% 弃权。
- **看门狗接管永不主动用牌**(一律「今不用」保守推进);玩家自愿托管则按上表策略走。
