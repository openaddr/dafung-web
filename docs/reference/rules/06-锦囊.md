# 锦囊

## 摸牌

全员定都后各发一张起手牌（`jinnang.ts` 的 `JINNANG_STARTING_HAND`），每个实际回合开始再摸一张（`JINNANG_TURN_DRAW`）。行军可获得[己城摸牌](./03-回合与行军.md#己城摸牌)，跳过的回合没有摸牌阶段。

各来源共用一副牌库。牌库空时将弃牌堆洗回，两堆都空时公布「锦囊已空」（`jinnang-execution.ts` 的 `drawJinnang` 和 `jinnangExhausted`）。

## 牌库与手牌

摸到的牌都入手。玩家看见自己的牌面、所有座位的手牌张数、牌库余量和弃牌堆内容。其他人的摸牌战报只记摸牌数量。逐座位的可见性见 [ADR-0016](../../adr/0016-per-seat-snapshot-redaction.md)。

打出即入弃牌堆。开局和弃牌堆洗回都按本局骰流洗牌，见[锦囊源码](../../../packages/core/src/engine/jinnang.ts)的 `buildJinnangDeck` 与 `reshuffleDiscardIntoDeck`。

## 出牌阶段

掷骰前，锦囊、主动技和可研读的技能书共用手牌区。三者都没有可用项时直接掷骰（`choices.ts` 的 `hasUsableJinnang`）。点「不出」可结束出牌阶段。通常结算后重算可用项，有可用项就继续。功能标签供规则引用，同回合可连续打出符合条件的同标签牌。

- 点牌选中，再点一次取消，点另一张换选。可以在手牌架上方读全文，长按可打开详情。不可用的牌压暗并显示原因。
- 需要目标时点「选目标」，再点棋盘的城池或右侧席位条的诸侯。点已选对象可取消。动作条显示当前步骤和已选对象，最后点「出牌」提交。点「取消选牌」回到选牌。
- 连环计分两步选人。选好首位后点「下一步」，可点「上一步」回改首选，再次前进后重新选第二位。最终有效提交才消耗锦囊（`TARGET_DOMAIN_STAGES`）。
- 火烧连营在地图上选择火源，受击城由 `choices.ts` 的 `fireWallSplashCities` 推导。进入地图选择时手牌架收起，点右下「锦囊」可再次打开。
- 「挟天子以令诸侯」没有目标段，额外回合中也可打出。被识破时牌照常消耗，其余可用选项仍可继续。接续和计数见[额外回合](./03-回合与行军.md#额外回合)。

主动技的目标和确认见[名将与技能](./08-名将与技能.md#主动技与出牌阶段)。标有「即时」的锦囊在对应的反应窗使用。

## 反应窗

锦囊宣布后、结算前，权威端向可拆招的座位开窗。按份拆的锦囊在零份时照常扣牌并宣布，随后直接结算。拦检的触发点见[途经他人城池](./03-回合与行军.md#途经他人城池拦检半路杀出281)。

被询问的座位共用截止时刻，两种窗口默认均为 30 秒。全部应答后推进，超时由权威端代答「不出」。重连沿用剩余时限，反识破进入新窗时重新计时。默认时长见[规则常量 `REACTION_WINDOW_MS`](../../../packages/core/src/engine/constants.ts)。

反应窗的动作条给出行动者、范围和倒计时。反识破还会显示原锦囊和本环争夺的对象。此时可用的牌亮金边。按份识破时先点受击城池或受影响诸侯，再点「出牌」，只有一份时也须点选。整计识破、反识破与拦检选牌后即可提交。

「不出」应答当前窗。「本回合不再询问」应答本窗，并在当前行动者本回合余下的询问中自动应答「不出」。时序设计见 [ADR-0017](../../adr/0017-non-blocking-reaction-windows.md)。

## 牌面与手牌架

多个选项叠放时，可点架尾计数章查看完整牌序。横滑浏览，点同名牌也逐张选中。手牌架可通过右下「锦囊」暂时收起或打开。已选牌保留，选目标时仍可从动作条查看、提交或取消。显隐和触摸设计见[视觉与交互](../../design/DESIGN.md)，声效见[音效设计](../../design/音效设计.md)。

## 拆招细则

- 锦囊宣布后，使用者之外的持牌诸侯可为受影响的对象拆招，包括替其他人挡招。主动技走独立结算。
- 横征暴敛的一份是一名被征收的诸侯，火烧连营的一份是一座实际受击的城。打空且免疫的都城不占份。识破只取消指定份，其他份照常结算。同窗同份收到多张识破时按座次只有第一张实际打出。
- 识破连环计任一目标会取消整计。识破袭扰会一并取消这次体力伤害的派生结算。
- 识破宣布后，本环出牌者之外的持牌者可再拆，原计使用者也可救自己的计。已经打出的牌照常消耗。反识破恢复上一环挡住的整计或指定份，直到再无新应答。见[反应结算](../../../packages/core/src/engine/reaction-window.ts)与 [ADR-0060](../../adr/0060-counter-counter-reaction-chain.md)。

棋盘上的识破结算指示见[出牌指示线](../../design/DESIGN.md#45-锦囊牌面)。

## 军情密探

目标手牌为空时仍可窥探，会显示「囊中空空」。窥探弹层关闭后结束阅览。出牌宣布全桌可见，实际牌面只随生效事件 `peekApplied` 发给窥方。

## 银两结算

连环计赔款和横征暴敛至多扣付款方现有的现金，按实际可付金额结算。锦囊手牌的破产去向见[破产清算](./09-破产清算.md)。

## 电脑诸侯如何出牌

`bot.ts` 的 `jinnangIntent` 决定选牌。横征暴敛、求贤令、挟天子以令诸侯可用即用。连环计选现金最高的两位，窃玉偷香优先选珍宝最多者，火烧连营优先影响城池领先者，袭扰优先令对手耗竭，缓兵之计用于拖慢身价领跑者。电脑的识破用于保护自身利益，半路杀出只拦当前现金领先的行人。
