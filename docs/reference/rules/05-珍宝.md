# 珍宝

> 一句话:珍宝是**可变卖换现的战利品**——落珍宝城则**落格先拼点探宝、后进交易链**,落在他人城里则由城主**交涉卖给你**;交涉价款在玩家间流转,是继都城补给之后的第二大资金话题。

数值口径:目录与价格一律降为索引,只锚代码符号;价位数字见 [10-关键数值总表](./10-关键数值总表.md)。

## 珍宝是什么

- 牌堆共 **14** 件、等级 **1–10**:目录定义于 `treasures.ts` `TREASURES`,开局按各条 `count` 展开成独立实例(`treasures.ts` `createTreasureDeck`)。
- 指导价只看等级:`treasures.ts` `TREASURE_PRICE` 逐级查表,`guidePriceOf` 缺等级直接抛错(零兜底)。

## 珍宝城:可购买的城池 + 拼点探宝

珍宝城与普通城池**完全同权**(ADR-0024):可购买、可扩军、可交涉、可公道买卖、可选都候选(`board-loader.ts` 与 `Property` 同口径入 catalog);与普通城的唯一差别,是落格固定事件=**拼点探宝**(#825 自交易链尾挂件迁来:**先探宝、后交易链**;数据承载为城池格 `event:"treasure"`(#826 起旧独立格型全量退役,装载器对其他格型值响亮报错)。盘面上珍宝城以右上角「珍宝」两字方印标识(#828;印文词表 `Tile.tsx` `TILE_EVENT_BADGES`,几何见 [03-回合与行军](./03-回合与行军.md))。

落格结算顺序为正典(ADR-0024 链序随 #825 迁移,机遇侧随 ADR-0035 改必出、珍宝城免掷随 ADR-0037 事件城同款;详见 [03-回合与行军](./03-回合与行军.md)):**机遇必出(珍宝城免掷)→ [固定事件:探宝] → 城池交易链(购地/扩军/按兵不动/珍宝交涉,含自动拒绝)→ 结束回合**。两个已拍板的语义位移:探宝**先于付银**——链中清算/破产**不再抑制**探宝(它已在落格时结算);交易链收口**零探宝**(旧「链尾必接一次探宝,按兵不动也探」钩子退役)。

探宝本体四步(`treasure-flow.ts` `drawTreasureAt`,`movement-flow.ts` `resolveCityEvent` 经壳上 `g.drawTreasureAt` 消费):

1. 从珍宝牌堆**随机抽 1 件**;
2. **掷双骰拼点**(2d6 = 2–12);
3. **拼点 ≥ 珍宝等级** → 获得该珍宝;**< 等级** → 珍宝放回**牌堆底**;
4. 牌堆已空 → 无事发生(「珍宝已被搜刮一空」,事件沉默、交易链照常)。

失败的珍宝不消失、只回堆底:珍宝城可反复尝试,但整局 14 件挖完即止。

**探宝与交涉并存于一格**:落**他人**珍宝城时,落格先探宝,城主有宝再照常触发珍宝交涉(见下节)——两条通道互不排斥;城主无宝则探宝后无事发生。落**自己**珍宝城:探宝后照常可免费扩军。

## 珍宝交涉(`AwaitingTreasureOwner`)

落到**他人城**(含珍宝城)且城主**有**珍宝时,由**城主**做三选一(`treasure-flow.ts` `resolveTreasureOwner`;选项集见 `choices.ts` `treasureOwnerChoices`,天然三项、永不自动执行)。**访客不可拒绝**:城主选了交易,访客必须掏钱——付不起就走破产清算(见 [09-破产清算](./09-破产清算.md))。

| 抉择                  | 售价                                      | 交易后                   |
| --------------------- | ----------------------------------------- | ------------------------ |
| **公道买卖**(fair)    | 指导价(`guidePriceOf`)                    | **城池 +1 级**(满级封顶) |
| **坐地起价**(premium) | 指导价 × `tradeMult[Lv]` + `tradeAdd[Lv]` | 不升级                   |
| **不交易**(skip)      | —                                         | 无事发生                 |

### 公道买卖成交即升级

升级挂在**交易达成时**(城主选定 fair、珍宝离手入托管,`treasure-flow.ts` `resolveTreasureOwner` fair 分支):`canUpgrade`(`economy.ts`)允许则城池 +1 级、满级封顶。**此后买家破产退宝也不回滚**——升级是对城主选择公道的奖励:不白送,也不撤销。

### 坐地起价公式

**售价 = 指导价 × `tradeMult[城池等级]` + `tradeAdd[城池等级]`**(先乘再加、四舍五入;`treasures.ts` `premiumPriceOf`):

- `tradeMult`/`tradeAdd` 由地图**逐城必配**(`economy.ts` `PropertyDef`,下标 = 城池等级 0..maxLevel、长度 = maxLevel+1);缺失或长度不符在 `loadMap` 当场校验失败——无静默回退,配置缺失是数据 bug 不是兼容场景。

### 交割托管(escrow):先付款后交货

成交后珍宝不直接到手,先进**交割托管区**(`authority.ts` `escrowTreasure`,随快照序列化):

```
成交 → 珍宝入托管 → 买家付款(不够可经破产清算变卖自救)
    ├─ 付清 → 交割 deliverEscrow:珍宝归买家
    └─ 破产 → 退回 returnEscrowToSeller:珍宝归卖家
```

- **托管中不可得宝即卖**:托管珍宝不在买家手中,无法经 `sellTreasureBankruptcy`(`authority.ts`)变卖抵债——封堵「得宝即卖」的白嫖套利。
- **破产退回**:买家最终破产,托管珍宝退回卖家;若卖家亦已破产出局,则归入牌堆。

## 银两只在玩家间流转

交涉价款一律 **访客 → 城主** 直接过户,无银行注入、无第三方抽成(`treasure-flow.ts` `resolveTreasureOwner` 头注);托管只押珍宝、不押钱。
