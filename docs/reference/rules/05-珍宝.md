# 珍宝

> 一句话:珍宝是**可变卖换现的战利品**——无主时到宝物城**拼点探宝**,落在他人城里则由城主**交涉卖给你**;交涉价款在玩家间流转,是继都城补给之后的第二大资金话题。

数值口径:目录与价格一律降为索引,只锚代码符号;价位数字见 [10-关键数值总表](./10-关键数值总表.md)。

## 珍宝是什么

- 牌堆共 **14** 件、等级 **1–10**:目录定义于 `treasures.ts` `TREASURES`,开局按各条 `count` 展开成独立实例(`treasures.ts` `createTreasureDeck`)。
- 指导价只看等级:`treasures.ts` `TREASURE_PRICE` 逐级查表,`guidePriceOf` 缺等级直接抛错(零兜底)。

## 宝物城:拼点探宝

落到宝物城(以及辅路 treasure 格,行军细则见 [03-回合与行军](./03-回合与行军.md))触发四步(`game.ts` `resolveTreasureCity` → `drawTreasureAt`):

1. 从珍宝牌堆**随机抽 1 件**;
2. **掷双骰拼点**(2d6 = 2–12);
3. **拼点 ≥ 珍宝等级** → 获得该珍宝;**< 等级** → 珍宝放回**牌堆底**;
4. 牌堆已空 → 无事发生(「珍宝已被搜刮一空」)。

失败的珍宝不消失、只回堆底:宝物城可反复尝试,但整局 14 件挖完即止。

## 珍宝交涉(`AwaitingTreasureOwner`)

落到**他人城**且城主**有**珍宝时,由**城主**做三选一(`game.ts` `resolveTreasureOwner`;选项集见 `choices.ts` `treasureOwnerChoices`,天然三项、永不自动执行)。**访客不可拒绝**:城主选了交易,访客必须掏钱——付不起就走破产清算(见 [09-破产清算](./09-破产清算.md))。

| 抉择 | 售价 | 交易后 |
|---|---|---|
| **公道买卖**(fair) | 指导价(`guidePriceOf`) | **城池 +1 级**(满级封顶) |
| **坐地起价**(premium) | 指导价 × `tradeMult[Lv]` + `tradeAdd[Lv]` | 不升级 |
| **不交易**(skip) | — | 无事发生 |

### 公道买卖成交即升级

升级挂在**交易达成时**(城主选定 fair、珍宝离手入托管,`game.ts` `resolveTreasureOwner` fair 分支):`canUpgrade`(`types.ts`)允许则城池 +1 级、满级封顶。**此后买家破产退宝也不回滚**——升级是对城主选择公道的奖励:不白送,也不撤销。

### 坐地起价公式

**售价 = 指导价 × `tradeMult[城池等级]` + `tradeAdd[城池等级]`**(先乘再加;`treasures.ts` `premiumPriceOf`):

- `tradeMult`/`tradeAdd` 由地图逐城配置(`types.ts` `PropertyDef` 可选字段,下标 = 城池等级 0..3、长度 4);两者任一存在即用新公式。
- 无 per-level 配置时**回退旧公式** `tradePriceOf`(markup/multiply 两型,缺省指导价 ×1.5 保底),等级倍率查 `CITY_LEVEL_MULTIPLIER`(`treasures.ts`,= [2, 3, 4, 5],下标 Lv0..3)。

### 交割托管(escrow):先付款后交货

成交后珍宝不直接到手,先进**交割托管区**(`game.ts` `escrowTreasure`,随快照序列化):

```
成交 → 珍宝入托管 → 买家付款(不够可经破产清算变卖自救)
    ├─ 付清 → 交割 deliverEscrow:珍宝归买家
    └─ 破产 → 退回 returnEscrowToSeller:珍宝归卖家
```

- **托管中不可得宝即卖**:托管珍宝不在买家手中,无法经 `sellTreasureBankruptcy`(`game.ts`)变卖抵债——封堵「得宝即卖」的白嫖套利。
- **破产退回**:买家最终破产,托管珍宝退回卖家;若卖家亦已破产出局,则归入牌堆。

## 银两只在玩家间流转

交涉价款一律 **访客 → 城主** 直接过户,无银行注入、无第三方抽成(`game.ts` `resolveTreasureOwner` 头注);托管只押珍宝、不押钱。
