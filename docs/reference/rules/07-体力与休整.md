# 07 · 体力与休整

体力是全桌可见的攻防状态。袭扰可以压低对方体力，回到己都城、发动名将技或休整都可恢复体力。

## 增减体力

- 开局体力等于上限，现为 100（`constants.ts` 的 `STARTING_STAMINA`／`STAMINA_MAX`）。`authority.ts` 的 `addStamina` 将体力夹在 0 与上限之间。
- 「袭扰」在出牌阶段指定棋盘双向最短距离 3 格内、未休整的一名其他在场诸侯，造成 10 点伤害（`jinnang.ts` 的 `XIRAO_RANGE`／`XIRAO_DAMAGE`）。先结算识破，再扣体力。见[锦囊](./06-锦囊.md)。
- 都城补给恢复已损体力的一半，半点向上取整（`constants.ts` 的 `CAPITAL_STAMINA_RECOVERY_RATE` 与 `movement-flow.ts` 的 `applyResupply`）。正好落在都城与都城必停都可补给。华佗「青囊」恢复自己，「赈济」可为在场诸侯回体。见[都城补给](./04-地产经济.md#都城补给)和[名将与技能](./08-名将与技能.md)。
- 体力浮字按 `staminaChanged` 的实际差值显示，零变化时省略。例如体力剩 6 时受 10 点伤害，只损失 6 点。实际扣体触发 `StaminaLoss`，其技能和待决应答结清后再处理归零一击。
- 实际损耗时，钝击贴体力浮字。实际恢复时，听到一声柔和的上行短音。都城补给有银两到账时，同次回体与银两共用到账声。零变化留给画面。

## 耗竭、外敌乘虚与休整

1. **外敌乘虚**。诸侯体力被打至 0 时，名下各城依次承受等于各自当前防御值的城损。城损继承归零一击的来源，包括已破产的来源。无来源的耗竭保持无来源。每座城的实际城损、降级、攻陷、发银和待决技能都结清后才处理下一座。都城可以打空防御，始终由城主保有。见 `stamina-damage.ts` 的 `damageStamina`／`resolveExhaustion` 和[城池攻陷与奖励](./04-地产经济.md#城池攻陷与奖励)。
2. **卧床休整**。逐城结算完后，耗竭者进入休整，累加两次跳过回合（`constants.ts` 的 `EXHAUSTION_REST_TURNS`），与缓兵之计共用 `skipTurns`。进休整还会触发 `TurnSkipImposed`，例如曹丕的「行殇」可延长休整。若耗竭者是行动者，随后进入回合收尾。若是其他诸侯，全部待决选择及派生效果结清后，行动者从原结算处继续。
3. **期满恢复**。回合推进消费完跳过次数时，清除休整状态并回满体力（`turn-end.ts` 的 `skipTurn`）。中途回体不会提前结束休整。休整时仍领取轮末持城收益，并且不能成为袭扰目标。跳过的座位没有摸牌阶段。

耗竭时先呈现城池变化，城损按最重结果响一次，随后下行闷鼓随休整宣告收口。归零一击的损耗声合在这组结算里。跳过回合和常驻休整状态由画面表现。

耗竭者休整后继续对局。破产规则见[破产清算](./09-破产清算.md)。
