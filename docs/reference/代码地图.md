# 代码地图(各文件职责速查)

> 本文件自 AGENTS.md「关键文件」节外移(2026-10-15):哪个文件管什么,按需查。改玩家可见机制后的文档回填义务(DoD)见 AGENTS.md;模块划分纪律见架构红线 8([ADR-0019](../adr/0019-module-governance-principle.md))。

## packages/core/src/engine/（权威引擎，零 DOM）

- `authority.ts` — 引擎壳:状态/薄委托/命令路由/快照通道(`check-core-purity` 门禁看守,行数与内容禁区见 ADR-0019 壳纪律)
- 机制域模块:`reaction-window.ts` 反应窗 · `jinnang-execution.ts` 锦囊执行 · `stamina-damage.ts` 体力伤害与耗竭 · `movement-flow.ts` 行军、己城摸牌与落格 · `bankruptcy.ts` 破产清算 · `treasure-flow.ts` 珍宝交涉 · `setup-flow.ts` 开局三段式 · `recruitment.ts` 招贤、求书与授技 · `roster.ts` 麾下槽位+授技单点(#785) · `hero-dismiss.ts` 免费主动遣散——槽移除/回池划名/已学技折书(#1147)
- `model.ts` 共享领域模型 · `timing.ts`+`effects.ts` 时机总线与效果注册表 · `choices.ts` 决策选项集(ADR-0013)
- `board.ts`/`board-loader.ts` 棋盘路径与地图契约 · `economy.ts` 经济原语 · `bot.ts` AI
- 数据表(加数据只改这些):`skills.ts` 技能(名将池引用)/ `heroes.ts` 名将 / `treasures.ts` 珍宝 / `jinnang.ts` 锦囊
- `snapshot.ts` 快照序列化 · `constants.ts` 共享常量 · [`theme.ts`](../../packages/core/src/engine/theme.ts) 配色和动效参数
- `game-events.ts` 事件词汇与产出通道 · `event-tiers.ts` 折叠/表现消费档位;`landingResolved` 由 `movement-flow.ts` 在落格决策挂起后产出,最终相位与载荷由 `protocol/event-fold.ts` 直接折叠,行军到达不推演城池规则。

## apps/client/src/app/（瘦客户端，React）

- `main.tsx` 入口 · `store/` zustand(`game` 全局态 / `net` 联机)
- `controllers/` 基类 `controller.ts` + 单机 `local.ts` + 联机 `online.ts` + `registry.ts`(含 `installDebugHooks`)
- `gameLogArchive.ts` 按局归档和对局目录 · `game-diagnostics.ts` 同局现场、时间线与帧诊采集 · `diagExport.ts` 复制摘要与保存文件 · `game-diagnostic-summary.ts` 摘要选取和排版
- `components/board/` 棋盘(Canvas 底板、SVG 触区和等级徽记、动态 HTML 宿主，ADR-0045；board-viewport 统一取景，city-scene 提供城池状态) · `components/card/` 牌面(JinnangCardFace / HeroCardFace / SkillCardFace / TreasureCardFace)与卡面选择按钮壳(SelectableFaceButton,#1188)
- `screens/` home/setup/lobby/game(各屏 `testids.ts` 是测试和单次辅助选择器单源;editor 屏已随 ADR-0048 退役)
- `screens/game/GameScreen.tsx` 编排对局画面与 `rackHidden`（回合、抉择窗、手动开合），把出牌和目标选择接到手牌架、动作条、席位与沙盘。
- `screens/game/jinnang-play.ts` 处理出牌阶段的锦囊和名将主动技，`reaction-play.ts` 处理反应锦囊。两者从权威选项派生可选目标，共用 `target-selection.ts` 管理本步草稿并展示权威已收到的首选。
- `screens/game/HeroInspectionModal.tsx` + `hero-inspection.css` — 人物卷单源：自己与他人的名将检视共用画像签、大幅人物、实授技能内滚与固定遣散；`PileModal`、`SeatAttrModals` 只接入语境，学习选人层另沿现役卡面。
- `screens/manual/ManualTreasuresTab.tsx` + `treasure-rows.css` — 珍宝图文行册与详情：目录与指导价读权威表，画心复用 `components/card/TreasureArt.tsx`，长文自然增高，详情返回保留列表位置。
- `screens/home/MapStrip.tsx` — 首页矮横屏档横排地图条带(#707,MapSelectPanel 的横排替代件):滑动可达全部地图、点选即换图,选图+开局一屏完成零滚动
- `fx/` 骰子/行军/浮字/音效编排 · `net/` 传输/Worker 时钟

## packages/core/src/room/ 与 protocol/（共享房间和协议）

- `room.ts` 房间编排 · `room-record.ts` 房间记录与引擎重建 · `room-persistence.ts` 持久化接口 · `seat-projection.ts` 座位投影和下行装配 · `event-batch.ts` 共享事件批语义 · `bot-driver.ts` bot 和托管驱动 · `watchdogs.ts` 房间看门狗。
- `protocol/wire.ts` 负责传输编解码，`room/player-submissions.ts` 校验提交身份与决策点，`protocol/player-command-outbox.ts` 保存座位尚待回执的指令。
- `protocol/seat-interaction.ts` 管理本座草选和可执行意图，`protocol/seat-replica.ts` 与 `protocol/event-fold.ts` 负责座位摘要恢复和事件更新。安卓和无界面客户端共用。
- `scripts/headless-player.ts` 将共享的玩家接口接入已认证的 WebSocket。真实房间验收见 [headless-player.test.ts](../../test/online/headless-player.test.ts)。

## apps/server/src/（联机服务器）

- `server.ts` HTTP、WebSocket 与服务器编排 · `room-persistence.ts` 文件适配 · `map-files.ts` 磁盘地图 · `extension-loader.ts` 磁盘扩展装载。

## scripts/（仓库工装）

- 开发线有 `cli.ts` 的纯 CLI 对局，以及 `dev.ts` 编排的 Vite 开发入口与 `play` 快照入口。
- 工装:`generate-theme-tokens.ts` 配色生成 · `pr-merge.ts` PR 检查与收口、`pr-merge-checks.ts` 影响域选检、`pr-merge-cleanup.ts` 合入后收账 · `check-freshness.ts` 基线检查 · `check-core-purity.ts` 架构红线 · `check-doc-links.ts` 文档链接 · `rule-docs.ts` 规则生成与检查 · `check-map-docs.ts` 地图对账 · `fetch-asset.ts` 素材登记 · `shot.mjs` 用户明确请求时的截图工具 · `test-lock.ts` 全量测试锁。
- 无头确定性层(#1160 波,ADR-0052~0055):`state-digest.ts` 状态摘要口径单源(规范化哈希+链式战报哈希) · `whole-game.ts` 无头整局驱动单源(driveToEnd 六守卫+人类座缝) · `sim-digest.ts` 单局逐回合摘要导出(`sim:digest`) · `check-goldens.ts` 黄金台账差分门禁(check/update 双模式,台账 test/goldens/) · `sim-bench.ts` bot 基准+历史区间台账(`check:sim-bench`) · `test-corpus.ts` 无头语料单源(图/种子/座位工厂) · `fault-proxy.ts` 故障注入代理(确定性三旋钮 WS 中继) · `online-client.ts` 无头联机协议客户端(wire 单源上行+确定性等待)

## test/(高频主干速查;族目录:接线 `wiring/` · 联机 `online/` · 整局无头 `whole-game/` · 地图 `maps/` · 扩展 `extensions/` · 演出 `presentation/`,其余引擎机制与诊断住根;共享场景与时钟见下;慢例池标记同在各文件头注——`DAFUNG_SLOW=1 bun run test:slow` 才跑,判据口径见 how-to「把测试跑起来」)

- `test/whole-game/invariant-soak.test.ts` — **六不变量 soak**(现金非负/身价非负/位置合法/破产无残留/终局有胜者/锦囊守恒):全 bot 多 seed 秒级几十局,改引擎语义后的第一道绊线
- `reaction-window.test.ts` — 反应窗全回路:识破/拦检/**反识破链**/快照往返 + **`botReactionDecision` 纯决策口径**(助手 makeEngine/setHand/armUser/scriptDice)
- `bot-jinnang.test.ts` — bot **出牌线**策略(botAct/jinnangIntent/Simple 掺骰);⚠️ 反应窗决策不在此文件(名字近,住所在上条)
- `jinnang.test.ts` — 锦囊目录/牌库构建/出牌阶段决策;`choices.test.ts` 选项集
- `game-events.test.ts` + `game-events-vocab.test.ts` — 事件流产出与词汇表;`test/online/event-fold.test.ts` 事件序列→状态折叠契约
- `test/online/wire.test.ts` / `test/online/seat-projection.test.ts` / `test/online/downlink-assembly.test.ts` — 联机协议面守卫(线上形状逐字固定 / redact 档位普查 / per-seat 下行装配)
