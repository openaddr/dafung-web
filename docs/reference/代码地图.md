# 代码地图(各文件职责速查)

> 本文件自 AGENTS.md「关键文件」节外移(2026-10-15):哪个文件管什么,按需查。改玩家可见机制后的文档回填义务(DoD)见 AGENTS.md;模块划分纪律见架构红线 8([ADR-0019](../adr/0019-module-governance-principle.md))。

## core/(权威引擎,全部纯逻辑、零 DOM)

- `authority.ts` — 引擎壳:状态/薄委托/命令路由/快照通道(`check-core-purity` 门禁看守,行数与内容禁区见 ADR-0019 壳纪律)
- 机制域模块:`reaction-window.ts` 反应窗 · `jinnang-execution.ts` 锦囊执行 · `encounter-flow.ts` 机遇+耗竭 · `movement-flow.ts` 行军落格地产 · `bankruptcy.ts` 破产清算 · `treasure-flow.ts` 珍宝交涉 · `setup-flow.ts` 开局三段式 · `recruitment.ts` 招贤 · `roster.ts` 麾下槽位+授技单点(#785) · `hero-dismiss.ts` 免费主动遣散——槽移除/回池划名/已学技折书(#1147)
- `model.ts` 共享领域模型 · `timing.ts`+`effects.ts` 时机总线与效果注册表 · `choices.ts` 决策选项集(ADR-0013)
- `board.ts`/`board-loader.ts` 棋盘路径与地图契约 · `economy.ts` 经济原语 · `bot.ts` AI
- 数据表(加数据只改这些):`skills.ts` 技能(名将池引用)/ `heroes.ts` 名将 / `treasures.ts` 珍宝 / `encounters.ts` 机遇
- `snapshot.ts` 快照序列化 · `constants.ts` 共享常量 · `theme.ts` 配色单源(改后跑 `bun run gen:theme`,不手改 tokens.css)

## app/(瘦客户端,React)

- `main.tsx` 入口 · `store/` zustand(`game` 全局态 / `net` 联机)
- `controllers/` 基类 `controller.ts` + 单机 `local.ts` + 联机 `online.ts` + `registry.ts`(含 `installDebugHooks`)
- `components/board/` 棋盘(静态底板 SVG + 动态 HTML 宿主,ADR-0045;boardHost=矩阵同步单源) · `components/card/` 牌面(JinnangCardFace / HeroCardFace / SkillCardFace / TreasureCardFace)与卡面选择按钮壳(SelectableFaceButton,#1188)
- `screens/` home/setup/lobby/game(各屏 `testids.ts` 是 e2e 选择器单源;editor 屏已随 ADR-0048 退役)
- `screens/home/MapStrip.tsx` — 首页矮横屏档横排地图条带(#707,MapSelectPanel 的横排替代件):滑动可达全部地图、点选即换图,选图+开局一屏完成零滚动
- `fx/` 骰子/行军/浮字/音效编排 · `net/` 事件折叠/传输/Worker 时钟

## scripts/(权威服务与工装)

- 对局线:`server.ts` 权威引擎服务(瘦传输) · `room.ts` 房间编排(零 WS 依赖) · `room-record.ts` 房间记录形状+「记录→引擎」重建单源 · `room-persistence.ts` 落盘适配 · `wire.ts` 协议编解码单源(联机 WS/单机内存双工同一本体) · `seat-projection.ts` 客户端投影+下行装配单口(per-seat redaction 必经) · `event-batch.ts` 事件批下行共享批语义 · `bot-driver.ts` bot/托管驱动(bot 座位步进配速 #730,零 WS/fs) · `watchdogs.ts` 四组同构看门狗(停摆代开托管/自动起摇/反应窗/掉线保留) · `engine-helpers.ts` CLI/Server 共享层
- 开发线:`cli.ts` 纯 CLI 对局 + LLM 演练线(auto/run-to-end) · `dev.ts` 一键开发编排(vite+引擎服务一条命令) · `play.ts` 一键快照游玩(build+起服)
- 工装:`generate-theme-tokens.ts` gen:theme token 生成(theme.ts 单源) · `check-freshness.ts` 开工基线检查 · `check-core-purity.ts` 架构红线门禁(baseline 指纹+壳纪律断言) · `check-doc-links.ts` 文档死链门禁 · `check-map-docs.ts` 地图数值文档对账门禁(tileCount/「N 格 N 城」对账) · `fetch-asset.ts` Wikimedia/三国杀 wiki 抓图登记 · `shot.mjs` 截图自证单源(起服样板勿手写) · `test-lock.ts` 全量测试锁(全量级跑同机互斥:撞锁报错不等待,定向不拦;机制单源在脚本头注)
- 无头确定性层(#1160 波,ADR-0052~0055):`state-digest.ts` 状态摘要口径单源(规范化哈希+链式战报哈希) · `whole-game.ts` 无头整局驱动单源(driveToEnd 六守卫+人类座缝) · `sim-digest.ts` 单局逐回合摘要导出(`sim:digest`) · `check-goldens.ts` 黄金台账差分门禁(check/update 双模式,台账 test/goldens/) · `sim-bench.ts` bot 基准+历史区间台账(`check:sim-bench`) · `test-corpus.ts` 无头语料单源(图/种子/座位工厂) · `fault-proxy.ts` 故障注入代理(确定性三旋钮 WS 中继) · `online-client.ts` 无头联机协议客户端(wire 单源上行+确定性等待)

## test/(高频主干速查;缝约定:助手按文件自持、不跨文件 import,职责细节以各文件头注为准;慢例池标记同在各文件头注——`DAFUNG_SLOW=1 bun run test:slow` 才跑,判据口径见 how-to「把测试跑起来」)

- `invariant-soak.test.ts` — **六不变量 soak**(现金非负/身价非负/位置合法/破产无残留/终局有胜者/锦囊守恒):全 bot 多 seed 秒级几十局,改引擎语义后的第一道绊线
- `reaction-window.test.ts` — 反应窗全回路:识破/拦检/**反识破链**/快照往返 + **`botReactionDecision` 纯决策口径**(助手 makeEngine/setHand/armUser/scriptDice)
- `bot-jinnang.test.ts` — bot **出牌线**策略(botAct/jinnangIntent/Simple 掺骰);⚠️ 反应窗决策不在此文件(名字近,住所在上条)
- `jinnang.test.ts` — 锦囊目录/牌库构建/出牌阶段决策;`choices.test.ts` 选项集
- `game-events.test.ts` + `game-events-vocab.test.ts` — 事件流产出与词汇表;`event-fold.test.ts` 事件序列→状态折叠契约
- `wire.test.ts` / `seat-projection.test.ts` / `downlink-assembly.test.ts` — 联机协议面守卫(线上形状逐字固定 / redact 档位普查 / per-seat 下行装配)

- `game.test.ts` 开局三段式与引擎基本面 · `economy.test.ts` / `bankruptcy.test.ts` / `encounters.test.ts` 各域结算
