# 代码地图(各文件职责速查)

> 本文件自 AGENTS.md「关键文件」节外移(2026-10-15):哪个文件管什么,按需查。改玩家可见机制后的文档回填义务(DoD)见 AGENTS.md;模块划分纪律见架构红线 8([ADR-0019](../adr/0019-module-governance-principle.md))。

## core/(权威引擎,全部纯逻辑、零 DOM)

- `authority.ts` — 引擎壳:状态/薄委托/命令路由/快照通道(`check-core-purity` 门禁看守,行数与内容禁区见 ADR-0019 壳纪律)
- 机制域模块:`reaction-window.ts` 反应窗 · `jinnang-execution.ts` 锦囊执行 · `encounter-flow.ts` 机遇+耗竭 · `movement-flow.ts` 行军落格地产 · `bankruptcy.ts` 破产清算 · `treasure-flow.ts` 珍宝交涉 · `setup-flow.ts` 开局三段式 · `recruitment.ts` 招贤
- `model.ts` 共享领域模型 · `timing.ts`+`effects.ts` 时机总线与效果注册表 · `choices.ts` 决策选项集(ADR-0013)
- `board.ts`/`board-loader.ts` 棋盘路径与地图契约 · `economy.ts` 经济原语 · `bot.ts` AI
- 数据表(加数据只改这些):`heroes.ts` 名将 / `treasures.ts` 珍宝 / `encounters.ts` 机遇
- `snapshot.ts` 快照序列化 · `constants.ts` 共享常量 · `theme.ts` 配色单源(改后跑 `bun run gen:theme`,不手改 tokens.css)

## app/(瘦客户端,React)

- `main.tsx` 入口 · `store/` zustand(`game` 全局态 / `net` 联机)
- `controllers/` 基类 `controller.ts` + 单机 `local.ts` + 联机 `online.ts` + `registry.ts`(含 `installDebugHooks`)
- `components/board/` SVG 棋盘 · `components/card/` 牌面(JinnangCardFace / HeroCardFace / TreasureCardFace)
- `screens/` home/setup/lobby/game/editor(各屏 `testids.ts` 是 e2e 选择器单源)
- `fx/` 骰子/行军/浮字/音效编排 · `net/` 事件折叠/传输/Worker 时钟

## scripts/(权威服务与工装)

- 对局线:`server.ts` 权威引擎服务(瘦传输) · `room.ts` 房间编排(零 WS 依赖) · `room-record.ts` 房间记录形状+「记录→引擎」重建单源 · `room-persistence.ts` 落盘适配 · `wire.ts` 协议编解码单源(联机 WS/单机内存双工同一本体) · `seat-projection.ts` 客户端投影+下行装配单口(per-seat redaction 必经) · `event-batch.ts` 事件批下行共享批语义 · `bot-driver.ts` bot/接管/托管驱动(零 WS/fs) · `watchdogs.ts` 四组同构看门狗(停摆接管/自动起摇/反应窗/掉线保留) · `engine-helpers.ts` CLI/Server 共享层
- 开发线:`cli.ts` 纯 CLI 对局 + LLM 演练线(auto/run-to-end) · `dev.ts` 一键开发编排(vite+引擎服务一条命令) · `play.ts` 一键快照游玩(build+起服)
- 工装:`generate-theme-tokens.ts` gen:theme token 生成(theme.ts 单源) · `check-freshness.ts` 开工基线检查 · `check-core-purity.ts` 架构红线门禁(baseline 指纹+壳纪律断言) · `check-doc-links.ts` 文档死链门禁 · `fetch-asset.ts` Wikimedia/三国杀 wiki 抓图登记 · `make-huanyou-map.ts` 内置地图生成器 · `shot.mjs` 截图自证单源(起服样板勿手写)
