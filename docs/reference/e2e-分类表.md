# 浏览器 e2e 分类表(#1165 审计)

浏览器 e2e(`e2e/*.spec.ts`)逐条分类审计:哪些用例是**浏览器在场的理由成立**的 UI 壳,哪些是**经浏览器绕路断言引擎/协议行为**的逻辑透过 UI。分类判据、删缩依据与落点核对过程见 [ADR-0056](../adr/0056-e2e-slimming.md);验证分层口径(无头层为主力 / 浏览器层为壳冒烟 / AI 浏览器自动化为探索性工具)见[开发与测试](../how-to/开发与测试.md)。

## 分类判据(细则在 ADR-0056,此处速览)

- **UI 壳用例**:断言面 = 布局几何 / 拖拽输入 / 横竖屏形态 / 可见性(锦囊·secrecy·横幅·弹层)/ 交互语义(点选·长按·二段确认·悬停)。浏览器在场的理由成立——无头层不持有 DOM 与演出面,替代不了。
- **逻辑透过 UI**:断言面 = 引擎结算 / 协议行为,只是经浏览器绕路取证。已由无头层(单测 / 无头整局两跑门 / 黄金台账 / bot 基准 / 协议故障注入)覆盖的标「已迁(落点)」;尚未迁移的标「应迁候选」(**只登记不迁移**,另开票处置)。
- 处置只有两种:**整删**(内容全为已迁逻辑且无 UI 壳价值)、**缩**(同 spec 内删已迁用例留壳用例)。拿不准一律归「留」,不硬删。

## 总账

- spec 文件 40 个,#1165 本票后**整删 0 个文件、缩删 3 个用例**(审计基线 131 → 128);#1181 迁移波再**整删 3 个用例**(超时兜底/超时代发/断线座位,见 reaction 两行);#1181 棒一全量重筛(2026-11-07)**整删 2 个重复例**(react-layout「席位格字段」/react-solo「席位格同步」,均被 react-seat-cells ① 投影逐席一致面覆盖)、**缩 5 例**已迁断言(交涉/破产/珍宝城购地/体力/扩展招贤,删已迁结算面留接线与可见性壳)→ 现 125。菜单A(2026-11-07,效率清退接续)**整删 1 + 缩 1 + 挪慢池 5**:整删 react-seat-cells「旧席位卡形态退役核销」(纯零残留核销断言)、缩 react-layout「浮层件可见」例(删 13 项退役容器零残留段留骨架哨兵)、5 个 40s+ 贵例挪慢池(board 城池等级珠/ambient-align 氛围对位/diag-export 诊断包/encounters 机遇卷轴/abort 作废面板)——理由一句话:核销例价值衰减;40s+ 贵例移出日常触碰面(快池门禁 --grep-invert @slow)。用例总数会随开发漂移,本文不追踪总数,只追踪分类与处置。
- 每例的引擎语义面若无头层已覆盖,表中「已迁落点」列给出;应迁候选(无头层暂无落点)单独登记于文末,本票一律不动。#1181 棒一重筛结论:**零新增应迁候选**——40 文件逐例问「按今天的无头覆盖面还剩什么无头层给不了」,全部存留例都能答出独占壳面(几何哨兵/可见性/交互接线/浏览器侧装载),登记节保持销账状态。
