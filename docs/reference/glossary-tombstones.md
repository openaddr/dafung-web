# 退役名词志(glossary-tombstones)

退役词条与弃用名墓碑一行式收殓:名→退役票/ADR+avoid 名单;GLOSSARY 主件只留现役词(定名+卫词),票号/ADR 即考古线索。

**环游图**(#948,随 ADR-0048 地图系统瘦身整图退役):_Avoid_: 环游图、闭环图、环形图、默认图(已废)
**自建地图(Custom Map)**(#947,随 ADR-0048 整体退役):_Avoid_: 自建地图、自定义地图、编辑器地图(已废)
**州名(Region)**(#828,随 #823 区域单源化退役):_Avoid_: 区域→区域分组、地域(已废)
**功能格**(#826,正典=特殊城池/全城池制):_Avoid_: 功能格、特殊格(已废)
**手势栈(.bv-stack,ADR-0045)**(#946 退役,ADR-0048):_Avoid_: 双板双写(已废)
**默认行为(Default action)**(词条现役,墓碑行移此):_Avoid_: fallback choice(已废)
**定制问询(Custom Inquiry,#424,ADR-0022)**(#1065 整线退役):_Avoid_: 定制问询、Custom Inquiry、自定义问询、自定义弹窗(已废)
**命令流重放(Command Replay)**(已随 ADR-0021 退役,术语仅存档):_Avoid_: 读叙述推理(已废)
**都城补给(Resupply)**(词条现役,墓碑行移此):_Avoid_: 驻跸费、补给系数、沃野、边陲(已废)
**珍宝城**(词条现役,墓碑行移此;宝物城旧名 #825 起只此一典):_Avoid_: 宝物城、宝物商店、探宝格、宝物格(已废)
**锦囊格**(#826,正典=锦囊城 `event:"jinnang"`):_Avoid_: 锦囊格、机会格、幸运格(已废)
**随机事件格**(随辅路机制整体移除,ADR-0023):_Avoid_: 随机事件格、锦囊事件(已废)
**中伏**(随辅路机制整体移除,ADR-0023):_Avoid_: 中伏(已废)
**降噪口(Reaction Mute,「本回合不再询问」)**(词条现役,墓碑行移此):_Avoid_: 暂定无懈、免打扰(已废)
**单人格弹层(Seat Pop,#701)**(#1097 退役,#1096 决议1):_Avoid_: 席位详情窗、个人面板、托管钮、格 tap 开详情(已废)
**巡幸得状(WarrantGained)**(已废,2026-11-01):_Avoid_: 过起点领钱、俸禄、委任状、巡幸得状(已废)
