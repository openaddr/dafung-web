# 退役名词志(glossary-tombstones)

退役词条与仅存于历史档案(ADR/DESIGN/research/dogfood)的弃用名墓碑收殓于此;GLOSSARY 主件只留现役词(定名+卫词),ADR 编号即线索。以下条目按 GLOSSARY 原顺序整段搬迁,文本未改写。

## 收殓条目(按 GLOSSARY 原序;注「词条现役,墓碑行移此」者为现役词条的弃用名墓碑行,词条本体仍在 GLOSSARY)

**环游图**(已废,#948):
内置地图之一(`public/maps/huanyou.json`,#938 起让位首项)。主环为 9×4 满格螺旋环(#827):外环先环游边境一周再盘旋入中原腹地。随地图系统瘦身(ADR-0048)整图退役——文件与生成器删除、测试钉谱全量重钉关中图;内置图余两张:关中图(默认)/中原争霸(速战)。
_Avoid_: 环游图(已废,勿再用)、闭环图(语义过泛)、环形图(与几何术语混淆)、默认图(默认图是关中图)

**自建地图(Custom Map)**(已废,#947):
玩家曾用编辑器创建或从文件导入、存储在浏览器 `localStorage` 的地图,曾在「选择地图」里与内置地图并列可选。编辑器与 localStorage 图库通路已随地图系统瘦身(ADR-0048)整体退役——地图扩展改走「PR 一个 JSON」进内置清单(通路见[自制地图](../how-to/自制地图.md))。
_Avoid_: 自建地图(已废,勿再用)、自定义地图(语义模糊)、编辑器地图(工具名而非产物名)

**州名(Region)**(已废,#828):
城池旧自由文本地域字段(幽州/并州一类),曾显示于城池详情;随 #823 区域单源化退役——区名唯一源 = 区域分组 `groupNames`(详情/购地卷轴地域行出口),字段已从地图 schema 与 UI 摘除。
_Avoid_: 区域(泛称;单说「区域」优先指区域分组)、地域

**功能格**(已废,#826):
旧棋盘的不可购买格子族——招贤/锦囊/天命/缴税/行情五种格型(`board.ts` `TileType` 旧成员,行为随格型承载、不可购买)。特殊城池制([ADR-0037])落地后由「城池 + event 字段」替代;格型全权退役已随 #826 收口:TileType 收口到唯一值、分流通路删除、环游图七格原地转城(缴税格转普通县城,机制不再放)。
_Avoid_: 功能格(已废,勿再用;正典是「特殊城池」/「全城池制」)、特殊格(已废,勿再用)

**手势栈(.bv-stack,ADR-0045)**:
~~手势进行中的公共 transform 宿主:增量写栈、提交拍一次性写回 viewBox~~ **#946 退役(ADR-0048)**:平移缩放全形态退役后取景恒 computeFitView 总览定格,无手势增量亦无提交拍,栈随手势通路一并删除;ADR-0042 宿主矩阵同步只剩挂载/尺寸/换图/字体事件拍。
_Avoid_: 双板双写(ADR-0040 顶板已随本栈退役)

**默认行为(Default action)**(词条现役,墓碑行移此):
_Avoid_: fallback choice(不是兜底,是产品决策)

**定制问询(Custom Inquiry,#424,ADR-0022)**:
~~扩展交互 handler 在既有决策相位之外发起的问询(askInquiry/AwaitingInquiry 相位/resolveInquiry 命令全链)~~ **#1065 整线退役**:对局里不再存在问询相位,任何包/内置内容都无法发起定制问询——choices 通路(ADR-0013)是唯一问询通路,问询一律走各决策相位的注册计算器。
_Avoid_: 定制问询/Custom Inquiry(整线退役,#1065)、自定义问询(ADR-0022 行文旧用词)、自定义弹窗(问询呈现归通用卷轴,不存在扩展自定弹窗面)

**命令流重放(Command Replay)**:
以 seed+座位+玩家命令序列重建确定性引擎的复现方式。已随 ADR-0021 退役,术语仅存档(cmd 行保留为审计归档)。_Avoid_: 读叙述推理(精度不足)

**都城补给(Resupply)**(词条现役,墓碑行移此):
_Avoid_: 驻跸费、补给系数(旧 per-level 概念)、沃野/边陲(旧地域补给档)

**珍宝城**(词条现役,墓碑行移此):
_Avoid_: 宝物城(旧名,已废,#825 起只此一典)、宝物商店、探宝格(旧口径「不可购买、落格直探」下的俗称)、宝物格

**锦囊格**(已废,#826):
落格即从牌库抽一张锦囊的旧功能格(旧「机会格」语义复活重定义;格型已随 #826 退役,正典承载是「**锦囊城**」(`event:"jinnang"`),抽牌实现单源共用)。与机遇区分:锦囊城必得一张;机遇是落格必出一条(见「机遇必出」),两者皆为确定事件,差别只在「得牌 vs 出事件」。
_Avoid_: 锦囊格(已废,勿再用)、机会格(旧名)、幸运格

**随机事件格**:
原指辅路 event 格,落格触发随机小事件;已随辅路机制整体移除(ADR-0023),格型与术语一并退役。
_Avoid_: 随机事件格(已退役,勿再用)、锦囊事件(与锦囊系统混淆)

**中伏**:
原指辅路 penalty 格效果(踩中下回合跳过);已随辅路机制整体移除(ADR-0023)。跳过回合的机制由 `skipTurns` 承接(耗竭善后/缓兵之计共用),对局日志归 `system` 类「按兵不动」。
_Avoid_: 中伏(已退役,勿再用)

**降噪口(Reaction Mute,「本回合不再询问」)**(词条现役,墓碑行移此):
_Avoid_: 暂定无懈(别家游戏借称)、免打扰(口语)

**单人格弹层(Seat Pop,#701;#1097 退役)**:
席位格 tap 开的单人纵深弹层,已随 #1096 决议1 整体退役(组件 SeatPopModal 与 seat-pop.css 删除)——格面纯展示化后此层不复存在。生前形制(存档):ui/dialog 壳,头=国号印+国号+现金章,体力/声望数值行,城池/手牌/名将/珍宝四徽章(城池/名将可钻入),仅自机格带托管开关行。接替去向:**查档**=诸侯详情四钻入(城池 chips/名将 chips/珍宝槽/声列,金描边+尾「›」),**托管开关**=设置弹层「托管」行(同一 ADR-0028 引擎通路)。
_Avoid_: 席位详情窗、个人面板(旧右栏语义)、托管钮(旧仪表条按钮形态,已退役——开关只在设置弹层)、格 tap 开详情(旧通路,随本词条退役)

**巡幸得状(WarrantGained)**(已废,2026-11-01):
委任状(买城额度属性)整建退役,本时机随之删除;买城改纯现金门槛,途经己都城仍必停+补给(见「都城补给」)。
_Avoid_: 过起点领钱(Monopoly 直觉,本作无此物)、俸禄、委任状、巡幸得状(以上均已退役)
