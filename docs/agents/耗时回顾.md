## 方法要点

1. **口径先行**:只计「轮内时间」(turn.started→completed),用户离席(轮与轮之间的大 gap)剔除——那是节奏问题不是耗时问题。
2. **归因三分**:轮内 = 子代理墙钟 + 主线模型时间 + 等待(gap 里对得上 e2e/build 的)。主线模型时间从 rollout `durationMs` 求和;等待从长 Bash(`tool.call.completed` 且 `toolName=Bash`、`durationMs≥60s`)逐条认领。
3. **并行要遮盖算**:T2∥T3 时 wall 只算 max(T2,T3);并行省下的 = 被遮盖代理的墙钟。
4. **排行榜按 wall 占比排**,每个大户追问一层「它的内部时间去哪了」(代理墙钟 175min 里模型仅 65min,56% 是内部 bash——build/e2e/截图)——对策才打得准。
5. **master 对照实验**:怀疑 diff 引入的 flake,在 master 跑一次同负载全量定性(一次 6min,买断「是不是我搞坏的」的全部争论)。

## 物理成本基线(probe:cost;#1222 起常驻)

测试耗时讨论先跑 `bun run probe:cost`(scripts/cost-probe.ts)拿数,禁拍脑袋。形制:dist 预览 + 844×390 DPR3 真机档 + swiftshader + e2e fixtures 同款五键注入(倍率 0.25 / bot 配速 0),量「挂载链(goto→__dafung 桥可用)→ seedSolo 种局 → 首掷行军链(waitMyRollDone+waitSettled)」三段 + 最慢资源 TOP6;最慢资源 TOP6 恒为字体 woff2 族(冷 context 每只 ~0.5-0.8s、20-90KB)——首屏文本渲染的物理大头。

历史定版(2026-11-08,#1277 启动打点同形制 A/B):全链 2750→**2684ms**——seedSolo **221→46ms**(引擎构造仅 ~8ms)/ 挂载 DCL 146→117ms(fonts 出阻塞)/ 823KB 单包首执行编译税 ~140ms(对局屏懒化后移出窗口,最大 chunk 208.5KB)/ 首包 JS+CSS 999→802KB(-19.7%,未达 -25%:弹层原语被主页/设置屏消费)。构造器到站例地板 ~1.6-2.1s(瞬空形制:残余=seedSolo 开局链+300ms 沉降窗+构造器态演出排空;#1272 负结果——驱动循环轮询税精确归零后墙钟持平,演出排空才是关键路径)。历版标定靠 git 考古。
