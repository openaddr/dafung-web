# 测试成本当前快照

测试取舍单源为 [ADR-0065](../adr/0065-test-economics-browser-retirement.md),运行入口见[开发与测试](../how-to/开发与测试.md)。历史执行轮与旧浏览器池标定交 git 考古,不以旧基线要求浏览器验收。

## 当前反馈路径

- 开发迭代只执行受影响的无浏览器单文件/单族。
- 完整 Bun 默认池与 build 留最终收口一次;新失败或新代码影响才补验。
- 浏览器常驻池与自动门槛已删除,单次辅助仅用户明确要求时执行。
- 完整整局语料、协议故障、持久化恢复与 CLI 元测试只在对应能力改动时定向执行。

## 最近实测的适用范围

本轮关键接线定向墙钟 4.86s。完成删减后的默认池与最终门槛实测见 [PR #1442](https://github.com/openaddr/dafung-web/pull/1442);PR 保留原始失败、修复与最终结果,本页不重复维护用例数。删减前后的覆盖范围不同,墙钟差值只说明反馈成本变化,不宣称等量覆盖提速。

## 判读

优先删除重复断言、等待与失效设施,不为快照补同量用例。规则直接期望、独立双端与关键命令保留;真实视觉和设备体验由用户在 APK 中验收。正式覆盖与死代码体检遵各自低频技能,不为日常性能归因重复执行。
