# 分诊标签

本仓使用技能默认标签，按下表原样填写：

| 标签              | 含义                   |
| ----------------- | ---------------------- |
| `needs-triage`    | 等待维护者评估         |
| `needs-info`      | 等待报告者补充信息     |
| `ready-for-agent` | 规格完整，可交代理实施 |
| `ready-for-human` | 需要人工实施           |
| `wontfix`         | 不予处理               |
