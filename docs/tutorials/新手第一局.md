# 新手第一局

这局先练三件事。挑一座都城，买下一座普通城，再试着用手里的锦囊。

## 起兵

1. 安装[安卓客户端](../../README.md#下载)，打开「群雄逐鹿」，点「单机模式」。
2. 在准备页把目标身价选为「速战」。想多练几个自己的回合，可以先减少诸侯数。
3. 在右侧填一个国号，或打开「字盘」选字，再点「起兵」。

## 选都

等棋盘提示轮到你，再点一座亮金圈的候选城。先看建城费和确认后的余额。想多留些银两买城，可以挑费用较低的一座。点「定都于此」确认，也可点「再想想」比较另一座。

## 买下第一座城

轮到你时，若手牌区进入出牌阶段，可以先点「不出」，等棋子自动行军。落到无主城时，比较卷轴里的购入价和每轮收益，再点「购地」。先记住这座城的位置，后来走到自家城时试试扩军。

如果第一把没落到无主城，处理当前卷轴的选项，下一次再找买城机会。可按[落格结算](../reference/rules/03-回合与行军.md#落格结算总表)查当下遇到的城。

## 试一张锦囊

下一次轮到你时，点一张亮边的牌读全文。拿到「火烧连营」时，可先看一座敌城名下的等级徽记和蓝盾，再跟着动作条选目标并出牌。对手的行动打开反应窗时，横幅会提示当前可以应对的招数。按钮和用牌细节见[出牌阶段](../reference/rules/06-锦囊.md#出牌阶段)和[反应窗](../reference/rules/06-锦囊.md#反应窗)。

## 继续打到终局

观察席位格上的现金和体力。差一点到目标时，先从现有城池和手牌里找能进银的行动。想了解交易、破产或胜负判定，可查[规则手册](../reference/rules/README.md)。

第一次看到终榜，可以点「再战一局」，或先[保存本局诊断](../reference/对局日志.md#单局诊断文件)。想改和朋友一起玩，按[联机对战](../how-to/联机对战.md)建房。
