# Android 适配

安装包内的 Activity 按传感器横屏，方便玩家换手后仍看到正确方向。原生设置在 [AndroidManifest.xml](../../apps/client/src-tauri/gen/android/app/src/main/AndroidManifest.xml)的 `MainActivity`。重建 Android 工程时，从这里核对方向配置。

[客户端入口](../../apps/client/index.html)声明 `viewport-fit=cover`。[应用样式](../../apps/client/src/app/styles/app.css)集中管理安全区、WebView 可见高度和减少动效偏好。贴边控件使用同一套安全区变量，系统软键盘出现时可继续按实际可用高度布局。字体从[本地字体定义](../../apps/client/public/fonts/fonts.css)加载。

触屏细则见[视觉与交互](../design/DESIGN.md)，真机验收流程见[开发与测试](../how-to/开发与测试.md#apk-设备冒烟)。
