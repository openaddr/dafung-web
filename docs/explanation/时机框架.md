# 时机框架

时机让技能挂在一个有名字的结算点上。新增同类技能时可以复用原有派发契约，行军、交易和回合推进各自维护自己的结算顺序。时机的主体座位和可用上下文由[时机注册表](../../packages/core/src/engine/timing.ts)的 `GameMoment`、`MOMENTS` 和 `MomentCtx` 定义。

## 一次结算如何续接

[时机派发](../../packages/core/src/engine/moment-stages.ts)会先排定技能顺序。「你可」需要玩家应答时，`PendingMoment` 保存当前上下文、下一项技能和可序列化的续接操作。应答后由 `resumePendingMoment` 继续同一个时机，再回到城损、回合收尾等原先的结算点。重连时保留进度，派发的先后仍由权威引擎决定。

把阶段放在时机里面，使同一个已发生的事实足以驱动其所有阶段。例如「得银」的各阶段都从到账后的状态读取余额。阶段顺序和文案约定见 [ADR-0068](../adr/0068-moment-stages.md)。

## 规则、效果与演出

[技能表](../../packages/core/src/engine/skills.ts)声明技能何时触发，[效果注册表](../../packages/core/src/engine/effects.ts)决定触发后怎样改状态。供玩家观看的对局事件由[事件定义](../../packages/core/src/engine/game-events.ts)登记，客户端用来折叠状态和播放演出。区分时机与事件后，画面播放速度和网络恢复都不会重新触发技能。

具体的时机主体、冷却与派发口径见[名将与技能](../reference/rules/08-名将与技能.md#冷却与派发)。计数见[回合与轮次](../reference/rules/03-回合与行军.md#回合结束与轮次)。实现步骤见[扩将指南](../how-to/扩将指南.md#新增技能)。
