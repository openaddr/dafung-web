# 锦囊设计

## 1. 定位与设计红线

锦囊是对局中的暗置手牌。常用牌造成小到中等影响，让玩家根据眼前的体力、城防和手牌决定是否出手。名将获取和更换成本更高，承担影响较大的技能。规则与数值见[锦囊规则](../reference/rules/06-锦囊.md)，攻防与供给决策见 [ADR-0071](../adr/0071-city-combat-cards-and-hero-progression.md)。

## 补给与持城

起手牌让每位诸侯在首次行动前就有底牌。实际回合自动摸牌，为先出牌还是先留牌提供持续选择。己城摸牌把补给与持城、路线和实际位置连起来，各地图共用牌库。弃牌洗回让公开出过的牌有机会再次出现，「缓兵之计」在整副牌中仍只有一张。

## 出牌与反应

锦囊要在用不用、何时用、对谁用中至少提供一项真实权衡。出牌阶段把锦囊、主动技与可研读技能书放在同一手牌区，选择结清后再掷骰。功能标签供效果引用，可连续使用满足条件的同标签牌。

「袭扰」将站位和体力带进攻防。范围和休整限制给防守方留出走位空间，识破可以应答攻击，返回都城则可补体力。「火烧连营」直接威胁一片城池，可按受击城拆招。拦检与识破的结算入口见[反应窗](../reference/rules/06-锦囊.md#反应窗他人的结算点你的出手时机281)。

## 公开信息

诸侯能看见他人的手牌数、出牌声明和结算。普通摸牌只公开张数。军情密探生效时，仅窥探方能查看牌面。逐座位投影见 [ADR-0016](../adr/0016-per-seat-snapshot-redaction.md) 和[联机架构](./联机架构.md)。
