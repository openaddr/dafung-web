# 锦囊系统规格(设计定稿,已实装:#143/#151)

来源:#122 + 2026-09-09 拷问会(四轮,全部分歧已收敛)。术语已登记 CONTEXT.md「锦囊与暗牌」节;暗牌的联机协议决策另见 ADR-0016(per-seat 快照投影)。

> **规则细节的唯一事实源:[`06-锦囊.md`](../reference/rules/06-锦囊.md)**——五条渠道、牌库构成、八牌目录、使用流程、免战/窥探时窗、bot 策略均已实装,该页与代码逐符号核对。本页只留设计叙事:红线、目标手感、为什么这么设计;凡规则细节以该页为准,不再复述。

## 1. 定位与设计红线

- **中频暗牌博弈系统**,对局**基本机制,无开关**(单机/联机默认 always on,不做配置文件/起兵屏开关/房主选项)。
- 全游戏**唯一的隐藏信息**:持有暗置,使用与结算公开。
- **红线:拿到即用、无需思考的牌不配当锦囊**——那类效果属于机遇。每张锦囊必须在「用不用/对谁用/这回合用哪张」中至少一问上有真实权衡。
- 演出补注:出牌/拼点的印章与双骰 3D 演出未接(浮字+战报已承载公开信息),留 polish 票;「此计暂未启用」灰置路径保留为新增 effect.kind 的落地护栏(目录 ⊆ LIVE 有运行时守卫)。

## 2. 频率与获取:渠道设计

五条渠道的触发规则与代码位置见 [`06-锦囊.md`](../reference/rules/06-锦囊.md)「获取:五条渠道」。设计要点:

- **渠道分层**:起手发牌是保底(开局即感知系统存在);锦囊格与声望献计是双主渠道——一个绑地图探索,一个焊住声望循环(只认向上穿越,刷不出来);机遇「圯上授书」与辅路「军师来投」是佐料,搭既有事件便车,不构成可刷目标。军师来投与其余随机事件**等概率**抽中(事件池无权重字段;原稿「低权重」为设计期措辞,#147 落地为均一)。
- **锦囊格数随地图**:sanguo 2/40、默认图 chessboard 3 格、zhongyuan 0——格数是地图参数,不进规则;sanguo 格位避开开局热区。
- **目标手感**:人均每局经手 3~5 张。牌库抽空后一切抽牌**落空**(浮字「锦囊已空」),不报错不回流——稀缺是设计态:耗尽可感知、不可补救。

## 3. 牌库与手牌:稀缺与公开信息

牌库构成、手牌上限、剩余数公开见 [`06-锦囊.md`](../reference/rules/06-锦囊.md)「牌库与手牌」。设计要点:

- **缓兵之计全场唯一(×1)是刻意埋设的公开信息**:「谁打出过、牌库还剩没有」人人可推——小牌库里的一条确定性公共地标;其余 7 种 ×2 保证单牌见面频率。
- 牌库 15 张偏小是手感参数:抽空可发生,落空浮字是正常反馈而非异常路径。
- 口径修订存档:「破产清空入弃牌堆」已实装(#198,`finalizeBankruptcy` + 守恒单测),规则见 06-锦囊「数值口径」。

## 4. 目录终稿:设计要点

八牌数值/文案以 `jinnang.ts` `JINNANG_CARDS` 为唯一事实源,完整目录表见 [`06-锦囊.md`](../reference/rules/06-锦囊.md)「八牌目录」。设计要点:

- **三类目标域的灰置语义各不相同**(实装口径):two-others 域(连环计)在卡牌段即整卡灰置「对手不足」;one 域(密探/缓兵/窃玉/火烧)卡牌段可选、目标段全灰只能「作罢」;all-others(横征暴敛)无目标段,免战/破产者跳过、无人缴纳时照常消耗。原稿「对手 <N 不可用」只对连环计按卡牌段灰置完整实现。
- **免战金牌设计变更存档**(2026-09-10):原「免租金」→「免战=不可被锦囊指定」——引擎本不收租,按等义落地;只挡锦囊,机遇/天命/缴税照常。
- 数值口径(玩家间转移上限=付款方现金、不触发清算;锦囊不计身价)复用机遇 siphon/levy 既有口径,细则见 06-锦囊「数值口径」。

## 5. 使用流程:设计要点

相位机、选项集、目标段与命令校验见 [`06-锦囊.md`](../reference/rules/06-锦囊.md)「使用:回合开始、掷骰前」。设计要点:

- **用牌决定先于掷骰**:新决策相位 `AwaitingJinnang` 挂在回合开始、掷骰前——先结清「用不用/对谁用/这回合用哪张」三问,再掷骰走格子;与机遇(落格触发)天然分层,不抢戏。
- **零可用静默跳过**:无牌可用的回合不弹卷轴(选项集 ≤1 不打扰);只要有一张可选,卷轴必弹且「今不用」永远在场——不强迫、不隐瞒。
- **标签名额制的两个自然推论**:缓兵之计〔谋+攻〕一张占两席;用后重算卡牌段——同回合仍有异类标签可用牌则卷轴再开(2026-09-10 实现口径)。
- **选人可反悔**:目标段可「作罢」(保留牌,收卷);连环计两步选人(A 段全员→B 段排除 A)。
- **公开信息最小集**:出牌是公开事件(浮字+战报),结算全员可见;只有持有暗置。
- `GameCommand` 新变体 `useJinnang`(cardId + targets),相位/持有/标签名额/目标合法性由引擎校验——UI 永不裁决(ADR-0013 同则)。
- **#188 档 3 扩展**:此窗扩为**军师幕**(锦囊 + 名士主动技统一决策窗,窗口正名、testid 沿用),机制细则见 [`../reference/rules/08-名士与技能.md`](../reference/rules/08-名士与技能.md);本篇其余内容为锦囊系统自身的定稿叙事,不受影响。

## 6. 暗牌协议(ADR-0016)

引擎快照仍是 god-view(单一事实);可见性由传输层 `clientView` 的 **per-seat 投影**裁剪:他人手牌→数量、私有载荷(抽牌结果/窥探)只发本人、含手牌内容的 choices 只留 decisionOwner。**对局日志不落手牌内容**(只记「抽了一张锦囊」——抽牌 dice 驱动可重放推导,日志本身可安全外发)。单机引擎在本机不设防,UI 只渲染自己的手牌(bot 手牌同样隐藏,军情密探在单机因此同样有用)。

## 7. UI / 演出 / 契约

- 侧栏:己方牌面(牌名/单字标签方章/文案);他人座位「锦囊 ×n」牌背计数——复用 note-head 单字印章视觉,标签方章同款。
- 锦囊卷轴:ScrollShell 挂轴复用,牌选项 = note-card 列表 + 标签方章;目标段列国号方章候选(testid 见本节单源清单)。
- 演出:全部走既有 PresentationEvent——出牌 `sealStamped`(牌名首字方章)+ `textFloat`;拼点 `diceRolled` ×2;转移 `cashDelta`。不新增事件类型。
- testids(入 SCROLL_TESTIDS/TESTIDS 单源):`scroll-jinnang`、`scroll-jinnang-option-*`、`scroll-jinnang-target-*`、`scroll-jinnang-pass`(今不用)、`scroll-jinnang-cancel`(作罢)、他人计数 `jinnang-count-<seat>`。既有 testids 零改动。

## 8. bot / 看门狗 / 托管

- `INPUT_PHASES` 增 `AwaitingJinnang` → driveBots/托管/看门狗自动覆盖,room.ts 无需新机制。
- bot 策略(EV 贪心,先过选项集同口径,细则见 06-锦囊「bot 与看门狗」):横征暴敛=可用即用;连环计=选现金最高的两人相咬,次富者现金 ≥400 才值得;窃玉=目标珍宝最多者;火烧=城最多的领先者;缓兵=仅当目标当前身价领先;密探=自己手牌 ≥2 时用(bot 拿信息无用,基本留给玩家);免战=现金低于全体玩家现金**中位数**时用(原表「房租均值」——引擎无房租,#148 改中位数);求贤=可用即用;Simple 难度 50% 弃权。
- **看门狗接管:永不主动用牌**(一律「今不用」,保守推进);托管按上表(玩家自愿交出)。

## 9. 重放与持久化

- 抽牌/拼点全走 `this.dice` → 命令流重放天然复现;`useJinnang` 是普通 cmd 行。
- 快照新增字段:牌库/弃牌堆/各座手牌(cardId 数组)、`jinnangShield`(免战旗)、窥探状态(viewer/target/到期回合)、声望已领里程碑(`repMilestones`)。`restoreFromSnapshot` 全量还原;房间持久化/重启恢复自动携带(随快照走,room.ts 零改动)。

## 10. e2e 方案

- 无配置开关 → 既有用例兼容靠共享助手:`actIfCan` 学会 `scroll-jinnang`(默认点 `scroll-jinnang-pass`)。
- 专项 spec(固定 seed):起手有牌→卷轴弹出→连环计两步选人→拼点演出→银两转移断言;引擎配置 fail-fast 照 `window.__dafung.getEngine()` 惯例;声望献计/军师来投单测覆盖为主,e2e 只做冒烟。
