# 锦囊设计

## 定位与设计红线

每张牌至少要让玩家在「用不用」「何时用」「对谁用」中权衡一次。常用牌承担小到中等影响，变更较大的能力通常留给获取和更换成本更高的名将。现行牌面见[锦囊目录](../reference/rules/06-锦囊.md#锦囊目录)。首版牌库规模和评估人数见 [ADR-0074](../adr/0074-six-seat-standard-and-eight-seat-capacity.md)。

## 补给与持城

起手牌让先行动和后行动的玩家都能较早作选择。己城补给给路线与经营多一层价值。弃牌回流也让读过战报的玩家仍要权衡对手可能持有什么。各来源和时点见[摸牌规则](../reference/rules/06-锦囊.md#摸牌)。

## 出牌与反应

「袭扰」使棋子之间的位置有攻防意义。「火烧连营」让单个反应可以保住一座重要的城，其他目标仍需要玩家自己应对。反应等待只对能改变结果的持牌座位打开，暗牌通过逐座位投影发送。[反应窗](../reference/rules/06-锦囊.md#反应窗) · [城池与体力设计决策](../adr/0071-city-combat-cards-and-hero-progression.md)
