# 城池经济:购价恒定与三条等级曲线

> 一句话:**城是产钱机器,不是升值资产**——购买价与城池等级完全脱钩;等级驱动变卖价、坐地起价、都城补给三条独立曲线;升级免费,但只奖励公道买卖。

本文讲「关系」:购价、等级与三条收益曲线如何互相咬合。各曲线自身的数值口径见规则手册对应页(数值以代码为准,本文不复制数值)。

## 总览:一次购买,三份长期收益

- **购买价 = 固定入场费**:落到无主城支付购价 + 1 张委任状,入手必为 Lv.0(`economy.ts` `buy`)。价格不随任何等级变化——不存在「买几级的城」,等级是买下之后长出来的。
- **等级 = 持有期收益放大器**:Lv.0..maxLevel(上限由地图 `maxLevel` 逐图必配,内置图均为 3 即共 4 级;`economy.ts` `PropertyDef`),升级免费,同一等级同时抬升三条曲线。
- 等级是**持有期**属性:城回无主后再被购买,又是全新 Lv.0(`economy.ts` `buy` 落 `level: 0`)。

| 曲线         | 公式                                      | 作用域                          | 口径详见                                         |
| ------------ | ----------------------------------------- | ------------------------------- | ------------------------------------------------ |
| 变卖价       | 地图 `valueByLevel[level]` 查表           | 全部持有城(都城除外:永不可变卖) | [04-地产经济](../reference/rules/04-地产经济.md) |
| 坐地起价要价 | 指导价 × `tradeMult[Lv]` + `tradeAdd[Lv]` | 全部有主城(他人落城交涉时)      | [05-珍宝](../reference/rules/05-珍宝.md)         |
| 都城补给     | `resupplyPerLevel × (Lv+1)`               | 仅自己的都城                    | [04-地产经济](../reference/rules/04-地产经济.md) |

## 升级怎么来:免费扩军 + 公道买卖

两条升级路、一条降级路(等级变更留痕见 ADR-0015,降级时机 `PropertyDemolished`):

- **免费扩军**:自己到达己城,零花费零委任状 +1 级(`economy.ts` `upgrade`)。
- **公道买卖成交 +1 级**:城主对访客选择公道买卖(按指导价出售)且成交,城池 +1 级、满级封顶(`treasure-flow.ts` `resolveTreasureOwner`);买家破产退宝不回滚。
- **坐地起价不升级**:同一交涉里城主若选坐地起价(溢价出售),城池不涨——**公道换成长,还是溢价换现银,是城主的核心取舍**。
- **降级**:火烧连营、体力耗竭「降 1 级」处置——三条曲线随等级一齐下移。

## 设计意图:两条曲线的不对称

- **变卖曲线围绕购价、温和**:Lv.0 变卖远低于购价(破产变卖贵城是割肉),满级也只略超购价——折算系数由守卫测试锁定(`test/map-economy-guard.test.ts`)。
- **坐地起价曲线陡峭**:Lv.0 即显著溢价起步,满级放大数倍且外加逐档递增的固定加值——**等级的真正回报在「向访客卖宝」,不在「卖城」**。两套内置形态:普通城「乘数递进 + 逐档加值」,乘法城「纯乘数、加值恒零」,逐城档位同样由守卫测试锁定。
- 与**身价 = 仅现金**口径一致:三条曲线全是现金流概念(补给流入 / 交涉流入 / 变卖回流),城的账面价值从不进身价。
- 购价恒定的另一面:**买城是纯一次性决策**,委任状额度才是扩张的真实闸门(`constants.ts` `BUY_WARRANT_COST`);等级成长把「买得早」变成「收得久」。
