# 城池经济

## 买城的现金流

买城把手头现金换成长线收入。持有期间还可以借城池交易，受攻时则要考虑后续银两损失和失去城池的风险。早买城能早收银，接近称帝时多一笔支出就可能把胜利往后推。参见[持城收益](../reference/rules/04-地产经济.md#持城收益)和[胜利条件](../reference/rules/01-总览与胜利.md#胜利条件)。

## 选择城档与成长路线

不同城档让低价珍宝和高价珍宝分别有合适的交易地点。两种加成共享同一套交易规则，也给地图作者留出组合空间。城主在公道买卖与坐地起价之间权衡时，眼前的现金和下一次交易能力都重要。变卖价主要服务于陷入现金短缺时的选择。见[四档城制](../reference/rules/04-地产经济.md#四档城制adr-0034)、[珍宝交涉](../reference/rules/05-珍宝.md#珍宝交涉awaitingtreasureowner)和[破产清算](../reference/rules/09-破产清算.md)。

## 给进攻方即时回报

如果攻城只奖励最后一击，率先压低敌人防御的玩家容易把收益留给后来者。把收益分给打出有效伤害的诸侯，有助于让出手的选择成立。归属仍然值得争夺，因为它决定之后的持有收入。讨论取舍见 [ADR-0067](../adr/0067-city-conquest-economy.md)，具体结算见[城池攻陷与奖励](../reference/rules/04-地产经济.md#城池攻陷与奖励)。
