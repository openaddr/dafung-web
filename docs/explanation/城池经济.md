# 城池经济:购价恒定、四档城形与两条等级曲线

> 一句话:**城是产钱机器,也能增值,但变卖只发生在破产自救**——购买价与城池等级完全脱钩;等级驱动变卖价与坐地起价两条曲线,都城补给是固定值;升级免费,但只奖励公道买卖。

本文讲「关系」:购价、四档城形与收益曲线如何互相咬合。各曲线自身的数值口径见规则手册对应页(数值以代码为准,本文不复制数值)。

## 总览:一次购买,几份长期收益

- **购买价 = 固定入场费**:落到无主城支付购价 + 1 张委任状,入手必为 Lv.0(`economy.ts` `buy`)。价格不随任何等级变化——不存在「买几级的城」,等级是买下之后长出来的。
- **等级 = 持有期收益放大器**:Lv.0..maxLevel(上限由地图 `maxLevel` 逐图必配,内置图均为 3 即共 4 级;`economy.ts` `PropertyDef`),升级免费,同一等级同时抬升两条曲线。
- 等级是**持有期**属性:城回无主后再被购买,又是全新 Lv.0(`economy.ts` `buy` 落 `level: 0`)。

| 收益         | 公式                                      | 作用域                          | 口径详见                                         |
| ------------ | ----------------------------------------- | ------------------------------- | ------------------------------------------------ |
| 变卖价       | 地图 `valueByLevel[level]` 查表           | 全部持有城(都城除外:永不可变卖) | [04-地产经济](../reference/rules/04-地产经济.md) |
| 坐地起价要价 | 指导价 × `tradeMult[Lv]` + `tradeAdd[Lv]` | 全部有主城(他人落城交涉时)      | [05-珍宝](../reference/rules/05-珍宝.md)         |
| 都城补给     | 地图顶层 `resupply` 固定值                | 仅自己的都城(落地/驻跸每次结算) | [04-地产经济](../reference/rules/04-地产经济.md) |

## 四档城形:一座公式,四种退化(ADR-0034)

坐地起价公式只有一条(`指导价 × tradeMult + tradeAdd`),四档城形全是它的退化或全量,引擎零特判:

- **县城 / 郡城(纯加法)**:倍率恒 1——加值即全部溢价。低价值珍宝靠大额加值照样有收益;郡城是加法城的满配形态,县城是其廉价入门版。
- **奇城(纯乘法)**:加值恒 0,倍率逐级陡升且高于名城——低等级平平无奇,高等级配上高价值珍宝(荔枝/玉玺级)就是翻盘神器。
- **名城(乘加)**:倍率低于奇城、加值低于郡城,但两者都有、购价明显高——不论便宜贵价珍宝都有体面收益,全能但昂贵。
- 满级分域自然涌现:便宜宝(指导价 <600)加法系/名城称王,贵宝奇城一骑绝尘;牌堆中存量最大的青囊书(600)恰是奇城/名城的分水岭。

## 升级怎么来:免费扩军 + 公道买卖

两条升级路、一条降级路(等级变更留痕见 ADR-0015,降级时机 `PropertyDemolished`):

- **免费扩军**:自己到达己城,零花费零委任状 +1 级(`economy.ts` `upgrade`)。
- **公道买卖成交 +1 级**:城主对访客选择公道买卖(按指导价出售)且成交,城池 +1 级、满级封顶(`treasure-flow.ts` `resolveTreasureOwner`);买家破产退宝不回滚。
- **坐地起价不升级**:同一交涉里城主若选坐地起价(溢价出售),城池不涨——**公道换成长,还是溢价换现银,是城主的核心取舍**。
- **降级**:火烧连营、体力耗竭「降 1 级」处置——曲线随等级一齐下移(补给除外:补给是固定值)。

## 设计意图:曲线的分工与不对称

- **变卖曲线围绕购价、可增值**:Lv.0 变卖六折(割肉但比旧制从容),满级 1.5 倍购价——城池养得好是能升值的资产;但变卖只挂在破产自救且「凑足即止」(`assertStillOwing`),不构成囤城套利,都城永不可变卖。折算系数由守卫测试锁定(`test/map-economy-guard.test.ts`)。
- **坐地起价曲线按城档分工**:**等级的真正回报在「向访客卖宝」,不在「卖城」**。四档城形让买城决策变成选「我想要哪条收银曲线」:稳(县城)/厚(郡城)/博(奇城)/全(名城),逐城档位由守卫测试锁定。
- 与**身价 = 仅现金**口径一致:全部曲线都是现金流概念(补给流入 / 交涉流入 / 变卖回流),城的账面价值从不进身价。
- 购价恒定的另一面:**买城是纯一次性决策**,委任状额度才是扩张的真实闸门(`constants.ts` `BUY_WARRANT_COST`);等级成长把「买得早」变成「收得久」。
