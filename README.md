# 群雄逐鹿 · 三国大富翁

一款古风水墨的三国大富翁。掷骰行军、买城经营，用锦囊和名将攻守，争先称帝。

## 下载

在[最新发布](https://github.com/openaddr/dafung-web/releases/latest)下载安卓安装包（APK），安装后打开「群雄逐鹿」。
