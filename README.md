# 群雄逐鹿 · 三国大富翁

一款**古风水墨**画风的多人三国大富翁:掷骰行军、购地经营、拼点探宝,率先攒够身价者称帝。

## 拿到游戏

**安卓安装包(APK)是唯一正式交付形态**:装进手机即玩,启动即横屏。出包配方见[开发与测试](./docs/how-to/开发与测试.md)的「安卓出包」。

联机同用 APK:一人建房,把房间码发给朋友入座即可,见[联机对战](./docs/how-to/联机对战.md)。仓库同时产出网页构建(公共实例 [https://dafung.openaddr.cn](https://dafung.openaddr.cn)),但它不面向玩家——只作开发与 AI 浏览器自动化测试通道,验收一律按 APK 同款形态(移动端横屏 844×390)。

## 玩法速览

- 2–8 人一局:单机是你对阵电脑,联机则各带一台设备、真人同桌。
- 每回合掷骰行军:买城进驻、免费扩军经营;落宝物城拼点探宝,踏进别人的城便有一场珍宝交涉。
- 锦囊是全游戏唯一的暗牌:暗攥在手、他人不见,出牌的时机就是你的底牌。
- **身价 = 仅现金**(珍宝、城池都不计入),率先达到目标身价,或让对手尽数破产,即称帝获胜。
- 规则与数值全集见[规则手册](./docs/reference/rules/README.md)。

## 五分钟上手

不用先啃规则,跟着[新手第一局](./docs/tutorials/新手第一局.md)走完一局,你就会了。

## 为开发者

```bash
jj git clone https://github.com/openaddr/dafung-web && cd dafung-web
bun install && bun run dev   # 本地开发服务器 http://localhost:5173
```

本仓 VCS 为 jj colocated,`jj git clone` 是首选克隆方式;未装 jj 时 `git clone` 亦可(双通道,git = 逃生舱)。测试与 AI 自动化接口及版本协作口径见[开发与测试](./docs/how-to/开发与测试.md);架构与红线见 [AGENTS.md](./AGENTS.md);设计决策存档见 [docs/adr/](./docs/adr/)。
