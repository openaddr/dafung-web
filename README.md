# 群雄逐鹿 · 三国大富翁

一款**古风水墨**画风的多人三国大富翁。掷骰行军，买城经营，守城收银，攻下敌城争夺归属。积累现金，称帝获胜。

## 拿到游戏

**安卓安装包(APK)是唯一正式交付形态**:装进手机即玩,启动即横屏。出包配方见[开发与测试](./docs/how-to/开发与测试.md)的「安卓出包」。

联机同用 APK:一人建房,把房间码发给朋友入座即可,见[联机对战](./docs/how-to/联机对战.md)。仓库同时产出网页构建(公共实例 [https://dafung.openaddr.cn](https://dafung.openaddr.cn)),但它不面向玩家——只作开发和用户明确要求的单次排查通道,验收一律按 APK 同款形态(移动端横屏 844×390)。

## 玩法速览

- 2–8 人一局:单机是你对阵电脑,联机则各带一台设备、真人同桌。
- 每回合掷骰行军，落无主城可买城，落己城可免费扩军。有主的非都城在全桌轮末给当时的城主发放持城收益。
- 敌城每实际扣 1 点防御，进攻者领 5 两。火焰可使城池燃烧，持续扣防。攻陷时，累计伤害决定城池归属和分银。落珍宝城还能拼点探宝，落他人城可能触发珍宝交涉。[城池攻陷与奖励](./docs/reference/rules/04-地产经济.md#城池攻陷与奖励)
- 开局各得一张暗置锦囊，实际回合开始及行军经过或到达己城时摸牌。锦囊可伤城或袭扰诸侯，体力耗竭会引发城损与休整。
- 招贤可招将或求书，出牌阶段可在手牌区研读技能书。
- **身价只数现金**。实际回合收尾判胜，达标者中现金最高的诸侯称帝，最高现金并列则拼点。唯一存活的诸侯直接称帝。[胜利条件](./docs/reference/rules/01-总览与胜利.md#胜利条件)
- 规则与数值全集见[规则手册](./docs/reference/rules/README.md)。

## 为开发者

```bash
jj git clone https://github.com/openaddr/dafung-web && cd dafung-web
bun install && bun run dev   # 本地开发服务器 http://localhost:5173
```

本仓 VCS 为 jj colocated,`jj git clone` 是首选克隆方式;未装 jj 时 `git clone` 亦可(双通道,git = 逃生舱)。测试与 AI 自动化接口及版本协作口径见[开发与测试](./docs/how-to/开发与测试.md);架构与红线见 [AGENTS.md](./AGENTS.md);设计决策存档见 [docs/adr/](./docs/adr/)。
